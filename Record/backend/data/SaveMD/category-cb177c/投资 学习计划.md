# 一、先说最重要的一件事：以后不要把“投资学习”理解成看书

投资能力大致可以拆成：

| 能力         |  权重 |
| ---------- | --: |
| 看懂企业和商业模式  | 25% |
| 财务报表与会计    | 20% |
| 估值         | 20% |
| 行业与竞争分析    | 10% |
| 资本配置与管理层   | 10% |
| 组合管理、概率、风险 | 10% |
| 投资心理       |  5% |

所以你的学习时间最好采用：

**30% 阅读 + 50% 公司研究 + 10% 建模/编程 + 10% 投资复盘。**

比如一天学习 3 小时：

**1 小时读书 + 1.5 小时研究真实公司 + 30 分钟整理模型/笔记。**

这是我认为最重要的原则。

如果三年以后你读了 100 本投资书，却只认真研究过 10 家公司，你大概率仍然不会投资。

如果三年以后你只读了 30 本真正重要的书，却完整分析过 **100–150 家企业、读过 200 份以上 10-K/10-Q、做过 50 个估值模型**，你的水平会完全不一样。

# 二、你的最终训练体系

以后学习投资，不再只是问：

> “NVDA 值不值得买？”

而要能够自己回答下面 12 个问题：

1. 公司到底靠什么赚钱？
2. 客户为什么购买它？
3. 客户为什么不会换成竞争对手？
4. 行业结构如何？
5. 公司有没有护城河？
6. ROIC 为什么这么高/低？
7. 增长从哪里来？
8. 未来十年还能增长多少？
9. 管理层如何配置资本？
10. 财务报表有没有隐藏的问题？
11. 企业值多少钱？
12. **当前价格给我留下多少安全边际？**

最终所有股票都变成：

> **Business → Economics → Financials → Management → Valuation → Risk → Price**

而不是：

> 新闻 → 股价上涨 → 分析师目标价 → 买。

这会是三年训练的主线。

# 第 33 月：Variant Perception

问：

> 市场相信什么？

> 我跟市场哪里不同？

15%。

Bearish variant.

你认为：

25%。

Bullish variant。

**没有 variant perception 的投资，很容易只是跟市场讲同一个故事。**

You are assisting an equity investor.

ANALYST INFERENCE
ASSUMPTION

# 你的投资方法论代码化版本。

# 十九、最关键的毕业标准

我不会以：

> “赚了多少钱”

作为前三年的唯一考核。

因为牛市里乱买也可能赚钱。

真正的标准是：

**随便给你一家 S&P 500 公司，你能不能在 1–2 天内：**

读完核心 filings；

理解商业模式；

建立十年财务历史；

判断 ROIC；

分析竞争优势；

判断管理层；

发现主要会计风险；

建立 Base/Bull/Bear；

完成 DCF；

完成 Reverse DCF；

计算预期收益；

写出 5–10 页投资报告；

最后给出：

> **Buy / Watch / Pass**

而且能够清楚说明：

> **什么证据出现以后，我会承认自己错了。**

如果三年以后你可以稳定做到这一点，我会认为你的基础已经非常扎实。

我们可以把未来三年真正变成一个长期课程。我可以按这个体系继续带你学：
