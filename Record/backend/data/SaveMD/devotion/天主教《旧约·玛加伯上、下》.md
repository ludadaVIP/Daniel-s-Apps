# 《玛加伯上、下》：白话重述

> 这不是逐句翻译，也不是取代《圣经》的正式译本；它依照天主教《旧约·玛加伯上、下》的主要情节，用现代白话写成，帮助初读者先掌握人物、事件和信仰重点。

## 先认识这两本书：不是“上集”和“下集”

《玛加伯上》和《玛加伯下》讲的是大致同一时代：公元前二世纪，犹太人在塞琉古王朝的压迫下，为守住信仰、圣殿与生活方式而奋起反抗。

但它们不是一前一后接着讲的连续故事。

| 书卷         | 大致内容                                             | 写法和重点                                                   |
| ------------ | ---------------------------------------------------- | ------------------------------------------------------------ |
| 《玛加伯上》 | 从安提约古四世逼迫犹太人，到息孟建立较稳定的犹太自治 | 像一部较有条理的历史叙事，重点是家族、战争、政治与民族复兴   |
| 《玛加伯下》 | 主要重讲犹大·玛加伯从圣殿受辱到战胜强敌的一段时期    | 像一部带有强烈信仰反思的历史书，重点是殉道、复活、圣殿、祈祷与天主的审判 |

读《玛加伯上》可以看清“发生了什么”；读《玛加伯下》则更能看见“人在这些事中怎样信赖天主”。两书有重叠、也有叙述角度不同的地方，不需要勉强把每个细节拼成一张完全一致的时间表。

# 第一部分：《玛加伯上》白话重述

## 一、危机从哪里开始：有人要犹太人放弃自己是谁

亚历山大大帝死后，他的帝国被部将分割。犹太地后来落在塞琉古王朝统治下。起初日子不一定都很难过，但后来有些犹太领袖开始羡慕希腊人的生活方式，觉得遵守祖先的法律太落后，想把耶路撒冷变得和希腊城市一样。

他们建立体育场，模仿外邦风俗，并逐渐轻看割损、安息日、圣殿礼仪和祖先留下的生活方式。问题不只是“学外国语言”或“接触新文化”，而是有人要求把信仰和天主的诫命整个丢掉。

塞琉古王安提约古四世后来强力推动这种同化。他进入耶路撒冷，抢掠圣殿的财宝；又颁布法令，不准人守安息日、行割损、献符合犹太法律的祭献，也不准保存或阅读法律书。人被迫吃猪肉、向外邦神明献祭。拒绝的人会被杀。

公元前 167 年，圣殿祭坛被玷污，外邦祭献被安置在那里。对犹太人来说，这不只是政治压迫，而是要从根上抹去他们与天主所立的盟约。

## 二、玛塔提雅：一个老人说“不”

在莫丁城，住着一位年老的司祭，名叫玛塔提雅。他有五个儿子：若望、息孟、犹大、厄肋阿匝尔和约纳堂。

王的官员来到城里，要求玛塔提雅带头向外邦神献祭。他们以为他有名望，只要他先做，其他人就会跟着屈服，还答应给他钱财和地位。

玛塔提雅拒绝了。他说，就算所有国家都离弃祖先的宗教，他和他的家仍要遵守天主的盟约。正当有另一个犹太人走出来，愿意按命令献祭时，玛塔提雅悲愤之下杀了那人和王的官员，毁掉祭坛。

这成为公开反抗的开始。他和儿子逃到山中，呼吁所有愿意忠于法律的人跟随他们。

一开始有一群非常严格敬虔的人逃进旷野。他们在安息日遭军队袭击，却不愿在安息日抵抗，结果被杀。玛塔提雅和同伴从这场悲剧得到一个艰难结论：若完全不抵抗，敌人会把所有人杀光，法律也无人能守。因此他们决定，敌人在安息日发动袭击时，可以为保命而自卫。

玛塔提雅临终前叮嘱儿子们：不要被强权吓倒，要热爱法律；他的儿子息孟要作谋士，犹大最勇敢，可以带领作战。玛塔提雅死后，儿子犹大接起了领导责任。

## 三、犹大·玛加伯：小军队怎样赢过大军

犹大的绰号是“玛加伯”，常被理解为“铁锤”。后来整个家族和这场起义都因此被称为玛加伯。

犹大并不总有足够的人和武器。他面对的是训练更好、人数更多的军队。但他不断提醒同伴：胜负不取决于军队大小；天主要不要拯救，才是关键。于是他们一面作战，一面祈祷、禁食、遵守法律。

他先后击败了阿颇罗尼约、色龙等将领。塞琉古王派出更大的军队，由里息雅负责；里息雅又派尼加诺尔和哥尔基雅等人进攻。敌人甚至带着商人同行，预备把战败的犹太人卖作奴隶，可见他们以为胜利毫无悬念。

犹大没有只靠士气。他会选择地形、夜袭、分兵，也会在战前整顿队伍。厄玛乌斯一战尤其有名：敌将哥尔基雅夜里带精锐去突袭犹太人的营地，以为犹大仍在那里；犹大却已带人绕到敌军主营，趁空虚发起攻击。哥尔基雅回来时，只看见营地起火，军心大乱，整支军队溃败。

这些胜利让许多人重新看见：他们虽弱小，却不是毫无希望。

## 四、最重要的一场胜利：洁净圣殿

犹大击败强敌后，终于进入耶路撒冷。他看见圣殿荒凉、祭坛被亵渎、院落杂草丛生，心里非常痛苦。

他先派人继续守卫，自己则带领众人清理圣殿。他们拆掉被玷污的旧祭坛，按法律另造新的；又修复器具、重燃灯台、恢复祭献。

三年以前，圣殿曾被外邦祭献玷污；如今，在基色娄月二十五日，洁净后的祭坛重新献给天主。全体人民庆祝八天，献祭、唱歌、感谢天主使他们能重新敬拜。

这就是犹太教“献殿节”（Hanukkah，光明节）所纪念的历史背景。本书的重点并不是后来流传的每一个民间细节，而是：被剥夺敬拜自由的人，终于重新拥有圣殿与礼仪。

## 五、胜利之后，仍要面对四面八方的威胁

圣殿恢复并不等于战争结束。邻近的民族看见犹太人重新团结，便攻击散居各处的犹太社区。

犹大和弟兄们四处救援：到加里肋亚救被围困的人，到约但河东援助受威胁的同胞，也应对南方和沿海地区的敌人。他们有时获胜，有时也有痛苦的损失。

例如，约帟夫和阿匝黎雅没有得到犹大的命令，却想自己打出名声，贸然出战，结果惨败。这个插曲提醒人：热心和勇敢不等于冲动；不听指挥、只想证明自己，也会害人。

## 六、犹大的最后几年：同盟、战败与牺牲

安提约古四世死后，王朝内部不断争权。犹大有时需要和一个王谈判，有时又要抵抗另一个将领。里息雅一度同意让犹太人按自己的法律生活，犹太地暂时得到喘息。

可是新的冲突很快出现。大司祭职位被政治交易污染；有人借希腊王权打压自己的同胞。犹大曾率军进入耶路撒冷，在一场极其惨烈的战斗中取得胜利。

后来，尼加诺尔再次威胁耶路撒冷，甚至扬言要毁掉圣殿。犹大击败并杀死了他。为纪念这次胜利，后来有“尼加诺尔日”。

犹大也派人到罗马，希望建立同盟，借此制衡塞琉古王朝。但在同盟真正能带来帮助之前，新的王室军队已经压境。

最后一战，犹大手下只剩少量人。有人劝他撤退，他没有选择逃走；他宁愿冒险作战，也不愿让敌军自由践踏自己的人民。战斗中，他英勇阵亡。

他的兄弟把遗体带回莫丁，葬在父亲旁边。全以色列为他哀哭。犹大没有活着看见一切完成，但他使民族重新拥有了抵抗、敬拜和盼望的可能。

## 七、约纳堂：从游击队领袖到政治领袖

犹大死后，敌人重新加强压迫。玛加伯家的弟弟约纳堂接任领导者。他不像犹大那样以一次次大胜闻名，却非常懂得在复杂的王朝内斗中周旋。

他带着人到旷野与沼泽地区避难，也经历过弟弟若望被敌人杀害的悲痛。后来塞琉古王朝的几位竞争者争夺王位，都想争取约纳堂的支持。约纳堂借这个机会，为犹太人争得较大的自治空间。

他被任命为大司祭和地方领袖，重新修建耶路撒冷的城墙与防御工事，也与斯巴达、罗马等地建立关系。

可是政治联盟非常危险。他信任的一位外邦统治者特黎丰，后来设计把他骗去谈判，再把他扣押。约纳堂最终被杀。

他的一生说明，解放不只需要战场上的勇敢，也需要谈判、建设和耐心；但跟强权结盟，始终伴随背叛的风险。

## 八、息孟：终于有一段相对自由的日子

约纳堂死后，长兄息孟成为领袖。息孟年长、谨慎，也很有组织能力。

他先稳住内部，又利用塞琉古王朝的变动，争取免税和正式承认。犹太人终于可以摆脱外邦的驻军，夺回耶路撒冷卫城；这一天被当作大喜日来纪念。

人民开会决定，让息孟担任大司祭、军队统帅和民族领袖，而且由他的家族世袭，直到出现一位可靠的先知。这个决定标志着哈斯摩乃家族开始实际统治犹太地。

息孟整修城池和港口，让农民可以耕作，让市场恢复生意。书中描绘了一幅久违的平安图景：老人安坐街头，少年在街上玩耍，土地有出产。

可是最后，息孟和两个儿子在女婿仆托肋买设下的宴席中被杀。这个背叛再次显示：外患并没有自动消失，权力与家族之间的野心仍会制造伤害。

息孟的儿子若望·依尔卡诺逃过一劫，接过领导权。《玛加伯上》就在这里结束。

## 《玛加伯上》读完后，可以抓住什么？

### 1. 信仰不是抽象口号，它会进入日常选择

不吃什么、守不守安息日、孩子是否行割损、圣殿能不能献祭——这些看似细小的事，在当时都关系到一个民族还能不能忠于自己的天主。

### 2. 自由常常要付代价

玛塔提雅一家不是为了冒险而打仗。他们面临的是：若不抵抗，法律、礼仪和民族生活都会被强行消灭。书中不避开战争的惨烈，也让人看见自由不是廉价得到的。

### 3. 人要尽力，但不能把胜利当成自己的神

犹大会筹划战术、组织军队；同时他也反复强调，人的数量和武器不是最后的保证。这不是否定努力，而是反对把力量、军队或领袖绝对化。

# 第二部分：《玛加伯下》白话重述

## 一、这本书怎样开始：先请散居各地的人一起守节

《玛加伯下》开头收录了写给埃及犹太人的信，邀请他们也庆祝圣殿重新洁净的节日。接着作者说明：自己不是从头写一部很长的历史，而是把一位名叫基勒乃人雅松所写的五卷历史，浓缩成一本书。

所以这本书不像《玛加伯上》那样从头讲到尾；它聚焦在较短的一段时期，尤其是犹大·玛加伯的奋斗。

## 二、希腊化的诱惑：从圣殿内部开始的混乱

故事先回到大司祭敖尼雅三世的时代。敖尼雅敬畏天主，努力维护圣殿。有人想动用圣殿储存的钱财，圣殿的保护和敖尼雅的正直使这件事没有成功。

后来，敖尼雅的兄弟雅松用钱向国王买到大司祭职位。他不满足于管理圣殿，反而推动耶路撒冷全面希腊化：建体育场、训练青年，鼓励人以希腊公民身份为荣。

再后来，默乃劳用更多的钱抢走大司祭职位，并偷取圣殿器物来支付贿赂。敖尼雅公开谴责他，却被设计杀害。

这段很令人沉痛。真正的危机先不是来自城外军队，而是来自那些为了地位、金钱和认同感，愿意出卖圣殿与同胞的人。

## 三、安提约古四世的迫害与以理阿匝尔的选择

安提约古四世误以为耶路撒冷发生骚乱是在反叛自己，于是残酷镇压。他抢劫圣殿，杀害居民，后来又派人强迫犹太人放弃法律。

年老的经师以理阿匝尔被强迫吃猪肉。有人同情他，暗中建议他：你只要假装吃，把自己的合法食物带来吃就行了，表面上配合一下，便能活命。

以理阿匝尔拒绝了。他不是不知道这样做能保命；他担心年轻人会以为他在老年背弃了法律，也不愿以谎言留下一个坏榜样。他宁愿受刑而死，也不愿用假装忠诚来换取生存。

这个故事的重点不在鼓励人轻视生命，而是提出一个艰难问题：当权力逼你公开否认最深的信念时，什么代价是人不能用来交换的？

## 四、七位兄弟与他们的母亲：对复活的盼望

接着是一段《玛加伯下》最著名也最沉痛的故事。一位母亲和她七个儿子被抓，因为他们拒绝吃猪肉、违背祖先的法律。

国王当着母亲的面，一个接一个折磨儿子，企图以恐惧迫使其余的人屈服。兄弟们却互相鼓励。他们并不否认痛苦，也没有说死亡不可怕；但他们相信，创造人身体的天主有能力把生命还给忠于祂的人。

其中一个儿子对国王说：你能夺走我们的现世生命，但万王之王会使我们复活，进入永恒的生命。另一个说：宁愿死在人的手中，也仍然盼望从天主那里得到复活。

母亲失去七个孩子，却没有叫他们背弃信仰。她提醒他们：你们不是自己给自己生命；创造世界的天主看见你们，也能把生命重新赐给你们。最后她自己也被杀。

这段经文是天主教传统中谈复活盼望的重要旧约见证之一。它不把殉道写成轻松的英雄戏，而是把它写成极深的伤痛，同时坚持：残暴者不是最后的审判者。

## 五、犹大起身：悔改、祈祷和作战

压迫最深的时候，犹大·玛加伯与同伴进入山野。他们禁食、穿苦衣、在天主面前认罪，也请求天主记得自己的盟约、圣殿和受苦的人民。

随后，他们开始作战。书中一再写到一种次序：先祈祷，承认自己无力；然后实际集结、部署、迎战。犹大不是坐等奇迹，而是在相信天主的同时承担行动。

他击败了多个敌将，例如阿颇罗尼约和色龙。后来里息雅带着庞大军队进攻，犹大和同伴在痛苦中祈求，最后获胜。作者不断把胜利归于天主，而不是夸大犹大自己的军事天才。

## 六、圣殿洁净：失而复得的敬拜

犹大取得阶段性胜利后，进入耶路撒冷。他们看见圣殿荒废、祭坛受辱，便哭泣祈祷，随后清理、修复，并重新献上合乎法律的祭献。

他们庆祝八天，像庆祝帐棚节那样欢喜，因为从前被逼得无法在合宜的地方守节，如今终于能自由敬拜。这正是献殿节的核心记忆：天主的敬拜场所被夺走，又被洁净恢复。

## 七、两场战争中的祈祷：尼加诺尔与天主的审判

后来，尼加诺尔奉命攻击犹大。他一开始对犹太人很友好，因为他了解犹大的为人；但王怀疑他不忠，逼他改变态度，要求他逮捕犹大。

尼加诺尔威胁圣殿和司祭，态度越来越傲慢。他要拆毁圣殿，甚至嘲笑犹太人的希望。

犹大没有只用仇恨来动员众人。他提醒大家想起天主过去怎样拯救自己的子民，又带大家祈祷。他们最终打败尼加诺尔。尼加诺尔战死，他威胁圣殿的手臂被砍下，作为对他亵渎行为的警告。

故事在这里设立了纪念日。重点是，霸道的权力若把自己当成最高裁判，也终会面对审判。

## 八、为死者祈祷：一段很重要的经文

在一次战斗后，犹大的人发现阵亡者衣服里面藏着外邦偶像的护符。大家明白，这些人虽为民族作战，却也犯了违背法律的罪。

犹大没有简单说“他们已经死了，与我们无关”。他带领大家为死者祈祷，求天主赦免他们；又收集银钱送到耶路撒冷，为阵亡者献赎罪祭。

作者解释说，犹大这样做，是因为他相信死者还有复活的盼望。若人死后毫无盼望，为死者祈祷就没有意义；正因为相信天主能审判、怜悯并赐生命，所以仍可以把死者交托给天主。

这段是天主教传统中为亡者祈祷的重要经文基础之一。它提醒人：对已经离世的人，爱和祈祷并不会因死亡自动停止。

## 九、书末的最后一战：犹大没有依靠自己的把握

《玛加伯下》末尾，叙述塞琉古王德默特黎派来的将军巴基德和阿耳基默，准备消灭犹大一党。犹大的人看见敌军声势强大，很多人害怕。

犹大却坚定地说：我们不要看他们有多少人，要看天主能怎样帮助我们。他带领众人祈祷，回忆天主过去怎样差遣天使拯救耶路撒冷。

在这本书的结尾，作者着重呈现天主对受压迫者的保护，以及傲慢者遭到挫败。全书以赞美天主作结，而不是以犹大个人的荣光作结。

## 《玛加伯下》读完后，可以抓住什么？

### 1. 身体会受伤害，人的忠诚仍有价值

以理阿匝尔、七兄弟和母亲的故事非常残酷。它所坚持的是：暴力可以伤害身体，却不能替人决定良心最后该属于谁。

### 2. 复活使苦难不被说成“没有关系”

本书不是说受苦很容易，也不是说死亡不重要。恰恰因为生命宝贵，作者才宣告：天主不会让忠心者的生命最终被死亡吞没。

### 3. 圣殿不只是建筑物

它代表一个民族可以公开敬拜天主、守住盟约、记得自己从哪里来的地方。因此圣殿被玷污与被洁净，都具有很深的信仰意义。

### 4. 亡者仍可被交托给天主

犹大为阵亡者祈祷的行动，表达一种不会因死亡而断绝的爱：人不能替天主判定死者的结局，却可以求天主以怜悯接纳他们。

# 两书放在一起读：最容易混淆的地方

| 问题                               | 简单回答                                                     |
| ---------------------------------- | ------------------------------------------------------------ |
| 两书是不是同一故事的上下册？       | 不是。两书有重叠；《下》主要重讲《上》中犹大·玛加伯时期的一段历史。 |
| 为什么《下》有些事件显得更戏剧化？ | 《下》特别要表达天主怎样回应祈祷、保护圣殿、审判傲慢，因此更常写异象、祈祷、殉道与神迹性的拯救。 |
| “玛加伯”是谁？                     | 起初是犹大·玛加伯的绰号；后来也常用来指他的家族与起义。      |
| 为什么洁净圣殿如此重要？           | 因为危机不只是换了统治者，而是人是否还可以按自己的信仰敬拜天主。 |
| 这两书的核心精神是什么？           | 在巨大压力下，不把权势当作最后的主宰；守住良心、彼此扶持、祈祷并勇敢行动。 |

## 建议怎样回到思高版阅读

如果想先掌握事件顺序，可以先读《玛加伯上》：第 1—2 章看迫害和玛塔提雅起义；第 3—4 章看犹大的早期胜利与洁净圣殿；第 5—9 章看四方战事、犹大之死与约纳堂接任；第 10—16 章看约纳堂与息孟的治理。

再读《玛加伯下》时，不妨把它当作对同一时代的“信仰近景”：第 3—5 章看圣殿内部的腐败；第 6—7 章看以理阿匝尔和七兄弟母子的殉道；第 8—10 章看犹大作战与献殿；第 12 章特别留意为亡者祈祷；第 13—15 章看尼加诺尔的威胁、祈祷和胜利。
