可以。这个任务虽然很大，但非常值得做。

你现在分别读四福音，很容易产生一种感觉：**“这个故事我好像刚看过”“这个地方约翰怎么突然讲到这里”“马太和路加为什么顺序不一样？”**
真正把四卷书放在一起以后，会发现它们其实像是从四个角度拍摄同一个人的一生。

而且有一个很重要的前提：

> **四福音不是四本严格按照时间流水账写成的传记。**

尤其马太、路加常常会为了主题把某些材料集中放在一起；约翰则有大量独有材料。因此，我们可以做出一个**相当可靠的“事件时间轴”**，但不能假装每一个事件的先后都百分之百确定。学术上的“福音合参”本身也承认这一点。([聖經研究所][1])

下面我给你做一个比较完整的版本。

---

# 一、先告诉你怎么看这张“总地图”

我把耶稣一生分成 **10个阶段**：

1. 道成肉身与降生
2. 童年与隐藏时期
3. 公开事工前的预备
4. 早期犹太事工
5. 加利利早期事工
6. 加利利中期事工——声望达到高峰
7. 加利利后期事工——开始退到门徒训练
8. 最后的上耶路撒冷之路
9. 耶路撒冷最后一周
10. 受死、复活与升天

这和传统的福音合参结构基本一致。([马六甲福音堂][2])

记号：

* **太** = 马太福音
* **可** = 马可福音
* **路** = 路加福音
* **约** = 约翰福音
* **★** = 只有一卷福音书特别详细记载
* **△** = 时间顺序存在争议

## 22. 耶稣洁净圣殿

**约 2:14-22**

★

这里出现一个非常有意思的问题。

约翰把洁净圣殿放在**耶稣公开事工的很早期**。

而马太、马可、路加把洁净圣殿放在**最后一周**。

因此存在两种主要解释：

1. **耶稣洁净圣殿两次**
2. **四福音作者对事件进行了不同次序的编排**

不少福音合参采用“**两次洁净圣殿**”的理解；但这不是所有解释者都接受的结论，因此最好标记为 **△**。([聖經研究所][1])

# 但这里还有一个更重要的发现

你把四福音这样合起来以后，会发现**耶稣一生不是简单的一条“神迹越来越多”的故事线。**

其实有一个非常明显的结构：

### 前半段

**耶稣越来越受欢迎。**

人群越来越多：

> 神迹 → 医治 → 赶鬼 → 五饼二鱼 → 众人拥戴

甚至出现群众想：

> **“强逼他作王。”**（约 6:15）

---

### 中间那个巨大转折

**彼得认基督。**

> “你是基督。”

然后耶稣马上说：

> “人子必须受许多的苦，被长老、祭司长、文士弃绝，并且被杀，过三天复活。”

所以：

> **群众所期待的“基督”，和耶稣所启示的“基督”，开始发生冲突。**

---

### 后半段

耶稣开始越来越少把重点放在：

> “让更多人知道我的神迹。”

而越来越集中于：

> **训练十二使徒。**

于是你会发现一个非常明显的比例变化：

前面：

> 众人 → 神迹 → 传道

后面：

> 门徒 → 教导 → 十字架

最后：

> 十二个人 → 大使命 → 万国

这其实解释了为什么你读到后半段，会明显感觉：

> **耶稣好像越来越专注于门徒，而不是群众。**

# 四福音合起来以后，四个作者各自像什么？

这也非常值得你在以后读的时候注意。

| 福音书    | 特别突出的角度                        |
| ------ | ------------------------------ |
| **马太** | 耶稣是君王、弥赛亚；天国与旧约应验              |
| **马可** | 耶稣是行动中的神子；节奏快、神迹多、冲突强          |
| **路加** | 耶稣是救主；特别关注贫穷人、妇女、罪人、外邦人、祷告与圣灵  |
| **约翰** | 耶稣是谁；强调“我是”、神迹作为记号、荣耀、生命、与父的关系 |

所以你以后再读某个事件，可以问四个问题：

> **马太为什么这样讲？**
> **马可为什么这样讲？**
> **路加为什么这样讲？**
> **约翰为什么干脆不讲这个，反而讲另一个？**

这样读，四福音就不会再只是“四次重复的故事”，而会变成：

> **四个人共同见证同一位基督。**

而且你会越来越清楚地发现：**“重复”本身也是神学信息。**

例如五饼二鱼四卷都讲；彼得认基督三卷讲；十字架四卷都讲；复活四卷都讲。
但它们并不是简单复制，而是在共同见证同一个核心事实。四福音彼此大量重叠，同时又有大量独有材料，这正是“福音合参”之所以有价值的原因。

## 一个重要的校正

上面的时间轴可以作为你个人读经的**主线**，但不要把每一个编号当成“圣经明确证明的绝对日期”。

尤其有几处需要长期保持开放：

1. **圣殿洁净是一次还是两次**
2. **拿撒勒被拒绝的两段是否为同一次事件**
3. **部分比喻、讲论是否是同场合，还是耶稣在不同时间重复讲过**
4. **约翰福音若干事件与符类福音之间的精确对应位置**
5. **彼得认基督以后部分事件的具体天数**

这些不是“四福音互相矛盾”，而是因为福音书的写作并非现代意义上的逐日编年史。合参本身就是一种重建。([聖經研究所][1])
