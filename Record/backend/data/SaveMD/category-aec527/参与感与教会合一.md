> **人不是只会被结果激励，人还会被“这是我参与创造出来的”激励。**

而这件事情，恰好可以同时解释你在**门徒成长、教会服事、教会决策、教会合一**中观察到的很多现象。

我觉得可以从几个层次来看。

---

# 一、为什么“参与服事”可能推动一个基督徒成长？

你说的第一点，我觉得特别值得拆开。

很多人会把属灵成长理解成：

> 读经 → 明白真理 → 生命改变。

这当然没有错，但它容易忽略一个因素：

> **人真正进入一件事情以后，他和这件事情的关系会发生变化。**

一个刚信主的人，如果一直只是：

> 听讲道、参加聚会、坐在那里、接受别人服事。

他的身份比较像“消费者”。

但是当他开始：

> 招待新人、带小组、参与敬拜、帮助儿童、探访、传福音、准备查经……

他的心理状态会发生一个变化：

> “这不是别人的教会，这是**我的服事、我的弟兄姐妹、我的责任**。”

这时，人的投入程度往往不一样了。

## 这其实有几个心理机制

### 1. 责任感上升

当一件事情与你有关，你自然更会关注它。

例如一个人只是来教会听道：

> “今天讲得怎么样？”

但如果他负责儿童主日学，他就会开始思考：

> “这些孩子真的听懂了吗？”
>
> “这个课程有没有效果？”
>
> “那个孩子最近是不是不太对劲？”
>
> “下周我要怎么预备？”

他从**评价者**变成了**承担者**。

---

### 2. 会主动学习

这是非常重要的一点。

很多知识，只有在“我需要拿它来做事情”的时候，才真正进入人的大脑。

比如：

一个人平时读圣经，可能觉得：

> “马可福音这一段我看过了。”

但突然让他带一次查经，他会开始问：

> 为什么这里这样写？
>
> 这个词是什么意思？
>
> 上下文是什么？
>
> 这段和前面有什么关系？
>
> 我怎么向慕道友解释？

原来的“阅读”，变成了“研究”。

因此：

> **服事有时候不是属灵成长之后的结果，而本身可以成为属灵成长的训练场。**

这点与你本身比较喜欢“主动学习、深入研究”的习惯其实也很契合。

---

### 3. 人会更关心自己参与塑造的东西

这就是你引用的书里面非常核心的东西。

一个人投入过时间、精力、汗水，他通常更容易产生：

> “这是属于我的。”

甚至可能产生一种：

> “我必须把它做好。”

这当然可以是好的。

所以，一个人参与教会服事以后，他可能不只是对教会多做了一件事情，而是：

> **他对教会产生了更深的心理归属。**

而归属感又会进一步增加参与。

于是可能形成一个正循环：

**参与 → 投入 → 责任 → 归属 → 更愿意参与 → 更多成长**

---

# 三、所以教会里“服事”最微妙的问题其实是：参与感与自我中心只有一线之隔

这也是我认为你引用的那几段话，放到教会里以后特别有意思的地方。

因为在普通组织里：

> “我的方案”

通常只是利益、荣誉、权力的问题。

但在教会里，它会包装成更加神圣的语言：

> “我为主摆上这么多。”
>
> “我觉得神感动我这样做。”
>
> “我已经祷告过了。”
>
> “我做这个事工这么多年，我最了解。”
>
> “这是为了教会好。”

于是问题会变得特别复杂。

因为**人的自我中心可以借着属灵语言表达出来。**

这也是为什么教会比一般组织更难处理冲突。

并不是因为基督徒没有圣灵、没有圣经。

而是：

> **圣灵重生的人，仍然是人。**
>
> 旧有的性情、骄傲、偏见、经验、习惯、控制欲，并不会因为信主以后立即消失。

保罗自己都不断强调：

> “凡事不可结党，不可贪图虚浮的荣耀，只要存心谦卑，各人看别人比自己强。”
> ——腓立比书 2:3

这个命令之所以存在，本身就说明：

> **即使是基督徒，也非常容易把自己的判断、自己的贡献、自己的位置看得过高。**

---

# 四、这就进入你说的第二个问题：为什么“非我发明”会伤害教会决策？

你举的例子特别典型：

A 提出方案：

> “我们今年应该这样做。”

领导听完：

> “不错，但我们决定用另一套方案。”

理论上这只是：

> **Idea A vs Idea B**

但人的心理很容易自动变成：

> **A vs 我。**

然后 A 真正感受到的不是：

> “我的方案没有被采用。”

而是：

> “我的意见不被重视。”

再进一步：

> “既然你们也不听我，那我以后也不说了。”

最终可能变成：

> **退出参与。**

这就是你观察到的非常现实的现象。

---

# 五、所以一个成熟的教会领导机制，最重要的不是“每个人提出的方案都被采用”

这一点非常重要。

因为那根本不可能。

如果一个教会有20个人：

20个人有20个意见。

如果要求：

> “只要认真提出的意见，就必须被采用。”

那最后的结果只能是瘫痪。

所以真正的问题不是：

> **“你的方案有没有被采用？”**

而是：

> **“虽然你的方案没有被采用，但你是否仍然感觉自己是这个共同体的一部分？”**

这两件事情差别巨大。

---

# 六、我觉得这里可以建立一个非常重要的原则：

> **让人拥有参与感，而不是让人拥有决定权。**

这可能是你这段思考里最值得提炼出来的一句话。

比如：

一个人提出方案。

领导经过讨论之后没有采用。

但是领导可以告诉他：

> “你提出这个问题非常重要，我们确实因为你的建议发现了一个盲点。”

然后解释：

> “最后我们没有采用这个方案，是因为 A、B、C 三个原因。”

这样，这个人虽然没有得到：

> **“我赢了。”**

却仍然得到：

> **“我的参与产生了价值。”**

这非常重要。

因为：

> **人真正需要的往往不是“我赢”，而是“我不是被忽视的”。**

---

# 七、甚至可以把教会决策拆成三个不同层次

这会使整个问题清晰很多。

### 第一层：贡献思想

> 任何合适的人都可以提出意见。

这是开放的。

### 第二层：讨论和检验

> 大家一起问：圣经依据是什么？目标是什么？资源够不够？有没有更好的方案？

这是共同体的辨别。

### 第三层：承担决策

> 最终由具有相应治理责任的人作决定。

这是权柄。

这样就不会出现一种错误观念：

> “既然我参与了讨论，我就应该拥有和最终决策者完全相同的决定权。”

也不会出现另一种错误：

> “既然最后是领导决定，那普通人就不要提意见。”

成熟的治理恰恰是：

> **输入可以广泛，检验可以公开，责任必须明确。**

---

# 八、而且，这里还有一个比“非我发明”更深的问题：荣誉归属

假设：

A 提出一个非常好的想法。

领导说：

> “我们决定采用。”

但是领导完全不提 A。

A 很可能不舒服。

为什么？

因为人的心理不仅需要：

> **结果**

还需要：

> **贡献被看见。**

所以一个好的领导，完全没有必要假装：

> “这是我们领导团队想到的。”

反而可以说：

> “这个方案最初是 XX 提出来的，我们后来一起讨论、修改，最后形成了现在这个版本。”

这件事情成本很低。

却可能极大地增加参与感。

因为这样：

> **领导没有丢掉权柄，提出者也没有丢掉尊严。**

这是一个非常好的组织机制。

---

# 九、我甚至觉得这可以解释很多教会为什么会出现“老人越来越沉默”

一个教会刚开始的时候：

大家都很积极。

> “我们可以这样做！”
>
> “我们可以办这个！”
>
> “我来负责！”
>
> “我有一个想法！”

几年以后：

> “算了。”
>
> “反正领导有安排。”
>
> “你们决定就行。”
>
> “我不参与了。”

表面看是：

> “这个人越来越冷淡。”

但未必。

可能发生的是：

**提出建议 → 多次不被采纳 → 感觉贡献不被重视 → 降低心理投入 → 减少参与 → 进一步失去归属感**

所以领导看到的是：

> “这个人怎么越来越没有积极性？”

而这个人心里可能是：

> “反正这里也不需要我。”

这是一种非常典型的组织性恶性循环。

---

# 十、让所有人参与，不等于让所有人掌舵

这一点我觉得你特别需要注意。

因为你已经看到了：

> 教会里每个人想法真的差很多。

这是非常正常的。

甚至可以说：

> **教会合一绝不是“大家想法一样”。**

《哥林多前书》12章恰恰把教会比作身体：

> “身子原不是一个肢体，乃是许多肢体。”

所以：

> **合一 ≠ 同质化。**

眼睛、手、脚，本来就不一样。

问题是：

> 它们是不是属于同一个身体？

这其实非常重要。

---

# 十一、教会真正困难的地方，就是“价值观统一”与“判断差异”可以同时存在

比如大家都相信：

> 要传福音。

但是接下来马上会出现几十个问题：

> 去哪里传？
>
> 用什么方式？
>
> 做儿童还是成人？
>
> 用活动还是关系传福音？
>
> 投多少预算？
>
> 谁负责？
>
> 做一年还是做三年？

圣经未必直接给出唯一答案。

于是：

> **圣经真理可以高度一致，具体判断却高度多样。**

所以教会真正需要学习的不是：

> “怎样让所有人想法一样？”

而是：

> **“怎样让不同的人，在共同的真理和共同使命之下合作？”**

我觉得这是成熟教会和不成熟教会之间非常大的差异。

---

# 十二、这里《使徒行传15章》其实是一个特别漂亮的案例

耶路撒冷会议面对一个非常严重的问题：

> 外邦人信主到底需不需要受割礼？

这不是“今天聚餐吃什么”级别的问题，而是严重的神学与教会实践问题。

他们并不是：

> “彼得最大，所以彼得说了算。”

也不是：

> “大家各说各话。”

而是：

> **讨论、陈述见证、引用圣经、彼此辨析，然后形成共同结论。**

最后那个非常值得注意的表达：

> “圣灵和我们定意……”

这句话背后其实存在一种很成熟的思想：

> **既不是个人独裁，也不是民主投票崇拜。**

而是：

> **共同体在神的话语、使徒见证、现实经验和圣灵引导之下辨明。**

---

# 十三、所以我觉得你观察到的“教会合一很难”，本身并不令人意外

反而可以换一个角度：

> **如果教会里面的人完全没有意见分歧，反而很奇怪。**

因为人本来就不同。

不同成长背景：

> 中国南方 / 北方
> 城市 / 农村
> 工程师 / 教师 / 生意人
> 年轻人 / 老年人

不同属灵经历：

> 有人强调真理
> 有人强调关系
> 有人强调传福音
> 有人强调牧养
> 有人强调祷告
> 有人强调教导

甚至不同性格：

> 冒险型 / 保守型
> 快速决策 / 仔细分析
> 重效率 / 重关系

所以教会面对的真正挑战不是：

> “怎么消灭差异？”

而是：

> **怎么让差异变成互补，而不是变成分裂。**

---

# 十四、这里还有一个非常有意思的“怪诞行为学式陷阱”

就是：

> **我们通常会认为自己的意见来自理性。**

但是实际上很可能是：

> **先产生偏好，再用理性给偏好寻找理由。**

A 提出方案 A。

后来听到方案 B。

他可能开始寻找：

> “为什么 B 不行。”

领导支持 B。

A 于是会越来越容易看到：

> B 的缺点。

领导也会越来越容易看到：

> A 的缺点。

最后双方都认为：

> “我是在客观分析。”

实际上可能已经变成：

> **所有权进入了判断系统。**

这就是为什么教会的“属灵争论”有时候特别难。

因为双方都可能是真诚的。

双方甚至都可能：

> 真的祷告过
> 真的查过圣经
> 真的觉得是在为教会着想

但是：

> **真诚并不能自动消除认知偏差。**

这是我觉得《怪诞行为学》放到教会环境里以后特别值得警醒的地方。

---

# 十五、因此，教会需要一种非常刻意的“去个人化决策”

也就是说，不要讨论：

> “这是你的方案还是我的方案？”

而要不断把讨论重新拉回：

> **“哪个方案更符合我们的使命？”**

例如把：

> “我觉得应该办青年营。”

改成：

> “我们今年的目标是增加青年门徒训练，那有哪些方式？”

此时：

A 的方案只是其中一个候选方案。

B 的方案也是。

C 的方案也是。

然后大家一起比较：

| 问题       | 方案 A | 方案 B | 方案 C |
| -------- | ---- | ---- | ---- |
| 是否符合教会使命 |      |      |      |
| 圣经原则     |      |      |      |
| 可能帮助多少人  |      |      |      |
| 人力需求     |      |      |      |
| 财务成本     |      |      |      |
| 可持续性     |      |      |      |
| 风险       |      |      |      |

这个机制很有意思。

因为它把：

> **“我的方案”**

逐渐转化为：

> **“我们正在研究的方案。”**

人的心理就比较容易从：

> “我要证明我对。”

转向：

> “我们一起找哪个更好。”

---

# 十六、所以我特别想给你一个更深的概括

《怪诞行为学》说：

> **投入会制造喜爱。**

放到教会里，我觉得可以进一步推导出：

> **参与制造归属，归属制造责任，责任又会促进成长。**

但是与此同时：

> **参与也可能制造占有，占有又可能制造控制，控制最终伤害合一。**

所以同一个心理机制，可以产生完全相反的结果：

### 正向链条

**参与 → 投入 → 归属 → 责任 → 成长 → 建造教会**

### 负向链条

**参与 → 投入 → 占有 → “这是我的事工” → 防卫 → 权力冲突 → 分裂**

这就是你引用的“非理性的积极力量”最有意思的地方。

**积极和消极的力量，可能根本不是两个机制，而是同一个机制的两面。**

---

# 十七、我再给你一个我认为非常重要的洞见

### 成熟，不是“不爱自己的想法”。

而是：

> **我可以非常爱自己的想法，同时真诚地接受它可能不是最好的。**

这是非常高水平的认知能力。

一个成熟的人不是：

> “我的想法没被采用，我无所谓。”

而是：

> “我真的觉得这个方案很好，我愿意为它努力；但是如果你们经过充分讨论发现另一个方案更好，我愿意支持更好的方案。”

这其实是一种非常宝贵的能力：

> **投入，但不占有。**

我觉得这四个字甚至可以成为你今天思考的核心。

---

# 十八、而这四个字其实非常接近基督徒生命的一个重要特征

因为基督徒参与服事，本来就应该是：

> **忠心，而不是占有。**

保罗说：

> “我栽种了，亚波罗浇灌了，惟有神叫他生长。”
> ——哥林多前书 3:6

这句话非常深。

保罗当然投入了。

他甚至可以说：

> “我栽种了。”

可是他并没有因此说：

> “所以这是我的教会。”

后面马上就说：

> “可见栽种的算不得什么，浇灌的也算不得什么，只在那叫他生长的神。”

这其实把“参与”和“所有权”分开了。

我们可以非常深地参与：

> 但我们不是主人。

可以非常爱一个事工：

> 但不能把事工变成自己的领地。

可以认真提出意见：

> 但不能把“我的意见”变成“神的旨意”。

可以努力承担责任：

> 但最后必须承认：

> **教会是基督的，不是我的。**

---

# 十九、最后，我觉得你其实碰到了一个比“教会管理”更大的问题

这个问题其实不只存在于教会。

它存在于：

> 公司
> 家庭
> 教育
> 科研
> 投资
> 国家
> 甚至人的思想体系

就是：

> **一个人如何做到“深度投入，但不被自己的投入绑架”？**

你自己以后做那个“认知提升 / 投资能力”的 APP，其实也会遇到同样的问题。

你用大量时间建立一个框架之后，你会天然倾向于：

> 维护这个框架。

越是自己辛苦建立的理论，越容易舍不得推翻。

所以真正高级的学习者，必须同时培养两种能力：

> **建构能力 + 自我证伪能力。**

也就是：

> 我认真建立一个观点。

同时我主动寻找：

> “什么证据可以证明我错了？”

这其实就是把你刚才说的：

> **参与和开放检验同时存在**

推广到了整个认知世界。

我甚至会把它浓缩成一句话：

> **好的共同体，不是让每个人都拥有自己的答案，而是让每个人都愿意为共同的问题认真贡献答案，并允许自己的答案被检验。**

而一个成熟的教会，可能也不是“大家意见一致”的教会。

更可能是：

> **大家可以有不同判断，却仍然愿意彼此聆听；可以认真提出自己的方案，却不把方案当成自己的领地；可以积极投入，却不把投入变成占有；最终在基督和真理之下，愿意一起寻找“什么是最能建造身体”的道路。**

这可能正是你从《怪诞行为学》这一章，能够进一步挖出来的一个非常深的主题：**“所有权感”本身不是敌人，真正的问题是——我是在说“这是我参与的”，还是已经悄悄变成“这是我的”？**
