# Koine Greek course roadmap

This is a **reading-first New Testament Greek path**, not a modern-language CEFR claim. The familiar labels keep the four Free Language apps easy to navigate while the outcomes are adapted for Koine Greek.

| Stage | Planned lessons | Reading outcome |
| --- | ---: | --- |
| Foundation | 36 | Decode the script; recognize core noun, article, verb, and clause patterns; read short controlled lines. |
| A1 Core | 42 | Complete the main noun and present/imperfect verb systems; read graded NT-style sentences. |
| A2 Bridge | 36 | Follow connected narrative with participles and common prepositions. |
| A2 Core | 42 | Read one short Gospel paragraph with guided parsing. |
| B1 Bridge | 36 | Move between narrative, discourse, and epistle-style prose. |
| B1 Core | 42 | Read selected New Testament paragraphs independently, using a lexicon carefully. |
| B2 Bridge | 36 | Handle non-finite verbs, subordinate clauses, and discourse signals. |
| B2 Core | 42 | Do close reading and basic syntactic argumentation. |
| C1 Bridge | 36 | Compare textual and grammatical alternatives responsibly. |
| C1 Core | 40 | Work through sustained NT passages and write compact exegetical observations. |

## Audio policy

Every Greek line is playable. The built-in `el-GR-AthinaNeural` voice is deliberately presented as a **natural modern-Greek reference voice**: it helps the learner hear fluent Greek letter strings and avoids robotic audio. It is not reconstructed Koine audio. Foundation teaches a transparent seminary/academic pronunciation key beside the text; later, human-recorded Koine tracks can replace or supplement this voice without changing the lesson template.
