# IBKR 推荐奖励

对，IBKR（Interactive Brokers）目前确实有 **Refer a Friend（推荐朋友）**计划。我刚查了 IBKR 2026 年最新官方页面和 2026 年 7 月更新的条款。现在这个政策对“被邀请开户的人”其实也挺有价值。([Interactive Brokers][1])

### 目前的核心规则

| 角色    |                               奖励 |
| ----- | -------------------------------: |
| 推荐人   |            **每成功推荐 1 人，USD 200** |
| 被推荐人  | **最高 USD 1,000 的 IBKR 股票（IBKR）** |
| 推荐人上限 |                每年 15 人，终身累计 30 人 |

推荐人需要自己的 IBKR 个人或联名账户**净清算价值至少 USD 2,000**，并且已经做过至少一笔证券交易。([Interactive Brokers][1])

推荐成功后，你拿 **$200** 不是朋友一开户就立即拿到。被推荐人需要：

**通过你的专属 referral link 开户 → 30 天内存入至少 USD 10,000 → 至少保持 USD 10,000 达一年。**

满足条件后，你才符合获得 **USD 200** 推荐奖励的要求。([Interactive Brokers][1])

## 更值得注意的是：朋友也有奖励

目前 IBKR 官方页面写的是：

> **每存入 USD 300，可获得价值 USD 1 的 IBKR 股票，最高 USD 1,000。**

也就是说按照当前公开政策：

|     朋友入金 |   大约获得 IBKR 股票 |
| -------: | -------------: |
|  $10,000 |            $33 |
|  $30,000 |           $100 |
|  $50,000 |           $167 |
| $100,000 |           $333 |
| $200,000 |           $667 |
| $300,000 | **$1,000（封顶）** |

所以，如果一个朋友本来就准备往 IBKR 投 **10万—30万美元**，那最好**开户之前**就使用 referral link，否则可能白白损失几百到一千美元的 IBKR 股票奖励。([Interactive Brokers][1])

这里还有一个容易混淆的地方：IBKR 2026 年早些时候的条款曾出现过 **每 $100 奖励 $1** 的版本，但**2026 年 7 月 2 日的新条款以及当前官网已经改成每 $300 奖励 $1**。所以网上看到“入金 $100,000 就拿 $1,000”的说法，现在已经不能按那个计算了。([Interactive Brokers][2])

## 对你来说还有两个重要限制

第一，**中国大陆居民目前不能参加这个推荐计划**。这里看的是 residency / domicile，而不仅仅是拿什么护照。IBKR 当前明确排除日本、丹麦、西班牙、葡萄牙、波兰、中国大陆和以色列居民。([Interactive Brokers][1])

第二，IBKR 特别规定：**推荐完成后，推荐人不能参与朋友账户的管理、开户协助、交易指导等行为**。另外，**同一实际居住地址的家庭成员之间推荐，不支付推荐奖金/欢迎股票**。([Interactive Brokers][1])

所以它不是那种“拉个人注册就给钱”的活动，而更接近：

**朋友真正开户 + 真正投入较大资金 + 长期维持账户 → 双方获得奖励。**
