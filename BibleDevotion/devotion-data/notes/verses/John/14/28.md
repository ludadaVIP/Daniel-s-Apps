# 因为父是比我大的

约翰福音 14:28 是一节很值得仔细解释的经文，尤其最后一句：

> **“因为父是比我大的。”**

如果单独抽出来看，很容易产生一个疑问：**耶稣既然是神，为什么又说父比祂大？这是不是说明子低于父，甚至不像父一样是神？**

答案是：**不是。这里谈的重点不是父与子在“神性本质”上的高低，而是道成肉身的基督在救赎使命中的地位与状态。** 把它放回约翰福音整体，就很清楚了。

## 一、先看上下文：耶稣是在安慰即将失去祂的门徒

约翰福音 13—17 章是耶稣受难前最后的教导。门徒已经知道耶稣要离开，因此非常忧愁。

所以耶稣说：

> “你们听见我对你们说了，我去还要到你们这里来。”

这里的“去”，首先指祂将经过**受死、复活、升天，回到父那里**；“还要到你们这里来”，在这个语境中至少包含祂复活后与门徒相见，并且与前文圣灵降临、基督继续与门徒同在的应许密切相关（约 14:16–18）。

因此耶稣接下来讲了一句很重要的话：

> **“你们若爱我，因我到父那里去，就必喜乐。”**

门徒从自己的角度看：“耶稣要离开我们了。”

耶稣却要求他们从**基督的角度**来看：“如果你们真正爱我，就应该为我要回到父那里而喜乐。”

为什么？

因为十字架不是耶稣最终的状态。祂现在正处于**降卑的状态**：取了奴仆的形象，成为人的样式，要被羞辱、鞭打、钉十字架。

但祂即将完成救赎，复活、升天，回到父那里，重新进入祂荣耀彰显的状态。

这和约翰福音 17:5 完全呼应：

> “父啊，现在求你使我同你享荣耀，就是未有世界以先，我同你所有的荣耀。”

所以门徒不应该只是想：

**“我们的主离开我们了。”**

而应该想到：

**“我们的主完成了祂的工作，要回到父那里，进入荣耀了。”**

---

# 二、“父比我大”，不是说“父比我更是神”

这是理解这节经文最关键的地方。

约翰福音绝不可能在 14:28 突然否定基督的神性，因为整卷约翰福音恰恰非常明确地宣告基督的神性。

开篇就是：

> “太初有道，道与神同在，**道就是神**。”
> ——约翰福音 1:1

耶稣又说：

> “我与父原为一。”
> ——约翰福音 10:30

甚至就在约翰福音 14 章前面，腓力说“求主将父显给我们看”，耶稣回答：

> “人看见了我，就是看见了父。”
> ——约翰福音 14:9

所以，“父比我大”不能解释成：

> 父是真神，耶稣是次一级的神。

也不能解释成：

> 父的神性比较高，子的神性比较低。

三位一体的正统理解是：

**父、子、圣灵在神性、本质、荣耀、永恒性上完全同等；但三个位格彼此有区别，在救赎历史中的位格关系和使命次序也有区别。**

换句话说：

**“同等”不等于“没有区别”；“有次序”也不等于“本质低等”。**

---

# 三、关键在于“道成肉身”：基督主动进入了降卑状态

理解约翰福音 14:28，腓立比书 2:6–8 是非常好的钥匙：

> “他本有神的形像，不以自己与神同等为强夺的；反倒虚己，取了奴仆的形像，成为人的样式；既有人的样子，就自己卑微，存心顺服，以至于死，且死在十字架上。”

这里同时告诉我们两件事情：

**第一，基督本来与神同等。**

**第二，基督主动降卑，成为奴仆，顺服父。**

所以基督在地上的时候，我们会不断看见祂说：

> “我从天上降下来，不是要按自己的意思行，乃是要按那差我来者的意思行。”
> ——约翰福音 6:38

这不是说：

**“我不是神。”**

而是说：

**“我是父所差来的子，我已经取了人的样式，现在以中保、弥赛亚、神仆的身份完成父所托付我的救赎使命。”**

因此，“父比我大”最自然的理解，就是在这个**道成肉身、降卑、中保使命**的背景下理解。

## 四、一个非常重要的区别：本体上的平等，使命中的次序

可以这样整理：

| 问题   | 父与子        |
| ---- | ---------- |
| 神性   | 同等         |
| 永恒性  | 同等         |
| 神的本质 | 同一本质       |
| 荣耀   | 同享神圣荣耀     |
| 位格   | 有区别        |
| 救赎使命 | 父差遣子       |
| 道成肉身 | 子成为人       |
| 中保身份 | 子顺服父       |
| 十字架  | 子完成父所托付的工作 |

所以圣经可以一方面说：

> **“道就是神。”**

另一方面又说：

> **“父是比我大的。”**

这两句话并不矛盾，因为它们回答的不是完全相同的问题。

前者告诉我们：

**基督是谁？——祂在本质上是神。**

后者是在道成肉身和救赎使命的语境下告诉我们：

**基督现在处于怎样的状态？——祂作为降卑的中保、被父差遣的子，正在完成父托付给祂的工作，而父仍在天上的荣耀中。**

# 五、其实“你们若爱我……就必喜乐”才是这一节的情感中心

如果只盯着“父比我大”，很容易错过耶稣真正想对门徒说的话。

门徒的逻辑是：

> **耶稣离开 → 我们失去耶稣 → 所以忧愁。**

耶稣却在重新调整他们的视角：

> **耶稣离开 → 救赎工作完成 → 回到父那里 → 进入荣耀 → 所以你们若爱我，应当为我喜乐。**

这句话其实非常动人。

真正的爱不是：

> “只要你留在我身边，我才高兴。”

真正的爱会想到：

> **“什么对你是好的？什么使你得荣耀？”**

门徒舍不得耶稣离开，这很自然；可是他们仍然主要从“我们会失去什么”来理解这件事。

耶稣却把他们带到一个更高的角度：

**如果你们爱我，就不要只看你们将失去什么，也要看我要去哪里。**

祂不是走向失败。

不是被十字架吞灭。

不是从历史中消失。

而是：

**经过十字架，战胜死亡，完成救赎，回到父那里。**

所以十字架背后其实已经隐约出现了复活、升天和荣耀。

---

## 六、这也解释了为什么耶稣说“我去还要到你们这里来”

基督的离开并不是抛弃。

这是约翰福音 14 章反复强调的主题。

前面耶稣已经说：

> “我不撇下你们为孤儿，我必到你们这里来。”
> ——约翰福音 14:18

所以整个逻辑实际上是：

**基督离开 → 完成救赎 → 回到父那里 → 圣灵被赐下 → 基督继续与属祂的人同在。**

因此，耶稣的离开反而开启了一个新的阶段。

从门徒当时有限的眼光来看：

> “耶稣要走了。”

从整个救赎历史来看：

> **“基督的工作即将完成。”**

这就是为什么耶稣可以说：

**“你们应当喜乐。”**

---

## 七、这节经文对三位一体还有一个很重要的提醒

我们很容易犯两个相反的错误。

一个错误是为了强调三个位格的区别，就把父、子、圣灵理解成三个等级：

**父最高 → 子次之 → 圣灵再次之。**

这是错误的。

另一个错误则是为了强调三位一体，就把父、子、圣灵之间真实的关系和区别全部抹掉，好像只是同一个神换了三个名字。

这同样错误。

圣经给我们的图景更加丰富：

> **父是父，子是子，圣灵是圣灵；三个位格彼此区别，却同为一位神。**

父差遣子，子顺服父；父与子差遣圣灵；但这种位格与使命上的秩序，并不意味着神性有高低等级。

因此，约翰福音 14:28 不是三位一体教义的麻烦，反而帮助我们看见三位一体真正的精细之处：

> **同一本质，却有位格区别；完全同等，却有关系与使命的秩序。**

### 最后可以把整节经文浓缩成一句话

**“父比我大”不是说“父比子更有神性”，而是耶稣以道成肉身、降卑为人的中保身份说话；祂即将完成父所托付的救赎工作，从降卑进入荣耀，因此门徒若真正爱祂，就不应只因祂离开而忧愁，更应该因祂回到父那里、恢复祂荣耀的彰显而喜乐。**

而这节经文背后，其实正好有一条很漂亮的基督论脉络：

**永恒的荣耀 → 道成肉身 → 主动降卑 → 顺服父 → 十字架 → 复活 → 升天 → 回到父那里 → 得荣耀。**

把**约翰福音 14:28、腓立比书 2:6–11、约翰福音 17:1–5**放在一起读，这条线会非常清楚。
