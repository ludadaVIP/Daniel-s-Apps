# 电子账本：把酸碱、氧化还原与反应产量接起来

本单元接在第 91–93 课之后，也连接已有的金属置换、配平与限制反应物课程。先确认孩子能解释“整体电荷”和“H⁺ 转移”；前置课链接均在课程顶部。每课约 19–22 分钟，可把阅读与练习分成两次。

| 课次 | 关键区分                             | 操作后应能解释                                                              |
| ---- | ------------------------------------ | --------------------------------------------------------------------------- |
| 94   | 整体电荷、氧化数、实际原子电荷       | NH₃ 变为 NH₄⁺ 时整体电荷改变，但 N 仍为 −3；CO₃²⁻ 的整体 −2 不是 C 的氧化数 |
| 95   | 电子配平与最简比、形式守恒与真实发生 | Al/Cu²⁺ 需要 2∶3 来匹配 6e⁻；4∶6 仍守恒，但可以约简                         |
| 96   | 电子转移量与剩余物、混合固体与纯产物 | 用给定 Zn/Mg–Cu²⁺ 比例找限制量，再分别记录原金属、铜和全部水相离子          |

每课均有学习目标、四段解释、延迟展开的例题、三道即时检查、六道带概念标签的练习，以及无选项的口述/纸上解释。先让孩子预测，再打开模型或例题；不要直接引导其点击显示过的正确选项。

## 家庭学习与回忆

1. 第 94 课：把 NH₃/NH₄⁺、HCl/Cl⁻ 各写两栏：整体电荷、指定元素氧化数。若孩子看到正负号就说发生氧化还原，要求写出加权总账。O₂ 和 H₂O₂ 作为“氧不总是 −2”的反例，只讨论符号，不做实验。
2. 第 95 课：先试 Al/Cu²⁺ 各一份，再用 2∶3 配平，最后改为 4∶6。让孩子说明第三种不是“不守恒”，只是没有约到最简。问“还原剂自身为什么被氧化”，检查其是否理解名字指向对方的变化。
3. 第 96 课：先预测 2 mmol Zn 与 5 mmol Cu²⁺ 的新铜量，再交换输入。列出固相、水相两张表；问能否把回收到的全部固体算成纯铜。最后切换 Mg，解释本模型为何仍为 1∶1，但 Al 的比不能照抄。
4. 隔一天不看屏幕，用不同数字回忆。第 3、7、14、30 天可轮换氧化数反例、半反应配平、限制量与完整库存。可给出新的形式半反应 Mg → Mg²⁺ + 2e⁻ 与 Ag⁺ + e⁻ → Ag，要求自行推出最简比例；这是符号迁移题，不是实验指令。

记录原话、需要的提示和隔日能否自行解释。测验允许看反馈后修改，保存的是最后分数，不足以证明独立掌握；App 尚未自动安排上述复习。

## 模型边界

- 氧化数模型只处理给定的一种未知元素；给出的 H、O 值带具体适用条件。单质为 0、单原子离子与电荷数一致；H₂O₂ 中 O 为 −1。共价物种中形式整数氧化数不是原子的实测净电荷，也不表示存在对应游离离子。此入门模型不处理混合价、歧化或任意化学式解析。
- 半反应案例为 Zn/Cu²⁺、Al/Cu²⁺、Zn/Ag⁺，每个倍数乘整条半反应。既接受守恒的倍数式，也指出最简整数比。只审查给定物种的原子与电荷，不预测热力学方向、反应速度、电压或实际产率；铝的表面膜是形式配平不能替代实际条件的一个例子。
- 定量置换仅为指定 Zn/Mg 与 Cu(NO₃)₂ 的理想 1∶1 模型，假定充分反应，忽略表面膜、杂质、与水/酸的副反应、平衡及收集损失。Cu 摩尔质量近似取 63.5 g/mol。硝酸根在这一指定模型中为旁观离子，不概括所有含硝酸根条件。
- 电子是给出与接受之间的内部转移量，不作为水中独立积累的剩余物。原金属剩余与新生成铜分开记录；总固体质量不能直接当纯铜质量。净离子式只需左右总电荷相等，不要求两边各为零；加入旁观离子后的完整溶液库存才在本模型中保持整体电中性。
- 所有活动完全虚拟，不提供家庭金属盐混合、过氧化物操作或电路实验步骤。颜色、气泡与单个产量差值都不能独自证明某种原因。
