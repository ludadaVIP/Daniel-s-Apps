# 科学观察与实验基础：初学孩子的四次入门

这是 Plan.md 中 Level 0「科学思维与实验基础」的第一组课程，面向还没有化学知识的孩子。内部编号 97–100 只是保持已有保存记录稳定的维护编号，不表示要先学完前 96 课。

入口为 Chemistry 首页的入门卡片或「初学入口：科学观察与实验基础」，也可从学习路径的 00 模块进入。四课完成后，“下一课”推荐原有的「什么是物质？」。原有课程 ID 和顺序编号不改。

每次约 12–17 分钟，可分两段。先让孩子自己判断，再看反馈或展开例题。每课有三个目标、四段解释、例题、三道即时检查、六道练习、不同解释方式及无选项的口述任务。平均值计算不熟练时，可先比较原始记录和最大最小，再由家人协助计算；不要让算术挡住证据判断。

## 家庭使用方法

- 第一课：让孩子给两句话分别标“记录”和“解释”，再问解释是否有依据。不要把所有推断都说成错误，也不要把仪器观察说成永不出错。
- 第二课：只研究温度时选 A/B；只研究搅拌时选 A/D。用 A/C 或 A/E 故意检查混杂条件。再问“多重复几次能不能修复同时改多个条件的设计”。所有数据已提供，不用实际配制、加热或测试材料。
- 第三课：参考样品题给 10.0 g。B 读数集中但平均 10.5 g；C 平均接近参考但波动更大；D 只显示整数克。请孩子遮住名称读图，说明为什么不能仅凭平均或相同显示判断可靠性。
- 第四课：先比较糖分散，再切换水转为气态和产气记录。开放范围读数下降时，把气体计回范围外；封闭范围还要把内部气体算进去。最后分清“容器及内容物”与“只算内容物”。封闭产气只在虚拟模型中讨论。

隔一天先不看屏幕回忆一个问题。第 3、7、14、30 天可换一张证据卡、换一个比较目标、比较另一组读数或改变称量边界；这些是家庭手动安排，App 尚未自动调度。记录孩子是否能在无提示下指出“还需要什么证据”，不要只看允许修改后的选择题分数。

## 数字与模型边界

1. 证据卡是作者给定的情境，不是摄像头或真实仪器采集。分类与证据充分性分开：合理的融化解释也属于推断；气泡、透明度或温升不能单独唯一鉴定身份与原因。
2. 溶解对照表用固定的 A–E 条件与三次时间记录，假定温度维持、未列出的条件一致。它只练习控制变量与结果记录，不提供任何真实材料的溶解速率公式，也不把重复当成控制变量的替代。
3. 五次称量记录均为虚构，参考质量由题目给定。图统一使用 9–11 g 标尺；1 g 与 0.1 g 分辨率的显示不能只凭观察范围直接比较真实精密度。入门均值报告保留到单次显示的小数位，不是通用的不确定度估计规则；这里不估计均值不确定度，也不把最大最小范围当成完整不确定度。真实校准还需检查参考值本身。
4. 质量模型的每种情境初始均为 20 g 容器加 90 g 全部材料，合计 110 g。糖分散不跨界；水转气态的五个记录对应 0/5/10/15/20 g；产气情境对应 0/0.5/1/1.5/2 g。记录位置不是时间，气体量由教学记录给定，不由反应方程式、速率或温度计算。
5. 封闭情境气体留在称量范围；开放情境将其记在外部，内外合计不变。模型不包含外部物质进入，也不模拟压力、气体体积、浮力、泄漏、洒出或仪器误差。其他开放过程可因气体进入而增重；真实读数差也可能有多种原因，不能单凭它确定产气。图示不按体积比例。
