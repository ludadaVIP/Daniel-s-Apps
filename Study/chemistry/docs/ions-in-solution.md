# 溶液中的离子：四次循序渐进的学习

适用：已经认识离子、离子晶格、溶解和简单方程式的学习者。不要让刚开始学化学的孩子从第 87 课直接开始。每课顶部可打开前置课程；允许自由回看，不用课程编号代替知识准备。

| 课次 | 学习问题                       | 开始前确认                  | 学完应能解释                                        |
| ---- | ------------------------------ | --------------------------- | --------------------------------------------------- |
| 87   | 盐和糖都溶解，为什么导电不同？ | 离子晶格、溶质与溶剂        | 导电同时需要电荷与可移动性；电中性不等于没有离子    |
| 88   | 两杯清液混合，沉淀从哪里来？   | 第 87 课、化学变化与守恒    | 用溶解性证据判断；分别记录固相与剩余水相            |
| 89   | 净离子方程式可以省略什么？     | 第 88 课、读方程式、配平    | 只消去两侧相同物种、状态与数量；旁观离子没有消失    |
| 90   | 沉淀最多多少，滤液还含什么？   | 第 89 课、mol/L、限制反应物 | 先转换 mmol，再按系数求限制量，用元素与电荷检查结果 |

每次只学一课，约 16–22 分钟，可把最后一课分两次。先预测，再操作；先自己尝试，再展开例题推理。即时检查用于发现误解，六题测验用于练习与迁移；答题后的修改分数不能证明独立掌握。

第二天先不打开答案，请孩子口述上一课核心解释，再开始下一课。建议在第 3、7、14、30 天各抽一道题换数字重做。这是家庭手动复习建议，App 尚未自动安排这些复习。

## 家庭试用观察

1. 第 87 课：让孩子画干盐、盐水、糖水，解释“有电荷”和“能移动”。若说“水让盐第一次带电”，回到晶格模型。
2. 第 88 课：切换到无沉淀对照。如果孩子坚持“换搭档就沉淀”，请其引用已给出的溶解性证据。白色不能唯一鉴定物质。
3. 第 89 课：先故意消去 Ag⁺，观察反馈，再只消去正确的旁观离子。要求说明 Ag⁺(aq) 与 AgCl(s) 为什么不是同种物种。
4. 第 90 课：固定左侧 2 mmol，右侧依次取 1–6 mmol，先记录预测，再看结果。画产量平台，并把滤液所有主要离子列全。迁移题改成左侧 4 mmol，最后更换为 CaCO₃ 案例。

记录孩子原话、困难点和提示次数；下一次先不提供提示，再试同概念的新例子。可把“能否自主解释、能否换条件预测、隔几天能否再做”作为观察指标，不能仅看最后分数。

## 科学依据与模型边界

2026-11-24 核对了以下教材内容。课程文本、案例数字和模型均为本项目编写，外部阅读可选，不影响离线课程学习。

- [OpenStax Chemistry 2e §11.2 Electrolytes](https://openstax.org/books/chemistry-2e/pages/11-2-electrolytes)：离子固体与溶液、带电粒子迁移、非电解质；导电性也受离子种类、浓度、温度等影响，不能只凭导电唯一鉴定物质。
- [OpenStax Chemistry 2e §4.2 Classifying Chemical Reactions](https://openstax.org/books/chemistry-2e/pages/4-2-classifying-chemical-reactions)：沉淀、溶解性规律、旁观离子、净离子方程式。
- [OpenStax Chemistry 2e §15.1 Precipitation and Dissolution](https://openstax.org/books/chemistry-2e/pages/15-1-precipitation-and-dissolution)：难溶物的微量溶解与溶解平衡，说明“完全沉淀”只是近似。

导电活动不构建真实电路、不显示未经计算的电流或亮度。省略水自电离、杂质、电极反应与真实迁移率；对蔗糖溶液的“不明显导电”不是绝对零电导。HCl 形成离子的反例防止把“共价”误等同于“非电解质”。

沉淀活动使用 AgNO₃/NaCl、CaCl₂/Na₂CO₃ 两个案例，NaCl/KNO₃ 为无沉淀对照。输入为每份 100 mL、1–6 mmol，混合体积按 200 mL 处理。使用近似完全沉淀，忽略微量溶解、酸碱平衡、络合、体积非加和、过滤与收集损失。AgCl、CaCO₃ 摩尔质量分别近似取 143.5、100 g/mol。卡片表示物种与 mmol 数，不是粒子真实大小或数量。固体用晶格组成表示，不画作独立小分子。

所有活动完全虚拟，不提供家庭接电、试剂混合、过滤或化学废物处理操作。真实样品的白色外观、清澈滤液或导电性，均不能单独证明身份、纯度或饮用安全。
