# Chemistry Path / 化学学习路径

The product specification is [Plan.md](Plan.md). This folder contains the first independent Study app.

Current status: **Phase 1 in progress**. The bilingual home and learning path now lead into twenty-nine complete lessons, covering Matter & Particles, Elements/Compounds/Mixtures, atomic structure through ions, periodic-table exploration through Groups 1, 17 and 18, and the opening lessons in Ions & Chemical Bonding: why atoms connect, ionic lattices, covalent electron sharing, and metallic bonding. Each lesson includes a real-life hook, an interactive model, misconception repair, a small at-home observation, a bilingual vocabulary panel, and instant-feedback mastery questions saved locally.

From the Study workspace root, double-click `start.bat` on Windows or `start.command` on macOS. You can also run `pnpm install` and `pnpm dev`. The Study hub opens at `http://localhost:3456`, with Chemistry at `http://localhost:3456/chemistry`. See the root [README](../README.md) for checks and workspace layout.
