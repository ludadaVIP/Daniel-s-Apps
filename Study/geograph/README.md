# Geography Explorer · 地理探索

依据 [Plan.md](Plan.md) 已实现 **GEO-001–040**，全部六阶段、96 课保留规划目录，其余56课继续开发。沿用 Study 的共享侧栏、课程查找、折叠偏好、语言切换与移动抽屉。

## 打开应用

使用 Study 原有启动方式，访问 `http://localhost:3456/geography`，也可以从 Study 首页点击「地理」。

独立开发：

```sh
corepack pnpm --filter @study/geography-web dev
```

独立入口为 `http://localhost:3461/geography`。两种入口各自使用所属浏览器源的本机存储。

「温故知新」提供课程的迁移问题，完成七天后推荐回访，也可提前练习。「发现手帐」支持修改笔记、导出 Markdown 和每四课一组的独立家庭反馈。记录仍用 `study-geography-v1`，兼容首四课的旧笔记与反馈；新增课程不会清空旧记录。保存失败时显示提示，仍可继续并导出手帐。没有账户、定位采集、上传或云端同步。

## 建议家庭验收

1. 从 Study 首页进入地理，切换中文／英文／双语，查找课程并折叠侧栏。
2. 在 GEO-001 放大真实照片，选一个猜想，完成线索任务；选错一次，检查提示能否帮助重新观察。
3. 留下一句话或勾选已口头解释，刷新页面，确认内容、任务和环节保留；完成回顾并记录探索。
4. 在 GEO-002 用点击或拖放放置标签，再切换地图中心，解释两侧的太平洋为什么是同一片海洋。
5. 在 GEO-003 读各视图的图例，说明影像、道路图和地形图分别能回答什么问题。道路与地形是教学示意图，不能逐像素叠加，也不能用于导航。
6. 在 GEO-004 转动地图并尝试直接跨河，再选择过桥路线；解释地理方位为何没有因屏幕旋转而改变。
7. 在 GEO-005 用1×、2×视图核对同样的实地距离；在 GEO-006 用键盘或触控滑块标记给定经纬度。
8. 在 GEO-007 比较一月与七月的城市时间和日期；在 GEO-008 比较六月、十二月与零倾角光照。
9. 打开发现手帐，在十个四课组分别留下家庭反馈并导出；检查其余56课为「规划中」，不计作已学习。
10. 手机可从菜单打开导航；世界地图和经纬网保留内部横向查看，滑块可用方向键逐帧控制。

11. 在 GEO-009核对照片与高度设色；GEO-010切换两个视图和两种等高距，确认同一山体不变。
12. 在 GEO-011试点内流湖后沿相连低点走到河口；GEO-012读五个样点的时段与单位，比较相近纬度的海拔例外。

13. GEO-013比较三种土地利用；GEO-014定位七处区域；GEO-015每张影像需两条线索与揭示来源后核查。
14. GEO-016制作地图与三条自己的发现，刷新核对长段证据，再导出HTML／SVG／Markdown；第一阶段作品没有精确家庭地址。
15. GEO-017拼装四层并解释地幔；GEO-018用键盘改间距、看三类运动；GEO-019比较断层帧及历史数据限制；GEO-020完成三个熔融环境案例。

16. GEO-021比较三种移除量；GEO-022点击或拖放过程卡、尝试无效转换与直接变质；GEO-023核对颗粒与影像三种显示；GEO-024移动卡片后重新核对，解释平原辫状反例。

17. GEO-025两侧弯道的外岸不能按页面左右判断；GEO-026后退时冰块仍向谷地下方移动；GEO-027反转来浪并核算进入／离开量；GEO-028先检查错误层序再修复，观察水0／25／50与空气50／25／0。

18. GEO-029试一条不相连的过程，再走三条有效路径；GEO-030分别读取A/B两个月的数据，不把温度图当速度图。
19. GEO-031叠加三层并比较三段运动，核对历史样本的年份／范围／阈值；空白区不代表未来安全。
20. GEO-032自选案例，填写自己的过程与两条证据／推论／局限，勾选核对并完成中英讲解；换案例后必须重新核对。刷新验证保存，再导出HTML／Markdown／位置SVG／过程SVG。S1地图作品与S2报告独立保存。

21. GEO-033比较两个UTC历史日与南岛／欧洲30年月平均，分类时间尺度并说明平均不等于每天。
22. GEO-034匹配五层、切换两个红外例并分别核对地面与整体收支；五层图不按比例。
23. GEO-035比较0／4／12 hPa，交换高低压及半球，辨别力方向、相对运动左右和风的来向命名。
24. GEO-036两种气块在0／1／2 km比较云底；有云时切换小滴／假设增长，完成解释、回顾与反思。

25. GEO-037反转西／东来风、比较湿干与山高；长期两站对照不是整个岛或当天雨量。
26. GEO-038比较0°／75°和43°S季节，检查低角度等宽光束的地面展开；纬度热量带不等于完整气候分类。
27. GEO-039用方向键比较−2／0／+2符号级，读取印度西岸与东南近海格子；东北季风可为部分地区带来雨。
28. GEO-040比较两张NASA照片和四地雨量／温度，解释冬雪、夏热、古老冰与水分输入的区别。

## 内容维护

- `content/curriculum.json`：由规划导入的 96 课元信息、顺序、前置关系和发布状态。
- `content/lessons/s1/*.md`、`content/lessons/s2/*.md`、`content/lessons/s3/*.md`：可编辑的双语知识内容。每块使用 `section`、`zh`、`en` 注释标记；不执行 Markdown 中的 HTML 或脚本。
- `content/activities/lessons.json`：目标、猜想、术语、题目、解释、反馈和来源。
- `metadata/asset-manifest.json`：图片、底图和自绘图的作者、许可、来源、年份、修改与核查日期。照片原样保存在 `Study/public/geography/`。
- `apps/web/src/visuals.tsx`：复用的教学 SVG；`content/map-data.json` 保存 Natural Earth v5.1.2 派生几何。
- `apps/web/src/SkillVisuals.tsx`、`SkillActivities.tsx`、`skillModels.ts`：比例尺、经纬度、明确日期时区与季节对照；所有模型注明简化条件。
- `apps/web/src/TerrainVisuals.tsx`、`TerrainActivities.tsx`、`terrainModels.ts`：地形、同一山体等高线／剖面、河网追踪与气候图读取。
- `apps/web/src/PlaceVisuals.tsx`、`PlaceActivities.tsx`、`placeModels.ts`：土地利用、新西兰概略地图与照片侦探。`AtlasEditor.tsx`、`atlasModel.ts` 提供S1个人地图与HTML／SVG／Markdown作品；证据课限定为S1以保证保存一致。
- `apps/web/src/GeologyVisuals.tsx`、`GeologyActivities.tsx`、`geologyModels.ts`：地球分层、相对板块运动、断层与火山成因。逐帧控制没有时间、应力或喷发预测尺度。
- `apps/web/src/LandscapeVisuals.tsx`、`LandscapeActivities.tsx`、`landscapeModels.ts`：造山挤压／高度收支、非强制循环的岩石网络、颗粒迁移、真实前后影像及条件河道。所有数值、视角、简化条件和资料限制随图说明。
- `apps/web/src/EarthSurfaceVisuals.tsx`、`EarthSurfaceActivities.tsx`、`earthSurfaceModels.ts`：曲流与洪泛平原、冰川剖面／冰舌、沿岸颗粒与泥沙收支、土壤剖面与共享孔隙。所有数量均明确为教学单位，不推算真实流速、洪水范围、冰川年份、海岸变化率或土壤产量。
- `apps/web/src/WaterEarthVisuals.tsx`、`WaterEarthActivities.tsx`、`waterEarthModels.ts`：多路径水循环、固定10份雨水对照、概略洋流与真实月海温、概念热量输送、新西兰多层证据。所有教学数量／路径与真实数据分开标明。
- `apps/web/src/LandformReportEditor.tsx`、`landformReport.ts`：S2自选地貌报告，位置点仅0.1°，三步图不是实测时间轴；来源课限定S2或手填公开http/https链接。HTML完整作品内嵌地图和过程图，并保留本人的证据、推论、局限与中英讲解，不自动评价科学质量。
- `content/ocean-temperature-data.json`、`scripts/prepare-ocean.py`：NOAA OI SST V2原始1°、1991–2020月长期平均及配套陆海掩膜，输出一月／七月北大西洋SVG和同纬A/B四读数；原始链接与两份SHA256可重建，离线运行时不调用NOAA。
- `content/nz-earthquake-data.json`、`scripts/prepare-nz-quakes.py`：GeoNet2020 UTC、164–180°E/33–48°S、震级≥4、earthquake类型190条。原查询191条排除一个其他类型；保留完整ID、时间、位置、震级类型、深度和状态、SHA256与CC BY3.0 NZ署名。不称为完整目录或风险图。
- `content/soil-photo-source.json`：NPS图库所选土壤照片的公开许可、创建日期字段、下载地址与SHA256；图库字段不冒充独立核实的拍摄时刻。
- `content/earthquake-data.json`：USGS首选事件、2020 UTC、震级≥6、121条记录、原始查询与SHA256。`scripts/prepare-earthquakes.py` 从本地原始GeoJSON重建；课程离线显示，含可选的完整文字表。
- `content/nz-overview-data.json`、`scripts/prepare-nz-overview.py`：Natural Earth v5.1.2新西兰主岛派生海岸，概略山河另绘。
- `content/climate-data.json`：NOAA原始资料地址、SHA256、1991–2020统计时段、转换方法和五个网格读数。
- `scripts/prepare-climate.py`：从原始NetCDF重建温度SVG与样点，需要numpy和netCDF4。原始数据不进入运行时，离线显示无需外部请求。
- `apps/web/src/WeatherVisuals.tsx`、`WeatherActivities.tsx`、`weatherModels.ts`：天气／气候时间尺度，大气五层与单层辐射思想模型，同距离气压场／半球运动偏转，湿干气块近似云底。任意能量数量、预设气压与强制抬升不作为实测或预报。
- `content/weather-data.json`、`scripts/prepare-weather.py`：两份2020日均和两份1991–2020月常年值NetCDF，SHA256与原始94×192高斯网格可重建。降水率kg/m²/s×86400得到mm/day液态水当量，不是月总量。历史日为2020-01-11/15 UTC；红点42.8564°S/172.5°E不是城市气象站。
- `apps/web/src/ClimateVisuals.tsx`、`ClimateActivities.tsx`、`climateModels.ts`：两站长期雨量与条件地形雨、纬度热量带／季节等宽光束、概略季风环流和干燥环境证据。图形与文字共用模型几何；所有符号级、假设雨落与太阳光量都注明限制。
- `content/climate-process-data.json`、`scripts/prepare-climate-processes.py`：GPCP V2.3原始2.5°网格1991–2020降水常年值与既有NCEP 2 m温度，保留不同网格中心、月份权重、原文件SHA256与来源。月每日率乘平均月天数得到mm/month，年量为未舍入月量之和；本地图离线使用，不是完整干旱分类或天气站资料。
- `metadata/fact-checks.md`：新课程的事实核查、几何验证、时区示例年份和使用限制。
- `scripts/prepare-assets.py`：从指定的 Natural Earth GeoJSON 重建本地底图，下载地址见素材清单。

新增课程时必须同时准备完整双语 Markdown、任务与完成判据、逐课 `assetIds` 和核查过的素材，再将目录状态设为 `available`。课程加载会检查发布状态与全部引用素材的许可确认。当前是持续扩展的家庭试学版；家庭长期效果和家长实测仍待验收，未宣称96课已开发或获得机构认证。
