# 跨单元技能复现审查 / Cross-unit skill recurrence

2026-10-25更新。依据plan.md §3“每个技能在后续至少跨单元复现两次”，检查具体任务是否要求重新使用早先概念。此记录核验内容供给，不声称学习者已经做过、记住或迁移成功。用户已确认尚未试用。

## 全路线盘点与证据规则

当前358课、67单元的实际引导、练习、出口及课程技能元数据共出现361个不同技能标签。它们是现有内容的检索索引，不是已经穷尽所有细分技能的教育分类。一个宽标签下可能还需逐个检查多个子目标。

[机器可复查清单](SKILL_RECURRENCE.json)逐标签列出首次课程、源单元的具体任务ID、后续同标签候选和已审查的语义证据。现361项课程级技能均有至少两个不同后续单元的具体任务和双语语义证据；H37/H38十项由实际R01/R02维护承接。第一轮现有标签待核数为0；这不是全部细分目标或真实学习成效验收。具体补题、复用任务和验证按下列批次记录，最新见[终章维护](POST_ROUTE_RECURRENCE.md)及[细分目标](SUBSKILL_REVIEW.md)。候选为空可能是后续题用了不同标签，不能直接宣布缺失；候选很多也不自动表示充分覆盖。审查应读题干、图示、答案和理由，不能只连先修关系。

证明一项内容复现至少要同时满足：

1. 有可定位的原技能、源课和源任务；按课程目录顺序确定“后续”。
2. 两个不同的后续单元有实际可打开的任务；同一单元两题、原课新参数SRS和原单元回顾不能冒充。
3. 学习者必须重新生成相关数值、图或理由，而不是只看到标签、读到介绍或抄答案。
4. 有说明“具体复现了什么”的双语语义理由；说明题保留人工核验，不按关键词打勾。
5. 数学、图示单位、答案和记录隔离经过验证。新增维护任务不计入358个正式课号，也不增加原单元6–10题回顾的题量。

## 数学核对与家长观察

B03三道数值为40,806、600、480。第一题40,000+800+6保留千位和十位零；第二题6在百位；数轴(600−400)÷10=20，P=400+4×20=480，460<480<500。

4,499到相邻千数4,000、5,000的距离为499、501，所以直接到千为4,000；先到百得到4,500再到千为5,000，是改变决定的反例。403退位为3百9十13一，仍为403；若写成3百10十13一就是413，重复保留了换出的十。403−178=225，用225+178=403交叉检查。家长应看换组过程是否守恒，不能仅凭写出225确认理解。

B05三道数值为60,070、1,000、450。60,000+70中的千、百、个位零各占其位；31,040=30,000+1,000+40。刻度(500−200)÷6=50，P=200+5×50=450，400<450<475。

7,849到7,800、7,900的距离为49、51，最近百数为7,800；若每人一票，7,800少49张。整百购买时为保证够用取7,900，这是另一个向上满足约束的问题。4百12十6一与5百2十6一都表示526；卡片张数由22变13，不等于人数减少。家长须核对两个表示的单位值及为什么相等，而不是只找“不变”字样。

两个维护会话使用`B03-MAINT-B01`、`B05-MAINT-B01`，与原`*-CHECK`、B01课程及SRS各自保存。输入解释不自动完成，必须家长显式审核；提示后的正确作答保留支持记录。一次或两次完成都不自动提升原课掌握状态。补桥链接随当前题分别指向B01-L01至L05，不把所有困难都送到读数第一课。
