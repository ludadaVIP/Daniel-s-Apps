# 测量树高与坡度

## 先说明量的是哪一段

本课使用虚构情境，不要求真实外出测量。测高前先说明：目标是否直立，仰角用什么单位，已知距离是水平距离还是视线距离，仪器离地多高，以及目标基部与观测地面是否同高。没有这些前提，一个看起来像直角三角形的草图不能保证唯一结果。

仰角从仪器的水平线向上量。直角辅助三角形的竖直对边，是树顶高于仪器的部分，不是完整树高。若两处地面同高，树高=这个高差+仪器高；若树基另有高程，还要减去树基相对于观测地面的高差。

### 例 1：水平距离与视线距离

同高基面、直立树、仪器高1.5 m，水平距离12 m，仰角45°。高于仪器部分=12tan45°=12 m，所以树高13.5 m。直接交12 m会漏掉仪器高度。水平距离是邻直角边，不是沿地面斜路走到树基的距离。

若水平距10 m、仰角30°，树高h=10tan30°+1.5≈7.2735 m，最后取一位小数7.3 m。若同样“10 m”指视线距离，它是斜边，应改用高差10sin30°=5 m，树高6.5 m。两题角和写出的10都相同，实际所量对象不同，答案就不同。中间保留更多位，避免先把tan30°截成0.6导致7.5 m。

### 例 2：坡度百分数不是坡角

一个虚构坡面竖升3 m、水平前进4 m，斜长5 m。坡度百分数=3/4×100%=75.0%；坡角θ满足tanθ=3/4，θ≈36.9°。斜长5 m是第三种量，不能把3/5×100%=60%当作这里的坡度。

75%不是75°，也不是75 m。百分数描述每一百份水平距离对应多少份竖升，角度用°，长度用m。坡度百分数可以超过100%，例如竖升2、水平1为200%，对应锐角仍小于90°。水平前进为零时分母为零，不能给有限坡度百分数；这也是本课普通锐角模型的边界。

## 未知地面高差会改变树高

保留水平12 m、45°仰角和仪器高1.5 m，树顶相对于观测地面仍在13.5 m高处。如果树基与观测地面同高，树高13.5 m；如果树基高2 m，树高变为11.5 m。两个例子保留相同的角、水平距离和树顶，却有不同树高，所以缺少基面关系时应回答不能唯一确定。

图中的水平辅助线位于仪器高度，不自动代表树基地面。工作台可以只显示另一种可能树基，原来的“条件不足”判断应保留；改变实际仪器高度或所给情境则重新作答。图形横纵按同一长度单位绘制，显示缩放不改变现实量。

家庭挑战在纸上设计测量卡和坡面图，分别报告角、比、长度及精度，并画出基面不同的反例。家长核验完整建模链：已知量身份→合法直角三角形→选sin或tan→求高差→处理仪器与基面→最后舍入。得到一个正确小数只是其中最后一步，完整解释仍需人工阅读。

# Measuring heights and gradients

## Identify the measured segment

All scenarios are fictional and require no outdoor measurement. State whether the target is vertical, the elevation-angle unit, whether distance is horizontal or along the sight line, instrument height and the relative base levels. A convenient sketch does not supply these premises or guarantee a unique height.

Elevation is measured upward from the instrument's horizontal line. The opposite side of the auxiliary right triangle is the rise above the instrument, not the full tree height. Equal ground levels permit adding instrument height. If the tree base has a different elevation, subtract that base elevation relative to observer ground.

### Example 1: horizontal and sight distances

For a vertical tree on equal base levels, instrument height 1.5 m, horizontal distance twelve metres and elevation 45°, rise=12tan45°=12 m. Full height is 13.5 m. Twelve omits instrument height. Horizontal distance is the adjacent leg, rather than a sloping walking distance along the ground.

At horizontal ten metres and elevation 30°, h=10tan30°+1.5≈7.2735 m, giving 7.3 m to one decimal place. If ten metres instead measures sight distance, it is the hypotenuse: rise=10sin30°=5 m and full height is 6.5 m. Identical written numbers can describe different quantities. Keep intermediate precision instead of first rounding tan30° to 0.6 and obtaining 7.5 m.

### Example 2: grade is not angle

A slope rises three metres over horizontal run four, with inclined length five. Percentage grade=3/4×100%=75.0%, while its angle satisfies tanθ=3/4 and is approximately 36.9°. Inclined length is a third quantity; 3/5×100%=60% is not the grade defined here.

Seventy-five percent is neither seventy-five degrees nor a length. Grade describes rise per hundred parts of horizontal run. It can exceed 100%: rise two over run one is 200%, still corresponding to an acute angle. Zero horizontal run gives a zero denominator and no finite percentage grade, also reaching the boundary of this ordinary acute model.

Keep horizontal twelve, elevation 45° and instrument height 1.5 fixed. The top remains 13.5 m above observer ground. A base at the same level gives tree height 13.5; a base two metres higher gives 11.5 with the same observations. Without the base-level relationship, height is therefore not unique. The horizontal auxiliary line is at instrument level, not automatically at tree-base ground.

The lab preserves an insufficient-evidence judgement while showing alternative bases. Changing actual instrument height or scenario creates a new task. Horizontal and vertical lengths share one scale; display zoom changes no real quantity.

The paper family challenge records angle, ratio, length, precision and a different-base counterexample. A parent reviews the chain from givens and side roles through a valid model, function choice, rise, instrument/base correction and final rounding. A correct decimal alone is only the last step.
