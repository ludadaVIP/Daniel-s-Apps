# 关系式 y=mx+b

## 一条规则里的四种角色

函数给每个允许输入一个确定输出。在 `y=2x+3` 中，x 是输入，y 是按规则得到的输出；固定的二与三是参数。换一个 x，规则不变，只是在同一关系上换一个点；换二或三，才换了整条关系。字母名称与它代表的量和单位要先定义，不凭出现位置猜含义。

一般形式为 `y=mx+b`。m 表示每增加一个 x 单位时 y 的变化，b 是 x=0 时的 y。先计算 mx，再加 b。b 包含自己的符号，例如 y=3x−4 中 b 是负四；−x/2 的 x 系数是 −1/2，不是负二。

本单元采用中文教材的一次函数约定：**m≠0**。其中 b=0 的特例叫正比例函数。若 m=0，得到常函数 y=b，仍然是每个输入只有一个输出的函数，但本单元不把它归作一次函数或正比例。英文资料对 linear/affine 的叫法有差异，本课以明写的公式与条件为准，不靠名称猜范围。

### 例 1：规则与一次输出

给定 m=2、b=3，代入 mx+b 得到一般关系 `y=2x+3`。x 尚未指定，它代表所有允许输入，而不是某一个隐藏答案。若题目只问 y 右侧一般式，就写 `2x+3`，不再加 y=。

输入 x=4，先算二乘四为八，再加三得 y=11。点 (4,11) 表示一个输入输出对。十一正确回答“这次输出多少”，却不能代替一般式：输入改成零，输出为三而非十一；输入负一，输出为一。把三行画在坐标系内，会落在同一条直线上。

若把 b 改为四，输入四的输出变成十二；所有对应输出都比原来多一。若把 m 改为三而 b 保持三，输入四得十五，但零输入仍为三。两种参数的作用不能互换。

### 例 2：负系数与常函数

`y=−x/2+4` 可写成 `y=(−1/2)x+4`，所以 m=−1/2、b=4。x=2 时输出三；x=4 时输出二。x 每增加二，y 减少一，说明每个 x 单位减少半。图像向右下降，仍是本单元的一次函数。

若把 m 改为零而 b 保持四，得到 y=4。无论 x=−2、零、三，输出都为四，是水平常函数。它不是“不能输入”或“没有函数”，只是变化率为零，违反本课一次函数的非零系数条件。常函数也可以表示明确情境，例如在给定时段保持不变的理想读数，不能因为例子简单就将它排除出函数概念。

## 操作与家长提示

工作台让你改变 m、b 与输入 x；表格、点和直线一起响应。宽图仅在图内滚动。改变输入或图窗保留一般式作答，改参数才清空针对旧关系的证据。视窗看不到某点，不表示它没有对应输出。

家长分别问：哪个量固定、哪一个输入正在变化、题目要数值还是一般式？让孩子在同一规则中换两个输入验证，而不把“知道一个点”当作已经写出整个函数。屏幕倾角与斜率的关系下一课将按轴刻度计算。

# The form y=mx+b

## Four roles in one rule

A function assigns one output to each permitted input. In y=2x+3, x is the input and y its output; the fixed two and three are parameters. Changing x moves to another point under the same rule. Changing a parameter changes the relationship. Define quantities and units before interpreting their roles.

In y=mx+b, m gives the output change per input unit, and b is the output at x=0. Multiply before adding. Keep signs: b=-4 in y=3x-4, while -x/2 has coefficient -1/2 rather than minus two.

This unit uses the first-degree convention **m≠0**. With b=0 it is direct proportion. At m=0 the rule is a constant function y=b, still a function but not first-degree or direct under this convention. English linear/affine terminology varies; rely on the stated formula and conditions.

### Example 1: a rule and one output

For m=2,b=3 the general rule is y=2x+3. The variable x still represents all allowed inputs. Asked for the expression after y=, enter 2x+3 without the equal sign.

At x=4, multiply to get eight and add three to obtain eleven. The point (4,11) represents one input-output pair. Eleven answers this evaluation but cannot replace the rule: zero gives three and minus one gives one. All three points lie on the same line.

Changing b to four raises every output by one. Changing m to three while keeping b=3 gives fifteen at x=4, while zero still gives three. The parameters have different roles.

### Example 2: negative slope and a constant

Write y=-x/2+4 as y=(-1/2)x+4. Thus m=-1/2,b=4. Inputs two and four give three and two. A rise of two input units decreases the output by one, a rate of minus one half. This decreasing rule is still first-degree.

If m becomes zero and b stays four, every input gives four, producing a horizontal constant function. It has valid inputs and outputs, not an absence of function. Its zero rate excludes it from this unit’s first-degree category. It could model an ideal unchanged reading over a specified interval.

## Investigate

Change m, b and x in the workshop and inspect the table, point and graph. Changing the input or window retains a rule answer; changing parameters resets evidence for the old relationship. An off-window point still has its mathematical output.

A parent asks which values are fixed, which input varies and whether the task requests one output or a general expression. Check two inputs under one rule rather than confusing a single point with a whole function. The next lesson calculates slope from labelled axis units.
