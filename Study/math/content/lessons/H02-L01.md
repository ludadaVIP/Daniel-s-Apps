# 定义域、值域和对应

平方机把−1和1都送到1，这不是故障。函数要求的是“每个输入有恰好一个输出”，并不要求“不同输入的输出都不同”。先从对应关系出发，函数就不只是一条等待代数计算的公式。

## 一条核心想法

**一个函数由给定的定义域和对应规则确定。** 定义域D包含允许输入；陪域C是事先指定的输出目标集合；实际值域由真正能产生的输出组成，必须包含于C，但可以比C小。

检查函数时，对D里的每个输入分别问两次：有没有输出？是不是只有一个？少一个输入没有输出，或同一输入给两个不同输出，都不符合函数定义。许多输入共用一个输出则完全允许。常函数也能是函数。箭头图中的“多对一”和“一对多”不能混读。

同一公式不保证同一函数：f(x)=x²若只允许整数−2到2，和允许整个实区间[−2,2]，是两个定义域不同的函数。图像视窗、表中列出的几项和函数实际定义域也不是同一回事。

### 例1：有限对应与未用的陪域值

取D={−2,−1,0,1,2}、C={0,1,4,9}，规则为x→x²。依次得4、1、0、1、4。每个输入恰有一个输出，因此是函数；实际值域是{0,1,4}，而不是C。9虽然写在目标集合里，却没有允许输入能产生它。

现在保留D，却删去2的箭头：这不是D上的函数，因为2没有输出。若给0同时画到0和1的两条箭头，也不是函数，因为同一输入的输出不唯一。不能为了保住“是函数”的判断，在没有说明时偷偷删掉定义域里的问题输入。

### 例2：连续域、最大自然定义域与给定域

取f=x²、D=[−2,3]。最小输出在0处为0；两端平方为4与9，最大是9；中间0到9的每个输出y都可由x=√y∈[0,3]产生，所以值域是[0,9]。只算端点得到[4,9]会漏掉中间最低点；只找到最小、最大却不说明中间可达，也还不够完整。

“按式有意义的最大定义域”与“题目另给的定义域”须区分。1/(x−2)只需排除x=2，最大实定义域是x<2或x>2；√(5−x)要求5−x≥0，最大实定义域为x≤5。若题目另规定只用[0,1]，就保留这一更小的给定域，不擅自扩大。实际情境还可能限制整数、非负量或时间上限。

## 工作台：先核输入，再收集输出

先看完整对应清单，预测是否为函数，再显示箭头图。观察陪域9有没有箭头指向。切到缺箭头和双箭头案例，明确指出究竟哪个输入违反了哪条要求。

将有限平方域换成连续区间，再查询1/2：有限域中它是域外；连续域中它有输出1/4。这里是改变了函数的域，不是改善了计算精度。有限值域用花括号，连续值域用区间；集合输入框若用x作统一占位符，题目会说明它代表输出值。

## 家长核对

让孩子说出“允许输入”“每个恰好一个”“实际输出”三个角色，再用一个多对一例子反驳“函数必须一对一”。若孩子只背D、C、值域的词，回到箭头图逐个核查。出口解释保留人工审核，重点听到范围如何改变输出集合。

# Domain, range and mapping

A squaring machine sends both minus one and one to one. That is allowed. A function requires exactly one output for each input; it does not require different inputs to have different outputs. Starting with a correspondence makes a function more than a formula awaiting substitution.

## One central idea

**A function is determined by its stipulated domain and mapping rule.** The domain D contains admissible inputs. The codomain C is the specified target set of outputs. The actual range consists of outputs that really occur: it is a subset of C and may be smaller.

For each input in D, ask whether an output exists and whether it is unique. A missing output or two different outputs for one input violates the definition. Several inputs sharing an output is fine; constant functions are functions too. Distinguish many-to-one from one-to-many.

The same formula need not define the same function. Squaring only the integers from −2 through two differs from squaring every real in [−2,2]. A graph window, a short table and the complete function domain are also different objects.

### Example 1: A finite mapping with an unused codomain value

Take D={−2,−1,0,1,2}, C={0,1,4,9}, with x mapped to x². The outputs in input order are 4,1,0,1,4. Each input has exactly one, so this is a function. Its actual range is {0,1,4}, not C: nine is available in the target set but has no admissible preimage.

Keep D but remove the arrow from two. The resulting correspondence is not a function on D because two has no output. Giving zero arrows to both zero and one also fails uniqueness. Do not silently remove a troublesome domain input to preserve a claim that the original correspondence was a function.

### Example 2: An interval domain and a natural domain

Let f=x² on D=[−2,3]. The minimum output is zero at x=0. Endpoint squares are four and nine, so the maximum is nine. Every output y between zero and nine occurs at x=√y in [0,3]. Thus the range is [0,9]. Endpoint values alone would miss the interior minimum; minimum and maximum alone also need an argument that intermediate outputs occur.

A maximal domain allowed by a formula differs from a smaller stipulated domain. For 1/(x−2), exclude x=2, giving x<2 or x>2. For √(5−x), require 5−x≥0, giving x≤5 including the zero radicand. If a problem explicitly restricts the function to [0,1], retain that smaller domain. A context may impose whole numbers, nonnegative quantities or a final time as well.

## Workbench: audit inputs, then collect outputs

Read the complete correspondence list and predict function status before revealing arrows. Inspect whether any arrow reaches the codomain value nine. In missing-arrow and split-arrow cases, identify the exact input and the failed existence or uniqueness requirement.

Switch from a finite square domain to an interval and query half. Half is excluded from the finite domain but has output one quarter in the interval domain. This changes the function, not calculation precision. Use braces for a finite range and interval notation for a continuous one. If a set-entry field uses x as a generic placeholder for output values, the question explicitly says so.

## Parent review

Ask the learner to connect admissible input, exactly one output and actual range in one explanation, then refute “every function must be one-to-one” with a many-to-one example. If only labels are recalled, return to checking arrows one input at a time. The exit argument stays human-reviewed, especially its explanation of how the domain changes the range.
