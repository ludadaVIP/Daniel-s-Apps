# 函数的多种表示

一条规则、数表的一行、图上的一点，可能在说同一件事：输入某个数，得到某个输出。多种表示的价值是互相核验，而不是凭几个点就创造没有给定的规则。

## 一条核心想法

**把同一个输入贯穿公式、语言、数表与坐标图。** f(a)表示输入a时的函数值，不是f乘a，也不是“第a个点”。图点按(x,f(x))的顺序记录输入与输出；交换两坐标通常会变成另一个关系。

表格只列有限行，可能只是完整函数的部分记录，也可能恰好列完离散定义域。先读题目哪一种才知道能否求表外输入。图像应由明确规则、定义域或题目规定的模型建立，不是默认把看到的点用线连接。

### 例1：同一条规则的三种核验

完整给定f(x)=x²−2，D=[−2,2]。取输入3/2，先平方得9/4，再减2得1/4，所以f(3/2)=1/4。数表的一行是输入3/2、输出1/4，图点是(3/2,1/4)。点(1/4,3/2)则把身份颠倒了。

再取−1，整个负数的平方是1，f(−1)=−1。若要找所有使输出为2的输入，要解x²−2=2，得x=±2，两者均在域内。一个输出可以对应两个输入，这仍是原来的函数；不要把求一个函数值与找全部原输入混为一题。

### 例2：有限域与只有观测的情况

保留f=x²−2，但D只给{−2,−1,0,1,2}。图上只有五个允许点，不连成连续曲线；f(1/2)是域外，不能仅因为公式可计算就增加输入。相反，若D=[−2,2]且完整规则已给，即使表里没有1/2，也可依法求值。

另一个问题只说D=[−2,2]、f(−1)=f(1)=1，没有规定函数族。此时f(0)无法唯一确定：f=x²在0为0，f=1在0为1，二者都吻合两个观测。输入0在域内，问题在于证据不足，而非域外。两点确定一次函数还需要“一次函数”的前提，不能将其推广到任意函数。

## 联动工作台

点击表中一行，追踪图上的同一输入，并把点坐标主动写出。切换“只看表”“只看图”“两者联动”，数学规则不变，原预测保留。换查询输入则重算数值与点；改成离散域时检查半整数是否被排除。

观测模式只显示两个已知点。点击两种可能延伸时，虚线表示候选模型而不是真实已知函数；完整规则的图像与“可能符合资料的图像”不能使用同一种证据语言。只改图窗不改变定义域，也不把窗口之外的输入自动判为不存在。

## 自己迁移与家长核对

自定一个小函数，例如f(x)=2x+1、D={0,1,2}。写一句规则、三行表和三个点，再核同一行。想改成D=[0,2]时，必须明确宣布域改变，才能在点间画连续直线。家长可故意颠倒一个坐标或把f(2)写成2f，让孩子用另一种表示纠正；最后让孩子解释，哪些信息是题目给定，哪些只是从图中观察到。

# Multiple representations of functions

A rule, a table row and a graph point can express the same event: one input produces one output. Multiple representations help audit that event. They do not license inventing an unspecified rule from a few observations.

## One central idea

**Track the same input through language, formula, table and graph.** f(a) is the function value at input a, not f multiplied by a or the “ath point”. A point (x,f(x)) records input first and output second. Swapping them generally describes a different relation.

A finite table may be a partial record of a complete function, or it may list every admissible input of a discrete domain. Read which situation is stipulated before evaluating a missing row. Construct a graph from an actual rule, domain or supplied model premise; connecting observed points is not an automatic rule.

### Example 1: Audit one rule in three forms

Given f(x)=x²−2 on D=[−2,2], input 3/2 has square 9/4 and output 9/4−2=1/4. Thus f(3/2)=1/4. The table row is input 3/2, output 1/4, and the graph point is (3/2,1/4). The reversed point (1/4,3/2) exchanges the roles.

At input −1, square the entire negative number: f(−1)=1−2=−1. To find every input giving output two, solve x²−2=2, obtaining ±2. Both are admissible. An output can have two preimages while the forward rule remains a function. Evaluating one input and finding all inputs for an output are different tasks.

### Example 2: A discrete domain versus incomplete evidence

Keep the formula x²−2 but stipulate D={−2,−1,0,1,2}. There are only five allowed points, so leave them unjoined. Half is outside the domain even though substitution into the formula is arithmetically possible. If instead the interval domain [−2,2] and complete rule are given, a missing table row at half can be evaluated.

Now a different problem gives only D=[−2,2] and observations f(−1)=f(1)=1, with no function family. The value f(0) is not uniquely determined. The candidates f=x² and f=1 fit both observations but give zero and one at zero. Zero is in the domain; the issue is insufficient rule evidence, not domain exclusion. Two points determine an affine function only when the affine premise is supplied, not an arbitrary function.

## Linked workbench

Inspect a table row, track its input on the graph and construct the ordered pair yourself. Switching table, graph and combined views preserves the mathematical prediction. Changing the input changes its value and point; switching to a discrete domain requires rechecking half-integer inputs.

Observation mode initially shows only the two known points. Revealed dashed extensions are possible models, not an established true rule. Describe a stipulated graph differently from a graph that merely fits the data. A changed window does not change the mathematical domain or erase inputs outside the displayed frame.

## Transfer and parent check

Invent f(x)=2x+1 on D={0,1,2}. Write a sentence, three table rows and three graph points, then audit each row across forms. To use D=[0,2], explicitly change the domain before drawing a continuous line. A parent can reverse one coordinate or write f(2) as 2f and ask the learner to repair it using another representation. Conclude by naming what was given and what was merely observed.
