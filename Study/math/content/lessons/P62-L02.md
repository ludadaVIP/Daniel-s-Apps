## 换一种写法，保持同一个数

0.375 与 37.5% 看起来有不同的数字，却表示同一个数。关键是把百分号与它前面的数一起读：**37.5% 就是 37.5÷100**。只盯着“37.5 比 0.375 大一百倍”，会遗漏百分号的作用。

小数转百分数时，先找“除以一百之后等于原数”的系数。这个系数是原小数的一百倍，再添百分号。改变的是表示方式，实际数值没有放大一百倍。也可以用位值说明：一个千分之一等于十分之一个百分之一，0.001=0.1%。

### 例 1 · 千分位也能换成百分数

1. 原数 **0.375=375/1000**。
2. 按每百份写为 **37.5/100**，仍与原分数等值。
3. 因此 **0.375=37.5%**。
4. 百格图涂三十七格半；原量仍为一个整体的 0.375，并没有扩大。
5. 反向核查：**37.5÷100=0.375**。若只写 0.375%，实际为 **0.00375**，比原数小一百倍。

“小数点右移两位”可以作为熟练后的快捷观察，但要能解释：移位产生百分数系数，百分号负责除以一百。不能删去百分号仍声称两个数相等。对零要单独想：0=0%，二者都表示零，不应机械套用“只加百分号必改变大小”的口号。

### 例 2 · 小于 1% 与超过 100%

1. **0.035=3.5/100=3.5%**，不是 35%。其中千分位的五不能漏掉。
2. 更小的 **0.008=0.8%**；百分数前面的数也可以小于一。
3. 另一方面，**1.25=125/100=125%**。一个完整参考整体是 100%，剩下 0.25 对应 25%。
4. 百格图增加第二个同样的框并涂其中二十五格，不能把两个框合起来重新叫作 100%。
5. 核查 **125÷100=1.25**，与一个又四分之一个原整体相同。

反向从百分数转小数时，直接解释百分号：37.5%=37.5÷100=0.375。注意 37.5 与 37.5% 并不相等。输入框如果要求百分数，就应包含百分号；如果题目明确要求小数，就不再带百分号。表示形式是本课目标的一部分，数量等值但未完成形式时，会提示再检查写法。

工作台用千分之几控制同一个量。选 0.035、0.375、1 或 1.25，先看百格图并预测，再核对等值式。图中的每个粗框始终是同样的一个整体，不会因为换成百分数而变大。改变滑块会清空旧结果，不能拿上一次的百分数回答新小数。

**试着口头比较：** 0.5=50%，0.05=5%，0.005=0.5%。它们每次都是前一个数的十分之一，百分数的系数也对应缩小。用除以一百乘回检查，比凭小数点位置猜更可靠。

**家长陪学：** 让孩子补完“__% 表示 __÷100，所以等于 __”。认可位值、分数或百格图解释，不能仅因移位正确就认为已经理解。**带走一个发现：** 系数变了，百分号补偿了这个变化；两种写法表示同一个数。

## A new representation of the same number

0.375 and 37.5% look different but represent the same number. Read the coefficient and percent sign together: **37.5% means 37.5÷100**. Noticing only that 37.5 is one hundred times 0.375 overlooks the sign that follows it.

To convert a decimal, find the coefficient that becomes the original number when divided by one hundred. Multiply the decimal by one hundred for that coefficient, then attach %. The representation changes without enlarging the quantity. Place value offers another explanation: one thousandth is one tenth of a hundredth, so 0.001=0.1%.

### Example 1 · Converting a thousandths value

1. Start with **0.375=375/1000**.
2. Rewrite it per hundred as **37.5/100**, preserving equivalence.
3. Therefore **0.375=37.5%**.
4. A hundred grid shades thirty-seven and a half cells. The quantity remains 0.375 of one reference whole.
5. Check **37.5÷100=0.375**. Merely writing 0.375% would instead mean **0.00375**, one hundred times smaller.

“Move the decimal point two places” can become a convenient shortcut once understood. Explain that the shift produces a percent coefficient and the percent sign divides by one hundred. Removing the sign would destroy the equality. Treat zero thoughtfully: 0 and 0% both represent zero, so a blanket claim that appending % always changes the value has an exception.

### Example 2 · Below 1% and beyond 100%

1. **0.035=3.5/100=3.5%**, rather than 35%. Retain the thousandths digit.
2. The smaller **0.008=0.8%** shows that a percent coefficient can be below one.
3. **1.25=125/100=125%**. One reference whole is 100%, and the extra 0.25 contributes 25%.
4. Add a second identical hundred-grid frame and shade twenty-five of its cells. Do not redefine the two frames together as 100%.
5. Check **125÷100=1.25**, the same as one and one quarter original wholes.

For the reverse conversion, interpret the percent sign directly: 37.5%=37.5÷100=0.375. The numbers 37.5 and 37.5% are different. If a question asks for a percentage, include %. If it explicitly asks for a decimal, leave the percent sign out. Representation is part of this lesson’s objective, so an equivalent value in the wrong form still needs revision.

The workshop controls one quantity in thousandths. Try 0.035, 0.375, 1 and 1.25, predict from the hundred grid, then reveal the equality. Each thick frame remains the same reference whole; converting notation does not enlarge it. A slider change clears the old result so that an earlier percentage cannot answer the new decimal.

Compare these aloud: 0.5=50%, 0.05=5%, 0.005=0.5%. Each number is one tenth of the preceding number, and the coefficients scale accordingly. Dividing the coefficient by one hundred checks the result more reliably than guessing from the decimal point’s appearance.

**For a parent:** invite the learner to complete “__% means __÷100, which equals __.” Accept place-value, fraction or grid explanations; a correct shift alone does not establish understanding. **Takeaway:** the coefficient changes, and the percent sign compensates for that change, preserving the original number.
