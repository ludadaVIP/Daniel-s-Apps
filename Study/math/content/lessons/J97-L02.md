# 乘法法则与树状图

## 沿路径走时，条件也在前进

树状图不只是把几条线画漂亮。每条第二步分支的概率，都要解释为“已知走到了这个第一步节点，下一步的机会”。对P(A)>0，一般乘法法则是P(A且B)=P(A)P(B|A)。这条法则本身不要求独立；只有模型给出独立，才能把条件概率换成未改变的P(B)。

本课的袋子有R1、R2、R3三红和B1、B2两蓝，各编号球每次在当时可抽球中等机会。R/B表示颜色，不代表单个编号。结果写RR、RB、BR、BB保留先后顺序，不能把颜色路径数量当作等可能基本结果数。

### 例 1：不放回的两次红

第一步红有3/5机会。若第一步已经取走红球，剩两红两蓝共4个球，第二红条件概率2/4。因此RR概率=3/5×2/4=3/10。第二个分子和分母都根据走过的路径更新，不能沿用3/5，也不能只把总数改4却仍写3/4。

已知首红后求次红只问2/4=1/2，不要再乘首步3/5；求完整RR才问3/10。条件概率与联合概率的研究范围不同，分母分别是条件下剩余选择与原完整试验。

### 例 2：颜色不同须合并两条路径

先红后蓝RB的概率3/5×2/4=3/10。先蓝后红BR的概率2/5×3/4=3/10。一次有序试验不可能同时是RB和BR，所以这两个路径事件互斥；颜色不同概率为3/10+3/10=3/5。

乘法用于同一条路径连续满足条件，相加用于互不重叠的替代路径。把两条路径概率相乘会问到另一个问题，不能表达这一次试验“RB或BR”。若用补事件，也可先算RR与BB之和再从1减去，但仍须同一个明确样本空间。

## 放回改变的是模型

如果第一抽后放回并充分混匀，第二抽又在原五球中等机会，则第二红仍3/5，RR=9/25。这个模型的两抽独立；不放回的RR为3/10，不能因为袋子颜色标签没换就照抄前一个概率。树枝的布局不决定独立性，抽取规则和条件才决定。

每个已能到达节点向外的分支概率应合为1；第一步概率为零的节点不会到达，不能在该零条件下假装求通常条件概率。工作台主要两种颜色都至少一个，但某条次步分支可为零，例如只有一红时，首红后第二红为零。虚线零分支不是可发生结果。

先填写整路径概率和第二步条件概率，再显示数量核验。切换编号表与树只是观察方式，预测应保留；更改球数、路径或放回规则，就要按新条件重新预测。家长请孩子逐枝说“已知什么、剩什么、分母是谁”，再核为什么跨路径可以相加。

# Multiplication rule and trees

## Conditions move forward along the path

A tree is a record of conditional choices. Each second branch means the chance of that result given the first node already reached. For P(A)>0, P(A and B)=P(A)P(B|A). This general rule does not require independence. Only a justified independence model allows replacing the conditional probability with the unchanged marginal P(B).

Our bag contains red R1,R2,R3 and blue B1,B2, with each eligible ID equally likely at each draw. R/B denote colour categories, not individual IDs. RR,RB,BR,BB retain order and are not automatically equally likely merely because four labels appear.

### Example 1: two reds without replacement

The first red probability is 3/5. After a red has been removed, two red and two blue remain, so second red given first red is 2/4. Multiply to obtain P(RR)=3/10. Update both numerator and denominator; neither 3/5 nor 3/4 describes that second conditional branch.

Asked only for second red given first red, answer 1/2 without multiplying by the first probability. Asked for the complete RR path, answer 3/10. Conditional and joint probabilities describe different subsets and denominators.

### Example 2: two disjoint ways to differ

RB has probability 3/5×2/4=3/10. BR has probability 2/5×3/4=3/10. One ordered trial cannot be both RB and BR, so add these disjoint alternatives to obtain 3/5 for different colours.

Multiplication follows successive requirements within a path; addition combines nonoverlapping alternatives. Multiplying RB and BR does not represent RB or BR in one trial. A complement calculation is also possible, provided all events use the same defined space.

Returning and remixing before draw two restores all five eligible IDs. The second red probability remains 3/5 and RR becomes 9/25 under independent redraws. Without replacement it was 3/10. Branch layout does not establish independence: the experiment rules and conditions do.

Outgoing probabilities at a reachable node sum to one. An impossible first node cannot supply an ordinary conditional calculation. Although both colours are present in this lab, a second branch can have zero probability: after drawing the sole red, no red remains. A dashed zero branch is not a possible outcome.

Predict the complete path and second conditional before revealing the count audit.
