# 复合函数与逆函数深化

复合不只是把两个式子套在一起。一个输入能否走完两步，取决于它先能进入内函数，内函数的输出又能进入外函数。反函数则要把每一个输出唯一地还原为输入，因而需要一对一性。公式、定义域和取值范围共同组成函数的信息。

## 先走内层，再检查外层

设f(u)=u²，但本课先将它限制在u≥0；设g(x)=x+1。记H=f∘g，意思是H(x)=f(g(x))，先加1再平方。虽然计算式可写成(x+1)²，合法输入还必须满足x+1≥0，因此H的定义域是[−1,∞)，值域[0,∞)。不能因为化简式是多项式，就把定义域偷偷扩成全部实数。

复合的顺序通常不可交换。一般地，D(f∘g)={x∈Dg:g(x)∈Df}。若题目给了区间或离散输入，还要先与内函数自身的定义域相交。本课g收全部实数，才只剩第二层条件。

### 例1：把中间值写出来

输入x=2。先算g(2)=3；3≥0，进入f后得9，所以H(2)=9。反序先算f(2)=4，再算g(4)=5，因此g(f(2))=5。两条路径的起点相同，操作次序不同，结果也不同。

再试x=−2。g(−2)=−1，不在f的原定义域，因此H(−2)无定义。扩展多项式(−2+1)²当然可算为1，但那是另一个定义域更大的函数，不能充作原H的值。这里不是算术错误，而是输入资格不满足。

### 例2：限制分支，再反向还原

若H(x)=9，先得到(x+1)²=9。代数候选为2和−4，但原域x≥−1仅保留2。H在此域严格递增，每个非负输出恰有一个原像，因此H⁻¹(y)=√y−1，逆函数定义域[0,∞)，值域[−1,∞)。

若改把f限制为u≤0，H的定义域变成(−∞,−1]。同样输出9须先选负分支u=−3，再减1得到x=−4。此时H⁻¹(y)=−√y−1，而不是仍沿用正根号。若f收全部实数，正输出通常有两个原像，H不是一对一，交换坐标所得是逆关系，不是一个反函数。

## 为什么撤销顺序反过来

H先执行g再执行f，因此恢复输入时先撤销最后一步f，再撤销g。在相应域和值域匹配时，(f∘g)⁻¹=g⁻¹∘f⁻¹。可沿用“穿鞋前先穿袜，脱时先脱鞋”的顺序理解，但证明仍要核每一步定义域以及唯一性。

反函数上标−1不表示倒数。1/H(x)在H(x)=0时无定义，与交换输入输出的规则完全不同。图上把点(x,H(x))换为(H(x),x)，并以y=x作镜面；两轴相同刻度才适合直接看反射。有限窗口看到的点只能帮助检查，不能证明整条曲线一对一。

## 操作与出口

工作台可切正分支、负分支和全部实数，并改变平移与输入。先预测定义域和9的全部原像，再打开核验。分支改变时应重新审查原像；输入改变不应改变函数的整体定义域。

家长可以先遮住答案，让学生指出哪个中间输入被拒绝，再让学生用输出9检验两个分支。出口报告要包含两步规则、原域、值域、唯一性和逆序；只写一个根号公式仍不完整。

# Composition and inverses revisited

A composite is a two-stage rule with input restrictions. An inverse must recover exactly one original input from each allowed output. A formula alone does not specify either object: keep its domain and range beside it.

## Follow the intermediate input

Let f(u)=u² on u≥0 and let g(x)=x+1 on all real inputs. The notation H=f∘g means H(x)=f(g(x)): shift first, square second. The formula is (x+1)², but the intermediate value must satisfy x+1≥0. Thus H has domain [−1,∞) and range [0,∞).

In general D(f∘g)={x∈Dg:g(x)∈Df}. This checks two admissions, not merely the final arithmetic. If g itself has a restricted domain, intersect that restriction too. Replacing the composite by a polynomial on a larger natural domain defines an extension, rather than changing the original function by algebra.

### Example 1: Compare the two orders

At x=2, g produces three. The outer f accepts three and produces nine, so H(2)=9. In reverse order, f(2)=4 and g(4)=5. The same starting value gives different answers because the operations were ordered differently.

At x=−2, g produces −1, which the restricted f rejects. H(−2) is therefore undefined. The polynomial expression (−2+1)² can be evaluated as one, but it belongs to an extended rule at that input. This is a domain issue, not an arithmetic mistake.

### Example 2: Select a branch before undoing

Solve H(x)=9. Squaring gives candidates x=2 and x=−4. On the stated domain x≥−1, only two survives. The restricted H is strictly increasing and gives each nonnegative output one preimage. Hence H inverse is √y−1, with domain [0,∞) and range [−1,∞).

If f is instead restricted to u≤0, H has domain (−∞,−1]. Output nine first gives the negative intermediate value −3, then x=−4. Its inverse is −√y−1. Keeping the positive square root would silently change the branch. If the square accepts all real inputs, opposite nonzero intermediate inputs share a squared output. The swapped relation has two branches and fails to be an inverse function.

## Undo in reverse order

Since H applies g and then f, undo the last operation f first and then undo g. Where the domains and ranges match and each step is invertible, (f∘g) inverse equals g inverse composed with f inverse. The statement is conditional; writing the symbolic order without checking admissible inputs does not establish a valid inverse.

An inverse-function superscript is not a reciprocal. The reciprocal 1/H(x) excludes zeros of H and performs a different operation. An inverse swaps input and output. On a graph, exchange each point (x,H(x)) with (H(x),x), reflecting across y=x when the axes have equal unit lengths. A finite graph window supports checks but cannot prove global uniqueness.

Use the workbench to switch branches and shifts. Predict the domain and all preimages of nine before revealing the audit. Changing a probe input does not change the entire function’s domain. Explain the intermediate input that is rejected, compare the two inverse branches and report both inverse domain and range. A square-root formula without those restrictions is unfinished.
