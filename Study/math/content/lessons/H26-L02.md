# 驻点与极值

解出f′=0只是找到驻点，下一步才是判断它是不是山顶或谷底。本课把“位置”“函数值”“局部”“整个区间”分开，防止一个零导数包办所有结论。

## 约定与候选

驻点是导数存在且为0的输入及其曲线上点。临界输入的范围更广，还包括函数有定义而导数不存在的内点。定义域外的空洞不能当作已达到的极值。

本课的局部分类采用双侧内点的严格局部极值：足够近的其他输入值都更低，才叫严格局部极大；都更高，才叫严格局部极小。若教材允许非严格比较，常数函数每点既是局部极大也局部极小；本课严格分类把它们记作neither。端点按闭区间绝对极值比较，不硬套双侧局部标签。

连续候选点附近，若左侧导数始终正、右侧始终负，则先增后减，有严格局部极大；负到正则有严格局部极小；同号则没有这种转折。这个检验需要左右区间的完整符号，不能只比两个不相邻的样点。若周围不满足这些符号假设，不能把此简明检验当作所有函数的万能充要描述。

### 例1：同样水平，结果不同

f(x)=x³−3x，f′=3(x−1)(x+1)。在x=−1，导数由正变负，严格局部极大值f(−1)=2；在x=1，导数由负变正，严格局部极小值f(1)=−2。位置−1与值2不能混答。

g(x)=x³在0导数0，两侧导数却都正，所以没有局部极值。h(x)=|x|在0取得严格局部极小值0，但左右差商极限−1与1不同，不能说它是驻点。“可导内点有局部极值 ⇒ 导数0”成立；去掉可导前提或倒过来都不可靠。

### 例2：闭区间的端点也会胜出

求x³−3x在[−2,3]的绝对最大最小值。多项式连续，闭区间中一定能达到最大最小。内部驻点−1、1，加端点−2、3，逐个代原函数：f(−2)=−2、f(−1)=2、f(1)=−2、f(3)=18。

最大值18在x=3，局部峰值2并不是全局最大。最小值−2同时在x=−2和x=1达到；一个最小值可以对应多个位置。若把右端改为2，f(2)=2，于是最大值2在−1和2达到；答案随着范围改变，即使函数公式没变。若范围开口，不保证能达到极值，例如x在(0,1)既无最大值也无最小值。

## 工作台与出口

先选函数族和观察点，预测严格局部分类，再比较闭区间全部候选。表中x是位置，f(x)是值，别把绿色导数高度当作极值。常数函数的候选表用端点代表相同值，同时文字说明整个区间都达到最大最小；不会假装只有端点驻定。

出口必须同时解释平坦三次、尖点与闭区间端点。家长可要求孩子指出“哪条假设使导数0成为必要条件”，再问是否漏了不可导点。只写“求导得0所以最大”需要补两侧符号或完整候选比较，不能由关键词自动通过。

# Stationary points and extrema

Solving f′=0 finds stationary candidates. A separate argument decides whether they are peaks or valleys. Keep location, value, local behaviour and whole-interval comparisons distinct.

## Definitions and candidates

A stationary input has an existing derivative equal to zero. Critical inputs also include interior points where the function is defined but not differentiable. An excluded hole cannot be a point at which an extremum is attained.

Here local classification uses strict two-sided interior extrema: a strict local maximum exceeds all sufficiently nearby values at other inputs, and a strict local minimum is smaller than all of them. Under a non-strict convention a constant function has both a local maximum and a local minimum at every input. Our strict classification returns neither for it. Endpoints participate in absolute comparisons on the closed domain and are not forced into a two-sided local label.

At a continuous candidate, a positive derivative throughout a nearby left interval followed by a negative derivative on the right gives a strict local maximum. Negative followed by positive gives a strict local minimum. The same nonzero sign on both sides produces no turn. These statements require neighbourhood sign assumptions, not two distant sampled values. Without those assumptions, this simple test is not a universal characterisation of every possible function.

### Example 1: Horizontal tangents can behave differently

For f(x)=x³−3x, f′=3(x−1)(x+1). At −1 the derivative changes from positive to negative, so the function has strict local maximum value f(−1)=2. At one it changes from negative to positive, giving strict local minimum value −2. The location −1 is not the value two.

For g(x)=x³, the derivative at zero is zero, yet it is positive on both sides. There is no local extremum there. For h(x)=|x|, zero is a strict local minimum with value zero, but the one-sided derivative limits −1 and one disagree. This is not a stationary point. The valid necessary condition is that a differentiable interior local extremum has derivative zero. Reversing the implication or dropping differentiability creates false conclusions.

### Example 2: A closed interval can favour an endpoint

Find absolute extrema of x³−3x on [−2,3]. Continuity on the closed interval guarantees attainment. Compare the interior stationary inputs −1 and one together with endpoints −2 and three. The corresponding function values are −2, two, −2 and eighteen.

The absolute maximum is eighteen at x=3, so local peak value two does not win the whole-interval comparison. The absolute minimum −2 is attained at both x=−2 and x=1. A single minimum value can have more than one attaining input. If the right endpoint changes to two, its function value is two; the maximum is then two at both −1 and two. The formula is unchanged, but the authorised domain changes the answer. An open interval does not give the same guarantee: x on (0,1) attains neither a maximum nor a minimum.

## Investigate and explain

Choose a family and observed input, predict its strict local classification, then compare every closed-interval candidate. In the audit, x is a location and f(x) is a value. The height on a derivative graph is not the original function’s extremum value. For a constant, endpoint rows represent the common value; the accompanying text states that every point of the interval attains both absolute extrema and is stationary.

The exit combines the flat cubic, the corner and endpoint comparisons. A parent can ask which hypothesis makes zero derivative necessary and whether any nondifferentiable input was omitted. “Differentiate and set to zero, therefore maximum” needs a sign test or a complete candidate comparison. The written explanation receives human review, not a pass from matching mathematical keywords.
