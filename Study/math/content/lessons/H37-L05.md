# 数值方法与近似

数值方法不仅要报一个小数，还要说明它近似哪个量、误差如何保证。本课只研究二分法：在已确认含根的闭区间里，每次保留一半，用区间中点近似根的位置。中点是近似值，半宽是绝对误差上界，两者承担不同任务。

## 保持含根的不变量

先检查函数在整个闭区间连续，再检查端点是否已为根；若未命中端点且两端函数值异号，连续性保证至少有一个根。试中点m=(L+U)/2。若f(m)=0则精确命中并停止；否则保留端点异号的半区间。这样每轮既保留连续性，又保留至少一个根，而不只是让数字看起来收敛。

### 例1：三次更新后的近似与保证

求x²−2=0在[1,2]中的根。函数连续，f(1)=−1、f(2)=2。第一次试3/2，函数值1/4为正，保留[1,3/2]；第二次试5/4，函数值−7/16，保留[5/4,3/2]；第三次试11/8，函数值−7/64，保留[11/8,3/2]。

完成三次更新后，当前区间中点是(11/8+3/2)/2=23/16，不是第三次用于试符号的11/8。当前宽度1/8，任何被包围根离中点最多1/16，所以可报告√2≈23/16，绝对误差≤1/16。23/16这个分数本身是精确写出的有理数，但它作为√2的估计仍是近似，不能写成两者精确相等。

初始宽度W，更新n次且未精确命中时，宽度为W/2^n，中点误差≤W/2^(n+1)。从W=1要保证误差≤1/100，n=5时上界1/64仍太大，n=6时1/128合格，最少六次。这里求的是保证所需步数，不是声称实际误差恰等于上界。

### 例2：精确命中和前提失败

对x²−4在[1,3]试中点2，f(2)=0，直接停止，包围收为[2,2]，误差0。若起始区间就是[2,3]，应在任何更新之前识别端点根2。不能把零函数值硬归为正或负，继续执行不适用的分支。

1/x在[−1,1]两端异号，却在0无定义，闭区间连续性失败，实际上没有任何零点。另一方面，x²在[−1,1]两端同为正，却有根0；异号判据不适用不能推出无根。对x²−2在[2,3]同号，也只能说当前二分启动条件不成立，要另作分析才谈有无根。

## 残差与位置误差

|f(m)|叫残差，量的是函数值离零多远；|m−r|是横坐标误差。把函数乘一个很小常数会使残差很小，却不改变根和位置误差，因此不能自动等同。二分法的保证来自“根仍在区间中”，不依赖显示小数看起来稳定。多个根时，它保证保留下来的某个根，不自动找到全部根。

工作台保留精确分数、旧端点、所试中点和符号，另列更新后的区间、中点与误差界。无保证时不提供伪造的误差任务；不连续图分两支画，绝不跨0连线。图只是辅助，有限像素不证明连续性或根存在。

出口报告前三步、误差公式与两个前提反例，由人审核。家庭纸笔挑战可先给出所需误差，再预测更新次数，手算检查区间是否始终包围根。家长问“报的是估计还是上界”和“哪个条件保证根在里面”，而不是只追问小数位数。

# Numerical methods and approximation

A numerical method should identify the estimated quantity and justify its error. This lesson studies bisection: retain half of a certified root interval at each update, then use the current midpoint to estimate a root location. The midpoint is the approximation; half the width is an absolute-error bound. These are different quantities.

## Preserve a root enclosure

Check continuity on the entire closed interval first, then check whether either endpoint is already a root. If neither is a root and endpoint values have opposite signs, continuity guarantees at least one root inside. Test midpoint m=(L+U)/2. Stop if f(m)=0; otherwise retain the half with opposite endpoint signs. Each update preserves continuity and an enclosed root, not merely a shrinking list of numbers.

### Example 1: Three updates and an error guarantee

For x²−2 on [1,2], continuity holds and endpoint values are −1 and two. First test 3/2, with function value 1/4, and retain [1,3/2]. Next test 5/4, with value −7/16, and retain [5/4,3/2]. Third test 11/8, with value −7/64, and retain [11/8,3/2].

After three updates the current interval midpoint is (11/8+3/2)/2=23/16. It differs from the third tested midpoint 11/8. The interval width is 1/8, so the enclosed root is at most 1/16 from the current midpoint. Report √2 approximately 23/16 with absolute error at most 1/16. The fraction specifies the rational estimate exactly; it does not make that estimate equal to the irrational root.

From initial width W, n updates without an exact hit give width W/2^n and midpoint error at most W/2^(n+1). With W=1, a guarantee of at most 1/100 needs at least six updates: five gives only 1/64, while six gives 1/128. This determines the steps needed for the bound, not the exact realised error.

### Example 2: Exact hits and failed prerequisites

For x²−4 on [1,3], the first midpoint is two and its function value is zero. Stop with the singleton enclosure [2,2] and zero error. Starting instead from [2,3] should detect the endpoint root before any update. Do not classify a zero value as positive or negative just to continue the procedure.

The function 1/x has opposite endpoint signs on [−1,1], but is undefined at zero. Closed-interval continuity fails, and this function has no zero. Conversely, x² has positive values at both endpoints of [−1,1] but a root at zero. Failure of the sign-change test does not establish that no root exists. Same-sign values of x²−2 on [2,3] likewise mean the stated initial certification is unavailable; a separate argument is needed to conclude anything stronger.

## Residual versus location error

The residual |f(m)| measures vertical deviation from zero. Location error |m−r| is horizontal. Multiplying a function by a very small constant reduces its residual without moving its roots or changing location error, so the two quantities are not automatically equal. Bisection’s guarantee comes from retaining a root inside the interval. For multiple roots it encloses some retained root, not necessarily every root.

The workbench keeps exact fractions and separates old endpoints, the midpoint tested for sign, and the updated interval’s midpoint and error bound. Invalid prerequisites suppress unsupported approximation tasks. The discontinuous graph has separate branches rather than a line across zero. A finite plot cannot prove continuity or root existence.

The exit reports the three updates, error argument and prerequisite counterexamples for human review. As a paper challenge, choose a target error before predicting the required number of updates. Check that the root enclosure persists at each step. Ask whether the reported number is an estimate or a bound and which condition certifies a root inside, rather than judging the result merely by its number of decimal places.
