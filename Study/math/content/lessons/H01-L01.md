# 集合与元素

先把桌上的数字卡记成清单：0、1、1、2。若问题是“抽到1的次数”，重复记录很重要；若问题是“出现过哪些不同的数”，我们关注的是集合。这两种对象服务不同的问题，不能丢掉数据清单的频数后还声称频数没变。

## 一条核心想法

**集合是由确定的、不同的对象组成的整体；组成它的对象叫元素。** 本课只讨论数作为元素的有限集合。规则必须能判断某个对象是否符合：“小于6的正整数”明确，“好看的数字”未给标准，不够明确。

用花括号列举元素：A={0,1,2}。集合不计顺序，也不重复计算同一元素，因此{0,1,1,2}、{2,1,0}都表示A。重复不是新的数，换位置也不会创造新的元素。

- 0∈A读作“0属于A”，左边是一个元素，右边是集合。
- 3∉A读作“3不属于A”。不属于不是说3这个数不存在。
- B⊆A读作“B包含于A”或“B是A的子集”：B中的每个元素都在A中。本课⊆允许两集合相等。

不能把∈和⊆随意互换。数0与集合{0}是不同对象。在这个数字集合中可写0∈A和{0}⊆A。更一般的数学允许集合本身作元素，但那需要另行定义的嵌套集合，本工作台没有使用。

### 例1：按边界列出集合

列出小于7的正偶整数。逐个读限定：整数排除1.5；偶数排除1、3、5；正数排除0与负数；小于7保留2、4、6而不保留8。结果是{2,4,6}。

再用“每个留下的符合吗？每个符合的都留下了吗？”核验。只写{2,4}虽然没有错误成员，却漏掉6，仍不是完整答案。若条件改成“非负偶整数”，0才加入；“正”和“非负”不是同一个边界。

### 例2：零、空集与单元素集合

∅={}表示空集，一个元素也没有；{0}中有数0这一个元素；0本身是一个数。因此0、∅、{0}不能画等号。问元素个数时，∅为0个，{0}为1个。

空集是每个集合的子集：没有一个空集元素能违反“每个元素都在A”的要求，所以∅⊆A；也有A⊆A。对数字集合{0,1}，0∈{0,1}成立，但0∈∅不成立。这一解释以后会连接“没有反例”的逻辑。

## 操作时先预测

先选重复清单，再换顺序，分别预测不同元素个数。切换到空集与{0}，说出差异。再把查询从“元素属于”改成“集合包含于”：左边原来查0，现在查{0}，关系符号也要相应改变。点击显示元素卡之前先写答案。

## 自己检查与迁移

为书桌卡片自定一个明确规则，例如“编号在1到8之间且是3的倍数”。先说明编号只取整数，再列{3,6}。家长检查规则是否能执行、是否漏数，以及孩子能否解释∈与⊆的两种对象。若仍混淆，回到三张卡：数0、空盒子、装着0的盒子；盒子比喻帮助区分对象，但数学集合不依赖真实容器。

# Sets and elements

Record the cards on a table as a list: 0,1,1,2. If the question is “How many times was one drawn?”, repetition matters. If the question is “Which distinct numbers appeared?”, we need a set. A data list and a set answer different questions. Removing repeated records changes frequency information even when it does not change the set of observed values.

## One central idea

**A set is a collection of definite, distinct objects, called its elements.** This lesson uses finite sets of numbers. A rule must determine whether a candidate belongs. “Positive integers below six” is definite; “beautiful numbers” lacks a criterion here. Uncertainty about your calculation is different from a rule that is undefined.

Use braces: A={0,1,2}. Order and repetition do not change a set. Thus {0,1,1,2} and {2,1,0} denote A. Rewriting a number does not create another distinct number.

- 0∈A means zero is an element of A.
- 3∉A means three is not an element of A; it does not mean three does not exist.
- B⊆A means every element of B is also an element of A. Our symbol ⊆ allows equality.

Membership relates an element to a set. Subset containment relates two sets. The number 0 and the set {0} are different objects: 0∈A and {0}⊆A are appropriate here. In more general mathematics, sets can themselves be elements, but that requires a specified set of sets. This numerical workbench does not use nested sets.

### Example 1: List a set by its boundaries

List positive even integers below seven. Read all four restrictions: integer excludes 1.5; even excludes 1,3,5; positive excludes zero and negative integers; below seven excludes eight. The result is {2,4,6}.

Audit in two directions. Does every listed element satisfy the rule? Has every qualifying element been listed? {2,4} has no invalid member but omits six, so it is incomplete. If “positive” changes to “nonnegative”, zero enters. These boundary words are not interchangeable.

### Example 2: Zero, empty set and singleton

∅={} is the empty set, containing no elements. {0} contains one element, the number zero. Zero itself is a number. Their cardinalities differ: ∅ has zero elements and {0} has one. Do not write 0=∅={0}.

The empty set is a subset of every set. There is no element of ∅ that violates “every element is in A”, so ∅⊆A. Also A⊆A. For the numerical set {0,1}, 0∈{0,1} is true whereas 0∈∅ is false. The empty subset argument will later connect to implications with no counterexamples.

## Predict before revealing

Choose the repeated source list, predict its distinct count, and then reorder it. Switch between an empty set and a singleton containing zero. Change the relation from element membership to subset containment: the candidate object changes from 0 to {0}, so the relation must change too. Write a prediction before displaying the element cards.

## Transfer and parent check

Invent a definite card rule: “integer labels from one through eight that are multiples of three”. Its set is {3,6}. State the integer domain, audit missing and extra members, and explain the two kinds of relation. If the objects remain confusing, compare three cards: the number zero, an empty box, and a box containing zero. A box is only a helpful analogy; mathematical sets do not require physical containers. The parent reviews the explanation rather than accepting vocabulary alone.
