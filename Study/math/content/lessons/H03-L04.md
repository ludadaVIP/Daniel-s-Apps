# 对数是指数的逆运算

知道底数2、指数3，可以算出8。现在保留底数和输出8，反过来问指数是什么。对数给这个“未知指数”一个专门的名字。

## 一条核心想法

**logₐb=c，当且仅当aᶜ=b；实数范围要求a>0、a≠1、b>0。** a是底数，b是真数，c是对数值。对数不是除法，log₂8不是8÷2，也不是“log乘8”。

合法底数的指数函数在全实数域严格单调，且实际输出恰为所有正数，所以每个正真数有唯一指数。将输入输出交换得到对数函数：定义域(0,∞)，值域ℝ。底数大于1时两函数都递增；底数介于0和1时两函数都递减。

### 例1：指数可以负，也可以是分数

log₂(1/8)=−3，因为2⁻³=1/8。log₃1=0，因为3⁰=1。真数为1并不意味着对数等于1，要看未知指数。

log₄8=3/2，因为4^(3/2)=(√4)³=8。log_(1/2)8=−3，因为(1/2)⁻³=8。底数小于1完全合法；“真数较大所以对数一定为正”的结论需要先明确底数大于1。

### 例2：存在与唯一缺一不可

log₂(−4)没有实数意义，因为2ˣ始终为正，不可能等于−4。log₂0也没有有限实指数解，不能用“很负的指数接近0”代替达到0。

log₁1看似有解，因为1⁰、1¹、1²都等于1，但正因此没有唯一指数，所以不能定义这个对数。log₁7则连指数解都没有。底数1不能形成所需的逆函数。底数0或负数也不满足本课在整个实数指数域定义严格单调指数函数的条件。

## 反向对应实验

先预测对数，再显示指数图和对数图。P=(c,b)位于指数图，交换坐标的Q=(b,c)位于对数图；两轴单位长度相同，y=x是反射参照线。改变窗口不改变坐标或答案；曲线采样弧端并不是定义域边界。

切到底数1或非正真数时，实验解释无定义的原因，不给伪造数值。底数小于1时试一遍正负对数，并用原幂式核验。

## 迁移与家长核对

虚构模型12=3×2ᵗ，先除去初量3得到4=2ᵗ，再得t=log₂4=2。不能直接对12取log₂而忘记系数。家长让孩子读出“底数的几次方等于真数”，再检查三条定义条件；英语读题可以协助，指数推理留给孩子。下课在对数法则中复现逆向唯一性。

# Logarithms as inverse exponents

With base two and exponent three, calculate output eight. Now keep the base and output but ask for the exponent. A logarithm names that unknown exponent.

## One central idea

**logₐb=c if and only if aᶜ=b, with a>0, a≠1 and b>0 over the reals.** Here a is the base, b the argument and c the logarithm. A logarithm is not division: log₂8 is neither 8÷2 nor a product involving a quantity called “log”.

For a valid base, the exponential function is strictly monotone on all real inputs and has exactly the positive reals as its range. Each positive argument therefore has one unique exponent. Reversing inputs and outputs gives the logarithm, with domain (0,∞) and range ℝ. Bases above one make both functions increasing; bases between zero and one make both decreasing.

### Example 1: Exponents can be negative or fractional

log₂(1/8)=−3 because 2⁻³=1/8. Also log₃1=0 because 3⁰=1. An argument of one does not make the logarithm one; the requested object is an exponent.

log₄8=3/2 because 4^(3/2)=(√4)³=8. Also log_(1/2)8=−3 because (1/2)⁻³=8. Bases below one are valid. The claim that a large argument must yield a positive logarithm needs the additional condition that the base exceeds one.

### Example 2: Existence and uniqueness are both required

log₂(−4) has no real value because 2ˣ stays positive and cannot equal −4. Nor does log₂0 have a finite real exponent solution. Very negative exponents approach zero without ever reaching it.

log₁1 appears solvable because 1⁰, 1¹ and 1² all equal one. Precisely that multiplicity prevents a unique inverse exponent, so the logarithm is undefined. log₁7 has no exponent solution at all. Base one cannot form the required inverse function. Zero and negative bases also fail the conditions for the strictly monotone exponential function defined across the whole real exponent domain in this lesson.

## Reverse-correspondence experiment

Predict the logarithm before revealing both graphs. P=(c,b) lies on the exponential, while swapping coordinates gives Q=(b,c) on its logarithmic inverse. Both axes have the same unit length, and y=x is the reflection reference. Changing the window changes neither coordinates nor answers. The ends of sampled arcs are not mathematical domain boundaries.

Selecting base one or a nonpositive argument produces an explanation rather than a fabricated number. For a base below one, try both signs of logarithm and audit each using its original power statement.

## Transfer and parent check

In the fictional model 12=3×2ᵗ, divide out the initial quantity three before obtaining 4=2ᵗ and t=log₂4=2. Taking log₂12 directly would lose the coefficient. A parent can ask the learner to read “base to what power equals argument?” and then check all three domain conditions. Help with English reading if needed while leaving exponent reasoning to the learner. Retrieve inverse uniqueness again when deriving logarithm laws.
