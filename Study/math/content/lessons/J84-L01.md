# 不等号和解集

## 一个解与所有解

等式问“两边相等吗”，不等式问大小关系是否成立。`<` 是严格小于，`>` 是严格大于；`≤` 与 `≥` 还允许两边相等。例如二小于三为真，三小于三为假，而三小于或等于三为真。“至多”对应 ≤，“至少”或“不小于”对应 ≥；读题时要把方向与是否包含边界分开。

本课的 x 在实数范围讨论，既有正负整数，也有分数、小数等数。把某个值代入后关系成立，这个值就是一个解。**解集**是所有成立的值组成的集合。列出几个正确数只证明这些数是解，不能证明没有别的解。

数轴向右数值越来越大。用空心圆表示端点不包含，用实心圆表示包含；向左或向右的涂色表示这一方向的全部数，箭头表示继续，不在图的边框处停止。图窗只是展示范围，不是对 x 额外施加的限制。

### 例 1：x<3，不止零、一、二

第一步读方向：小于三的数在三左边。第二步核端点：把三代入得到三小于三，为假，所以三处画空心圆。第三步向左连续涂色，并画继续的箭头。

检查候选：二给二小于三，成立；2.9 也成立；负十同样成立；三与四不成立。因此写 `x<3`，或者换边写 `3>x`。不能只写边界数三，也不能用 `{0,1,2}` 代替完整解集。虽然屏幕可能只显示负五到五，负十仍是解。

把条件改成 `x≤3`，涂色方向不变，只把三处改为实心：三现在使等号成立。相差一个等号，会改变一个边界点是否属于解集，而不是把整个方向反转。

### 例 2：不小于负二

“实数 x 不小于负二”表示 x 可以等于负二，也可以更大，写 `x≥−2`。把负二代入为真，所以画实心；大于负二的数在右边，向右涂色。

负二、负一点五、零、六都符合；负三不符合。特别注意，负一点五比负二大，它在负二右边。若把图画成向左，就会错误允许负三并错误排除零；若只改成空心，就只丢失负二本身。两种错误需要分开诊断。

这也说明“一个数不是整数”不代表它不能是解。除非题目明确限制为整数或计数，本课默认完整实数范围。

## 操作与解释

工作台先保留原条件。你可以代入一个候选数，分别读取左右数值与真假；再自行设置草图的边界、方向、是否包含并核对。草图初值是可修改的尝试，不是自动给出的答案。

十个整数样本只帮助观察。把一个样本改成分数，再挑一个图窗外的数，解释为什么也能判断。家长可用“边界代入会成立吗”和“这一方向还包括哪些看不到的数”检查理解；不把英语读句子的困难等同于数学不会。

# Inequality signs and solution sets

## One solution and the whole set

An equation asks whether two sides are equal. An inequality compares their sizes. The signs < and > mean strictly less and strictly greater; ≤ and ≥ also allow equality. Thus 2<3 is true and 3<3 is false, while 3≤3 is true. “At most” means ≤, and “at least” or “no less than” means ≥. Separate direction from inclusion when reading.

Here x ranges over the real numbers, including integers, fractions and decimal values. A value is a solution if substituting it makes the comparison true. The solution set contains **every** such value. A few successful examples do not establish a complete set.

Numbers increase to the right on a number line. An open circle excludes an endpoint; a filled circle includes it. Continuous shading represents all values in that direction, and an arrow continues beyond the displayed window. The screen edge is not an extra restriction on x.

### Example 1: x<3 includes more than zero, one and two

First read the direction: smaller values lie left of three. Next test the endpoint: three gives 3<3, which is false, so draw an open circle. Shade continuously left and add a continuation arrow.

Two, 2.9 and minus ten all pass; three and four fail. Write x<3 or the equivalent 3>x. The boundary three alone is not the answer, and {0,1,2} omits many solutions. Minus ten still passes even if the screen only displays minus five to five.

Changing the condition to x≤3 keeps the shading direction and fills the point at three. Equality changes inclusion of the boundary, not the direction of the whole set.

### Example 2: no less than minus two

“Real x is no less than minus two” allows equality and larger values, so write x≥-2. The endpoint passes, so fill it and shade right.

Minus two, minus one and a half, zero and six pass; minus three fails. Minus one and a half lies to the right of minus two. Leftward shading would wrongly admit minus three and reject zero. An open endpoint would instead lose only minus two. Diagnose these separately.

A value need not be an integer to be a solution. Unless a task specifies counts or an integer domain, use the entire real range.

## Investigate and explain

The workshop retains the original condition. Test a candidate, reading both evaluated sides and the truth value. Then build a sketch by choosing its boundary, direction and inclusion. Its initial state is an editable attempt rather than a supplied answer.

Ten integer samples support observation without representing every solution. Try a fraction and a value outside the window, and justify both. A parent can ask whether the endpoint passes and which unseen values continue in the shaded direction. Difficulty reading English need not indicate difficulty with the maths.
