## 等号是关系，不是“接下来算”

**等号 =** 表示左边的值与右边的值相等。两边都可以是算式，未知数可以在任一边。12=7+5 和 7+5=12 表达同样的相等关系；交换等号两边不会把十二变成另一数。

代数天平帮助表达这种关系，但示意图的横线看起来水平，不是严格相等的证据。要核对两边的数值，或说明已知关系为何保留。每个单位点代表一个计数单位，本题相同方框代表同一个未知数。未试代前的水平摆放只是在展示符号两边。

### 例 1 · 两边都有式子

1. 求 **8+4=□+5** 的方框。
2. 左边值 **8+4=12**；右边必须也为十二，而不是方框直接填十二。
3. 右边已有五，所以 **□=12−5=7**。
4. 代回：左边十二，右边 **7+5=12**，相等。
5. 两边各加三，得 **8+4+3=□+5+3**；七仍满足，两边都是十五。只给右边加三，会让右边十五、左边十二。

### 例 2 · 减去同量不会“造出相等”

1. 比较 **□+3** 与 **11**，先试方框四。
2. 左边 **4+3=7**，右边十一，本来不相等，右边大四。
3. 两边都减一，变成 **□+2** 与 **10**。候选四给六与十，仍相差四。
4. 若原候选是八，起初十一与十一相等；两边同减一后十与十，仍相等。
5. 同量加减保留两边的差，因此保留原有相等关系；它不会把错误候选自动变成正确答案。

### 连等式必须段段等值

写 7+5=12+4=16 来记录“先算，再加四”是不成立的：第一段值十二，后两段十六。可以另写两行 **7+5=12**、**12+4=16**；也可若本来求整体加四，写 **(7+5)+4=12+4=16**。时间先后与数值相等是不同关系。

“两边作相同操作”还要检查操作有定义。两边同除一个非零数可以保留相等；两边除零没有定义。这个限制将在一步方程中继续使用。天平拿走实物时也要先有足够的对象；不能把图中负的格数冒充拿走后的实物。

工作台可以两边各加减一个单位点或相同未知方框，也可以故意只改左边，对比两种做法。每次改变后重新试代，避免旧的对错标签留在新图里。观察数字差，比凭图形“像平衡了”更可靠。

**带走一个发现：** 等号两边有同样的值。交换两边保留关系；合法同量操作保留原有相等，却不会修正错误候选或允许除零。

## Equality is a relationship, not a next-step command

The **equal sign =** says that both side values agree. Both sides may contain expressions, and an unknown may appear on either. 12=7+5 and 7+5=12 state the same equality.

An algebraic balance illustrates this relationship. A horizontal line is not proof of equality: compare values or justify a transformation. Every dot is one count unit, and identical boxes in this problem represent one unknown. Before checking a trial, level placement simply displays the symbolic sides.

### Example 1 · Expressions on both sides

1. Find the box in **8+4=□+5**.
2. The left is **12**, so the entire right must also be twelve; the box itself is not twelve.
3. The right already contains five: **□=12−5=7**.
4. Substitute: both **8+4** and **7+5** equal twelve.
5. Add three to both sides: **8+4+3=□+5+3**. Seven still works and both sides are fifteen. Adding three only on the right breaks the original equality.

### Example 2 · Same subtraction does not create equality

1. Compare **□+3** and **11**, trying four.
2. The values are seven and eleven, with right greater by four.
3. Subtract one from both: **□+2** and **10** give six and ten. The difference remains four.
4. Trying eight originally gives eleven and eleven; subtracting one leaves ten and ten.
5. Identical addition/subtraction preserves the difference and hence an existing equality. It does not correct a wrong candidate.

### Every part of an equality chain must agree

7+5=12+4=16 is invalid as a record of “calculate, then add four”: its first value is twelve and the others sixteen. Use separate lines, or, when adding four to the whole expression, write **(7+5)+4=12+4=16**. Calculation sequence differs from equality.

Identical operations must also be defined. Dividing both sides by the same nonzero number is valid; dividing by zero is not. Removing material counters requires enough matching objects, rather than drawing negative object counts.

Compare operations on both sides with deliberately changing only the left. Each change clears the old trial comparison. Inspect the numerical difference instead of claiming equality because the drawing looks level.

**Takeaway:** equality relates two values. Reversing sides retains it, and valid identical operations preserve it. They neither repair wrong candidates nor permit division by zero.
