# 三维坐标与向量

空间点用有序三元组(x,y,z)描述。屏幕画成二维，并不意味着第三坐标可以丢掉。本课把**点的位置、两点位移、位移长度**分开，再用同一组坐标核对它们。

## 点与位移不是同一个对象

选定互相垂直、单位一致的x、y、z轴和原点O后，P(x,y,z)表示一个点。向量OP的分量恰为(x,y,z)，这是起点在原点的特殊情形。若起点改为A(x₁,y₁,z₁)、终点B(x₂,y₂,z₂)，AB=(x₂−x₁,y₂−y₁,z₂−z₁)，不能直接抄B。

在固定坐标系共同平移两个端点，相减时平移量抵消，所以自由向量的分量不变。方向也要保留：BA=−AB；两反向位移长度相同，向量却不同。若A=B，位移为零向量，长度0，但没有确定方向。

中点逐坐标取平均。位移长度由三维勾股得到：|AB|²=(Δx)²+(Δy)²+(Δz)²。先在xy平面合成前两项，再与垂直的z位移合成，得到三项平方和；最后开非负根。

### 例1：同一组点，核对不同对象

A(1,−2,3)、B(4,2,−1)，AB=(3,4,−4)。负的第三分量表示沿负z方向，不表示负长度。|AB|=√(9+16+16)=√41；只用前两项得到5，漏掉了真实空间位移。

中点M=((1+4)/2,(−2+2)/2,(3−1)/2)=(5/2,0,1)。BA=(−3,−4,4)，长度仍√41。B在xy平面的正投影是(4,2,0)，而不是原点或删成二元组；空间中这个投影点仍有第三坐标0。

### 例2：共同平移不改变位移

在同一坐标系把两点同加t=(2,−1,1)，得到A′(3,−3,4)、B′(6,1,0)。B′−A′=(3,4,−4)，与AB相同。中点却从(5/2,0,1)变成(9/2,−1,2)，也恰好平移t。

这次操作是移动两个物理点、保留坐标轴。若改换原点，则同一个物理点的坐标也会改变，但两点位移仍可相减抵消共同变化。不要把“点坐标变了”误当成“自由向量必变”。

## 用工作台核验，而不是量屏幕

先选基准A、B，再选择是否共同平移。分别预测AB、M、|AB|。共同平移后，AB与长度的已作答预测保留，中点预测需重新计算。换相机只改变正投影，所有数学答案保留。

正投影会缩短线段，也可能让不同空间点在画面重合。图中合并名字不代表空间坐标相同，精确表保留每个点。箭头按真实起终点绘制；零向量画点，不给它捏造朝向。

出口要给新端点、旧新位移和中点，用抵消说明不变量。家长可让孩子指认“这是点”“这是向量”“这是实数长度”，再进入下一课的三分量线性运算。

# 3D coordinates and vectors

An ordered triple (x,y,z) describes a point in space. A 2D screen does not remove the third coordinate. Distinguish **point position, displacement and displacement length**, then verify all three from coordinates.

## Position and displacement differ

Choose an origin and mutually perpendicular x,y,z axes with equal units. Point P has coordinates (x,y,z). Vector OP has those same components only because its tail is the origin. For A(x₁,y₁,z₁),B(x₂,y₂,z₂), displacement is AB=(x₂−x₁,y₂−y₁,z₂−z₁), rather than simply B’s coordinates.

Translating both endpoints in a fixed frame cancels the common translation in subtraction. A free vector retains its components. Direction matters: BA=−AB, with the same length but a different vector. When A=B, displacement is zero, with length zero and no defined direction.

Average each endpoint coordinate for a midpoint. Spatial Pythagoras gives |AB|²=(Δx)²+(Δy)²+(Δz)²: combine x,y in their plane, then combine that displacement with perpendicular z. Take the nonnegative root for length.

### Example 1: Different objects from the same points

For A(1,−2,3),B(4,2,−1), AB=(3,4,−4). The negative z entry indicates direction, not negative length. The length is √41. Using only x,y gives five and omits part of the spatial displacement.

The midpoint is (5/2,0,1). Reverse displacement BA=(−3,−4,4) still has length √41. The orthogonal projection of B onto the xy-plane is (4,2,0); it remains a spatial triple with z=0.

### Example 2: A shared translation preserves displacement

Add t=(2,−1,1) to both endpoints in the fixed coordinate system. New points are A′(3,−3,4),B′(6,1,0). Their difference is again (3,4,−4). The midpoint changes to (9/2,−1,2), exactly the old midpoint plus t.

This operation moves both physical points while retaining the axes. Changing the origin instead changes coordinates of fixed points, but their shared coordinate change still cancels in a displacement. A changed point coordinate need not mean a changed free vector.

## Audit coordinates instead of measuring the screen

Choose base points and a shared translation, then predict displacement, midpoint and length separately. A translation preserves displacement and length predictions but changes the midpoint task. Camera changes preserve every mathematical answer.

Orthographic projection shortens segments and can overlay distinct spatial points. Shared display labels do not imply identical 3D coordinates; the exact table retains each point. Arrows follow actual tails and heads, and a zero vector is a point without an invented direction.

The exit compares endpoints, displacements and midpoints before and after translation. Explain cancellation. Identify which objects are points, vectors and scalar lengths before moving to componentwise operations.
