# 极限的直觉

极限研究“输入靠近a但不等于a时，输出靠近什么”。函数在a本身的值是另一项信息。两者可能相同、不同，甚至其中一项存在而另一项未定义。不要仅看图上那个实心点，就替整个邻域作结论。

## 左、右与点值分开

本课研究有限的双侧极限。左边所有足够近的输入与右边所有足够近的输入，函数值须趋向同一个有限数L，才说lim(x→a)f(x)=L。不是把某几个点算术平均，也不要求函数必须取到L。

连续还多要求f(a)有定义，而且等于上述双侧极限。这解释为什么“极限存在”并不等于“函数在该点连续”。若左右趋向不同值，双侧极限就不存在；本课用does-not-exist表示，不以某侧点值代替。

有限数表是观察工具：它可能漏掉另一侧或更靠近处的不同表现。对本课给定的简单完整规则，可用约分恒等式或分段定义解释全邻域；没有完整规则时，不把有限样本当作通用证明。

### 例1：空洞与补点

f(x)=(x²−1)/(x−1)，原定义要求x≠1。分子分解为(x−1)(x+1)，在x≠1的邻域内约去后，值等于x+1。于是x从两侧趋近1时，输出趋近2。

原来的f(1)仍未定义，因为约分不改变原定义域。另造函数g，在x≠1时也取x+1，却规定g(1)=5，则极限仍为2、点值变5。两者在1都不连续；只有把缺失点补为2，才能与邻域值连续接上。点值是5并不会把附近的线整体上移到5。

### 例2：跳跃与连续尖点

h(x)=0当x<1，h(x)=2当x≥1。左极限0，右极限2，点值h(1)=2。两个方向不一致，所以双侧极限不存在。取平均1没有依据：附近左值一直0、右值一直2，都不会共同靠近1。

再看|x|在0。左、右函数值都趋0，实际点值也是0，所以在0连续。不过下一课会看到它的差商左−1、右1，没有共同导数。函数值的极限与变化率的极限是两项不同检查。

## 工作台与出口

模型分别显示空洞、补点、跳跃和绝对值。改变靠近距离δ，只改变左右样本位置；不会修改中心定义。空心端点排除该分支值，实心标记才是实际中心值。样本很近时改在精确表列出，避免实心样本盖住空心标记。跳跃两侧分别绘制，不用一条斜线跨过间断把不存在的值补出来。

先预测双侧极限，再预测中心点值。空洞点值输入undefined，跳跃的双侧极限输入does-not-exist；这两个代码描述的对象不同。改变补点时，未变的极限预测保留，点值预测则重新计算。

出口要把三种情形放在同一张“左、右、点值”表里，并讨论连续性。家长可先遮住中心点，让孩子只说两侧，再露出点值；这种分开读取能减少把极限直接代入原式的习惯。

# Intuition of limits

A limit concerns values at inputs near a but different from a. The function’s actual value at a is separate information. They may agree, differ, or exist independently. One filled dot does not determine the whole surrounding behaviour.

## Separate left, right and point value

We study finite two-sided limits. All sufficiently close inputs from either side must give values approaching the same finite number L. This is not an average of a few sampled values and does not require the function to attain L.

Continuity additionally requires a defined point value equal to the common limit. A limit can therefore exist without continuity at the point. If the two sides approach different values, there is no two-sided limit; enter does-not-exist rather than substituting the point value from one side.

A finite table supports observation but can miss another side or different behaviour closer in. For the complete simple rules here, cancellation identities or piecewise definitions explain an entire neighbourhood. Without a full rule, finite samples cannot prove general local behaviour.

### Example 1: A hole and a patched point

The original function f(x)=(x²−1)/(x−1) excludes x=1. For every allowed nearby input, factoring and cancellation give x+1. Hence values tend to two as inputs approach one from either side.

The original f(1) remains undefined: cancellation did not change its domain. Define another function g that equals x+1 away from one but has g(1)=5. Its limit is still two, while its point value is five. Neither function is continuous at one. Patching the hole with two would establish continuity; a point value five does not translate the neighbouring line upward.

### Example 2: A jump and a continuous corner

Let h(x)=0 for x<1 and h(x)=2 for x≥1. The left limit is zero, the right limit two and the point value two. Since the sides disagree, the two-sided limit does not exist. Their arithmetic mean one is not a limit: nearby left values remain zero and nearby right values remain two.

For |x| at zero, both value limits and the actual point value are zero, so the function is continuous. The next lesson will show its quotients approaching −1 and one instead. A limit of function values and a limit of rates are separate investigations.

## Explore and explain

Choose the hole, patch, jump or absolute value. Changing approach distance moves the left and right sample positions without rewriting the centre definition. Open marks exclude branch endpoints; filled marks show actual point values. Very close samples remain in the exact table rather than covering the open mark with filled dots. Separate jump branches prevent a drawn bridge from inventing intermediate values.

Predict the two-sided limit and centre value separately. Undefined is appropriate for the hole’s point value; does-not-exist describes the jump’s two-sided limit. When a patched value changes, a still-valid limit prediction remains while the changed point-value prediction clears.

For the exit, compare left limit, right limit and point value for all three discontinuous cases, then discuss continuity. A parent can cover the central dot while asking about the sides and reveal it afterward, separating the limit question from direct substitution.
