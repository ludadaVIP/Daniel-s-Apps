# 从表格到图像

## 一行对应一个有序点

表格把输入与输出配在同一行。把它转为坐标图时，输入通常在横轴，输出在纵轴；每行构成一个有序数对。不能把第二行的输入与第三行的输出相配，也不能只按数值大小排序后破坏原关系。

先标轴名、单位和均匀刻度，再描点。若 x 代表件数，y 代表费用，不能把两轴都写成厘米；若 x 为时间，必须说明分钟还是小时。相邻格距均匀，不等于每相邻观测的时间差相同，点的横位置要来自真正输入值。

### 例 1：给定规则生成同行数据

已给 `y=2x+1`，当 x 依次为零、一、二、三，输出依次为一、三、五、七。对应点是 `(0,1)`、`(1,3)`、`(2,5)`、`(3,7)`。例如 x=2 这一行必须配 y=5，不能误与邻行的三或七相配。

若 x=−1，则 `y=2×(−1)+1=−1`，点为 `(−1,−1)`。负输入也应按同一规则计算，不改成正数。工作台先隐藏最后一行输出，自己计算后再展示图，检查表与点是否表达同一关系。

### 例 2：点能不能连，要看输入含义

虚构整数份数 n 为零、一、二、三，费用 `C=2n+3` NZD。四点为 `(0,3)`、`(1,5)`、`(2,7)`、`(3,9)`。固定三只加一次。若 n 是完整件数，就只允许这些整数输入，不能在两点中间自动添加半件及对应费用。

另一题明确给连续模型 `y=4−x`，`0≤x≤3`，则 `x=3/2` 有定义，输出 `5/2`。在这个范围内可画出关系线，因为模型明确允许中间输入；不是因为点排得顺眼就连线。超过范围仍需新的假设，不能沿线无限外推。

## 记录不是整条模型的证明

若表只记录三行 `x=−2、0、3` 与 `y=−5、−1、5`，最后一行就是 `(3,5)`。这些点与 `y=2x−1` 相容，但表本身没有保证其他输入也服从它；还可能有经过相同点的其他关系。只有题设另给线性模型，才可在该模型内求参数与预测。

工作台的“连续模型/整数份数”切换改变允许输入和是否连线，不改变同一行配对的规则。图线来自给定规则，不是假装从四点自动证明出线性。已知的函数模型、真实观测记录和辅助连线应明确区分，后续统计课程会继续讨论证据与误差。

家长请孩子指认表中某行与图中哪点相同，说明轴单位，最后问连线的依据。如果答案只是“数学图都要连”，给整数件数与连续时间两个反例比较。核心是保存关系并尊重允许输入，不是把表格装饰成一条漂亮线。

# From tables to graphs

## One row gives one ordered point

A table pairs an input and output in the same row. Usually the input goes horizontally and output vertically. Preserve that pairing: do not combine neighbouring rows or independently sort the columns and destroy the relationship.

Label quantities, units and uniform intervals before plotting. Count versus cost uses different meanings and units on the axes. Time must distinguish minutes from hours. Uniform grid spacing does not imply uniformly spaced observations: horizontal positions follow the actual input values.

### Example 1: generate rows from a supplied rule

Given `y=2x+1`, inputs zero, one, two and three give outputs one, three, five and seven. The points are `(0,1)`, `(1,3)`, `(2,5)` and `(3,7)`. Input two must pair with five from that same row, not three or seven from a neighbouring row.

At x=−1, substitution gives y=−1 and point `(−1,−1)`. Do not change a negative input to positive. The workshop initially hides the last output, then displays the graph so you can compare table and plotted relationship.

### Example 2: whether to connect depends on the domain

Fictional integer counts n=0,1,2,3 have cost `C=2n+3` NZD, yielding `(0,3)`, `(1,5)`, `(2,7)`, `(3,9)`. The fixed three is added once. Whole items permit those integer inputs, not automatic half-item values between points.

A separate supplied continuous model `y=4−x` on `0≤x≤3` permits x=3/2 and y=5/2. Its relationship may be drawn across that interval because the model permits intermediate inputs, not merely because samples look aligned. Extending outside the domain needs another premise.

## Observations do not prove a complete model

A table recording x=−2,0,3 paired with y=−5,−1,5 gives final point `(3,5)`. These samples fit y=2x−1, but do not guarantee its outputs elsewhere. Other relationships can pass through the same points. A separately supplied linear premise permits parameter determination within that model.

Switching the workshop between continuous and integer inputs changes the domain and connection, while preserving same-row pairing. Its line comes from a supplied rule, not a claimed proof from four samples. Distinguish a model, observations and an illustrative connection; later statistics will revisit evidence and uncertainty.

A parent asks which row supplies a selected point, what each axis measures and why a connection is allowed. If the only reason is that graphs always connect points, compare whole-item counts with continuous time. Preserve relationships and valid inputs rather than decorating a table with a convenient line.
