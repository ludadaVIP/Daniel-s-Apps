# 组织两三步几何证明

## 每一步的条件先到位

短证明不要求写很多话，但每一句都应有依据。先列原始已知与待证，按需要加入明确辅助构造，再把可用的对应边角集合起来选择全等判据，最后推出对应结论。一个“大步骤”可以包含列举两个已知等量与一条公共边，但不能隐藏缺失或循环的前提。

公共边与自身相等是自反性，不必拿尺子量；内错角相等需要已有平行，不能只因两条线在图上看似平行就使用；构造角平分线会提供两个角相等，不会自动提供待证边相等。证明卡片检查只核这些明确依赖，不等于理解任意自由文字证明。

### 例 1：从两组平行证对边相等

已知 AB∥CD、BC∥AD，待证 AB=CD。连 AC。第一步，由各组平行得 BAC=DCA、BCA=DAC，且 AC=CA。两个角的顶点是 A/C，公共边正夹在它们之间，ASA 得 `△ABC≅△CDA`。

第二步，按 A↔C、B↔D、C↔A 匹配，AB 对应 CD，所以 AB=CD。若改写成 △ABC≅△CAD，会乱换对应，不能只因三个字母都出现就认为一样。

若在还没有两组角与公共边时提前写全等，需要补齐依据。如果说“AB=CD，因为平行四边形对边相等，而本题正要从定义证明这个性质”，就是直接引用目标。日后可以使用已证定理，但这道练习的证明范围明确不把它当可引用的前提。

### 例 2：等腰与角平分线

已知 AB=AC，AD 是 A 的内角平分线，D 在 BC 上，待证 BD=DC。先列 AB=AC（给定）、BAD=CAD（构造）、AD=AD（公共），SAS 得 `△ABD≅△ACD`，随后对应底边段 BD=DC。

若先写“D 是中点，所以 BD=DC”，就把目标塞进新假设。题目只说角平分线，不是给了中点。也不能先用 BD=DC 构成 SSS，再取回同一个结论；卡片工作台会指出这种循环。

改变待证问题后要重新核依赖。例如从等底角反推两腰相等，需要 AAS/ASA，而不能继续使用原证明中作为已知的腰相等。一个正确模板只有在原始条件相同、对应也保持时才能迁移。

## 审查与修复

面对“量屏幕两角约相等，所以 SAS”，应指出两处：近似测量不是精确等角证明，且还要核两边对应与夹角位置。可接受依据包括原始相等条件、公共边、明确角平分构造、已有平行导出的角关系，以及先前已证明的结论。

工作台允许先尝试一张缺依赖的卡，查看缺哪些前提；逐一建立后才加入记录。撤回最后一步会重新计算当前已知，若拿掉对应结论，目标状态随之退回未证。换案例清旧记录，不把另一问题的成功搬过来。自由证明仍在正式练习由家长逐步核对。

家庭挑战只需纸笔：画虚构花坛三角形与简单四边形，标清已知，写一条短证明，再设计 AAA、SSA 或一组平行的反例，修复一条循环论证。不要用像素或真实测量充当精确依据；无需购物、外出测量或个人资料。

# Structuring short geometric proofs

## Establish premises before using them

A short proof needs justified statements rather than many words. State givens and target, add an explicit auxiliary construction if useful, collect corresponding elements, invoke a valid criterion, then draw matching conclusions. A major step may collect several facts without hiding missing or circular dependencies.

Common sides use reflexivity, not measurement. Alternate-angle equality needs parallel premises. A bisector supplies equal angle halves, not whichever side equality is targeted. Finite proof-card checking does not understand arbitrary free-text proofs.

### Example 1: opposite sides from parallel pairs

Given AB∥CD and BC∥AD, target AB=CD. Draw AC. Parallelism gives BAC=DCA,BCA=DAC, and AC=CA is common. The side lies between the supplied angle vertices, so ASA establishes △ABC≅△CDA.

Now A↔C,B↔D,C↔A matches AB with CD, yielding the target. Writing CAD instead of CDA would change correspondence; using the same three letters is insufficient.

If congruence is claimed before its angle/side premises, fill those gaps. Citing the very opposite-side property being proved from the definition is circular within this exercise. An established theorem can be used elsewhere, but this task explicitly starts without that target property as a premise.

### Example 2: equal legs and a bisector

Given AB=AC and internal apex bisector AD meeting BC, target BD=DC. Collect AB=AC from the givens, BAD=CAD from construction and AD=AD from reflexivity. SAS gives △ABD≅△ACD, then corresponding BD=DC.

Calling D a midpoint first would introduce the target as a new assumption. A bisector was given, not a midpoint. Using BD=DC for SSS and then deriving it again is equally circular.

A changed target may require a different chain. Equal base angles implying equal legs uses AAS/ASA rather than assuming the equal legs used in the forward proof. Templates transfer only when their actual premises and correspondence remain valid.

## Audit and repair

“The screen angles measure approximately equal, therefore SAS” lacks exact angle evidence and still needs the correct side pairs and included angle. Valid reasons include givens, common sides, explicit constructions, parallel-angle facts and earlier established conclusions.

The workshop identifies missing dependencies before recording a card. Undo recomputes the fact set, removing a target if its concluding step is withdrawn. A new case resets the chain. A parent reviews each step of written proofs independently.

On paper, invent fictional garden triangles and a simple quadrilateral, mark givens, give a short proof and construct an AAA, SSA or one-parallel-pair counterexample. Repair a circular argument. No purchases, real measurements or personal data are required.
