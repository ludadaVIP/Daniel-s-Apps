# 反函数的概念

原函数把输入送到输出，反函数想从输出回到原输入。但平方把−2与2都送到4，倒着走就遇到岔路。交换箭头可以得到一个关系，未必得到一个函数。

## 一条核心想法

**以原函数的实际值域为新定义域，每个新输入若恰好有唯一原像，才得到反函数。** 原函数因此须一对一；它的普通函数资格却不需要一对一。反函数的定义域是原函数实际值域，反函数的值域是原定义域。陪域若含未用值，应先取实际值域，不能强迫那些没有原像的值倒着走。

f⁻¹是反函数记号，不是1/f。倒数对同一输入的输出取倒数，输出为0时还无定义；反函数反向恢复输入，是另一项任务。图上交换(x,y)成(y,x)，对应关于y=x的镜像；观察这个镜像仍要检查是否单值。

### 例1：线性规则反向恢复

f(x)=2x+3，D=[−2,4]。原函数严格增，实际值域[−1,11]。由y=2x+3解回x=(y−3)/2，所以f⁻¹(y)=(y−3)/2，定义域[−1,11]，值域[−2,4]。

例如输出7回到(7−3)/2=2，再核f(2)=7。若把反函数错写1/(2y+3)，在y=7得到1/17，没有恢复输入。原像查询也须先核输出是否真的出现：y=12不在实际值域，不能用更广的代数式偷偷扩大这个给定函数的逆域。

### 例2：平方的两支与域的限制

f=x²、D=[−3,3]的值域[0,9]，但输出4有两个原像±2，所以没有[0,9]上单值的反函数。水平线y=4与原图有两个交点；交换坐标后，同一新输入4产生两个输出。输出0恰好只有原像0，也不足以证明每个输出都唯一。

限制原域到[0,3]后，逆为√y，逆域[0,9]、逆值域[0,3]；限制到[−3,0]后，逆为−√y，逆域仍[0,9]，逆值域[−3,0]。负支输出4回−2，不能机械取正根。输出2的正支原像是精确√2，1.41只是近似，不是精确反向恢复。

## 工作台：整体性质与一次查询

先预测整体可逆性，再改变输出y查全部允许原像。换查询不清除整体性质预测，因为函数没有改变；若换原域，整体可逆性和逆域都要重新判断。

紫色为原函数，金色为交换坐标后的关系，虚线y=x作参照。完整平方的金色双支不能标成“反函数图”；限制域才选定一支。坐标轴同单位标尺帮助观察镜像，但图上的若干采样点仍不代替对每个实际输出的唯一性论证。

## 收尾与家长核对

让孩子分别说明“原来是函数吗？”与“反向后还是函数吗？”，用4的两个原像说明差异。再要求写正、负平方分支的域和值域，核一次往返恢复。出口保留人工审核，不能仅因写出√y就忽略原域、负支或倒数区别。

# Introduction to inverse functions

A function sends an input to an output. An inverse tries to recover the original input. Squaring sends both −2 and two to four, so the reverse journey branches. Reversing arrows gives a relation, not necessarily a function.

## One central idea

**Use the original actual range as a new domain. An inverse function exists only if every new input has exactly one preimage.** Thus the original must be one-to-one, although ordinary functions need not be. The inverse domain is the original actual range; its range is the original domain. Unused codomain values must not be forced into the inverse domain when they have no preimage.

f⁻¹ is inverse notation, not 1/f. A reciprocal takes the reciprocal of an output at the same input and is undefined when that output is zero. An inverse reverses the mapping. Swapping (x,y) to (y,x) reflects a graph in y=x, but the reflected relation still needs the single-output test.

### Example 1: Reverse a linear rule

Let f(x)=2x+3 on D=[−2,4]. It is strictly increasing with actual range [−1,11]. Solving y=2x+3 for x gives f⁻¹(y)=(y−3)/2, with domain [−1,11] and range [−2,4].

Output seven returns to (7−3)/2=2; substituting back gives f(2)=7. The incorrect reciprocal 1/(2y+3) gives 1/17 at seven and does not recover the input. Check output admissibility too: twelve never occurs in the original range, so a broader algebraic formula must not silently extend the stipulated inverse domain.

### Example 2: Two square branches

For f=x² on [−3,3], the range is [0,9] but four has preimages ±2. There is no single-valued inverse on that range. The horizontal line y=4 meets the original twice; after swapping, new input four has two outputs. Zero having just one preimage proves nothing about every other output.

Restrict the original domain to [0,3]. The inverse is √y with domain [0,9] and range [0,3]. Restrict instead to [−3,0]: the inverse is −√y with the same domain [0,9] but range [−3,0]. On that negative branch, four returns to −2. Do not automatically choose a positive root. The positive-branch preimage of two is exact √2; 1.41 is only an approximation.

## Global property versus one query

Predict invertibility before changing output y to inspect all admissible preimages. A query change preserves the global property because the function has not changed. Changing the original domain requires reconsidering invertibility and the inverse domain.

Purple is the original graph; gold swaps coordinates and the dashed y=x line is a reference. The full square’s gold double branch is an inverse relation, not an inverse function. Restricting the original selects a branch. Equal axis units support the reflection view, but sampled points still do not prove unique preimages for every actual output.

## Exit and parent review

Separate “Is the original a function?” from “Is its reverse a function?”, using the two preimages of four. State domains and ranges for positive and negative branches and audit one complete round trip. A written √y alone does not establish the domain restriction, account for the negative branch or distinguish an inverse from a reciprocal. The parent reviews the full explanation.
