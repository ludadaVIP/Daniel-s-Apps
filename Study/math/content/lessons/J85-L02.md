# 斜率代表变化速度

## 每个横向单位的纵向变化

同一条非竖直直线上，横坐标改变多少与纵坐标改变多少的比值固定。选 P(x₁,y₁)、Q(x₂,y₂)，按同一个方向从 P 到 Q 计算 `Δx=x₂−x₁`、`Δy=y₂−y₁`，斜率为 `m=Δy/Δx`，要求 Δx≠0。它描述每一个 x 单位对应的 y 变化，不是某次移动的总纵向变化。

若输入单位是小时、输出单位是摄氏度，m 的单位为 °C/h；距离和时间模型可以有 km/h。负斜率表示 x 增加时 y 减少，零斜率表示输出不变。数学中“速度”在此指有正负的变化率，具体量的方向与单位由变量定义。

### 例 1：纵变六，单位变化二

直线过 (1,3)、(4,9)。从第一点到第二点，Δx=4−1=3，Δy=9−3=6，所以 m=6/3=2。纵向总增六跨越三个横向单位，每个横向单位只增二。不能把六直接填作斜率，也不能反写成横变除纵变的 1/2。

反过来从 (4,9) 到 (1,3)，Δx=−3、Δy=−6，m=(−6)/(−3)=2，保持不变。两种有向变化必须同时换序；只改分母会错误得到负二。作图可画水平到达另一个 x、再竖直到达 Q 的变化三角形，读取其带单位的边长。

把图的纵轴显示范围扩大，六个 y 单位在屏幕占的像素可能减少，线看起来更平，但坐标仍是原数，m 仍为二。不能用肉眼比较倾斜角度，除非先保证横纵单位的显示比例及单位定义一致。

### 例 2：下降与精确分数

直线过 (−2,5)、(2,−3)。Δx=4，Δy=−8，故 m=−2。x 向右增加一个单位时，y 下降二。将点序反转得到 Δx=−4、Δy=8，比值仍为负二；这与“走反方向所以斜率变号”的说法不同。

另一个直线过 (−1,0)、(2,2)，斜率为 2/3。精确分数不能用 0.67 代替，因为多次使用近似会改变关系。若图上每格纵轴标四、横轴标二，必须数单位变化，而不是只数方格数量。

水平线通过 (−2,3)、(3,3)，Δy=0 而 Δx=5，所以 m=0，是有定义的零变化率。竖直线若两个 x 相同，则 Δx=0，不能除；那不是“斜率零”，而是斜率未定义，且不表示 y 关于 x 的函数。

## 操作与解释

工作台保留两点及其次序，先填写变化率，再主动显示变化三角形与两个差。交换 P/Q 时，分子分母一起改号，作答不清空；改变纵轴显示范围，也保留原坐标与成功证据。换成另一对点才重置针对旧题的作答。

家长问“这六个单位跨过几个横向单位”“每格代表多少”“负号说明什么”。若只会算差，继续让孩子解释为什么要除 Δx；若只说“越陡越大”，用同一关系改变轴比例提供反例。

# Slope as rate of change

## Output change per input unit

For two points on a nonvertical straight line, compute oriented changes in the same order: Δx=x₂-x₁ and Δy=y₂-y₁. Slope is m=Δy/Δx, requiring nonzero Δx. It measures output change per input unit, not the total vertical change of one move.

If input is hours and output is temperature, the rate has units °C/h. A negative slope means decreasing output as input increases; zero means unchanged output. Interpret the signed rate using the quantities and units, rather than an unlabelled idea of speed.

### Example 1: a rise of six gives a rate of two

For (1,3),(4,9), the changes are Δx=3 and Δy=6. Thus m=6/3=2: six output units occur across three input units. Neither the total six nor the inverse ratio one half is the slope.

Reversing the point order gives Δx=-3,Δy=-6 and the same slope two. Reverse both differences together; reversing only one would falsely negate the rate. A right-angled change triangle makes the horizontal and vertical changes visible in labelled units.

Expanding the vertical viewing range may make those six units occupy fewer pixels and flatten the apparent line. Coordinates and slope stay unchanged. Screen steepness alone is not a numerical rate unless the scales and units are accounted for.

### Example 2: decrease and exact fractions

For (-2,5),(2,-3), Δx=4 and Δy=-8, giving m=-2. Each increasing x unit lowers y by two. Reversing gives Δx=-4,Δy=8, preserving the negative rate rather than reversing it.

For (-1,0),(2,2), slope is exactly 2/3. The approximation 0.67 changes the relationship if treated as exact. If graph intervals represent four y units and two x units, calculate changes in those units rather than merely counting squares.

A horizontal pair (-2,3),(3,3) has Δy=0,Δx=5 and slope zero. A vertical pair has Δx=0, so its quotient is undefined, not zero. It cannot represent y as a function of x.

## Investigate

Enter a rate before revealing the change triangle and differences. Swapping P/Q or changing the vertical display range retains the answer and original coordinates. A new point pair resets evidence for the old problem.

A parent asks how many input units underlie the total change, what each interval represents and what a negative sign means. Use the same rule under different display scales to challenge judging by pixel steepness.
