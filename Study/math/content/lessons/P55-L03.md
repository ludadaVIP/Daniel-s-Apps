## 用构造规则解释式子，不只猜下一个数

本课的方形规则是：正方形排成一行，相邻两个恰好共一条边。每根小棒只计一次。**n** 表示方形个数，不是小棒总数。先说明构造，再写一个适用于所有正整数 n 的式子。

前三幅图的数字只能提供线索，不能单凭几个数就唯一确定所有未来项。一般式在这里有依据，是因为题目明确规定了每一步怎样构造。图形规律不等于看一眼数列就机械地“加三”。

### 例 1 · 共边方形与 3n+1

1. 一个方形四根；再添一个，与前一个共一边，只需添三根。
2. n 个方形从首个四根开始，再增 n−1 次：**4+3(n−1)**。
3. 也可不展开括号直接分类：上边 n 根，下边 n 根，竖边 n+1 根。
4. 合计 **n+n+(n+1)=3n+1**。两种计数方法表达同一构造。
5. n=4 时 **3×4+1=13**，不是 4×4=16；三个共边没有重复计数。n=10 时 **31** 根，不必画完十个再逐一数。

### 例 2 · 两行点与固定额外一个

1. 另一构造是两行点，每行 n 个，另加一个独立点。
2. 两行共 **2n** 个，加额外点得到 **2n+1**。
3. n=5 时，**2×5+1=11**；图中的每个圆点都计一个，不因颜色不同而少计。
4. n=6 时 **13** 个。2n 会漏掉额外的一点，3n 则错误地多造一行。
5. 1+2n 与 2n+1 都有效，因为同一个额外点加在前后不改变总数。用图中的行与额外点解释，比只背式子更可靠。

### 第一次碰巧对，不证明总是对

共边方形 n=1 时，4n、n+3、3n+1 都给四。但 n=2 实际七根：4n 给八，n+3 给五，只有 3n+1 保留构造。之后新增每个方形都只添三根，所以 n+3 不能凭第一幅通过核验。

正整数步数是本构造的范围。n=0 时没有方形，不能把“空图”的小棒数硬套为 3×0+1=1；式子来自首个方形存在且沿共边规则继续的条件。工作台从第一步开始，边界之外需要另外定义构造，不用一个公式替代条件。

3n+1 是**代数式**：给定 n 可以计算数量。3n+1=16 是带有等号的条件，要求找哪些 n 使两边相等；两者任务不同。方形规则只回答每一步的棒数，不把未来所有数字规律都归为这一种，也不暗示图形长得相似就有相同式子。

工作台真实画出共享竖边一次，保留小棒长度与方形形状。选择规律后要解释构造，才核对当前项；改变步数收起旧结果。宽图只在图内滚动，不缩成无法数清的黑线。

**带走一个发现：** 先指重复构造和固定额外量，再写式子。代入能算某一项，构造依据才能支持每一步都有效。

## Explain an expression through construction

The square rule is explicit: squares form a row, and neighbours share exactly one edge. Count each stick once. **n** is the number of squares, not the stick total. Describe the construction before writing an expression for every positive integer n.

A few observed numbers provide clues but do not uniquely determine all future terms. The expression here is justified by the specified construction at every step, rather than simply guessing “add three”.

### Example 1 · Joined squares and 3n+1

1. The first square needs four sticks. Each new square shares an edge and adds three.
2. Starting with four and making n−1 additions gives **4+3(n−1)**.
3. Alternatively count n top, n bottom and n+1 vertical edges.
4. **n+n+(n+1)=3n+1**. Both counts describe the same construction.
5. At n=4, **13** sticks are needed, not sixteen. At n=10, **31** are needed without drawing them all.

### Example 2 · Two rows and one fixed extra

1. Construct two rows of n counters, plus one separate extra counter.
2. The rows give **2n**; the extra gives **2n+1**.
3. For n=5, **11** counters result. Count the extra irrespective of its colour.
4. For n=6, **13** result. 2n misses the extra; 3n invents another row.
5. 1+2n and 2n+1 both work because changing the order of addition does not change the count. Explain the rows and extra rather than merely memorise a formula.

### An accidental first-term match is insufficient

At n=1, 4n, n+3 and 3n+1 all give four sticks. At n=2, the construction has seven; the first two expressions give eight and five. Only 3n+1 retains the construction. Every added square contributes three sticks, so fitting one picture does not prove a general rule.

Positive integer steps define the domain here. At n=0 there is no first square; do not claim that an empty picture must contain one stick by blindly using the formula. A different domain needs its own construction definition.

3n+1 is an **expression**, whose value can be calculated after specifying n. 3n+1=16 is an equality condition asking for a value that satisfies it. These pose different tasks. Similar-looking pictures need not use the same rule.

The workshop draws a shared edge once and retains square proportions and equal stick lengths. Justify the construction rule before checking the current term. Changing n hides the old result, and wide pictures scroll within their region.

**Takeaway:** identify repeated construction and fixed extras before writing an expression. Substitution calculates a term; construction justifies every term.
