## 大小比较，从最高的不同数位开始

比较非负整数时，先把个位右对齐。位数较多的数更大；位数相同，从左往右找**第一个不同的数位**。这个高位的差不能被后面的低位推翻。

数轴则把顺序画出来：**向右数值变大**。相同的数值差必须对应相同的图上距离。画得密或放大了，数字本身不会改变。

### 例 1 · 5,408 和 5,480

1. 千位都是 5，百位都是 4。
2. 第一次不同在十位：0 与 8。
3. 所以 **5,408 < 5,480**；个位的 8 与 0 不能改变这个结论。
4. 检查差值：5,480 − 5,408 = 72。数轴上前者在后者右边 72 个单位。

### 例 2 · 从刻度找位置

一段数轴从 500 到 600，分成 5 个等长区间。

1. 总差为 600 − 500 = 100。
2. 每格为 100 ÷ 5 = **20**。
3. 从 500 向右走 3 格：500 + 3 × 20 = **560**。
4. 要数的是三个区间，不是把起点 500 算成第一格。

### 放大窗口，不改变顺序

探索器会在 `0–1,000`、`400–600`、`500–520` 三个视窗里显示同一个数。512 在窄视窗里画得更靠右，不表示它变成另一个数。512 仍比 516 小，无论纸上把轴画多长。

**注意刻度单位。** 图上的两格不一定表示数字 2；每格若是 20，两格表示 40。起点也不一定是 0，所以最后还要加上起点。

**小检查：** 如果 0、10、20、30 的相邻画图距离不相同，这幅图能可靠比较差值吗？指出刻度问题，而不是照着图猜。

## Compare from the highest differing place

For non-negative whole numbers, align the ones places first. A number with more digits is larger. If lengths match, compare from the left until the **first differing place**. Lower places cannot outweigh that higher-place difference.

A number line makes order visible: **values increase to the right**. Equal numerical differences require equal drawn distances. Zooming or drawing marks closer together does not change a number.

### Example 1 · 5,408 and 5,480

1. Thousands both contain 5 and hundreds both contain 4.
2. Tens is the first difference: 0 versus 8.
3. Thus **5,408 < 5,480**. The final digits 8 and 0 cannot reverse this.
4. Check the difference: 5,480 − 5,408 = 72. The larger number lies 72 units to the right.

### Example 2 · Read a scale

A number-line window runs from 500 to 600 with five equal intervals.

1. The total difference is 600 − 500 = 100.
2. Each interval represents 100 ÷ 5 = **20**.
3. Three intervals right from 500 give 500 + 3 × 20 = **560**.
4. Count the three spaces, rather than count the starting mark 500 as interval one.

### Zoom changes the window, not the order

The explorer shows the same number in windows `0–1,000`, `400–600` and `500–520`. The mark for 512 moves on the screen as the window changes, but its value stays 512. It remains less than 516 regardless of the drawing’s length.

**Check the scale.** Two drawn intervals do not necessarily mean 2. If each interval is 20, two intervals mean 40. The starting mark may not be zero, so add the starting value too.

**Quick check:** if the marks 0, 10, 20 and 30 are not spaced equally, can the drawing reliably compare differences? Explain the scale problem instead of guessing from the image.
