# 单调性与奇偶性

x²在右侧越走越高，在左侧却越往右越低。说“这个函数递增”若不交代研究区间，就可能漏掉半个故事。奇偶性同样不能只看公式：把平方函数限制到[0,3]，左侧对应输入已经不在定义域了。

## 一条核心想法

**函数性质是带范围的全称陈述。** 本课“递增”“递减”都采用严格约定：在给定的非退化区间内，对任意x₁<x₂，分别要求f(x₁)<f(x₂)或f(x₁)>f(x₂)。常函数既非严格递增也非严格递减；有些资料把非减也称单调增，那是另一种约定，不能混用。

奇偶性研究完整函数而不是当前镜头：先要求定义域D关于0对称，即x∈D时−x也在D；再对每个允许x检查f(−x)=f(x)为偶，f(−x)=−f(x)为奇。可能既奇又偶，也可能两者都不是。若只切换用于研究单调性的子区间，原函数的奇偶性并未自动改定义。

### 例1：平方函数的区间与域

f=x²、D=[−3,3]。在[0,3]，任意0≤x₁<x₂都有平方差f(x₂)−f(x₁)=(x₂−x₁)(x₂+x₁)>0，故严格递增。在[−3,0]，第一因子正，第二因子负，平方差<0，故严格递减。整个D上两种严格方向都不成立：−2<−1却4>1反驳递增；1<2却1<4反驳递减。

完整D对称，(−x)²=x²，所以该函数为偶函数。若把完整定义域改成[0,3]，1在域内但−1不在，便不是偶函数，也不是奇函数。不是“公式算错了”，而是已经换成一个不同域的函数。

### 例2：零函数与必要条件

f=0、D=[−3,3]同时满足f(−x)=f(x)=0和f(−x)=−f(x)=0，因此既奇又偶。它在任何非退化子区间都没有严格升降，严格单调分类为“两者皆非”；这与它的奇偶分类是两个问题。

若奇函数在0有定义，代入0得f(0)=−f(0)，所以f(0)=0。但反向不成立：f=x²在0也是0，却有f(−1)=1≠−f(1)=−1。用H01的语言，这是必要条件，不是充分条件。反驳全称性质只需一个有效反例，证明则须覆盖所有允许对象。

## 工作台怎么用

先选择函数和原域，再选研究区间，分别预测严格单调性与原函数奇偶性。移动x₁、x₂观察输出，要先核两数在区间内并满足x₁<x₂。倒序、重合、域外输入不能冒充这一定义的测试。一个成功对不证明全部；图像也不能自动提供全称证明。

改变研究子区间只清单调性预测，保留原函数奇偶性；换完整函数或原定义域时两者重算。尝试立方函数的奇性、|x|的偶性、x²+1在0不为0但仍为偶函数，避免只背一个外形。

## 家长读理由

要求孩子先说“在哪个区间”“整个定义域是什么”，再下结论。用两个相反输入核奇偶时，需要说明关系为何对每个输入成立。若孩子只能在图上指出“看起来对称”，回到定义域与代数恒等式，并保留人工审核的解释题。

# Monotonicity and parity

The square function rises as we move right on its positive side, but falls as we move right on its negative side. Saying “it increases” without an interval omits part of the story. Parity also needs the domain: restricting the formula x² to [0,3] removes the opposite inputs on the left.

## One central idea

**A function property is a universal claim with a domain.** Here increasing and decreasing are strict. For every x1<x2 in a specified nondegenerate interval, require f(x1)<f(x2) or f(x1)>f(x2), respectively. A constant is neither strictly increasing nor strictly decreasing. Some sources use monotone increase for nondecrease; that is a different convention.

Parity concerns the complete function, not a camera view. First D must be symmetric about zero: whenever x is admissible, so is −x. Then require f(−x)=f(x) for every input for evenness, or f(−x)=−f(x) for oddness. A function can satisfy both or neither. Merely selecting a subinterval for a monotonicity study does not redefine the original function for parity.

### Example 1: The square function’s interval and domain

Let f=x² on D=[−3,3]. For 0≤x1<x2≤3, the difference f(x2)−f(x1)=(x2−x1)(x2+x1) is positive, establishing strict increase. On [−3,0], the first factor is positive and the second negative, establishing strict decrease. Neither direction holds on the whole D: −2<−1 but 4>1 refutes increase, while 1<2 with 1<4 refutes decrease.

The complete D is symmetric and (−x)²=x², so the original function is even. Change its complete domain to [0,3]: one is included but minus one is not. It is then neither even nor odd. The formula has not become arithmetically wrong; the domain defines a different function.

### Example 2: Zero and a necessary condition

The zero function on [−3,3] satisfies f(−x)=f(x)=0 and f(−x)=−f(x)=0. It is both odd and even. On any nondegenerate interval it has no strict rise or fall. Its parity and strict monotonicity are different classifications.

If an odd function is defined at zero, f(0)=−f(0), so f(0)=0. The converse fails: x² also vanishes at zero, yet f(−1)=1 differs from −f(1)=−1. In H01 language, this is necessary but not sufficient. One admissible counterexample refutes a universal property; proving it needs every allowed case.

## Using the workbench

Select the function and original domain, then the study interval. Predict strict monotonicity and original parity separately. Move x1 and x2 and compare outputs only after checking both inputs are in the study interval and x1<x2. Equal, reversed or excluded inputs do not test this definition. One successful pair, like a suggestive graph, is not proof for all pairs.

Changing only the study subinterval resets monotonicity but preserves the original parity prediction. Changing the whole function or original domain requires both to be reconsidered. Compare the odd cube, even absolute-value function, and x²+1, which is even despite not vanishing at zero.

## Parent review

Ask “On which interval?” and “What is the complete domain?” before accepting a label. The learner should explain why the algebraic relation holds for every input. If the argument only says a graph looks symmetric, return to domain symmetry and the relevant identity. Written reasoning remains human-reviewed.
