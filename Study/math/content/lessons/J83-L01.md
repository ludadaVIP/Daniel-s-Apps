# 两个未知数的关系

## 一个数对同时回答两条关系

二元一次方程含两个未知数，整理后形如 ax+by=c，x、y 的系数不同时为零。解不是单独一个数，而是一对按指定顺序对应的值。写 (4,3) 表示 x=4、y=3，交换成 (3,4) 通常是另一个候选。

一条关系往往有许多实数数对，例如 x+y=7 可取 (0,7)、(2,5)、(4,3)，也可取分数或负数。方程组把两条关系同时交给同一组未知数；需要同一个数对逐条通过，不能从第一式挑一个 x，再从第二式随便挑一个 y。

### 例 1：只通过一式还不够

检查 x+y=7、2x+y=11。候选 (2,5) 在第一式左边算出七，符合；在第二式算出 `2×2+5=9`，不等于十一，所以不是方程组的解。第一式通过不会自动让第二式通过。

换成 (4,3)，第一式为四加三等七，第二式为八加三等十一，两式都成立，因此是共同解。若交换成 (3,4)，和仍七，但第二式为十，仍失败。这说明顺序与同时核验都不能省。后面会学习怎样有依据地找出共同数对，而不只靠试猜。

### 例 2：先保留原关系，再求数值

两个量的和为八，x 比 y 多二。应先写 `x+y=8` 与 `x−y=2`，一条表示总量，一条表示差量。这里没有真实票数或长度限制时，可先讨论实数未知数；若来自现实，须另外定义单位和允许范围。

数对 (5,3) 同时符合这两式，但直接写 `x=5; y=3` 不能代替本题要求的“两条原数量关系”。它们给出了最后解，却没有展示总量与差量如何进入模型。可以交换两式次序、把两边换位或同步乘非零数，保留每条原约束；不能只因解相同就抹去模型来源。

## 两条方程不自动保证唯一

如果第二式只是第一式的倍数，例如 x+y=4 与 2x+2y=8，它没有增加新的独立约束。沿 x+y=4 有无穷多个共同数对，但不是平面上的所有数对，(0,0) 就不符合。若第二式改成 2x+2y=9，则与第一式矛盾，没有共同数对。

因此，“有两个未知数和两条方程”并不自动等于“必有一个解”。关键是两条关系共同限定了什么。后续会用代入、加减及图像判断唯一、没有或无穷多共同解。

工作台把候选分别代入两条原式，并列出第一式的十个整数样本。它们只是有限样本，不是第一式的全部实数解；勾记表示也满足第二式。家长请孩子说清同一个数对在两式各算出什么、坐标顺序表示什么，以及结论是否超出已核条件。

# Relationships with two unknowns

## The same ordered pair must satisfy both relations

A linear equation in two variables can be written ax+by=c, with the two variable coefficients not both zero. A solution is an ordered pair rather than one number. The pair (4,3) assigns x=4,y=3; reversing it usually changes the candidate.

One relation often has many real solutions. For x+y=7, examples include (0,7),(2,5),(4,3), with fractional and negative values also possible. A system requires the same pair to satisfy both relationships. Do not select x from one unrelated solution and y from another.

### Example 1: passing one equation is insufficient

Consider x+y=7 and 2x+y=11. Candidate (2,5) gives seven in the first equation but nine in the second, rather than eleven. It fails the system despite passing one relation.

Candidate (4,3) gives seven and eleven, passing both. Reversing it to (3,4) preserves the sum but gives ten in the second equation. Both order and simultaneous checking matter. Later methods find a shared pair systematically rather than relying only on guessing.

### Example 2: retain the original relationships before solving

Two quantities sum to eight and x exceeds y by two. Write x+y=8 and x−y=2: one is a total, the other a difference. Without a specified physical restriction, these can be real unknowns; a real context additionally needs units and a domain.

The pair (5,3) satisfies both, but submitting x=5;y=3 does not answer a request to model the original relationships. It lists solved values without showing how the total and difference formed the model. Equation order, swapped sides and nonzero scaling may change while each original constraint remains. A matching solution set alone does not preserve a modelling explanation.

## Two equations do not automatically mean one solution

If x+y=4 is paired with 2x+2y=8, the second relationship adds no independent restriction. Infinitely many pairs on that line solve both, but (0,0) does not. If the second constant changes to nine, the relationships contradict each other and no pair works.

Counting equations and unknowns is therefore insufficient. Examine the constraints together. Substitution, elimination and graphs will distinguish a unique pair, no shared pair and infinitely many shared pairs.

The workshop substitutes a candidate into both original equations and can list ten integer samples from the first. These are finite examples, not every real solution; a tick marks samples also passing the second. A parent asks for both calculated left values, the meanings of coordinate order and the scope of the conclusion.
