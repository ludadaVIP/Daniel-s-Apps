# 数学归纳法

本课只解决一件事：怎样把“开头成立”和“每一步都能传下去”结合，证明一个关于所有正整数的命题。目标命题P(n)为：1+3+…+(2n−1)=n²，n是整数且n≥1。范围必须先写清楚；归纳法不能不加说明就用于所有实数。

## 起点与任意一步

基例核最小允许值n=1：左边只有1，右边1²=1。随后任取整数k≥1，暂设P(k)成立，称为归纳假设。利用它推出P(k+1)，才能证明条件句P(k)⇒P(k+1)。这里没有假设全称结论，而是在证明一个条件句。真基例启动后，任意一步的传递才使每个正整数都被覆盖。

### 例1：把新增一圈写成代数

先算1、1+3、1+3+5，得到1、4、9。这些数提示平方，但提示还不是证明。n=1已成立。假设前k项和为k²，第k+1项不是2k−1，而是2(k+1)−1=2k+1。加入这一项得k²+(2k+1)=k²+2k+1=(k+1)²，恰好是下一命题。

因此基例和任意k的传递共同给出所有整数n≥1的公式。用k=4演示时，前四项和16，再添第5个奇数9得到25；演示解释符号含义，却不能代替任意k的推导。平方点阵从k×k扩为(k+1)×(k+1)，新增k+k+1个点，也能解释同一个代数式。

### 例2：链条可以传递，仍可能没有真起点

错误命题Q(n)声称奇数和为n²+1。若暂设Q(k)，加入2k+1会得到k²+1+2k+1=(k+1)²+1，传递的代数确实成立。但基例要求1=2，明显错误。所以不能只展示漂亮的传递步骤，就说证明完成。一个蕴含成立，不保证它的前提存在真起点。

另一错误命题把和写成n：n=1时正确，n=2时1+3=4≠2，所以真基例也不够。工作台的“只有基例”展示这一断裂；“只验证六项”则展示不同缺口：那些例子全真，却没有任意k步骤。即使检查一百万项，仍有无限多个整数没有被有限检查覆盖。

## 图示怎样使用

链图只画前六个位置，实线⇒表示一般条件句，空心起点表示基例未建立，叉号表示传递失败，问号表示只有有限核验。显示索引改变，只改变演示算式。核验表分列实际和、命题声称值、基例、传递与完整性，防止把任一勾选项当成完整证明。

归纳范围若改为n≥3，就要从3启动，并确保任意k≥3可传到k+1；若只会从偶数走到下一个偶数，还需要另处理奇数。不是每条看似延伸的箭头都覆盖原范围。先写范围、再核起点、最后核覆盖，是可迁移的证明习惯。

出口需写完整论证并比较三种不充分材料，由人核查逻辑，不靠出现“归纳”二字判对。家长可以追问“第一块骨牌真的倒了吗”和“哪一步对任意k成立”；若孩子仍把第k项当新增项，先回到数列求和，逐项编号再来。

# Mathematical induction

This lesson has one central task: combine a true starting case with an implication that works at every next step. Let P(n) mean 1+3+…+(2n−1)=n² for integers n≥1. State that domain first. An induction over positive integers does not automatically prove a claim for all real numbers.

## A starting case and an arbitrary step

At n=1, the left side is one and the right side is 1², also one. For an arbitrary integer k≥1, temporarily assume P(k). This is the induction hypothesis. Use it to derive P(k+1), thereby proving the conditional statement P(k) implies P(k+1). You are not assuming the universal conclusion. The true base starts the process; the arbitrary-k implication then reaches every positive integer after finitely many steps.

### Example 1: Add the next layer

The first sums 1, 1+3 and 1+3+5 are 1, 4 and 9. They suggest squares but do not prove the general formula. The base at one is true. Assuming the first k terms total k², the next term is 2(k+1)−1=2k+1, not 2k−1. Therefore the next sum is k²+2k+1=(k+1)², exactly the statement required at k+1.

The base and the general implication together establish the identity for every integer n≥1. At k=4, the first four odd numbers total sixteen and the new fifth term is nine, giving twenty-five. This numerical check illustrates the notation; it does not replace the arbitrary-k derivation. Enlarging a k-by-k square array adds k+k+1 points and explains the same algebra geometrically.

### Example 2: Propagation without a true base

Consider the false claim Q(n): the odd sum equals n²+1. If Q(k) is assumed, adding 2k+1 gives k²+1+2k+1=(k+1)²+1. Its propagation algebra is valid. However, the starting case would require 1=2, which is false. A correct implication alone does not provide a true starting point, so this is not a complete induction proof.

The different false claim that the odd sum equals n does have a true base at one. It fails at two, where the sum is four. A true starting case alone therefore does not suffice either. Finally, checking the first six true cases of the square formula provides neither a general implication nor coverage of all remaining integers. Increasing that finite checking to a million cases still leaves infinitely many untested cases.

## Reading the workbench

The chain shows six positions only. A solid implication arrow represents a general step; an open starting circle means the base is unestablished, a cross marks a broken link, and a question mark marks finite checks without a general argument. Changing the displayed index changes the illustration, not what has been proved. The audit separates the actual sum, the claimed value, the base, the implication and overall completeness.

If the domain began at three, start the base at three and propagate for arbitrary k≥3. If a step only moves between even integers, it does not cover odd integers without another starting chain. Always check scope as well as algebra. The exit argument is reviewed by a person: using the word “induction” is not enough. Ask which starting case is true and which calculation applies to arbitrary k. Return to indexed sequence sums if the learner confuses the kth term with the new term k+1.
