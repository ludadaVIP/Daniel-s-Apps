# 数乘向量

把箭头加长为两倍，同时完全反向，应怎样用一个数描述？标量−2可以同时记录这两种变化，而不需要发明“负长度”。

## 一条核心想法

**ku把向量每个分量乘同一标量k，模长乘|k|。** 非零向量在k>0时同向，k<0时反向；k=0时得到零向量。若原向量已经是0，不论k是什么，结果都为0，仍没有可比较的非零方向。

数乘符合k(u+v)=ku+kv、(k+l)u=ku+lu以及k(lu)=(kl)u。可以由对应分量的实数运算理解，不把规则误作“只改变箭头横向部分”。向量本身没有本课所用的一般除法；恢复倍数要核对分量与零条件。

### 例1：负号和绝对值各负责什么

u=(3,−1)，−2u=(−6,2)。两个分量都乘−2，箭头反向，长度变为两倍。原模长√10，结果模长√40=2√10；不是−2√10。

若u=(−4,6)，(1/2)u=(−2,3)，正半倍缩短而不反向。已知|u|=5时，|−2u|=|−2|×5=10。这里没有必要知道u指向哪里，因为缩放长度只依赖绝对倍率。

### 例2：恢复倍数与不能约去的零

u=(0,2)、v=(0,−6)，求v=ku的k。横分量都是0，不能算0/0；改用非零纵分量得k=−6/2=−3，再核横式0=(−3)×0。

ku=kv在k≠0时可两边乘标量1/k，得u=v；k=0时却完全不能这样约去，例如u=(1,0)、v=(0,1)都被映成0。类似ku=0只有在u≠0时才迫使k=0。若u=0，目标也是0，则任意k都可；目标非零则没有k。这三类情况不能混成“唯一解0”。

## 缩放工作台

选择原向量与正、负、分数或零标量，分别预测ku、模长和方向关系。先用图判断变化，再用每个分量乘k核对。零向量只画圆点，不用一支很短箭头假装有方向。

显示或隐藏表格、改变图窗保留作答。改变数学参数后重新预测，不把上一组恰好相同的数字当成新证据。精确根式可输入sqrt，近似小数不替代题目所问的确切模长。

## 家长核对与迁移

出口要说明标量约去的非零条件并构造k=0反例。家长可让孩子先举“原向量为0”和“标量为0”两例，再问它们有什么相同、不同。不要只检查符号运算；要听见“模长取绝对值”“每个分量同乘”和“不能除以0”。后续坐标向量用这些运算恢复终点，几何证明再用数乘刻画共线方向。

# Scalar multiplication

How can one number describe doubling an arrow while reversing it completely? The scalar −2 records both changes without inventing a negative length.

## One central idea

**ku multiplies every component by scalar k, while magnitude is multiplied by |k|.** For a nonzero source, positive k keeps direction and negative k reverses it. Zero k gives the zero vector. If the source itself is zero, every k still gives zero with no nonzero direction to compare.

Scalar multiplication obeys k(u+v)=ku+kv, (k+l)u=ku+lu and k(lu)=(kl)u through real-number arithmetic in each component. It does not merely alter the horizontal part of an arrow. This unit has no general division by a vector; recovering a multiplier requires component checks and zero conditions.

### Example 1: Sign and absolute value have different roles

For u=(3,−1), −2u=(−6,2). Multiplying both components by −2 reverses the arrow and doubles its magnitude. The source magnitude is √10 and the result is √40=2√10, not −2√10.

For u=(−4,6), (1/2)u=(−2,3). A positive half-scale shortens the arrow without reversing it. If |u|=5, then |−2u|=|−2|×5=10. The particular direction is unnecessary because the length change depends only on absolute scale.

### Example 2: Recover a multiplier without cancelling zero

For u=(0,2), v=(0,−6), solve v=ku. The horizontal components are both zero, but 0/0 cannot determine k. Use the nonzero vertical component: k=−6/2=−3, then verify the horizontal equation 0=(−3)×0.

When k≠0, multiplying ku=kv by scalar 1/k gives u=v. When k=0 this cancellation is invalid: u=(1,0) and v=(0,1) both map to zero. Similarly ku=0 forces k=0 only if u≠0. For a zero source and zero target every k works; for a zero source and nonzero target no k works. These are not all the same as a unique zero solution.

## Scaling workbench

Choose a source and positive, negative, fractional or zero scalar. Predict ku, its magnitude and its direction relation independently. Use the picture first, then audit by multiplying every component. Zero vectors are dots rather than short invented arrows with directions.

Showing the table or changing the viewing window preserves work. Changing mathematical parameters requires new predictions; an accidentally repeated number is not new evidence. Enter exact radicals using sqrt when required, rather than replacing them with approximate decimals.

## Parent check and transfer

The exit needs the nonzero condition for cancelling a scalar and a counterexample at k=0. Ask for separate examples of a zero source and zero scalar, then compare them. Listen for absolute magnitude, scaling every component and avoiding division by zero as well as correct arithmetic. Coordinate vectors next use these operations to recover endpoints; geometric proofs later use scalar multiples to describe collinear directions.
