# 参数对函数图像的影响

与其背“左加右减”等口诀，不如问一个源点去了哪里。本课固定源函数f(u)=u²+u，定义域为全部实数，研究G(x)=a f(b(x−h))+k。内部改变输入，外部改变输出；点映射给出两层运算各自的作用。

## 先解内部等式

取源点(u,f(u))。当b≠0时，令u=b(x−h)，得到x=h+u/b；新纵坐标为af(u)+k。因此点映射是(u,f(u))→(h+u/b,af(u)+k)。

两源输入的差Δu对应Δx=Δu/b，所以水平长度因子为1/|b|。b负时还发生水平反射；|b|越大，水平长度越短。纵向长度乘|a|，a负时发生纵向反射，之后按k平移。h与k分别指定所写形式中的水平、竖直平移，不能把内部所有符号分别当成独立平移。

### 例1：一个点和整个表达式互相核对

设a=2、b=2、h=1、k=−1。源输入u=1给f(1)=2，即源点(1,2)。内部等式2(x−1)=1解得x=3/2，纵坐标2×2−1=3，所以对应点为(3/2,3)，不是把横坐标乘2后的(3,3)。

完整函数为G(x)=2[4(x−1)²+2(x−1)]−1=8x²−12x+3。代入x=3/2得18−18+3=3，与点映射一致。再代x=1，内部为0，因此G(1)=−1；这能核验常数项与平移顺序。

若b改−2而h仍1，源输入u=2对应x=1+2/(−2)=0。先解内部等式比看图猜方向可靠。源函数u²+u不是偶函数，因此正负b的图通常不同；若换成偶函数，反射后的点集可能重合，逐点反射规律仍然成立。

### 例2：零参数不是正常伸缩的极限口诀

设G(x)=3f(0(x−2))−1。内部恒0，而本课f(0)=0，所以G(x)=−1对所有实x成立。不能把b=0塞进1/b或h+u/b。

当b=0，源输入u=2找不到对应的x，因为0(x−h)不可能为2；源输入u=0却对应所有x，不能挑一个“唯一映射点”。图上的常值函数存在，与源点一一映射公式失效是两件事。若a=0且b任意，本课内层均有定义，G也恒为k。

这依赖源函数在0有定义。本课源域R，因此没有隐含孔。若换成f(u)=log u，b=0会使内层一直落在非法输入，不能直接写成常数；即使外乘0，也不能用0乘无定义来创造值。

## 图、点、公式分别提供什么

工作台用灰虚线画源函数、紫线画G，并在b≠0时标一个由等式算出的对应点。坐标轴同单位标尺，超出窗口的曲线被裁剪，未将大数压回边界。改变源输入只换探查点，不改变整条G；参数改变才改变函数。

自动结果要求给出合并后的多项式，不接受只把原嵌套式抄一遍来代替展开；点映射的横坐标可写精确分数。图形采样帮助检查，不能证明所有x的代数恒等式。

## 出口与家长提示

让学生先解内部等式，再算输出，并用展开式代入同一x核验。追问b=0时哪一步禁止、对应源输入为何可能无解或不唯一。还要区别逐点映射与最终图像点集，避免用对称图形的巧合推翻变换规则。

出口应给一般映射、非零条件、水平长度因子和两个零参数情形，并声明本课源域R。背出方向而无法从u=b(x−h)推出坐标，不算完成本课目标。

# Effects of parameters on graphs

Track where a labelled source point moves rather than memorising direction slogans. Fix f(u)=u²+u on all real inputs and study G(x)=a f(b(x−h))+k. The inner expression acts on input; the outer expression acts on output.

## Solve the inner equation first

Take source point (u,f(u)). If b≠0, set u=b(x−h) and solve x=h+u/b. Its new height is af(u)+k. Thus the point mapping is (u,f(u))→(h+u/b,af(u)+k).

Differences satisfy Δx=Δu/b, so horizontal lengths scale by 1/|b|, with reflection for negative b. Larger |b| means shorter horizontal lengths. Vertical lengths scale by |a|, with vertical reflection when a is negative, followed by the vertical shift. In this written form h and k locate the shifts; individual signs inside an unanalysed expression are not independent transformations.

### Example 1: Check a point against the expanded rule

Let a=2,b=2,h=1,k=−1. Source input one gives f(1)=2. Solve 2(x−1)=1 to obtain x=3/2, then calculate the height 2×2−1=3. Source point (1,2) maps to (3/2,3), not to the point obtained by multiplying its horizontal coordinate by two.

The full formula expands as G(x)=2[4(x−1)²+2(x−1)]−1=8x²−12x+3. At x=3/2 this gives 18−18+3=3, confirming the mapping. At x=1 the inner input is zero and G(1)=−1, providing another check on the constant term and operation order.

If b becomes −2 while h stays one, source input u=2 corresponds to x=1+2/(−2)=0. Solving the inner equation is more reliable than guessing from a picture. This source is not even, so changing the sign of b generally changes the graph. For an even source the reflected point set may coincide, although the labelled point mapping still reverses inputs.

### Example 2: Zero parameters need separate reasoning

Consider G(x)=3f(0(x−2))−1. The inner input is always zero, and this source has f(0)=0, giving G(x)=−1 for all real x. Neither 1/b nor h+u/b is legal at b=0.

A nonzero source input such as u=2 has no corresponding x when b=0. Source input zero instead corresponds to every x, so no unique mapped point is specified. Existence of the constant graph and failure of the one-point mapping formula are distinct facts. With a=0, all inner values in this polynomial model remain defined and G is also the constant k.

These conclusions rely on the source being defined at zero. Replacing it by log u would make a zero inner multiplier invalid everywhere. Multiplying an undefined value by zero would not create a function value. Keep domain information even in degenerate parameter cases.

## Compare graph, point and formula

The workbench uses a grey dashed source and purple transformed curve, marking a mapped point when b≠0. Both axes retain equal unit lengths; curves outside the window are clipped rather than flattened. Changing only the selected source input changes the probe, not the function. Changing parameters changes G.

Enter an exact fractional horizontal coordinate and a collected polynomial, rather than copying an unexpanded nesting. Substitute the mapped point into the expanded rule as an independent check. A sampled graph is useful evidence but does not prove a polynomial identity for every x.

Derive the general mapping, state b≠0, explain the reciprocal horizontal length factor and treat both zero-parameter cases. Ask which division fails at zero and why a source input can then have no corresponding x or many. Retain the source domain and distinguish a labelled mapping from a possibly symmetric final graph.
