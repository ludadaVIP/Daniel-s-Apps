# 平均变化率

先比较两个输入对应的输出，再问“每单位输入平均改变多少”。这两个问题的答案不是同一种量：输出变化是Δy，平均变化率是Δy/Δx。本课从已经熟悉的直线斜率出发，把同样的比值用于曲线的两个端点。

## 两个差与一个比

设输入从a变为b，输出从f(a)变为f(b)。输入增量Δx=b−a，输出增量Δy=f(b)−f(a)，平均变化率为[f(b)−f(a)]/(b−a)，要求a≠b。它也是经过A(a,f(a))、B(b,f(b))的割线斜率。

两种增量必须沿同一方向相减。交换a、b时，分子分母同时变号，比值不变；只反转其中一个差会错误地改变斜率。输出下降、输入增加时，比值可以为负。有符号位移除以时间得到平均速度，不应自动取绝对值；路程除以时间才是另一种平均速率问题。

变化率的单位是“输出单位/输入单位”。输出以米计、输入以秒计，变化率就是米/秒。若输入单位从秒改成分钟，数值也须按单位一致换算，不能删去单位只比数字。

### 例1：输出变化8，变化率4

取f(x)=x²，从a=1到b=3。两个高度分别为1与9，因此Δy=8；横向增量Δx=2。平均变化率8/2=4，不是8，也不是终点高度9。

交换端点，从3到1，分子1−9=−8、分母1−3=−2，商仍为4。若将函数整体上移4，两个高度变成5与13，差仍8，平均变化率不变。竖直位置不是局部或区间变化率。

### 例2：平均为0，不代表中间不变

f(x)=x²在[−1,1]两端值都为1，所以平均变化率(1−1)/(1−(−1))=0。然而f(0)=0，与端点不同，函数显然没有在整个区间保持常数。平均率只连接端点，不能透露内部所有变化。

常数函数g(x)=7在任意不同端点间平均变化率也是0，但这次每处值的确相同，因为完整规则就是常数。两种情形有相同平均率，却有不同内部行为。若两个端点相同，Δx=0，原差商未定义；这不能拿后来学到的导数来替换。

## 工作台与出口

先选完整函数规则及a、b，分别预测Δy和平均变化率。金线连接不同横坐标的两个点；a=b时不绘制假割线。切换视窗只改显示，整体竖直平移改变高度但不改变增量和变化率。

# Average rate of change

First compare outputs at two inputs, then ask how much output changes per input unit. These answers are different quantities: output change is Δy, whereas average rate is Δy/Δx. We extend the familiar slope ratio from straight lines to the endpoints of a curve interval.

## Two differences and a ratio

For inputs a and b, input increment is Δx=b−a and output increment is Δy=f(b)−f(a). Their ratio [f(b)−f(a)]/(b−a) is the average rate, requiring distinct endpoints. It is also the slope of the secant through A(a,f(a)) and B(b,f(b)).

Subtract in the same direction in both differences. Reversing endpoints changes both signs and preserves the ratio. Reversing only one difference incorrectly changes the slope. A decreasing output over increasing input has a negative rate. Signed displacement divided by elapsed time gives average velocity; do not automatically take an absolute value. Total distance divided by time is a different average-speed question.

Units are output units per input unit. Metres against seconds give metres per second. If seconds change to minutes, the numerical rate must change consistently; removing units and comparing the bare numbers would obscure the quantities.

### Example 1: Change eight, rate four

For f(x)=x² from one to three, the heights are one and nine. Thus Δy=8 and Δx=2, so average rate is four. Neither output change eight nor endpoint height nine is the rate.

Reverse the endpoints: numerator 1−9=−8 and denominator 1−3=−2 still give four. Translate the function upward by four and the heights become five and thirteen, again differing by eight. Vertical position differs from a rate of change.

### Example 2: Zero average does not mean no internal change

For x² on [−1,1], both endpoint values are one, giving average rate zero. Yet the central value f(0)=0 differs from the endpoints. The function is not constant throughout the interval. The average compares endpoints rather than specifying every internal value.

The constant rule g(x)=7 also gives zero average rate between distinct endpoints, but its values really are constant because the entire rule says so. Equal averages can conceal different internal behaviour. When both endpoints coincide, Δx=0 and the original quotient is undefined; the derivative studied later does not replace that undefined quotient.

## Explore and explain

Choose the rule and endpoints, then predict output change and average rate separately. Gold represents the secant through different inputs. Equal inputs do not create a fake secant. Changing the display window affects only the drawing; a vertical translation changes heights while preserving increments and rate.

The exact audit retains both endpoint values, both increments and the average. A derivative at a is separately labelled for later comparison, not silently identified with the interval average. Curves use true coordinates and are clipped rather than flattened at the window edge.

For the exit, use fictional position s(t)=t² to explain displacement and average velocity from one to three seconds, including the effect of a constant shift. A parent can ask what eight metres and four metres per second each describe before moving on to approaching secants.
