# 小型数据调查

## 一张图不是一份完整调查

统计调查循环 PPDAC 包含问题 Problem、计划 Plan、数据 Data、分析 Analysis、结论 Conclusion。它不是只能走一遍的流水线：原卡有问题可返回数据步骤，发现问题太宽可重新限定；每次修改要留下理由。目标是用适当数据回答原问题，而不是先挑喜欢的答案再修图。

本课准备十二张虚构纸片下滑距离卡，单位 cm。A/B 表示两种折法，但它们来自不同桌面，没有随机分配。数据用来学习调查过程，不是真实实验结果；不需要购买、测量真实人物、上传资料或实际招募。一个合适问题是：“在这批记录中，两组典型距离和波动怎样比较？”它没有许诺回答所有纸片哪种折法最好。

### 例 1：计划、保留与有来源的纠错

原始 A 记录依编号为 4、5、5、6、缺失、27，B 为 3、4、4、5、5、6。总行数十二，A5 缺失，所以已知距离共有十一条。缺失不是零，不能补成“没有移动”；也不能删掉整行让人不知道原来漏了一次观察。

资料同时给出可核原卡 A6=7 cm，说明录入栏的 27 是转录错误。于是记“A6，原录27，依原卡纠正为7”，保留编号与这一条观察。若原卡本来确认27，就不能因为箱线图不好看而强改七；应保留并解释影响。纠正错误的依据是来源，不是大小或结论偏好。

计划应事先说明单位、同一测量方法、每行表示什么、缺失如何标记与可疑值如何核查。即使现成资料未做到相同桌面，也要把这项限制写进结论，而不是事后假装它受控。

### 例 2：从摘要到有边界的报告

纠正后 A 的已知值 4、5、5、6、7，n=5，中位数五；排除中位数，下半 4、5，上半 6、7，Q1=9/2，Q3=13/2，IQR=2，极差三。A5 仍缺失。

B 的六个值 3、4、4、5、5、6，中位数 (4+5)/2=9/2；两半各三条，Q1=4、Q3=5，IQR=1，极差也是三。两组极差相同不表示分布相同，也不抹去中位数与 IQR 的差别。

可以写：“在本批已知距离记录中，A 的中位数5 cm高于 B 的9/2 cm，但 IQR 2 cm也比 B 的1 cm大，中央记录更分散。有效条数 A五/B六，A有一条缺失，并按原卡更正 A6。由于桌面不同、未随机分配，不能仅把差异归因折法，也不直接推广全部纸片。缺失可能影响比较，后续可在共同条件下随机分配并增加重复。”

这段结论回答原问题，给数值、单位、来源与局限；没有把“典型更大”夸成“每张都更远”，也没有把更长距离自动判为所有任务更好。随机分配与更广抽样分别帮助因果辨别和推广范围，不能互相替代。

## 工作台与家长审核

工作台依次检查问题范围、保留缺失的计划、原卡纠错和中位数计算，再开放结论草稿与文本下载。可以返回前一步；这些有限检查并不自动理解最后的自由文字。导出的报告带原记录、纠错、有效 n、统计量、约定和孩子的原稿，明确仍待人工阅读。离开探索页前下载，临时草稿不会自动保存到学习记录。

正式引导、解释与出口题由家长核验。请让孩子指回记录说明每个数字从哪里来，再核结论是否越过证据；保存一份带局限的短报告，胜过没有来源却措辞确定的长报告。若目前不能解释中位数和 IQR，就回到本单元前两课补桥，不用增加术语掩盖问题。

# Mini data investigation

## A graph is not the whole investigation

PPDAC connects Problem, Plan, Data, Analysis and Conclusion. It is a revisitable cycle: check source problems in Data or narrow an overbroad question, recording reasons for changes. Evidence should answer the question rather than be edited to favour a predetermined conclusion.

Twelve fictional card-slide distance records in cm compare folds A/B from different desks without random assignment. They teach a process, not report a real experiment. No purchases, personal measurements, uploads or recruitment are needed. Ask how typical distances and spread compare within these records, not which fold is universally best.

### Example 1: plan and document a correction

A entries are 4,5,5,6,missing,27 and B entries 3,4,4,5,5,6. Twelve rows contain eleven observed distances. A5 remains missing, not zero or an erased row. Zero would be a known distance, while missing is unknown.

An available source card states A6=7 cm. Correct the transcription from 27 to seven, logging ID, old/new values and source while retaining the observation. If the source had verified 27, its size would not justify forcing seven. Source evidence, not a preferred box shape, determines correction.

Plan units, measurement, observational units, missingness and checks in advance. If existing records lack common desks, report that limitation rather than pretending it was controlled.

### Example 2: turn summaries into a scoped report

Corrected A has observed values 4,5,5,6,7, n=5 and median five. Excluding the middle gives Q1=9/2 and Q3=13/2, so IQR=2 and range=3. A5 is still missing.

B has six observations 3,4,4,5,5,6, median 9/2, Q1=4, Q3=5, IQR=1 and range=3. Equal ranges do not make distributions identical or remove centre/IQR differences.

A suitable report says that within the observed records, A’s median five cm exceeds B’s 9/2 cm, but A’s IQR two cm also exceeds B’s one cm. State n=5/6, one missing A record and the source correction. Different desks and no random assignment prevent attributing the difference solely to fold or generalising to all cards. Missingness might change the comparison; propose common conditions, random assignment and replication.

This answers the question with numerical evidence, units, sources and limits. “Larger typical distance” does not mean every A card travelled farther or that distance alone defines quality for every task. Assignment and wider sampling address different inference needs.

## Workshop and parent review

The workshop checks scope, a missingness plan, correction and a median before opening a conclusion draft and text download. Revisit earlier stages as needed. These limited gates do not understand free writing. The report retains records, correction, n, summaries, convention and the child’s original draft, explicitly awaiting human review. Download before leaving; this temporary workshop draft is not autosaved into the learning record.

A parent reviews formal introductory, explanation and exit responses. Ask where each reported number came from and whether the conclusion exceeds evidence. A short report with honest limits is better than certainty without sources. Revisit the first two lessons if medians and IQRs still need explanation.
