# 用图像解二次方程

## 给定高度，寻找所有输入

解f(x)=q，可以在原函数图像y=f(x)上画水平线y=q，寻找全部交点的横坐标。题目给的是高度q，未知的是哪些输入能达到这个高度，所以答案不是照抄q。只有q=0时，这条水平线就是横轴；不能把所有二次方程都在原图上机械地找横轴交点。

另一条正确路线是另定义差函数g(x)=f(x)−q，画y=g(x)找横轴零点。两种路线给相同横坐标，但原交点的纵坐标为q，差图零点的纵坐标为0。要明确当前画的是哪个函数，不能把差图标成原函数，或把原图的非零高度交点画在横轴上。

### 例 1：同一曲线遇到三条水平线

原函数y=x²−4x+3=(x−2)²−1。与y=0相交时，(x−1)(x−3)=0，横坐标1、3，对应点(1,0)、(3,0)。与y=−1相交时，(x−2)²=0，只有横坐标2，对应点(2,−1)。这是一处相切，两个公式分支重合，不能算成两个不同输入。

与y=−2相交需要(x−2)²=−1，实数平方不可能为负，所以没有交点。这个结论也可由原函数最小值−1解释；水平线−2在整条曲线下方。注意“没有交点”的空集与输入x=0不同，零代入原函数为3，并没有达到−2。

### 例 2：无理输入与精确核验

解x²=2，原图是y=x²与y=2，交点为(−√2,2)、(√2,2)，完整输入集合{−√2,√2}。图上可估计约为−1.41与1.41，但1.41²=1.9881，不严格等于2。有限读图小数可以用约号说明位置，不能作为精确解通过代回核验。

若改画差函数y=x²−2，横轴交点为(−√2,0)、(√2,0)，横坐标不变。再如原y=(x−1)²+2与y=6相交，得(x−1)²=4，输入−1和3，而不是±2或6。平方分支先给x−1=±2，还要解出x并检查完整集合。

## 窗口、游标与完整性

原y=(x−8)(x−10)的两个横轴交点在8、10。若窗口只显示x从−4到6，两点都看不见，不代表方程无实根。放宽窗口只是看见更多部分，没有改变函数。原图同时给纵轴标尺；若交点高度不在纵向范围，也应承认显示限制，而不是把点挪到图边伪装成可见交点。

工作台游标C是一个试探输入及对应原函数值，不是自动认定的交点。改变游标只改变观察点，应保留当前作答；改变函数或目标q则是新问题，需要重新求解。精确候选框把根式代回原f(x)=q，分别显示两边值。家长可让孩子说明“图像猜测、代数求根、原式核验、完整分支”各自承担的任务，而不让一张近似图替代全部理由。

# Solving quadratics graphically

## Given a height, find every input

To solve f(x)=q, intersect the original graph y=f(x) with horizontal y=q and take every intersection x-value. The height q is given; the unknowns are inputs reaching it. Only when q=0 is the target the x-axis. Do not seek x-axis intersections on the original curve for every equation.

Alternatively define g(x)=f(x)−q and find zeros of this separate difference function. Both methods give identical x-values, but original intersections have ordinate q while difference zeros have ordinate zero. Identify which function is plotted rather than relabelling a difference graph as the original.

### Example 1: three targets for one curve

For y=x²−4x+3=(x−2)²−1, intersecting y=0 gives (x−1)(x−3)=0, inputs one and three and points (1,0),(3,0). Intersecting y=−1 gives (x−2)²=0, one distinct input two and point (2,−1). Tangency is one position, even though two formula branches coincide there.

Intersecting y=−2 would require (x−2)²=−1, impossible for a real square. Equivalently, the original minimum is −1 and the target lies below the whole curve. An empty set is not input zero: f(0)=3 does not meet the target.

### Example 2: irrational inputs and exact checks

For x²=2, original y=x² meets y=2 at (−√2,2),(√2,2). The exact input set is {−√2,√2}. Reading about ±1.41 from a graph is useful, but 1.41²=1.9881 is not exactly two. Use an approximation sign when estimating, and retain radicals for exact substitution.

The difference graph y=x²−2 instead meets the x-axis at (−√2,0),(√2,0), with the same inputs. For original y=(x−1)²+2 meeting y=6, (x−1)²=4 gives x−1=±2 and hence x=−1,3. Neither the intermediate ±2 nor the given ordinate six is the answer.

## Windows, cursors and completeness

The x-axis intersections of y=(x−8)(x−10) occur at eight and ten. Neither is visible in an x-window from −4 to six, yet both roots exist. Widening the window changes visibility, not the function. A target height can also lie outside the displayed vertical range; do not move off-window points to the border and imply that they are visible intersections.

Cursor C marks a trial input and its original output, not a confirmed intersection. Moving it preserves the task; changing the function or target creates a new problem. The exact-candidate field substitutes radicals into original f(x)=q and reports both sides. A parent can distinguish graphical prediction, algebraic solving, original substitution and the argument that every branch has been included.
