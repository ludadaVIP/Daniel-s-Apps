## 中间位置和最高频数是两件事

中位数先把**全部记录从小到大排序**，再看中间位置。重复值代表不同记录，不能删掉；零也是有效数值，不能当成缺失。奇数条只有一个中间位置；偶数条取中间两个数的平均。这个平均数可能没有出现在原记录中。

众数看的是**出现次数**。本课约定：报告全部并列最高且至少出现两次的值；所有值都只出现一次时记“无众数”。这不等于众数零。判断前先说清规则，再完整报告并列，不能任意挑最小或最大的一项。

### 例 1 · 不按原来的中间位置猜

1. 原记录 **9、1、3、3、4** 有五条，两个三都保留。
2. 排序为 **1、3、3、4、9**。
3. 五条中第三条在中间，中位数为 **3**。
4. 三出现两次，其余各一次，因此众数也为三。
5. 这次两个统计量碰巧相同，定义却不同：一个看位置，一个看频数。

若记录改成 1、1、2、2、3，排序第三位为二，中位数二；一与二各出现两次，所以众数为**一和二**。不能因为中位数二就漏掉众数一，也不能因为并列就说“随便写一个都行”。答案框中多个众数用逗号、顿号或分号分隔，不重复，不写千位分隔逗号。

### 例 2 · 没观察到五，也能有中位数五

1. 原记录 **8、2、6、4**，排序为 **2、4、6、8**。
2. 中间是第二、第三位，即四和六。
3. 中位数为 **(4+6)÷2=5**，不是只挑四或六。
4. 五没有出现在原记录中，也符合中位数定义；这里求的不是“出现过的中间某条”。
5. 各数都只出现一次，按本课约定**无众数**，不能写零。

反过来，0、0、0 的众数就是零，因为零出现三次；中位数也是零。“没有众数”描述没有符合规则的重复最高值，“众数为零”描述真实的一个数值，它们不能混写。

中位数不是把最小和最大平均，虽然某些对称数据会碰巧得到同样结果。例如 1、2、8、20 的中间两数平均为五，而端点平均为十点五。数值巧合不能替代位置依据。

工作台卡片编号表示当前排列位置，卡片本身的记录身份保留。先查看原顺序，再排序并指出中间卡；换一组数据会清空旧答案。家长请孩子逐条数频数，说明为什么保留两条三；不要只听见“中间”“最多”两个词就确认理解。带走一个发现：**全记录排序求中位数，按频数完整报众数，无众数不等于零。**

## Middle position differs from highest frequency

For a median, order **all observations from least to greatest**. Keep duplicates as separate observations and zero as a value rather than missing data. An odd count has one central position; an even count uses the average of the two central values. That average need not have been observed.

Mode concerns **frequency**. This lesson reports every tied highest value occurring at least twice; when every value occurs once, it records “no mode.” State that convention and retain all ties. No mode does not mean mode zero, and one tied value cannot be chosen arbitrarily.

### Example 1 · Do not use the unsorted middle

1. **9,1,3,3,4** contains five observations, including two threes.
2. Order them as **1,3,3,4,9**.
3. The third of five is central, giving median **3**.
4. Three occurs twice while the others occur once, so mode is also three.
5. The results coincide, but one definition uses position and the other frequency.

For 1,1,2,2,3, the third ordered value is two, while both one and two occur twice. Report **both modes**, rather than omitting one because the median is two. Separate multiple answers with commas or semicolons, without repeats or thousands-grouping commas.

### Example 2 · A median need not be an observed value

1. Order **8,2,6,4** as **2,4,6,8**.
2. Positions two and three contain four and six.
3. Their average is **5**, not either middle value alone.
4. Five need not be in the original data: the definition averages the central pair.
5. Every value occurs once, so under the stated convention there is **no mode**, not mode zero.

In contrast, 0,0,0 has mode zero because zero occurs three times. “No mode” states that no repeated value meets the frequency rule; “mode zero” names an actual value. Median also differs from averaging extremes. For 1,2,8,20 the middle pair averages five, whereas the endpoints average ten-and-a-half. Coincidence on a symmetric example does not replace the positional definition.

Workshop cards retain observation identities while position numbers change. Inspect the original order, sort and identify central cards; selecting another set clears old answers. A parent can ask the learner to count every repetition and explain why both threes remain. The takeaway is complete records for ordered medians, complete ties for modes, and a clear distinction between no mode and zero.
