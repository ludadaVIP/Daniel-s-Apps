# 解析几何中的参数法

参数法把一个变量的选择变成坐标点，适合描述运动、代入求交和构造轨迹。但“每个参数都给出合法点”与“每个几何点都能被参数表示”是两回事。要检查覆盖范围，往往要寻找反参数。

## 圆的有理参数式

对r>0的圆x²+y²=r²，取有限实数t，设x=r(1−t²)/(1+t²)、y=2rt/(1+t²)。分母1+t²始终正，全部实t都可计算。它可以从固定圆点E=(−r,0)引直线y=t(x+r)，求另一个圆交点得到；斜率参数的竖直方向需要另审。

平方和的分子为r²[(1−t²)²+4t²]=r²(1+2t²+t⁴)=r²(1+t²)²，除分母平方后得到r²。因此每个有限参数点都落在圆上。这是恒等计算，不依赖画了多少个样本点。

### 例1：精确点与反参数

取r=5、t=1/2，分母5/4。x=5×(3/4)/(5/4)=3，y=10×(1/2)/(5/4)=4，得到P=(3,4)。代回9+16=25可独立核查。

从这个圆点反解t=y/(x+r)=4/(3+5)=1/2，恢复原参数。t=0给(5,0)，t=1给(0,5)，t=−1给(0,−5)。反参数比只验一个点在圆上多回答了“该点能否被此规则表示”的问题。

### 例2：漏点、限弧与不匀速

圆点E=(−5,0)使反参数分母为0。直接令参数式x=−5也得到1−t²=−(1+t²)，即1=−1，不可能。因此E虽在圆上，却无有限实t表示。要得到整个圆，需另补这个点，不能把“无穷参数”当作一个普通实数输入。

对任意其他圆点，x+r≠0，可取t=y/(x+r)，用圆方程代回可恢复其原坐标，所以没有别的漏点。若t只取[0,1]，x与y都非负，从(5,0)到(0,5)，对应第一象限含两端点的圆弧，而非整圆。

再比较t=0、1、2：三点(5,0)、(0,5)、(−3,4)，相邻弦长分别5√2与√10。虽然参数间隔相同，对应小圆弧长度不同。参数t只是编码，不能自动当作匀速时间；若要描述速度，还须另给时间关系。

## 图窗不是参数定义域

工作台灰虚线给完整圆，紫线只画有限参数窗[−4,4]，避免用很大的参数伪装完整覆盖。这个绘图窗不改变数学参数域R；靠近漏点的一些合法参数点可能未显示在紫色有限轨迹里。切成[0,1]时，紫线才画该限定域的完整四分之一弧。

空心E标的是参数表示的漏点，它仍属于参照圆。若探查t超出限定域，代数点能计算，却不属于当前参数轨迹；核验表同时显示资格与反参数。每次更换范围，要重读端点包含条件。

## 出口说明什么

报告参数域、坐标式、恒等验证、漏点与反参数的适用条件。可先证明所有生成点在圆上，再用反参数处理覆盖。若讨论运动，额外区分参数、时间与弧长，不把均匀取t的点说成匀速位置。

家长可追问“分母永不0为什么还漏点”与“有限画点为什么不能证明满射”。出口完整推理由人工审核；自动点坐标和集合检查只核计算，不替代覆盖性证明。

# Parametric methods in geometry

A parameter converts one choice into a coordinate point. It is useful for motion, intersections and locus construction, but every parameter giving a valid point does not imply every geometric point is reached. Coverage needs a separate check, often through an inverse parameter.

## A rational parameterisation of a circle

For r>0 and x²+y²=r², set x=r(1−t²)/(1+t²), y=2rt/(1+t²) for finite real t. The denominator is always positive. The formula can be obtained by drawing y=t(x+r) through fixed point E=(−r,0) and finding its other circle intersection; a vertical direction needs separate attention.

The squared-coordinate numerator is r²[(1−t²)²+4t²]=r²(1+t²)². Dividing by the squared denominator proves x²+y²=r² for every finite real t. This is an identity calculation, not evidence based on a finite trace.

### Example 1: An exact point and its inverse parameter

For r=5 and t=1/2, the denominator is 5/4. Compute x=3 and y=4, giving P=(3,4). Independently verify 9+16=25.

Recover t=y/(x+r)=4/(3+5)=1/2. Parameter zero gives (5,0), one gives (0,5), and −1 gives (0,−5). Inverse recovery answers whether a specified circle point is represented, beyond merely checking membership in the circle.

### Example 2: An omitted point, a restricted arc and unequal steps

At E=(−5,0), the inverse denominator vanishes. Directly setting x=−5 in the parameter formula gives 1−t²=−(1+t²), hence the contradiction 1=−1. E belongs to the circle but no finite real parameter represents it. Add E separately for the entire circle; infinity is not an ordinary real input.

For any other circle point x+r≠0, choose t=y/(x+r). Using the circle equation recovers the original coordinates, proving there are no other omissions. If t is restricted to [0,1], both coordinates are nonnegative and the trace runs from (5,0) to (0,5), giving the first-quadrant arc with both endpoints included.

At t=0,1,2 the points are (5,0),(0,5),(−3,4). Consecutive chord lengths are 5√2 and √10, so the corresponding minor arcs differ despite equal parameter increments. Parameter t labels points; it is not automatically physical time or uniform speed. A motion model needs an additional stated time relation.

## A plot window is not a parameter domain

The grey dashed reference is the full circle. Purple draws only the finite parameter window [−4,4], which does not change the mathematical domain R. Some represented points near E are outside that plotted parameter window. With the restricted domain [0,1], the purple trace instead shows the complete allowed quarter arc.

The open marker E refers to the parameterisation’s omission; E still belongs to the reference circle. A probe outside a restricted parameter domain can produce an algebraic coordinate without being part of the allowed trace. Audit admission, inverse recovery and endpoint inclusion separately.

Report the parameter domain, coordinate formulas, identity verification, omitted point and conditions for inverse recovery. First prove generated points lie on the circle, then use the inverse parameter to prove coverage away from E. If discussing motion, distinguish parameter, time and arc length. Automated coordinate checks verify calculations; a human reviews the argument about coverage and missing points.
