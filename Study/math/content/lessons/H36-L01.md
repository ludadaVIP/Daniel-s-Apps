# 直线与圆锥曲线交点

联立方程给出同时满足两条曲线条件的点。完整答案必须是坐标点的集合，不能停在消元后的几个x值。求解之前先判断代入式是否仍为二次，才能正确使用判别式；只有一个交点并不自动意味着相切。

## 用参数统一处理竖直线

设直线为P(t)=P0+t d，t遍历实数，方向d必须非零。横线可写(t,c)，竖线(c,t)，斜线y=x+c可写(t,t+c)。这种表示不会因为直线斜率不存在就漏掉竖直线。

把坐标代入圆锥曲线，整理为At²+Bt+C=0。A≠0时才是二次：Δ>0给两个不同实参数，Δ=0给一个二重参数，Δ<0无实参数。因d非零，不同参数对应不同点；在本课非退化圆锥曲线与直线的情形，二重根给相切。

若A=0、B≠0，应按一次方程解，不能把B²−4AC当成二次判别式；若A=B=0而C≠0，则常数矛盾，没有有限交点。先核次数能阻止把代数形式里的0t²误当作真实二次项。

### 例1：圆的两点、切点与空集

求x²+y²=25与y=3的交点。写P(t)=(t,3)，代入得t²−16=0，因此t=−4或4。还原两点(−4,3)、(4,3)，每点都满足横线，且16+9=25满足圆。完整交点集为{(−4,3);(4,3)}。

把横线改y=5，得到t²=0。零是二重根，但还原后只有一个不同点(0,5)，不可把重数误当成两个人或两点。改y=6得到t²+11=0，没有实根，交点集∅；这与仅有原点或一个零根不同。

### 例2：一个交点未必是切线

求抛物线y=x²与竖线x=2的交点。写P(t)=(2,t)，代入是t=4，一次方程，只给(2,4)。竖线穿过抛物线，但并非其在该点的切线。这里没有二次重根前提，所以不能用“只看到一个点”推相切。

再看双曲线x²−y²=1与y=x。代入P(t)=(t,t)得0=1，无有限交点。y=x是渐近线，曲线靠近它不等于在远处最终相交。若改y=x+1，代入得−2t−2=0，交点(−1,0)唯一，却仍是降次得到的单点，不能硬套二次相切结论。

## 精确点与图形的分工

工作台可切圆、椭圆、抛物线与双曲线，再切横线、竖线和指定斜线。表中列A/B/C、适用时的判别式、全部参数和全部点。圆与斜线可能给根式坐标，判题接受精确根式和分数，不用图上小数替代精确答案。

紫线画圆锥曲线、橙虚线画直线，交点标S1/S2；空集时不捏造一个点。坐标两轴使用同长度单位，曲线超出有限窗口被裁剪，不被压回边界。图用于检查代回结果，不能仅凭有限视窗判断没有其他交点。

## 为什么结果没有漏点

任一原交点在整条直线上，所以有唯一参数t；代入过程是等价地把同一坐标规则写入曲线，因此原交点的参数必在解出的参数全集中。反过来，每个参数根还原出的坐标都应代回两式。两方向结合，才给出完整性。

家长可让学生先预测次数，再计算根数；随后追问“参数根还原成了哪个点”。出口用三个反例区分重根、降次和无解，并明确判别式的A非零前提。只说图上碰到一次，不足以完成论证。

# Line–conic intersections

An intersection satisfies both original equations. A complete answer is a set of coordinate pairs, not merely the x-values left after elimination. Check the degree of the substituted equation before invoking a quadratic discriminant: one finite intersection alone does not establish tangency.

## Parameterise the whole line

Write P(t)=P0+t d for all real t, with nonzero direction d. A horizontal line can be (t,c), a vertical line (c,t), and y=x+c can be (t,t+c). This handles vertical lines without requiring a finite slope.

Substitution into the conic gives At²+Bt+C=0. If A≠0, the discriminant gives two distinct real parameters, one repeated real parameter or none. Nonzero d ensures distinct parameters produce distinct points. For the nondegenerate conics and lines used here, a repeated quadratic root corresponds to tangency.

If A=0 but B≠0, solve a linear equation instead. If both coefficients vanish but C does not, the result is a constant contradiction and there are no finite intersections. A written term 0t² does not make the equation quadratic. The usual quadratic interpretation of B²−4AC requires a nonzero leading coefficient.

### Example 1: Two points, a tangent point and an empty set

Intersect x²+y²=25 with y=3. Using P(t)=(t,3) gives t²−16=0 and t=−4 or 4. Restore (−4,3) and (4,3). Each lies on the line, and each gives 16+9=25 in the circle. The complete point set is {(-4,3);(4,3)}.

At y=5, substitution gives t²=0. Zero is a repeated parameter root but produces only one distinct point, (0,5). Multiplicity is not the number of different geometric points. At y=6, t²+11=0 has no real roots, so the intersection set is empty. An empty set is not a singleton containing the origin.

### Example 2: One intersection need not be tangent

Intersect y=x² with the vertical line x=2. Parameterise it as (2,t); substitution gives t=4, a linear equation. The only intersection is (2,4), but the vertical line is not the parabola’s tangent there. The repeated-quadratic-root criterion was never available.

For x²−y²=1 and y=x, substituting (t,t) gives 0=1. There is no finite intersection. An asymptote being approached does not mean the curve eventually meets it far away. Replacing the line by y=x+1 gives −2t−2=0 and the unique point (−1,0); this is another degree reduction rather than quadratic tangency.

## Exact algebra and graphical inspection

Switch among the circle, ellipse, parabola and hyperbola, then among the declared line directions. The audit reports A,B,C, the discriminant when applicable, all parameter roots and all recovered points. Some cases have radical coordinates: retain exact radicals and fractions instead of reading rounded pixels as exact roots.

Purple is the conic, orange dashed is the line, and verified intersections are labelled. Empty cases do not invent a point. Both axes retain equal unit lengths, and curves are clipped to the viewing window rather than flattened onto its boundaries. A finite plot cannot by itself prove no other intersections exist.

Completeness needs both directions. Every original intersection lies on the full parameterised line, so it has a unique parameter satisfying the substituted equation. Conversely, every solved parameter must recover a point satisfying both original equations. Account for every parameter and check both originals. Predicting the degree before calculating helps distinguish a repeated root, a linear reduction and a contradiction.
