## 解是使原方程成立的未知数值

带有未知数的等式称为**方程**。一个候选数代入后，使原方程两边相等，它就是方程的**解**。求解不只是把数移到另一边；每一步要说明为什么保留等量关系，最终代回原式核查。

一步方程可以用一个合法逆运算直接隔离未知量。未知加数用减去已知加数；未知原量减已知量时，两边加回；未知量乘非零因数时，两边除该因数；未知量除非零除数时，两边乘该除数。相同操作必须有定义，除以零永远不合法。

### 例 1 · 四个相同量不一定每个为整数

1. 已知 **4x=5**，四个相同量合计五。
2. 两边同除非零数四：**4x÷4=5÷4**。
3. 得 **x=5/4=1.25**。这里分数与小数都为精确值。
4. 代回：**4×5/4=5**，或 **4×1.25=5**，两边相等。
5. 若截成一，代回四而不是五；答案不是整数不意味着它错误。是否需要整数取决于未知对象：每段长度可为 1.25 m，实际不可分的物品个数要另查情境。

### 例 2 · 用已学分数恢复未知加数

1. 已知 **x+1/4=1**，未知量加四分之一为一。
2. 两边同减四分之一：**x+1/4−1/4=1−1/4**。
3. 把一写成四个四分之一，得 **x=3/4**。
4. 代回 **3/4+1/4=1**，核查原关系；允许小数时 0.75 也表示同一个精确值。
5. 两边的整体标尺不能在过程中变化，否则数字形式正确也不保证原情境成立。

### 不同未知位置与零因数

x−8=14 中，x 是原量，两边加八得到二十二；代回 22−8=14。x÷5=6 中，x 是平均分前的原量，两边乘五得到三十；代回 30÷5=6。不能只看到八或五就一律从右边减去它。

0×x=0 的每个允许候选值都满足，不能确定唯一 x；0×x=5 没有数能满足，因为左边总是零。这两种情况都不能把两边除以零来“求解”。工作台会单独分类，不输出伪造的零解，也不把无解与多个候选都满足混为一谈。

本单元常用非负数量与一步关系。后续课程会研究更复杂的方程与负数，不因当前图形只用实物就声称所有方程都有一个正整数解。精确的分数结果保留，近似小数不能冒充精确解。

工作台让你先试代，也可选有依据的逆运算，再展开逐步等式和核查说明。改方程或改处理方式时，旧解收起。试代成功不是全部解释；还应说清未知量的对象、为何这个操作合法，以及代回哪一条原关系。

**带走一个发现：** 用合法逆运算保留相等，解是未知数的值。保留分数，检查零因数边界，最后代回原方程。

## A solution is a value satisfying the original equation

An equality containing an unknown is an **equation**. A candidate that makes both side values agree after substitution is a **solution**. Solving is more than moving numbers: justify each equality-preserving step and check the original.

A one-step equation uses one valid inverse to isolate the unknown. Undo addition by subtracting the known addend; undo subtraction from the unknown original by adding back; undo multiplication by a nonzero factor by division; undo division by a nonzero divisor by multiplication. Division by zero is never valid.

### Example 1 · Equal amounts need not be integers

1. In **4x=5**, four equal amounts total five.
2. Divide both sides by nonzero four: **4x÷4=5÷4**.
3. **x=5/4=1.25**, both exact representations.
4. Substitute **4×5/4=5**, or **4×1.25=5**.
5. Truncating to one gives four on substitution and fails. Whether an integer is required depends on the object: a length may be 1.25 m, while counts of indivisible items need a contextual check.

### Example 2 · Recover an addend using fractions

1. In **x+1/4=1**, an unknown plus one quarter gives one.
2. Subtract one quarter from both: **x+1/4−1/4=1−1/4**.
3. Express one as four quarters to obtain **x=3/4**.
4. Check **3/4+1/4=1**. Where decimals are allowed, 0.75 represents the same exact value.
5. Retain the reference whole throughout; correct written arithmetic cannot repair changed measurement references.

### Unknown positions and zero factors

For x−8=14, add eight to both sides to obtain twenty-two, checking 22−8=14. For x÷5=6, multiply both sides by five to obtain thirty, checking 30÷5=6. Do not automatically subtract a visible constant regardless of its role.

Every allowed value satisfies 0×x=0, so no unique value is determined. No value satisfies 0×x=5 because the left is always zero. Neither equation permits division by zero. The workshop classifies these separately instead of inventing a zero solution or confusing no solution with many satisfying values.

This unit mainly uses non-negative quantities and one-step relationships. Later units study negative numbers and more complex equations. Retain exact fraction results; an approximate decimal must not masquerade as an exact solution.

Try a candidate or choose a justified inverse before revealing working lines and a substitution check. Changing equation or method hides earlier results. Explain the unknown’s object and operation validity as well as checking the original.

**Takeaway:** preserve equality through a valid inverse. A solution is the unknown’s value. Keep fractions, check zero-factor boundaries and substitute into the original.
