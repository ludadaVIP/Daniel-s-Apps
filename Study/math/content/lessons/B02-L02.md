## 每组一样多，才有一个共同的每组量

乘法可以表示若干相同数量的组。**组数 × 每组量 = 总量**：组数在数有几组，每组量在数一组里的物体，它们不是两个可以直接合并的物体部分。

阵列把物体排成等长的行与列，让每一组的结构清楚可见。一行可作为一组，一列也可作为一组；换一种计数组法，不会凭空增加物体。

### 例 1 · 三组每组四个

1. 先画三组，每组都画四个小球。
2. 合并三个相同的四：4+4+4=12。
3. 用乘法记成 **3×4=12**。
4. 3 是组数，4 是每组的物体数。3+4=7 没有计入所有物体。

### 例 2 · 阵列的两种计数方向

1. 十二个小球排成三行，每行四个。
2. 按行看，是三组每组四个，总量 3×4=12。
3. 按列看，是四组每组三个，总量 4×3=12。
4. 因此 **3×4=4×3**，对应的是同一批十二个小球。
5. 总量相同，不代表故事中的组数与每组量也相同；三袋每袋四个，与四袋每袋三个，是不同的装袋方式。

### 不是任何分组都能直接套乘法

若三组分别有 2、4、7 个，组量不同，不能说“三组每组四个”。应按实际各组相加，2+4+7=13。乘法式使用共同的每组量，必须先确认每组确实相同。

六组每组五个，是六个五合起来，6×5=30。分解成几组先算再合并，仍是在数同一批物体，不是另添一批。

每组八个但没有任何一组，总量为 **0×8=0**。八只是“如果有一组时每组多少”，不能当成已经存在的一组。若有五组但每组零个，总量也为零；组的轮廓可以存在，物体数量仍为零。

工作台可切换等组与阵列，并交换两个因数。每次先辨认哪一个数计组、哪一个数计每组，再预测总量。交换后，画出的行列或容器数会变，总物体数保持相同。

**小检查：** 花园四行每行六棵苗，为什么求总量用乘法而不是 4+6？指出两数的角色。

## Equal groups share one amount per group

Multiplication can describe repeated equal amounts. **Group count × amount per group = total**. Group count tells how many groups there are; amount per group counts objects in one. They are not two object parts to add directly.

An array arranges objects in equal rows and columns, making the grouping visible. A row or a column can be one group. Changing the counting direction does not create extra objects.

### Example 1 · Three groups of four

1. Draw three groups, each with four counters.
2. Combine three equal fours: 4+4+4=12.
3. Record this as **3×4=12**.
4. Three counts groups; four counts objects per group. 3+4=7 fails to count all the objects.

### Example 2 · Two ways to count an array

1. Arrange twelve counters in three rows of four.
2. By rows, there are three groups of four: 3×4=12.
3. By columns, there are four groups of three: 4×3=12.
4. Therefore **3×4=4×3** describes the same twelve counters.
5. Equal totals do not imply identical group counts or per-group amounts. Three bags of four and four bags of three are different packing arrangements.

### Unequal groups need their actual amounts

If three groups contain two, four and seven objects, they are not three groups of four. Add the actual quantities: 2+4+7=13. A multiplication expression uses a shared per-group amount, so first check that the amounts really match.

Six groups of five combine six equal fives, giving 6×5=30. Splitting those groups into smaller batches for calculation still counts the same objects; it does not add another batch.

Eight per group with zero groups gives **0×8=0**. Eight says what a group would contain, not that a group exists. Five groups with zero objects each also total zero: group outlines may exist while no objects are present.

The workshop switches between groups and arrays and swaps factors. Identify what each factor counts before predicting the total. Swapping changes row/column or container count, while retaining the object total.

**Quick check:** why does four garden rows with six seedlings each use multiplication rather than 4+6? Identify both quantity roles.
