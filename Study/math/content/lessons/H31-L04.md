# 局部与全局最值

导数帮助寻找候选，定义域决定比较范围，是否取到决定能否称最值。本课把这三步连起来，不把找到驻点当作优化结束。

## 先给范围，再给候选

连续函数在非空闭有界区间上一定取到最大和最小。这条定理不保证唯一，也不保证最值在驻点，更不能删除连续或闭有界条件后照用。

候选包括区间内f′=0的点、不可导但函数有定义的点，以及被包含的端点。局部极值比较某点附近；全局极值比较整个给定域。本单元沿用严格内点局部极值作分类，端点另作全局候选，避免不同端点局部约定造成混淆。

### 例1：并列位置必须完整

f(x)=x³−3x在[−2,2]。f′=3(x−1)(x+1)，内点候选−1、1，加上两端−2、2。

函数值依次为f(−2)=−2、f(−1)=2、f(1)=−2、f(2)=2。故全局最大值2，全部位置{−1,2}；全局最小值−2，全部位置{−2,1}。位置集合与输出最值不是同一答案类型。

导数在−1左正右负，所以−1为严格局部极大；在1左负右正，为严格局部极小。端点2虽不是内部驻点，却同样取到全局最大。每两个相邻候选之间导数符号固定，函数单调，因此这些候选覆盖全域，不能只以有限表格本身冒充证明。

### 例2：开端点与不可导点

g(x)=x²在(0,2)，每个函数值都大于0、小于4。可以趋近0与4，却不能取到：没有最小值也没有最大值；下确界0、上确界4。上/下确界是最紧的界，和是否取到是两项信息。

改为[0,2)，最小值0在0取到，最大值仍未取到。改为[0,2]才两者都取到。打开端点是否改变结论还要看内部是否已有同高点，不能只见开区间就一律说无最值。

再看|x|在[−2,1]：内点0不可导，却给最小值0；最大值2在−2。只找f′=0会完全漏掉0。驻点也不充分：x³在0导数0，左右仍递增，既非严格局部极大也非极小。

## 图像、候选表与完整论证

工作台把端点画空心或实心，精确表同时列端点值或趋近极限、是否包含、候选理由。裁切掉的曲线并未被改写为平台，窗外数值仍在表中。表里的空最值位置集合表示界未取到，不表示输入域为空。

选择不同函数和区间后，先报最小输出，再报最大输出的全部位置；若未取到，明确写not-attained。这比从图上挑一个最高像素更能暴露“漏端点、漏尖点、漏并列、混值与位置”的错误。

出口需写定理条件、完整候选、单调区间或其他全域理由，以及哪些界实际取到。常数函数还提醒我们最值位置可能是整个区间，不能总强行写有限点集；本课工作台选择了最值位置有限的三种函数，家长审核负责检查论证的实际范围。

# Local and global extrema

Derivatives locate candidates, the domain determines comparison scope, and attainment determines whether a bound is an extreme value. Connect all three rather than stopping at a stationary point.

## Specify the range of inputs first

A continuous function on a nonempty closed bounded interval attains a maximum and minimum. This theorem guarantees neither uniqueness nor stationary locations. Its continuity and interval conditions cannot simply be deleted.

Candidates include interior stationary points, interior nondifferentiable points where the function is defined, and included endpoints. Local extrema compare nearby inputs; global extrema compare the entire stated domain. This unit uses strict interior local classifications and treats endpoints separately as global candidates, avoiding ambiguity between endpoint conventions.

### Example 1: Retain every tied location

For f(x)=x³−3x on[−2,2], derivative3(x−1)(x+1) gives interior candidates−1 and one. Add endpoints−2 and two.

The four values are−2,2,−2,2 respectively. Global maximum value two occurs at{−1,2}; global minimum value−2 occurs at{−2,1}. The output value and its input locations are different answer types.

Derivative signs change positive to negative at−1 and negative to positive at one, establishing strict local maximum and minimum. Endpoint two is not an interior stationary point but still globally maximises. Between adjacent candidates the derivative sign is fixed, so monotonicity proves that the candidate list covers the domain. The finite table by itself is not the whole proof.

### Example 2: Excluded endpoints and corners

For x² on(0,2), every output lies strictly between zero and four. Both bounds can be approached but neither attained. There is no minimum or maximum; the infimum is zero and supremum four. A least upper or greatest lower bound carries separate information from attainment.

On[0,2), the minimum zero is attained at zero while the maximum remains unattained. On[0,2] both are attained. Opening endpoints must also be checked against interior points of the same height; an open interval does not automatically rule out every extreme.

For |x| on[−2,1], nondifferentiable zero gives minimum zero; the maximum two occurs at−2. Searching only for zero derivatives would miss the minimum. Stationarity is not sufficient either: x³ has derivative zero at zero but increases through it, giving neither strict local extreme.

## Connect plots, candidate tables and full arguments

The workbench uses open and closed endpoint markers. Its exact table records endpoint values or limits, inclusion and candidate reasons. Clipped curves are not flattened and out-of-view values remain in the table. An empty extreme-location set means an unattained bound, not an empty input domain.

After changing function or interval, predict the minimum output and every maximum location. Use not-attained when appropriate. This exposes omitted endpoints, corners and ties, and confusion between values and locations, more clearly than selecting a high pixel.

For the exit, state theorem conditions, all candidates, a monotonicity or other domain-wide argument and which bounds are attained. A constant function can have an entire interval of extreme locations, so finite point sets are not universally appropriate. The three workbench families have finite location sets; parent review checks that the argument stays within its actual scope.
