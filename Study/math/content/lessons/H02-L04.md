# 函数图像变换

“式子里面乘2”常让人直觉以为横坐标也乘2。追踪一个确定源点却会发现相反结果：若g(x)=f(2x)，要让内部输入仍等于原来的u，就须2x=u，所以新横坐标是u/2。

## 一条核心想法

**用同一个源点解释图像变换，而不只背方向口诀。** 设源点为(u,f(u))，新函数g(x)=a f(b(x−h))+k，b≠0。令内部输入b(x−h)=u，解得新横坐标x=h+u/b；新纵坐标是k+a f(u)。于是点对应为(u,f(u))→(h+u/b,k+a f(u))。

h改变横向位置，k改变竖向位置；a改变相对水平轴的竖向倍率，负a还反射；内部b使横向距离按1/|b|缩放，负b还反射。平移后要相对新的参照位置理解倍率。a=0会压成常值，但不自动解除题目规定的输入限制；b=0不属于这个可逆横向点对应公式。

### 例1：平移与竖向倍率

f=x²，g(x)=2f(x−3)−1。源点(1,1)的内部输入要求x−3=1，因此新横坐标4；纵坐标2×1−1=1，得到(4,1)。源点(0,0)则到(3,−1)，显示新顶点位置。不是把所有点向左3，也不是把最终新纵坐标整体乘2而忘记−1的位置。

代数再核：g=2(x−3)²−1=2x²−12x+17。代x=4得32−48+17=1，与追踪点一致。展开式与顶点式表达同一函数，但若任务要求展开合并，就必须完成相应形式，不把“数值等价”当作“任务形式已完成”。

### 例2：内部倍率、反射与给定域

g=f(2x)，源点(2,4)到(1,4)，横坐标缩半而纵坐标不变。f=x³时，g=f(−x)把(2,8)移到(−2,8)，是关于y轴的反射。不要因为奇函数还能写成−f(x)，就把这一步的点身份误记成(2,−8)；那是另一种点对应描述。

若原f只在[−2,2]定义，g=f(2(x−1))要求−2≤2(x−1)≤2，所以新域[0,2]。即使f有可写到更远的公式，也不能偷偷扩展它的给定域。若再乘a=0，表达式作为该给定函数的复合仍保留[0,2]；“可另定义为全实数上的零函数”是另一件事。

## 工作台：两种查询别混

“源点输入u”用于追踪源点到新点；“查询新输入x”用于直接算g(x)。改变u只重置点预测，不应清掉对固定新输入的函数值预测。改变a、b、h、k或原函数，才改变相应数学对象；只改窗口则保留全部预测。

绿色虚线为源图，紫色为新图，两轴单位长度一致。若所选点超窗，坐标不压到边框上，应扩大视窗或读精确数值。无界定义域只绘一部分示意弧，弧端不是函数定义域端点；有限给定域则显示实际端点。

## 迁移与审核

试g=−f(x+2)+3，把源点(1,1)变成(−1,2)，再代回内部输入与外部输出核验。家长不只问“左还是右”，还让孩子写出为何内部应等于u、倍率作用在哪个量上，以及给定域有没有一起改变。

# Graph translations and stretches

An inner factor of two can tempt us to double horizontal coordinates. Track a fixed source point instead: for g(x)=f(2x), preserving original input u requires 2x=u, so the new horizontal coordinate is u/2.

## One central idea

**Explain a graph transformation by following the same source point.** If the source is (u,f(u)) and g(x)=a f(b(x−h))+k with b≠0, set b(x−h)=u. The new point is (h+u/b,k+a f(u)).

h and k translate horizontally and vertically. a scales outputs, with negative a also reflecting. The inner factor b scales horizontal distances by 1/|b|, with negative b reflecting horizontally. Interpret scales relative to the shifted reference positions. At a=0 outputs collapse to a constant, but stipulated domain restrictions remain. b=0 is outside this reversible horizontal point formula.

### Example 1: Translation and vertical scale

Let f=x² and g(x)=2f(x−3)−1. For source point (1,1), x−3=1 gives new input four; the output is 2×1−1=1. Thus the point becomes (4,1). Source (0,0) becomes (3,−1), showing the new vertex. This is not a left shift by three, nor multiplication of the entire final output without respecting the later subtraction.

Audit algebraically: g=2(x−3)²−1=2x²−12x+17. At x=4 this gives 32−48+17=1, agreeing with the tracked point. Expanded and vertex forms describe the same function, but a task requiring a collected polynomial still requires completing that form.

### Example 2: Inner scale, reflection and domain

For g=f(2x), source (2,4) becomes (1,4): horizontal coordinates halve and outputs stay fixed. For f=x³ and g=f(−x), source (2,8) becomes (−2,8), a reflection in the y-axis. Although oddness also allows g=−f(x), do not confuse this source-point correspondence with (2,−8), which tracks points through another operation.

If f is defined only on [−2,2], then g=f(2(x−1)) requires −2≤2(x−1)≤2. Its new domain is [0,2]. A formula that could be extended does not extend the given function automatically. Even multiplying by a=0 retains [0,2] for this stipulated composition; defining a different zero function on all reals is another operation.

## Two different workbench queries

Source input u tracks a source point. New input x evaluates g directly. Changing u resets the point prediction but should preserve a function-value prediction at a fixed new input. Changing a,b,h,k, the source function or its domain changes the mathematics. A window change preserves predictions.

Green dashed is the source and purple is the transformed graph; both axes use equal unit lengths. An off-window point retains its true coordinates rather than being flattened onto a border. Read its exact value or enlarge the window. For an unbounded domain, an illustrated arc is only part of the graph; its sampled ends do not define the domain. Restricted domains have actual endpoint markers.

## Transfer and review

Try g=−f(x+2)+3. Source (1,1) becomes (−1,2). Substitute to audit the inner source input and the outer output. A parent asks not only left or right, but why the inner expression equals u, which quantity the scale changes, and whether the stipulated domain transformed too.
