# 分类计数与分步计数

计数前先完成一句话：“一个完整结果是……”。它可能是一张卡、一对有顺序的选择，或包含所有步骤的一件作品。**不同的选择路径不一定代表不同结果**；公式必须服务于结果的身份。

## 先列身份，再选运算

若所有结果分成互不重叠的类别，每个结果恰落一类，总数就是各类数量之和。这叫分类加法原理。若类别重叠，直接相加会重复；两类时可用|A∪B|=|A|+|B|−|A∩B|。减去交集一次，是因为它原先已被数了两次。

若一个完整结果必须完成多个步骤，第一步有m种选择，并且**每一种首步选择都恰有n个合法后续**，完整两步结果有mn种。这里没有假定随机独立：这是确定性的计数条件。概率中的独立性是后面另一项定义，不能混用。

分支后续数若分别为n₁,n₂,…，就分别数再相加，而不是找一个顺手的数统一相乘。可以在某些分支内部继续乘法，再把不同分支合并。加法与乘法往往在同一问题里合作。

### 例1：同一张卡出现在两类

第一类卡的身份是A,B,C，第二类是C,D。从两类中任选一张卡，完整结果是卡的身份。合并清单为A,B,C,D，共4种。3+2=5把C重复了一次，修正为3+2−1=4。

若任务改为“选择类别，再记录卡”，第一类C与第二类C的类别记录不同，此时可以有5个带类别的记录。数字不同来自**结果定义改变**，并不是同一问题有两个矛盾答案。题目必须说明到底记录什么。

### 例2：有禁配的两步

第一步选编号1,2,3，第二步选编号1,2。若全部搭配允许，完整结果为(1,1),(1,2),(2,1),(2,2),(3,1),(3,2)，共3×2=6。

加入“两个编号不能相同”后，删除(1,1),(2,2)，剩4种。也可按首步分支：首步1只可接2，有1种；首步2只可接1，有1种；首步3可接1或2，有2种。总数1+1+2=4。限制不意味着随意把第二步统一减1，因为首步3原本就不在第二步名单里。

## 工作台与出口

先选择“类别任选一张”或“完成两步”，预测后再展开核验。类别表保留重复身份和去重后的并集；分步表按首步列出每个合法有序数对。切换规则时检查是否改变了结果空间，不靠题目里有“或”就机械做加法。

出口需要自己列两类结果，并解释为什么相加或相乘。家长可追问：“这一个结果完整了吗？”“这个结果有没有被数两次？”若只能说口诀，回到J76的样本空间逐项列举，再把清单压缩成算式。

# Addition and multiplication counting principles

Before counting, complete the sentence: “One complete outcome is …”. It might be a card identity, an ordered pair, or a design that includes every required stage. **Different routes to a choice need not represent different outcomes.** A formula must count the identities the problem actually asks for.

## Define outcomes before choosing an operation

When categories are disjoint and cover all outcomes, each outcome appears in exactly one category. Add their sizes. If two categories overlap, direct addition counts their intersection twice, so |A∪B|=|A|+|B|−|A∩B| removes one copy of that intersection.

For a two-stage outcome, suppose the first stage has m choices and **each first-stage choice has exactly n legal continuations**. There are mn complete outcomes. This is a deterministic statement about the available choices, not an assumption of probabilistic independence. Independence will receive its own probability definition later.

If continuation counts vary, count each branch separately and add. For branches of sizes n₁,n₂,… the total is their sum. Some branches can themselves contain several stages, so addition and multiplication often work together rather than compete as alternative rules.

### Example 1: A shared card identity

Category one contains A,B,C, and category two contains C,D. If the outcome records only the selected card identity, the merged list is A,B,C,D: four outcomes. Adding 3+2 counts C twice. Correcting the duplication gives 3+2−1=4.

Now change the task to record both the category and the card. Category-one C and category-two C are different records, so there are five labelled records. This is a change in what defines an outcome, not two conflicting answers to an unchanged question. Explicitly naming the record resolves the ambiguity.

### Example 2: Restricted stages

Choose first from 1,2,3 and second from 1,2. With every pairing allowed, the six complete ordered outcomes are (1,1),(1,2),(2,1),(2,2),(3,1),(3,2). Each first choice has two continuations, giving 3×2=6.

Now forbid equal numbers. Remove (1,1) and (2,2), leaving four. Alternatively, first choice 1 allows only 2; first choice 2 allows only 1; first choice 3 allows either 1 or 2. Their branch sizes are 1,1,2, summing to four. Subtracting one from every second-stage count would be wrong: 3 was never an available second-stage number.

## Explore and explain

Choose between alternative categories and complete stages, predict the count, then open the audit. The category table retains shared identities and the deduplicated union. The stage table lists all legal ordered pairs within each first-stage branch. Ask whether changing a rule changes the outcome space instead of choosing an operation from a single word.

For the exit task, construct and list both kinds of outcomes. Explain why your lists are exhaustive and have no duplicate identities. A parent can ask whether a proposed outcome includes every required stage and where any duplicated outcome appears. If the explanation is only a memorised slogan, return to explicit sample-space lists before compressing them into arithmetic.
