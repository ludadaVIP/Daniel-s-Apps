# 截距代表初值

## 先确定是哪条轴

在 `y=mx+b` 中令 x=0，乘积项为零，剩下 y=b，所以代数直线与 y 轴的交点是 `(0,b)`。b 是一个 y 值，截距点是一个有序数对，这两种提问格式不同。x 轴上的点满足 y=0，不是 x=0；两个轴交点不能互换坐标冒充。

“初值”需要变量定义支持。如果 x 表示从开始计时的时间，且零时刻在模型适用域，b 可以解释为模型起始量。如果观测从 x=2 才开始，第一条记录不自动等于 b；如果允许域排除零，则代数延长线的截距也不自动是实际发生或观测的量。

### 例 1：两个轴交点

给定 `y=−x+3`。求 y 截距点：令 x=0，得 y=3，因此为 (0,3)。固定项三是截距值 b，点的横坐标必须为零。写成 (3,0) 会把点放到另一条轴。

若另问 x 轴交点，则令 y=0，解零=−x+3 得 x=3，交点为 (3,0)。这一次二者恰好有相同非零数三，也仍是两个不同位置，不能据此忽略顺序。

再看 y=2x−6：y 截距值为负六，点为 (0,−6)；x 轴交点由 2x−6=0 得 (3,0)。两种交点的非零数也不相同，更能暴露把固定项直接填进第一坐标的错误。

### 例 2：截距在图窗外或观测域外

关系 `y=−3x+8` 的 y 截距点为 (0,8)。初始图窗若只显示 −5≤y≤5，就看不到它，但不能把 b 改成五或声称没有截距。扩大纵向范围到含八即可显示；公式、坐标和已有作答都不因换窗口而变。

另给 y=2x+3，而实际只记录 2≤x≤6。代数延长线在 x=0 时仍给三，截距点为 (0,3)。第一条记录若为 (2,7)，七是零输入之后两个 x 单位的输出，不是 b；(0,3) 不在观测区间，也不能说“数据已经证明起点是三”。若线性只是有限数据下的假设，域外解释还需要证据。

这不是拒绝数学延长：完整代数直线可以有截距。需要分清题目是在问代数关系的交点，还是模型允许范围内实际记录了什么。

## 平移、斜率与语境

固定 m，只把 b 加一，每个同输入的 y 都加一，图像竖直平移一个 y 单位；固定 b 改 m，所有关系仍通过 (0,b)，但单位变化率改变。正负 b 都合法，不能把负数截距自动判作不合理；它是否合理依赖输出是什么以及零输入是否在域内。

工作台分别调整 m/b，显示 x=0 的点与表格零输入行；改变另一个输入不会改变截距。边界在窗外时仍保留精确结果。家长让孩子先说“哪一坐标为零”，再写点；之后才讨论该零输入在现实里是否有意义，不把两层问题混在一起。

# Intercept as starting value

## Identify the axis first

Setting x=0 in y=mx+b gives y=b, so the algebraic line crosses the y axis at (0,b). The intercept value is one number; the intercept point is an ordered pair. The x axis instead requires y=0. Exchanging coordinates generally exchanges different questions.

“Starting value” depends on definitions. If x measures time since a defined start and zero belongs to the model domain, b can represent that starting amount. An observation beginning at x=2 is not automatically b. An algebraic intercept outside the allowed domain is not automatically an observed or realised quantity.

### Example 1: two axis crossings

For y=-x+3, set x=0 to get y=3, giving the y intercept (0,3). Three is b; the first coordinate must be zero. Writing (3,0) places the point on the other axis.

To find the x-axis crossing, set y=0. Solving 0=-x+3 gives x=3 and the different point (3,0). Matching nonzero numbers in this example do not remove the importance of order.

For y=2x-6, the y intercept is (0,-6), whereas 2x-6=0 gives the x-axis crossing (3,0). Here even the nonzero values differ, exposing the mistake of putting b into the first coordinate.

### Example 2: outside the window or observed domain

The rule y=-3x+8 has y intercept (0,8). A window showing y only from minus five to five cannot display it, but b does not become five and the intercept does not disappear. Widen the window without changing coordinates, formula or answer.

For y=2x+3 with observations only over 2≤x≤6, the algebraic extension has intercept (0,3). The first observation (2,7) is an output two input units after zero, not b. The intercept was not observed. If linearity is merely a modelling assumption, extending beyond data needs further justification.

The full algebraic line may still be extended mathematically. Distinguish a request for its intercept from a claim about what actually occurred within the model domain.

## Parameters and context

Increasing b by one while retaining m increases every corresponding output by one, translating the graph vertically. Changing m while keeping b leaves the same y intercept but changes the rate. Negative intercepts are mathematically valid; their contextual meaning depends on the output quantity and permitted zero input.

The workshop separates m/b controls, the x=0 point and the table’s zero row. Changing another input does not alter the intercept. A parent asks which coordinate is zero before discussing whether that input has a real contextual meaning.
