# 排列与阶乘

排列数的是**不同对象占据有区别位置**的完整方式。两个人分别当队长与记录员，交换职责后是新结果；同权小组将在下一课合并这些顺序。本课每个对象都有独特身份，不讨论相同字母不可区分的多重排列。

## 逐位置数，阶乘只是缩写

n个不同对象无重复填r个有标签位置，0≤r≤n时，第一个位置有n种，第二个剩n−1种，依次得到P(n,r)=n(n−1)…(n−r+1)=n!/(n−r)!。全排n个时为n!=n(n−1)…1。

0!=1：一个空列表是“不放任何对象”的唯一结果。这使P(n,0)=1，也使P(n,n)=n!中的分母0!有意义。不要把“每个结果里没有东西”误当成“没有合法结果”。若r>n且不能重复，就确实没有合法完整排列，数量为0；无需引入负数阶乘。

允许重复时，放过的对象下一步仍可用，每个位置都有n种，改成n^r。这个规则不能从排列阶乘公式中省掉；同一个n、r会因是否重复而产生不同结果空间。

### 例1：职位分配

五位不同成员A,B,C,D,E中，选一位队长、一位记录员，每人最多一职。队长5种，选定后记录员剩4种，共5×4=20。A队长B记录员与B队长A记录员职责不同，都要数。

若四张不同卡全部排成一行，连续选择为4、3、2、1，总数4!=24。这里位置是从左到右的第1、2、3、4位；若改为围成圆圈且旋转视作同一个结果，结果定义又变了，不能继续照抄24。本课固定为线性有标签位置。

### 例2：重复与空位置

字母A,B,C填两个位置。不可重复时列出AB,AC,BA,BC,CA,CB，共6=3×2。允许重复时再加入AA,BB,CC，共9=3²。第二种并没有“新的对象”，改变的是可再次使用的规则。

若位置数变成0，只有空列表∅，共1种。它不是含有符号“∅”的一张新卡，只是空结果的显示记号。若只有3张卡却要无重复填4个位置，则有一个位置无法填满，完整结果数0。一个空结果与没有结果是不同概念。

## 怎样核验自己的公式

工作台可改变对象数、位置数及重复规则。先用小规模清单观察AB和BA，再展开全部有序结果；清单完整显示当前参数，没有用省略号冒充穷尽。r=0时核验表显示一个空列表。

出口先列清单，再解释每步剩余数。家长可交换两个位置询问是否为新结果，接着问同一个对象能否再次使用。若还混淆有序与无序，先用两张写姓名的卡分别放进“队长”“记录员”两个纸框，再进入组合课。

# Permutations and factorials

A permutation places **distinct objects into distinguished positions**. A captain and a recorder have different roles, so exchanging their occupants creates a different assignment. Equal-role teams will merge these orders in the next lesson. Every object here has a unique identity; indistinguishable repeated-letter arrangements are outside this lesson’s formula.

## Count positions before using factorial notation

To fill r labelled positions from n distinct objects without repetition, with 0≤r≤n, the successive choice counts are n,n−1,…,n−r+1. Thus P(n,r)=n(n−1)…(n−r+1)=n!/(n−r)!. Arranging every object gives n!=n(n−1)…1.

The convention 0!=1 represents one empty list: there is exactly one way to place nothing into no positions. It keeps P(n,0)=1 and the full-arrangement formula consistent. Having nothing inside each outcome is different from having no legal outcomes. If r>n without repetition, there are no complete arrangements, so the answer is zero; negative factorials are unnecessary.

When repetition is allowed, an object used earlier remains available. Every position has n choices, giving n^r instead. The repetition rule changes the outcome space even when the numbers n and r stay the same.

### Example 1: Assigning roles

From five distinct members A,B,C,D,E choose a captain and a recorder, with each person holding at most one role. There are five choices for captain and four remaining choices for recorder, giving twenty. A as captain with B recording differs from B as captain with A recording.

For four distinct cards in a line, the position counts are 4,3,2,1, so 4!=24. The positions are explicitly first through fourth from the left. A circular arrangement with rotations identified would define outcomes differently and cannot automatically use the same count. Here all positions are linear and labelled.

### Example 2: Repetition and empty positions

Using A,B,C in two positions without repetition gives AB,AC,BA,BC,CA,CB: six strings. Allowing repetition adds AA,BB,CC, giving nine. No new physical objects were introduced; the change is that a symbol may be reused.

With zero positions there is one empty list, displayed as ∅. That notation is a display convention, not an additional card bearing a symbol. By contrast, three cards cannot fill four positions without repetition, so there are zero complete arrangements. One empty outcome and no outcomes are mathematically different.

## Audit the formula

Change the number of distinct objects, positions and repetition rule in the workbench. Start with a small list that includes both AB and BA, then inspect the full ordered list. The audit enumerates every outcome for the chosen small parameters rather than hiding missing cases behind an ellipsis. With r=0 it displays the one empty list.

For the exit, list both repetition cases and justify every stage’s available choices. A parent can swap two occupants and ask whether the responsibilities changed, then ask whether a used object is available again. If order is still unclear, physically place two named cards in labelled captain and recorder boxes before moving to combinations.
