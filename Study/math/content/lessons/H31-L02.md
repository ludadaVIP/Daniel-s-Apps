# 三角函数的导数

三角函数的值与斜率在同一个输入处通常不同。本课的主要目标是在明确弧度制和定义域后，正确使用三角导数与链式因子。

## 弧度是公式的一部分

当x为弧度时，(sin x)′=cos x，(cos x)′=−sin x。正弦在0的值是0，斜率却是1；余弦在0的值是1，斜率是0。函数值不是导数值。

标准推导用到弧度极限sin h/h→1与(cos h−1)/h→0。由和角公式展开差商，正弦得到cos x，余弦得到−sin x。这些极限和链式法则是理由；有限差商表只能展示趋近，不是对全部输入的证明。

若变量d以度数衡量，g(d)=sin(πd/180)，则g′(d)=(π/180)cos(πd/180)。在0，斜率是π/180而非1。换输入单位会改每输入单位的变化率，不能只把横轴标签从弧度换成度。

### 例1：内层加快，斜率也乘因子

f(x)=3sin(2x)。外层正弦变余弦，原系数3保留，内导2再相乘：f′(x)=6cos(2x)。在0，f=0而f′=6；在π/2，f=0而f′=−6。这说明经过同一高度可以向不同方向运动。

h(x)=4cos(3x)给h′(x)=−12sin(3x)。负号来自余弦规则，3来自内导，不可互相抵消或漏掉。和式sin x+cos x的导数是cos x−sin x。

工作台中紫线为原函数，绿线为导函数；同一横坐标分别读值与斜率。系数k变大不仅压缩周期，也使导函数振幅乘k。图只能启发；完整公式说明变化为什么发生。

### 例2：正切导数与不存在的输入

tan x=sin x/cos x，只在cos x≠0处定义。由商法则，导数为[cos²x+sin²x]/cos²x=1/cos²x，也可写sec²x，仍须保留相同定义域。

在0，tan0=0而导数1。在π/2，cos=0，tan本身无定义，不能说导数为一个很大的有限数，也不能用画面上最近的点替代该输入。tan(kx)的导数是k/cos²(kx)，同样要求cos(kx)≠0。

例如k=2时，x=π/2使内角π，函数有定义、导数2；不能见输入包含π/2就机械判无定义，必须查实际内角。k=1时同一输入才落在渐近线。

## 把公式的条件带进结论

探索可切换sin、cos、tan、内层系数和π/2倍数输入。正切逐支画，不跨渐近线连出假线段；窗外部分裁切，不改写成平台。所选精确斜率依据规则及特殊角，不从图上估读判分。

公式任务接受题中同一角参数的sin(…)、cos(…)以及有理系数和括号；可按单位圆恒等式核验支持的等价多项式形式。正切的一般推导与度数转换在解释中由人审核。出口须指出输入单位、内导、符号及哪里不可定义，避免只背“正弦变余弦”。

# Derivatives of trig functions

A trig function’s value and slope usually differ at the same input. The main goal is to use trig derivatives and inner factors after checking radians and domain.

## Radians belong to the rule

With x in radians,(sin x)′=cos x and(cos x)′=−sin x. Sine has value zero but slope one at zero; cosine has value one but slope zero. Function value is not derivative value.

The standard derivation uses sin h/h→1 and(cos h−1)/h→0 in radians. Expand difference quotients with addition formulas to obtain cosine and negative sine. These limits and the chain rule supply the reasoning; a finite table of quotients only illustrates convergence.

For degrees d, write g(d)=sin(πd/180). Then g′(d)=(π/180)cos(πd/180), giving π/180 at zero rather than one. Changing input units changes rate per input unit; relabelling an axis alone is insufficient.

### Example 1: Faster inner input multiplies slope

For f(x)=3sin(2x), retain the coefficient three, change sine to cosine and multiply by inner derivative two: f′(x)=6cos(2x). At zero the value is zero and slope six. At π/2 the value is again zero but slope−6. The same height can be crossed in different directions.

For h(x)=4cos(3x), h′(x)=−12sin(3x). The minus sign comes from cosine differentiation and factor three from the inner rate; neither may be discarded. The derivative of sin x+cos x is cos x−sin x.

The workbench plots the original function in purple and its derivative in green. Read value and slope separately at a shared horizontal coordinate. Increasing k compresses the period and multiplies derivative amplitude. The formula explains why; the plot only illustrates it.

### Example 2: Tangent and missing inputs

Tangent equals sine divided by cosine and requires cos x≠0. The quotient rule gives[cos²x+sin²x]/cos²x=1/cos²x, also written sec²x, with the same domain restriction.

At zero tangent is zero and its derivative one. At π/2 cosine is zero, so tangent itself is undefined. Neither a large finite number nor a nearby plotted value supplies a derivative there. For tan(kx), the derivative is k/cos²(kx) where cos(kx)≠0.

For example k=2 and x=π/2 produce inner angleπ, so the function is defined and the derivative is two. The appearance of π/2 in the input does not automatically mean undefined: inspect the actual inner angle. With k=1 that input does hit an asymptote.

## Carry conditions into the conclusion

Explore changes function, inner coefficient and inputs measured in multiples of π/2. Tangent branches are drawn separately without false segments crossing asymptotes. Out-of-view pieces are clipped rather than flattened. Exact selected slopes come from rules and special angles, not pixel estimates.

Formula tasks accept sin(…),cos(…), rational coefficients and brackets with the stated argument, including supported polynomial equivalents justified by unit-circle identities. Human review checks the general tangent derivation and degree conversion. The exit must identify units, inner factors, signs and excluded inputs, beyond simply remembering “sine becomes cosine”.
