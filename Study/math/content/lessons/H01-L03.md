# 命题与反例

“所有数的平方都不小于它自己。”你试了−2、0、1、2，都符合；但1/2的平方是1/4，比1/2小。一次失败足以推翻“所有”，许多成功却未必覆盖所有。更有意思的是：若把范围改成整数，这个命题又是真的。

## 一条核心想法

**命题是有确定真假的陈述；范围与量词是命题的一部分。** 我们不知道它的真假，不等于它没有真假。“请打开窗户”是请求，没有真假值；未给x取值或量词的“x+1=3”是含自由变量的开语句，本课不把它当作已确定真假的命题。指定x=2，或说“存在实数x使x+1=3”，才得到相应命题。

“所有”是全称量词；“存在”要求至少有一个见证。反例针对全称陈述，必须同时满足：在规定范围内；违反所宣称的结论。域外的数、符合结论的数，都不能作为有效反例。

### 例1：同一个式子，不同范围

实数命题“对所有实数x，x²≥x”是假：取x=1/2，得x²=1/4<1/2。反例只需一个，不必找出全部失败值。注意x=−2不是反例，因为4≥−2成立。

整数命题“对所有整数n，n²≥n”是真。将差写成n²−n=n(n−1)。整数必有n≤0或n≥1，不存在0与1之间的整数：前一种情况下两因子都非正，后一种都非负，因此乘积总非负。这覆盖每一个整数，才是证明，不是只列几个例子。1/2在整数范围外，不能推翻这个版本。

### 例2：量词的否定

“所有整数都是偶数”的否定是“存在一个整数不是偶数”，见证可取1。否定并不是“所有整数都是奇数”；原命题只要一个失败就被否定，不要求所有都失败，0还是偶数。

“存在整数n使n²=2”的否定是“所有整数n都有n²≠2”。解释原存在命题为什么假：|n|≤1时n²≤1，|n|≥2时n²≥4，全部整数都被覆盖，没有平方等于2的。只试n=0不行，因为一个失败不能否定“存在”；否定存在需要排除所有候选。

## 操作时保持同一句话的范围

先选整数范围，预测x²≥x是否全称成立。输入1/2尝试反驳，工作台会先检查它是否在域内，而不会把计算正确当成反例有效。切换实数后，相同候选就能反驳。再试−1、0、1，解释为什么这些成功例不能替代完整证明。

工作台只接受有理数候选以便精确核验，这不把实数命题的范围缩成有理数；实数中的有理反例已足够反驳它。它也不自动判断任意中文证明的质量。

## 收尾：家长读的是理由

对一个新陈述先圈范围，再圈量词，再决定需要“一个见证”“一个反例”还是“覆盖全部的论证”。能够写下正确答案但混淆这些任务，仍应继续练习。出口题的否定与见证由家长阅读：要听到“至少一个不满足”，而非单纯把“大于”改成“小于”却漏掉等号，或把“所有”保留不动。

# Statements and counterexamples

“Every number has square at least itself.” The values −2,0,1,2 all work, but half has square one quarter, less than half. A single failure refutes “every”, while many successes need not cover everything. Changing the domain to integers makes this particular statement true.

## One central idea

**A statement is a declaration with a definite truth value. Its domain and quantifier are part of its meaning.** Not knowing the truth is different from having no truth value. “Please open the window” is a request. With x free and no value or quantifier, “x+1=3” is an open sentence, not a completed statement in this lesson. Specifying x=2, or saying “There exists a real x with x+1=3”, gives an appropriate statement.

“Every” is universal. “There exists” requires at least one witness. To refute a universal statement, a counterexample must belong to its domain and violate its conclusion. A value outside the domain, or one satisfying the conclusion, is not a counterexample.

### Example 1: Same expression, different domain

“For every real x, x²≥x” is false. Choose x=1/2: its square 1/4 is less than 1/2. One admissible failure suffices; we need not find all failing values. By contrast, −2 is not a counterexample because 4≥−2 is true.

“For every integer n, n²≥n” is true. Write the difference as n(n−1). Every integer has n≤0 or n≥1; none lies strictly between zero and one. In the first case both factors are nonpositive, and in the second both are nonnegative. Their product is therefore nonnegative. This argument covers every integer. A finite list of successful examples does not. Half cannot refute this version because it is not an integer.

### Example 2: Negating quantifiers

Negate “Every integer is even” as “There exists an integer that is not even”, witnessed by one. The negation is not “Every integer is odd”. To deny that every case succeeds requires at least one failure, not failure of every case. Zero is still even.

Negating “There exists an integer n with n²=2” gives “Every integer n has n²≠2”. Why is the original existence claim false? If |n|≤1, then n²≤1; if |n|≥2, then n²≥4. These cases exhaust the integers, so none has square two. Testing n=0 alone is inadequate: one failed candidate cannot rule out existence.

## Keep the domain attached

Choose integers in the workbench and predict the universal claim. Try half as a counterexample. The tool checks admissibility before treating a computation as refutation. Switch to reals: the same candidate now refutes the claim. Try −1,0,1 too and explain why their successes do not replace proof.

The candidate input accepts rational numbers for exact checking. This does not redefine the real domain as rational: one rational counterexample is also a real counterexample and already suffices. The workbench does not automatically grade arbitrary written proofs.

## Exit and parent review

For a new sentence, identify its domain and quantifier first. Decide whether the task needs one witness, one counterexample, or an argument covering all cases. A correct final label with confused reasoning still needs practice. The parent reads the exit explanation for “at least one fails”, not merely a reversed inequality sign that loses equality or a universal quantifier left unchanged. The explanation is reviewed as mathematics, not scored by keyword matching.
