# Physics Learning App — Long-Term Curriculum Plan
# 物理学习 APP 长期课程规划

> **Target learner / 目标学习者**  
> 主要面向 10–15 岁开始学习物理的学生，并可继续延伸到完整高中物理。  
> 课程默认学生一开始**几乎没有物理基础**，通过直觉、观察、实验、图像、动画、生活应用和逐步数学化，最终完成初中到高中阶段的物理核心知识体系。
>
> **Language / 语言**  
> 所有核心课程采用 **中文 + English 双语呈现**。  
> 公式、单位、物理量符号使用国际通行写法，重要术语同时显示中英文。
>
> **Product goal / 产品目标**  
> 第一阶段只服务自己的孩子：**简单、顺手、愿意学、真的学会**。  
> 不追求复杂社交、排行榜、商业化和庞大后台。内容质量、课程节奏、反馈体验优先。

---

# 1. 核心教育目标 / Core Learning Goals

这个 APP 不应该只是“把学校课本搬到屏幕里”，而应该帮助孩子形成真正的物理思维。

最终希望孩子获得六种能力：

1. **观察世界 / Observe**
   - 能注意到运动、力、温度、光、声音、电、磁等现象。
   - 会问：“为什么会这样？”

2. **建立直觉 / Build intuition**
   - 在看到公式之前，先理解现象。
   - 例如在学 `F = ma` 前，先理解“同样的推力，小车越轻越容易加速”。

3. **建立模型 / Build models**
   - 知道物理不是复制现实，而是用简化模型解释现实。
   - 如质点、光线、理想弹簧、匀速运动等。

4. **数学表达 / Describe with mathematics**
   - 从文字 → 图像 → 表格 → 坐标图 → 公式逐级过渡。
   - 理解公式，而不是机械代入公式。

5. **解决问题 / Solve problems**
   - 能够识别条件、选择模型、列式、计算、检查答案是否合理。

6. **应用和迁移 / Apply and transfer**
   - 能解释真实生活中的现象。
   - 能完成小实验、小项目和开放问题。

# 2. 课程设计原则 / Teaching Principles

## 2.1 先现象，后概念，再公式

推荐顺序：

> **See → Wonder → Explore → Explain → Calculate → Apply**

中文：

> **看到现象 → 产生问题 → 动手探索 → 建立解释 → 引入公式 → 真实应用**

不要一打开课程就出现定义和公式。

例如学习摩擦力：

1. 为什么鞋底有纹路？
2. 为什么冰面容易滑？
3. 拖动一本书，桌面材质改变会发生什么？
4. 得出“接触面之间会产生阻碍相对运动的作用”。
5. 再引入 friction / frictional force。
6. 最后解决刹车、轮胎、运动鞋等问题。

---

## 2.2 一课只解决一个核心问题

推荐每节课 **12–20 分钟**。

每课最好只有一个核心目标，例如：

- What is speed? / 什么是速度？
- Why do objects fall? / 为什么物体会下落？
- What is electric current? / 什么是电流？
- Why does a straw look bent in water? / 为什么吸管放进水里看起来弯了？

避免一节课塞入 5–10 个定义。

---

## 2.3 从具体到抽象 / Concrete → Visual → Symbolic

每个概念尽量经过三层：

### A. Concrete / 真实体验
球、小车、弹簧、水杯、镜子、电池、灯泡。

### B. Visual / 图像表达
箭头、轨迹、受力图、能量条、光线路径、电路图。

### C. Symbolic / 数学表达
`v = s/t`、`F = ma`、`P = W/t`、`V = IR`。

---

## 2.4 数学难度与物理同步增长

物理课程不要默认学生一开始就熟练掌握代数。

数学应按以下顺序嵌入：

1. 数和单位
2. 比例
3. 简单公式代入
4. 公式变形
5. 坐标图
6. 斜率
7. 向量
8. 三角函数
9. 二次关系
10. 简单微积分思想（高中进阶，可选）

---

## 2.5 错误是课程的一部分

每一个重要概念应该设计一个：

> **Common Misconception / 常见误区**

例如：

- “物体运动一定需要力维持。” ❌
- “重的物体一定比轻的物体掉得快。” ❌
- “电流被灯泡消耗掉。” ❌
- “镜子左右颠倒。”（更准确地说是前后方向反射）❌
- “夏天铁比木头温度低。” ❌

APP 应该主动制造认知冲突，然后纠正。

# 3. 单节课程标准模板 / Standard Lesson Template

每一节课建议使用统一结构。

## Section 1 — Hook / 引入（1–2 min）

一个问题、动画、图片或生活现象。

例如：

> 两张一样的纸，一张平铺，一张揉成球，同时掉下来，谁先落地？

---

## Section 2 — Predict / 先猜一猜（30 sec）

让孩子先选择：

- A
- B
- 一样
- 不确定

**这里不立即判分。**

目的是让孩子先形成自己的模型。

---

## Section 3 — Explore / 探索（3–5 min）

可以是：

- 小动画
- 可拖动模拟
- 图片序列
- 家庭小实验
- 简单数据表

---

## Section 4 — Explain / 概念解释（3–5 min）

语言保持短句和直观。

格式建议：

**速度 Speed**

> 速度描述物体运动得有多快。  
> Speed tells us how fast an object moves.

然后给图示和例子。

---

## Section 5 — Formula / 公式（如果需要）

格式固定：

`v = s / t`

Where:

- `v` = speed / 速度
- `s` = distance / 路程
- `t` = time / 时间

并说明：

> 这个公式不是需要背下来的魔法，而是说：  
> **速度 = 每单位时间走过的距离。**

---

## Section 6 — Worked Example / 示例题

只做 1–2 道。

必须解释每一步为什么这样做。

---

## Section 7 — Practice / 练习

建议 4 层：

### Level A — Understand / 理解
概念判断。

### Level B — Calculate / 计算
简单数字。

### Level C — Apply / 应用
生活场景。

### Level D — Challenge / 挑战
需要两步或多概念结合。

---

## Section 8 — Real World / 真实世界

例如速度课程：

- 汽车 speedometer
- GPS
- 跑步配速
- 高铁
- 光速

---

## Section 9 — One-Minute Summary / 一分钟总结

最多 3 个核心句。

---

## Section 10 — Exit Question / 离开前一题

一道非常短的问题，用来判断是否真正理解。

---

# 4. 整体课程地图 / Full Curriculum Map

建议整个物理课程分为 **9 个阶段**。

| Stage | 中文名称 | English | 建议年龄 | 核心目标 |
|---|---|---|---|---|
| 0 | 物理启蒙 | Physics Foundations | 10+ | 对世界产生物理直觉 |
| 1 | 初中物理 I | Junior Physics I | 10–12 | 测量、运动、力、密度 |
| 2 | 初中物理 II | Junior Physics II | 11–13 | 能量、热、声音、光 |
| 3 | 初中物理 III | Junior Physics III | 12–14 | 电、磁、压力、浮力 |
| 4 | 高中桥梁 | Physics Bridge | 13–15 | 数学化、图像、向量 |
| 5 | 高中力学 | High School Mechanics | 14+ | 运动学、牛顿定律、能量、动量 |
| 6 | 波动与热学 | Waves & Thermal Physics | 14+ | 波、声音、光、热力学 |
| 7 | 电磁学 | Electricity & Magnetism | 15+ | 电场、电路、磁场、电磁感应 |
| 8 | 现代物理 | Modern Physics | 15+ | 原子、量子、核、相对论概念 |

建议核心课程总量：

**约 220–280 节课**

每节 12–20 分钟。

如果每周学习 3–4 次，可以支持 **3–5 年持续学习**。

**What happened** 和 **Why it happened**。

## Stage 0 Final Project

### Project: Physics Detective / 物理侦探

让孩子从家里选择一个现象：

- 骑自行车

- 开灯
- 用镜子

## 电路教学必须避免的误区

不要说：

> 电池把电流送出去，灯泡把电流用掉。

更好的模型：

> 电池提供电势差，使电路中的电荷发生定向运动；能量被灯泡转换，而电荷并不会被灯泡“消耗掉”。

初中可以简化语言，但概念不能错误。

理解原子、核、光子、相对论和宇宙基本概念。

### Experimental Physics
能够：

- 提出问题
- 设计简单实验
- 控制变量
- 收集数据
- 作图
- 分析误差
- 得出结论

### Scientific Thinking
最重要的是形成习惯：

> **不要只问“答案是什么”，而要问“为什么”。**

# Appendix B — 每节课写作检查清单

每次制作课程前检查：

- [ ] 是否只有一个核心概念？
- [ ] 是否先有真实现象？
- [ ] 是否先让孩子预测？
- [ ] 是否有图或动画？
- [ ] 是否避免过早使用公式？
- [ ] 中文是否自然？
- [ ] English 是否自然？
- [ ] 术语是否统一？
- [ ] 是否有至少一道概念题？
- [ ] 是否有至少一道应用题？
- [ ] 是否指出常见误区？
- [ ] 是否有一句话总结？
- [ ] 是否有 exit question？
- [ ] 学习时间是否控制在 12–20 分钟？
- [ ] 孩子完成后是否真的“多理解了一件事”？

# Appendix C — 推荐下一步

在课程规划确定以后，建议真正开发时不要一次生成所有内容。

推荐顺序：

1. 先建立 **Lesson Template**
2. 制作 Lesson 1–5
3. 让孩子试用
4. 调整字体、节奏、双语比例和练习难度
5. 再制作 Lesson 6–15
6. 再次真实试用
7. 最后扩展到第一阶段 50 节

这样可以避免写完 300 节课程后才发现孩子并不喜欢某种形式。
