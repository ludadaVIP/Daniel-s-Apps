# 平舌和翘舌：多一个 h，声音也变了

## 本课目标：区分 z c s / zh ch sh r

读「丝」`sī` 和「诗」`shī`，再看两张拼音名片。多出来的 h 不是装饰。

| 平舌音        | 翘舌音         |
| ------------- | -------------- |
| zī 资（资料） | zhī 知（知道） |
| cī 疵（瑕疵） | chī 吃         |
| sī 丝         | shī 诗         |

`rì` 是「日」，开头是 r。今天不用追求夸张的卷舌，先辨认两个开头的位置和声音。

## 舌尖的位置，比音量重要

z/c/s 的舌尖位置靠前；zh/ch/sh/r 的舌尖稍微抬起，靠后一些。

先慢读 `sī → shī`，再读 `zī → zhī`。可以照镜子感受舌位，但不要硬把舌头往后卷。

c 与 ch 都有明显送气；z 与 zh 不送气。**平翘舌和送气是两条不同线索。**

## 两个字母，只有一个声母

`zh`、`ch`、`sh` 各表示一个声母，不是两个声母分开朗读。

`shī` 的开头写 sh，整串有三个字母。漏掉 h 会变成 `sī`，读音也跟着变了。

本课先通过完整的真实音节认识声音。第 7 课再解释为什么 zhi/chi/shi 等适合整体认读。

## 别让认识汉字替你完成辨音

听音题先不给汉字，只播放中文声音。把注意力放在字母差异和舌位上。

如果把 `jī` 和 `zhī` 混了，回想「鸡」和「知道」的开头。它们不是同一类声母，不能因为“听着有点像”就省略字母。

## 用同一条规则读新组合

这次独立挑战会把已学声母和 a 等已学韵母重新组合。先找开头有没有 h，再看韵母与声调。

认识一组新声母，不意味着要重新背所有音节。你在建立可以迁移的拼读规则。
