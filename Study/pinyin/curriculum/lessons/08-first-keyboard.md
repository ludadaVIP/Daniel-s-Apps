# 声母通关：从声音名片到键盘

## 本课目标：认读和键入分开做

读「你」时看 `nǐ`；电脑全拼通常键入 `ni`。调号帮助朗读，键盘拼写一般不用调号。

今天的字母题请切到英文键盘，只敲拼音字母。**这一步练的是拼写，不是最终汉字。** 系统输入法课程在第 17 课正式开始。

## 21 个普通声母，分组认就够了

我们已经覆盖 `b p m f d t n l g k h j q x zh ch sh r z c s`。

按熟悉的音节回想每组，不要求按表格顺序背诵。小学教学表常把 y/w 也列进去，它们在拼写规则里有特殊作用。

最常见的漏字：把 sh 敲成 s、ch 敲成 c、zh 敲成 z。

## 把已会的音节敲出来

| 阅读 | 全拼键入 |
| ---- | -------- |
| nǐ   | ni       |
| mā   | ma       |
| shì  | shi      |
| qù   | qu       |

qù 的 u 仍对应 ü 的读音；这里只是把它已有的规范拼音换成无调按键。

## 试着一次敲一个短词

`nǐ hǎo → nihao`。可以先按音节想，但把字母接着敲出来。

「吃吧」`chī ba → chiba`，后一个 ba 是轻声。阅读时标调、轻声有意义；全拼键入时通常不输入调号。

App 忽略字母题里的空格和大小写，不会把漏掉的 h 或错误韵母自动算对。

## 第一组键盘挑战

独立挑战会混合认读、单音节键入与短词键入。遇到不熟的词，先口头说出来，再找声母、韵母。

做完后可以到键盘实验室提前体验系统输入法；那里的预览不会替你完成后续真实打字课程。
