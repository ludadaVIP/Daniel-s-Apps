# 前鼻韵母：别把最后的 n 丢掉

## 本课目标：an en in un ün

用「蓝、门、心、轮、云」找出五组鼻音结尾。

| 例词         | 拼音            | 韵母线索         |
| ------------ | --------------- | ---------------- |
| 蓝 / 门 / 心 | lán / mén / xīn | an / en / in     |
| 轮           | lún             | un（uen 的缩写） |
| 云           | yún             | ün 的对应写法    |

本课先练 n 收尾，下一课专门比较 n/ng。

## n 是收尾，不是再加一个音节

读 lán，舌尖接近上齿龈收尾，让气流通过鼻腔。不要读完 a 就停，也不要再念英语 N。

可以慢读「蓝」，感受最后的鼻音，再把音节缩短。拼写里的 n 是不可少的声音线索。

## 看见 in，不要误读成 i

心 xīn 与洗 xǐ 不同：xīn 末尾有 n，xǐ 没有。

不必为了强调鼻音而把词拖得特别长。先有完整收尾，再回到自然的中文速度。

## un 与 ün，声音来源不同

轮 lún 中的 un 是普通 u 开头的组合缩写。云 yún 对应 ün，ü 的两点在这类写法里省略。

j/q/x 后的 `jun qun xun` 也对应 ün；不是看到字母 u，就一律读成普通 u。

完整的省略规则第 14–15 课会再用真实例词解释。

## 把鼻音带进词里

读一个双音节词时，先把每个音节的 n 收好，再连接到后一个音节。

本课独立挑战包括未直接展示过的合法组合。以后遇到 ng，就和今天的 n 放在一起比较。
