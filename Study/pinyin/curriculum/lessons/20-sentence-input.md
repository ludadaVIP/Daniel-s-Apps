# 输入完整句子：让中文读起来也完整

## 本课目标：句子、选词和标点一起检查

你可以把一句话先分成有意义的词组，再连续输入：`wo xihuan kexue → 我喜欢科学`。

输入法可能支持整句转换，也可以分词输入。目标是最终句子正确，不要求固定操作轨迹。

## 先把一句话说清楚

「我和朋友打篮球。」可以想成“我 / 和朋友 / 打篮球”。

「机器人向前走。」可以想成“机器人 / 向前 / 走”。

会说的中文就是内容来源；拼音帮助你把已经组织好的意思写出来。

## 三个常用标点

陈述句用句号 `。`，问句用问号 `？`，句中合理停顿用逗号 `，`。

例句：「你今天想看什么书？」

App 接受对应的中英文标点宽度，但不忽略漏掉句号或把问号改成逗号。真正写消息时，尽量使用中文标点。

## 更正候选字，不用全段重打

「我再学校。」想表达位置时，应把再改成在，其他正确内容保留。

可以用方向键移动、鼠标选中、退格删除或重新选词。编辑后通读一次，再检查标点。

## 第五周任务：一条真实消息

用系统中文输入法输入一条 30–50 字消息，主题是和朋友讨论一次机器人实验。

这一轮会出现短句和一条长消息。先选好候选词，再点检查；不是在 App 里拼几个积木字母就算会输入。

## 把技能带到 App 外

在普通文本编辑器中写一句想告诉家人的话。检查有没有同音错字、漏字，句子有没有结束。

结课后可打开「给朋友的一条消息」挑战，再做一次独立输入。
