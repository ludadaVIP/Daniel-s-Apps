# 同一串字母，五种声音

## 声调是声音的路线

读「妈、麻、马、骂」，开头和韵母都是 `m + a`，声音的走向不同，意思也不同。

| 声调 | 拼音 | 线索                 |
| ---- | ---- | -------------------- |
| 一声 | mā   | 高而平               |
| 二声 | má   | 从中间往上扬         |
| 三声 | mǎ   | 先降；单独读时常再升 |
| 四声 | mà   | 从高处快速落下       |
| 轻声 | ma   | 轻而短，没有调号     |

先看调号，再读出完整音节。不要把四声读成同一高度。

## 不看汉字，声音也能找到

试着只看 `mā má mǎ mà`，依次读出来，然后再听示范核对。

「拼音找读音」题只给拼音和几个试听按钮。先看调号，再听选项，别靠认识汉字猜答案。

三声在自然说话时常只读到低处，不必每个词都夸张地拐一个弯。

## 轻声需要一个语境

问句「好吗？」中的「吗」读轻声，拼音是 `ma`，**不标调号**。

听完整的「好吗？」感受最后一个字轻而短。轻声不是把所有字都读成第一声。

同一个 `ma` 可以对应不同汉字。拼音告诉你声音，意思还要看上下文。

## 去掉汉字，完成声调侦查

独立朗读时，先自己读，再点击「揭示并核对」。按实际情况标记「读对了」或「还需练」。家长也可以代为判断。

这不是普通话口音比赛。目标是让你**看懂调号，读出相应声音**。

独立挑战达到 85%，且没有某个知识点连续错两次，会标记已掌握。需要再练也能继续下一课。
