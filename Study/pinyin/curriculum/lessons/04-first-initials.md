# 给声音加一个开头

## 短短的开头，是声母

在 `mā` 中，`m` 是声母，`a` 是韵母，上面的横线是一声。

**声母要短，韵母接上去，连成一个完整音节。** 可以先慢读 `m—ā`，再连成 `mā`。不要念英语 M、A。

本课第一组声母是 `b p m f d t n l`。

## 一张纸，找到 b/p 与 d/t

把小纸条放在嘴前，轻读「八」`bā`，再读「怕」`pà`：`p` 送气更明显。

再比较「大」`dà` 与「他」`tā`：`t` 送气更明显。纸条只是辅助，不需要吹得特别用力。

| 声母  | 熟悉的音节            |
| ----- | --------------------- |
| b / p | bā 八 / pà 怕         |
| m / f | mā 妈 / fā 发（发出） |
| d / t | dà 大 / tā 他         |
| n / l | nǐ 你 / lè 乐（快乐） |

「发、乐」有不止一种读音，这里只学习括号语境里的读音。

## 拼起来，调号放在韵母上

`b + a + 一声 → bā`，`p + a + 四声 → pà`。

在拆拼题中，选择声母、韵母、声调，也可以用 Tab 和方向键操作下拉菜单。App 只按经过核对的完整组合判题。

再试试 `n + i + 三声 → nǐ`。i 加调号时不再保留上面的点，写作 `ǐ`。

## 从已见过的音，走向新组合

现在试读 `bà`（爸）、`pā`（趴）、`mǐ`（米）。它们用的声母、韵母和声调都已经学过，但不必死记整个答案。

先拆开，再连读，最后核对汉字与发音。把规则用到新音节上，才是真正学会。

第一周完成后可以重复薄弱点；后续课程会逐步加入更多声母、韵母和真正的电脑输入任务。
