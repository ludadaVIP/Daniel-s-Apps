# 第二组声母：找出声音的开头

## 本课目标：认识 g k h j q x

你会读「哥、可以、喝水、鸡、去、洗」。今天把这些中文声音的开头写出来。

| 熟悉的字     | 拼音         | 开头      |
| ------------ | ------------ | --------- |
| 哥 / 可 / 喝 | gē / kě / hē | g / k / h |
| 鸡 / 去 / 洗 | jī / qù / xǐ | j / q / x |

**用中文声音认识字母，不用英语字母名称来猜。** 独立挑战会出现学过规则、但没刚刚展示过的组合。

## g 与 k：气流是一条证据

轻读 `gē`，再读 `kě`，把手掌放在嘴前。`k` 的送气更明显，`g` 不送气。

`h` 有摩擦声，像 `hē` 的开头。三个声母都要短读，再接上韵母，不要在中间加英语字母名称。

示范音播放「可以、喝水」的完整语境，重点听第一个字。像「喝」这样有不同读音的字，要结合实际词语核对。

## j q x：字母眼熟，中文声音不同

`jī` 是「鸡」，`qù` 是「去」，`xǐ` 是「洗」。`q` 不读英语 Q，`x` 不读英语 X。

j/q 的一个区别是送气：q 更明显；x 的开头有摩擦声。先读熟悉的中文，再观察字母，不必背抽象的发音术语。

## qù 里的 u，不是普通 u

「去」的完整拼音是 `qù`，后面的声音是 **ü**，写法省掉了两点。

这一课先认得真实音节。第 14 课会总结 j/q/x 后的 ü 省略规则；不要现在把 `qù` 拼成 q 加普通 u。

## 带走这个方法

先认声母，再看韵母，最后看调号，把它们连成一个中文声音。

本课关键词：`g k h j q x`。碰到新组合时可以放慢，但不用把每个英语字母念一遍。

下一课用几对真正容易混的声母，检查你能不能听出开头。
