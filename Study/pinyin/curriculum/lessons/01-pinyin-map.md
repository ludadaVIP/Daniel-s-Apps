# 中文的声音地图

## 你会中文，只差一张地图

看到「你」，你已经知道怎么读。`nǐ` 就是把这个声音记下来的方法。

**汉字记录意思，拼音帮助我们找到读音。** 今天不背字母表，先认出几张熟悉的声音名片。

| 汉字 | 声音名片 |
| ---- | -------- |
| 你   | nǐ       |
| 好   | hǎo      |
| 书   | shū      |
| 妈   | mā       |

## 看起来是英文，读法却不同

拼音借用了拉丁字母，但要按**中文的声音**读。

`shū` 读作「书」，不用念成三个英文字母的名称。`mā` 读作「妈」，不是英语字母 M 和 A。

试着先读 `nǐ`，再按示范发音核对。不会也没关系，今天只是第一次找规律。

## 小符号也有线索

`mā` 上面的横线和 `nǐ` 上面的小折线，是**声调符号**。

它们帮助你知道声音怎么走。第三课会专门研究；现在先知道「调号不是装饰」就够了。

`nǐ hǎo` 是「你好」的规范拼音。连起来说时，第一个第三声听起来会变化；书面拼音仍写 `nǐ hǎo`。

## 读拼音，和敲拼音，是两件事

读「书」时看 `shū`；用电脑全拼输入时敲 `shu`，再选「书」。

**阅读需要认调号，常用电脑全拼输入通常不敲调号。** App 的字母练习测试拼写，中文输入练习测试最后打出的汉字。
