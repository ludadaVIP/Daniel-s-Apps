# 后鼻韵母：一眼看见 ng

## 本课目标：ang eng ing ong

忙 `máng`、风 `fēng`、听 `tīng`、红 `hóng`，都以 ng 收尾。

**ng 合起来表示一个鼻音韵尾，不是先念 n 再念英语 G。**

## n 与 ng，发音位置不同

前鼻音 n 用舌尖接近上齿龈收尾；后鼻音 ng 的舌根抬起，舌尖不用去顶那里。

不要求把音读得夸张。先慢慢比较，再读正常的词。家中口音可能让两组很接近，我们主要练习看清拼写并尝试对应读音。

## 两对最实用的证据

| 前鼻音         | 后鼻音          |
| -------------- | --------------- |
| jīn 金         | jīng 京（北京） |
| lín 林（树林） | líng 铃（铃声） |

这些成对的音节声母、声调相同，只比较韵母结尾。不要靠认识汉字抢答。

## 看清最后两个字母

读 ing 时把 ng 当作一个收尾。键盘以后必须敲两个字母，但发音不是两个独立音。

先自己读 `máng fēng tīng hóng`，再核对示范。耳朵和眼睛提供两种证据。

## 第三周收获：从韵母表走向真实词

现在已覆盖常用教学分类里的 24 个韵母：6 个单韵母、8 个复韵母、er、5 个前鼻韵母、4 个后鼻韵母。

**这还不等于所有实际组合都能读。** 下一课补齐 ia/iao/ian/iong/uan 等组合，不让表格成为学习的终点。
