# 连续输入一个词：把意思也交给输入法

## 本课目标：一次敲完两三音节词

如果只输入一个字的拼音，输入法不知道你想说哪一个同音字。完整词组提供更多上下文。

例如 `xuexiao → 学校`，不必在 xue 后急着选一个「学」或别的同音字。

## 四个常用词，先说再敲

| 想输入 | 规范拼音  | 全拼键入  |
| ------ | --------- | --------- |
| 学校   | xuéxiào   | xuexiao   |
| 朋友   | péngyou   | pengyou   |
| 电影   | diànyǐng  | dianying  |
| 图书馆 | túshūguǎn | tushuguan |

这不是四个要死记的密码。把每个词说出来，按音节找到声母和韵母，再连接字母。

## 三个音节，不意味着按三次空格

机器人 `jīqìrén → jiqiren`，图书馆 `túshūguǎn → tushuguan`。先敲完，再查看候选词。

如果输入法自动分出音节，注意观察，但不把它的显示格式当成拼音考试答案。我们检查最终汉字。

## 相似字母，不能靠模糊匹配过关

电影 diànyǐng 中有 ing，不能漏掉 g；朋友 péngyou 的第一个音节含 eng。

输入法可能有模糊音或自动纠错设置，App 的字母题仍要求准确拼写。真实汉字题检查最终文字是否正确。

## 换成你感兴趣的词

这一轮会把科技、运动和生活词放进同一个输入框。可以先在心里把词分成两三段，再把全拼连续敲出来。

先检查拼音串，再检查候选词。以后长句也可以按有意义的词组组织，不必逐字碰运气。
