# 三个省略规则：短写法有来历

## 本课目标：认出短写法，不读丢声音

拼音里有些组合接声母后写得更短。**写法缩短，不代表中文读音随便删去一部分。**

本课把之前认识的牛、归、轮放回同一套规则里，再解决 ü 的两点和键盘 v。

## iou → iu，uei → ui，uen → un

| 接声母时的缩写 | 例词            |
| -------------- | --------------- |
| iou → iu       | niú 牛          |
| uei → ui       | guī 归、shuǐ 水 |
| uen → un       | lún 轮          |

条件是**接在声母后**。没有普通声母时，iou 写 you，uei 写 wei，uen 写 wen；不能把所有词机械缩写。

## j q x 后，ü 省略两点

`jū qù xǔ` 中的 u 对应 ü 的音。字面没有两点，读音仍然保留 ü 的性质。

对应的 `jue que xue`、`juan quan xuan`、`jun qun xun` 也有 ü 的来源。看到不同组合，仍要按照已经学过的规则辨认。

## n 和 l 后，要保留 ü 的两点

女 `nǚ`、绿 `lǜ`。若把两点随意删掉，会和普通 u 的写法混在一起。

j/q/x 后的省略，不是“所有声母后都把 ü 改成 u”。先看开头属于哪一组。

## 阅读写 ü，常见全拼键入用 v

| 汉字 | 规范拼音 | 常见按键 |
| ---- | -------- | -------- |
| 女   | nǚ       | nv       |
| 绿   | lǜ       | lv       |
| 绿色 | lǜsè     | lvse     |

v 表示 ü 是常见输入法约定，具体以正在使用的输入法为准。jū/qù/xǔ 的键入仍是 ju/qu/xu，不因为它们有 ü 的来源就敲 jv/qv/xv。

## 用新词核对规则

独立挑战既有缩写认读，也有 nv/lv 的键盘拼写。女儿 `nǚ'ér` 还会用到音节边界；隔音符号下一课系统讲。

不要把“去调号”当作所有键入串的生成方法：nǚ 的常见按键是 nv，而不是 nu。
