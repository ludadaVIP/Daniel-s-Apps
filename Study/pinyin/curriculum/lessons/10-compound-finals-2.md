# 复韵母第二组：先放进你认识的词

## 本课目标：ui iu ie üe 与 er

| 例词    | 拼音      | 线索          |
| ------- | --------- | ------------- |
| 水      | shuǐ      | ui            |
| 牛      | niú       | iu            |
| 写      | xiě       | ie            |
| 月 / 雪 | yuè / xuě | üe 的对应写法 |
| 耳      | ěr        | er            |

er 是特殊韵母，不要把 e 和 r 念成两个英文字母。

## ui 与 iu，顺序不同

水 `shuǐ`，牛 `niú`。两组书写里都有 i/u，但次序不同，不能随手交换。

ui 与 iu 是接声母时常见的缩写，完整来源在第 14 课讲。今天先能把真实词认出来、读对。

## ie 与 üe：口型别搞混

写 `xiě` 含 ie；雪 `xuě` 含 üe。后者保持 ü 的口型，再过渡到后面的音。

月 yuè、雪 xuě 的拼写省掉了 ü 上的两点。**ue 在这些写法中不读成普通 u + e。** n/l 后需要保留两点，例如 lüè（略微的略）。

## er 是一个完整声音

耳 ěr 可以单独成音节。不要把 r 当一个新的独立音节接在后面。

慢读一次，再用正常说话的速度读完整词。我们学的是读音，不是给字母另加英语名称。

## 从单音节走到词语

用已经学过的声母、复韵母读一个新词。如果两个音节都能解码，试着连成你已经认识的中文词。

本课带走 `ui iu ie üe er`。遇到 ü 的省略，先根据词里的真实声音辨认，后面还有专门的规则课。
