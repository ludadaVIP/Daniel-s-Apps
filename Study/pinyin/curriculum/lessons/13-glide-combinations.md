# 组合扩展：不再只靠背音节

## 本课目标：用已会的声音读新组合

两拼可以看作声母 + 韵母。三拼常把声母、介音、后面的部分快速连起来，例如 `h + u + a → huā`。

也可以把 ua/iao/uan 等整体韵母组合先认出来再拼。两种拆法都帮助连读，**不要在介音后加停顿**。

本课内容稍多，可以分两次完成；不是要额外背几十个零散答案。

## i 开头的一组：ia iao ian iang iong

| 组合 | 代表音节         |
| ---- | ---------------- |
| ia   | jiā 家           |
| iao  | qiáo 桥          |
| ian  | jiān 肩          |
| iang | liǎng 两         |
| iong | xiōng 兄（兄弟） |

先找到声母，再把整个组合连起来。iong 不能漏掉 i，iang 不能漏掉鼻音 ng。

## u 开头的一组：ua uo uai uan uang

| 组合 | 代表音节       |
| ---- | -------------- |
| ua   | huā 花         |
| uo   | guó 国（国家） |
| uai  | kuài 快        |
| uan  | guān 关        |
| uang | huáng 黄       |

u 在这些组合里连接得短而快，不是插入一个新的音节。

## ü 开头的一组：üe üan

雪 xuě 对应 üe；选 xuǎn、远 yuǎn 对应 üan。

j/q/x 后的 ü 省略两点；没有普通声母时，üan 写作 yuan。**yuǎn 不是 y 加普通 u 的随意拼读。**

üan 与 uan 的声音不同。读「选」时保持 ü 的口型，再连接后面的部分。

## 用组合读一个完整词

熊猫 `xióngmāo`：先解码 xióng，再解码 māo，最后连成你知道的中文词。

如果只背「熊猫」的答案，换一个 xiang/iong 组合可能仍不会读。因此独立挑战会换成新的合法音节，检验同一条规则能不能迁移。

## 带走一张组合地图

`ia iao ian iang iong`；`ua uo uai uan uang`；`üe üan`。

从熟悉声音出发，逐步读到没刚刚见过的组合。这一课把常用 24 韵母之外的重要缺口补上，下一课再解释缩写和省略。
