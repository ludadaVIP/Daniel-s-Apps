# Study 学习工作台与笔记本验收

本次设计以清晰的内容组织、舒适的阅读和一致的视觉秩序为先，再适度收紧间距，适配 16 寸笔记本。

## 统一的组织方式

四科保留左侧导航。左栏分为学科标识、学习功能、课程目录和返回 Study 四个区域，右侧专注于当前学习内容。

| 学科 | 课程目录层级                                         |
| ---- | ---------------------------------------------------- |
| 物理 | 学习阶段 → 课程单元 → 课程；实践项目单独分组         |
| 化学 | 主题分组 → 学习阶段 → 课程                           |
| 生物 | 学习阶段 → 单元 → 课程，尚未开放的内容明确标为规划中 |
| 拼音 | 学习周 → 任务；阶段检查单独分组                      |

- 左栏默认展开。顶部和左栏底部都有折叠入口；折叠后保留图标导航，右侧自动增加宽度。展开、折叠偏好在此浏览器保存，并跨学科沿用。
- 当前课程自动展开对应目录层级，标记当前位置。目录支持关键词查找，搜索结果保留所属阶段和单元；选择后回到完整目录。
- 课程列表由左侧目录切换，减少右侧成排按钮和重复选择器。返回列表时保留课程阶段、单元或学习周。
- 手机改为侧边抽屉，通过菜单按钮打开、遮罩或 Escape 关闭；选择页面后自动收起。

## 视觉与阅读

- 保留各自的学科配色和插图，统一导航、按钮、卡片、边框和标题层级。
- 主体文字约 16–18px，双语阅读说明约 14–16px；装饰性标记和元信息使用较轻、小的字号。
- 恢复适量留白，使用柔和的背景与轻边框。按照内容区的实际宽度调整列数，折叠左栏时布局自然扩展。
- 学习步骤仍按环节展开，练习逐题显示。操作条放回内容末尾，避免遮住答案、实验按钮或解释。
- 较长的讲解和复杂实验保留必要滚动，不以塞满一屏为目标。

## 验收路径

在笔记本上打开 `http://localhost:3456` 并刷新，使用浏览器默认缩放。

1. 查看四科首页的左栏、卡片和标题是否舒适、一致。
2. 展开阶段、单元，进入课程，检查当前位置是否清楚；返回目录列表，确认位置保留。
3. 折叠左栏，确认阅读区变宽；再展开，确认目录和学习状态仍在。
4. 在目录搜索一个关键词，进入结果对应的课程或单元。
5. 做一次物理实验、化学答题，在折叠与展开之间切换，检查记录保留且操作不被遮挡。

## 验证记录

- 工作区类型检查、ESLint、各应用和 Hub 的生产构建。
- 766 个自动测试：原有 762 项，加四项左栏状态、目录层级、搜索和抽屉行为的回归检查。
- 桌面窗口覆盖 1440×900、1366×768、1280×800、1024×768，检查左栏展开和折叠两种状态；手机窗口 390×844。
- 覆盖四科入口、课程列表、首课、复习、笔记、工具箱、键盘实验室、报告，及中文、英文、双语布局。
- 检查目录查找、返回定位、折叠偏好、预测和答题保留、实验操作及手机抽屉。

修改文件单独进行格式检查。全仓库已有的九处格式提示和较大资源包构建提示仍在。

共享布局与目录组件位于 `packages/ui`；每个应用提供自己的课程结构，后续新增内容可以沿用这套组织方式。
