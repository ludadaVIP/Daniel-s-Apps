## Hook / 今天的谜题

### 中文

两次遇到相同抗原，为什么第二次曲线更早升高？这能保证不感染吗？

**学习目标（30分钟）**

- 把记忆细胞与第二次反应联系。
- 比较相同模型时点的曲线并正确标单位。
- 区分疫苗呈递抗原的方式与保护的局限。

### English

Why can a response to the same antigen rise earlier the second time? Does that guarantee no infection?

**Learning goals (30 minutes)**

- Link memory cells to a secondary response.
- Compare curves at matched model times with units.
- Distinguish antigen delivery from the limits of protection.

## Explain / 真正的科学解释

### 中文

初次遇到抗原时，合适的淋巴细胞需要被激活、增殖和分化，因此效应不会立刻达到峰值。反应后许多效应细胞减少，但部分记忆B、T细胞可以保留。再次遇到相同或足够相关的抗原时，这些细胞可更快参与反应。血中抗体量和记忆细胞不是同一个指标：某时刻抗体较低，不能单独证明全部免疫记忆已经消失。

本课把两次暴露的起点对齐，比较其后第0到第5个模型时点。首次抗体指数依次为0、1、3、8、4、2，再次为2、7、16、20、12、6。第2点再次是16、首次是3，相差13任意指数单位；再次峰值20也高于首次峰值8。模型用已有记忆解释较快、较高反应，但并不测真实人体的天数、感染机会或疾病严重程度。没有一个可把“指数16”换算成个人保护率的公式。

疫苗通过可控的抗原接触建立学习机会。类型包括减毒活、灭活、抗原成分或类毒素；有些使用遗传指令，使自身细胞暂时产生目标抗原。不是每种疫苗都含活病原体，也不是直接把永久有效的抗体装进身体。不同抗原、病原体变化、个体状态和时间都可能影响保护，因此免疫记忆不等于绝不感染；降低某种疾病风险与完全阻断感染也不是同一结局。

示范作答：“在相同的第2模型时点，再次抗体指数为16，首次为3，支持再次反应更快；已有记忆细胞能较快增殖分化是一个机制解释。但曲线是虚构模型，不能据此安排真实疫苗时间或断定个人感染风险。”如果把抗原换成差异很大的B，原有A的记忆未必同样有效。这一迁移要求先问‘识别的目标是否匹配’，而不是只看曾经接触过任何疫苗。

### English

A first encounter requires suitable lymphocytes to become activated, multiply and differentiate. The response therefore does not reach its maximum immediately. Many effector cells decline afterwards, but some specific memory B and T cells persist. On encountering the same or a sufficiently related antigen again, these cells can contribute more rapidly. Circulating antibody concentration and memory-cell persistence are different measurements: a low antibody reading alone does not prove that all memory has disappeared.

Our curves align the starts of two exposures and compare six model time points. Primary antibody indices are 0, 1, 3, 8, 4 and 2; secondary indices are 2, 7, 16, 20, 12 and 6. At point 2 the difference is 16 − 3 = 13 arbitrary index units. The secondary maximum, 20, also exceeds the primary maximum, 8. Existing memory is the mechanism represented, but the model does not measure real days, infection probability or disease severity. There is no conversion from index 16 to an individual protection percentage.

Vaccines provide an opportunity to develop recognition. Different preparations use weakened organisms, inactivated organisms, selected components or treated toxins. Some deliver genetic instructions for cells to produce a target antigen temporarily. Vaccines therefore do not all contain living pathogens, nor do they simply install permanent antibodies. Protection depends on the target, pathogen changes, time and host factors. Reduced disease risk and complete prevention of infection are different outcomes.

A worked answer is: “At matched model point 2, the secondary index is 16 compared with 3, supporting a faster response. Memory cells can proliferate and differentiate more promptly. However, these fictional curves cannot set real vaccination intervals or determine personal infection risk.” For an unfamiliar antigen B, ask whether recognition matches: memory against A need not provide the same response.

## Depth / 高中延伸

### 中文

高中延伸：记忆涉及细胞数量和状态变化；抗体指数只是一个读出，不代表全部细胞免疫。曲线未模拟抗原变异、黏膜防御或免疫缺陷。

### English

Depth: Memory changes cell numbers and states. Antibody index is one readout, not the entirety of cellular immunity. The curves omit antigenic variation, mucosal defence and immune deficiencies.

## Misconception / 容易搞错的地方

### 中文

低抗体不必等于零记忆；较快再次反应也不等于零感染。

### English

Low antibodies need not mean zero memory; a faster secondary response does not mean zero infection.

## Apply / 用到新情境

### 中文

新抗原B在第2点首次指数2，再次指数3，均为任意单位。自查：仅差1单位，不能照搬A的13单位；目标不同可能识别不匹配，且不能换算感染风险。

### English

For a new antigen B, point-2 primary and repeat indices are 2 and 3 arbitrary units. Self-check: the difference is 1 unit, not A’s 13; target mismatch may alter recognition, and neither index gives infection risk.

## Vocabulary / 生物学英语

### 中文

- **immune memory / 免疫记忆**: 再次接触相关抗原时改变反应的能力。
- **memory cell / 记忆细胞**: 反应后保留、可再被激活的特异性细胞。
- **primary response / 初次反应**: 首次遇到某抗原引发的适应性反应。
- **secondary response / 再次反应**: 再次遇到相关抗原的适应性反应。
- **vaccine / 疫苗**: 使免疫系统学习识别目标的制剂。
- **neutralisation / 中和**: 阻止目标与宿主结构相互作用等作用。

### English

- **immune memory / 免疫记忆**: Capacity for an altered response on re-exposure to a relevant antigen.
- **memory cell / 记忆细胞**: A persisting specific cell that can be reactivated.
- **primary response / 初次反应**: Adaptive response to a first encounter with an antigen.
- **secondary response / 再次反应**: Adaptive response to a later encounter with a relevant antigen.
- **vaccine / 疫苗**: A preparation that helps immunity learn to recognise a target.
- **neutralisation / 中和**: An action such as preventing a target from interacting with host structures.

## Check / 检查理解

### 中文

1. [concept] 哪项可解释再次反应更快？
   A. 抗体自己分裂
   B. 保留的相关记忆细胞更快参与反应
   C. 皮肤记住所有分子形状
   答案: B. 抗体是蛋白质，增殖的是细胞；记忆必须与目标相关。 复习: 回看曲线旁记忆细胞→效应的箭头。

2. [concept] 哪项疫苗说明最准确？
   A. 都含活病原体
   B. 有记忆就保证不感染
   C. 不同类型呈递抗原或相关指令，保护有边界
   答案: C. 疫苗类型不同；降低疾病风险不能自动等同完全阻断感染。 复习: 回看Explain疫苗类型和结局区别。

3. [reasoning] 第2点3与16，正确比较是？
   A. 相差13任意指数单位，不能换算个人保护率
   B. 差13天
   C. 保证提高13%保护
   答案: A. 读纵轴单位；模型时点不是临床时间，指数差不是风险差。 复习: 核对共同轴和完整静态表第2行。

4. [vocabulary] secondary response表示什么？
   A. 第二种先天屏障
   B. 对再次相关抗原接触的适应性反应
   C. 只有第二种疫苗才产生抗体
   答案: B. secondary指再次接触相关抗原，不是第二种病原体。 复习: 对照primary与secondary曲线标签。

### English

1. [concept] What can explain a faster secondary response?
   A. Antibodies divide
   B. Persisting relevant memory cells respond faster
   C. Skin remembers every molecular shape
   Answer: B. Antibodies are proteins; cells proliferate. Memory must be relevant to the target. Revisit: Revisit the memory-cell-to-effector arrow.

2. [concept] Which vaccine statement is most accurate?
   A. All contain live pathogens
   B. Memory guarantees no infection
   C. Different types deliver antigens or instructions; protection has limits
   Answer: C. Vaccine types differ; reduced disease risk is not automatically complete infection prevention. Revisit: Revisit vaccine types and the outcome distinction.

3. [reasoning] At point 2 the indices are 3 and 16. Which comparison is valid?
   A. Difference: 13 arbitrary index units; not a personal protection rate
   B. A difference of 13 days
   C. Guaranteed 13% more protection
   Answer: A. Read the y-axis unit: index differences are not time or risk differences. Revisit: Check the shared axes and static table at point 2.

4. [vocabulary] What does secondary response mean?
   A. A second innate barrier
   B. Adaptive response to a later relevant antigen encounter
   C. Antibodies occur only with a second vaccine type
   Answer: B. Secondary refers to a later relevant encounter, not the second type of pathogen. Revisit: Compare the primary and secondary curve labels.
