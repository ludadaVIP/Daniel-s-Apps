# S04 阶段作品：解释一个看得见的现象

Explain a visible phenomenon · S04-P01 · 2026-11-12 · `pilot`

入口：`/biology/project/S04`。建议25–35分钟，可分次完成。任选植物生长、酶活性或生态变化；三种题材均有独立数据、机制图、条件比较和预测图，草稿分别保留。采用四格分镜，依次表达 **现象 → 微观机制 → 条件对照 → 可检验预测**。这是原创科学解释作品，不是模型生成的真实实验报告。

## 学习目标 / Learning goals

- 用带时间、单位和来源的至少两条不同数值记录支持观察。
- 把实际观测、虚构教学观测和模型输出分开；指出模型假设与未测因素。
- 用细胞、酶、能量或分解过程解释宏观现象，并给出适用条件。
- 提出变量、结果测量、对照、独立重复和会挑战主张的结果。
- 用自己的话写四格说明和总结。可用中文或英文完成，另一语言用于练习，不作为进度门槛。

## 三种题材的科学合同

### 1. 植物生长 / Plant growth

所有幼苗数据都是原创虚构记录，不来自真实物种或真实家庭实验。每个光条件各有匹配但**独立**的第0天基线组3株和第7天终点组3株，两光条件合计12株；干质量测定属于破坏性取样，不能把同株活植物反复干燥后继续养育。比较的是组均值，不能把同一列误认成同株配对数据。

| 光指数 | 基线组ID与第0天干质量（g） | 独立终点组ID与第7天干质量（g） | 终点均值 | 组均值差 |
| ------ | -------------------------- | ------------------------------ | -------- | -------- |
| 20     | P20-D0：0.20、0.20、0.20   | P20-D7：0.28、0.30、0.32       | 0.30 g   | 0.10 g   |
| 60     | P60-D0：0.20、0.20、0.20   | P60-D7：0.44、0.46、0.48       | 0.46 g   | 0.26 g   |

同种类、匹配初始大小、土壤、水、CO₂与温度为教学设定，没有置信区间。CO₂供碳，光合作用形成的糖可提供生长材料并参与呼吸；净干质量还受呼吸、资源、叶面积与时间影响。数据本身没有直接测量光合作用或排除所有其他原因。

另一个**独立模型**固定CO₂指数60、25°C、水充足和叶面积：光指数20/60对应相对光合速率40/100。最小容量规则和25°C最适为虚构选择；不得将40/100改写成g、把它与0.10/0.26作单位换算，或声称模型预测7天生长。

检验提案应随机分组，改变光条件，在每条件的第0/7天各使用至少3株独立破坏性样本，比较组均值并保持上述条件。增加光却不增加干质量可挑战“光在这些条件下限制净积累”的主张，还须检查呼吸和叶面积等。作品仅要求设计，不要求执行干质量测定。

### 2. 酶活性 / Enzyme activity

全部数值是虚构酶E的模型输出，非实测值或通用酶阈值。基准pH7、底物指数8、酶量1：冷却后5°C初速约16.8；结构保持完整，复温40°C后为80.0相对初速单位。未损伤40°C对照也是80.0；先75°C处理10分钟再冷却到40°C的组为6.4，因为模型**假定**仅8%活性保留。更多酶量可使相对值超过100，100不是绝对上限。

区分测定温度与先前热史；低温慢不等于变性。合适的活性部位结合底物，降低反应活化障碍，酶总体再生；酶不供给反应自由能。检验先改变预处理条件，再在共同测定温度、相同pH、底物与酶量下测单位时间产物的初速，至少3个独立重复；若热处理组恢复至对照，便挑战本例的不可逆损伤假设。不要将酶E的40°C最适推广到所有酶。

### 3. 生态变化 / Ecological change

全部数值是原创确定性落叶分解功能模型，不是物种数、种群预测或论文数据。各组相同初始总分解功能100和落叶输入；**标准化短时干旱/洪水脉冲持续至第1天测量，之后立即恢复共同基线水分并维持到第30天**。模型给出三个快照，图中水平间隔为分类位置，不表示实际经过的天数。

| 群落   | 共同功能与响应设定         | 干旱第1/30天 | 洪水第1/30天 |
| ------ | -------------------------- | ------------ | ------------ |
| A：4种 | 都分解落叶，水分耐受性不同 | 70 / 90      | 55 / 85      |
| B：4种 | 都分解落叶，干旱敏感性相近 | 40 / 65      | 75 / 92      |
| C：1种 | 较耐旱而怕洪水的分解者     | 65 / 88      | 20 / 45      |

酶分解落叶有机物，碳可进入分解者、残留有机物或经呼吸回到CO₂；矿质元素可再利用，能量持续散热。完成**同一分解功能**的生物若水分响应不同，存活者可能补偿；这是预设解释，需要测各物种与酶活动验证，不能仅从总曲线证明。物种多不保证对每种扰动都稳定。

抵抗比例=第1天功能/100；30天内恢复损失比例=(第30天−第1天)/(100−第1天)。A两扰动均为约66.7%恢复，但原始抵抗与终点不同；该比例不是普遍恢复速率。独立检验应设置未扰动对照和相同脉冲/恢复时序，保持落叶种类、初始质量、温度与起始分解功能，至少3个独立微环境，测固定时间内单位落叶的质量损失。不同响应群落没有保持更多功能会挑战补偿解释，但需考虑测量误差与具体条件。

## 制作流程与评价 / Workflow and rubric

1. 读原始记录，选择两条不同ID的数值证据，写出哪些是观察、哪些是模型假设。
2. 浏览四张不同图：现象、微观机制、条件比较、检验设计。用“因为…所以…；但…”写各格自己的说明。
3. 填写观察、假设、机制链、改变变量、测量方法/单位/时间、保持条件及对照、独立重复数、反驳结果和至少一种语言总结。
4. 保存作品；六道跨单元题全部作答并可订正，至少5/6正确。可回看L075、L079、L082、L087、L090、L096。
5. 下载完整SVG，与家人或教师核对以下标准。导出保留全部写作和数据，下载草稿并不意味着阶段完成。

| 标准 | 科学上可接受的表现                       | 需修订的例子                     |
| ---- | ---------------------------------------- | -------------------------------- |
| 证据 | 两条不同有效记录，时间/单位/来源明确     | 仅写“更好”、把模型说成实测       |
| 机制 | 微观过程与现象有因果链，说明适用条件     | 光直接变成植物质量、慢就等于变性 |
| 对照 | 一项主动变量；对照与共同测定条件明确     | 热处理与测定温度混在一起         |
| 假设 | 指出未测因素、替代解释和虚构参数         | 从总分解曲线推出每个物种贡献     |
| 检验 | 结果有方法/单位/时间，独立重复及反驳结果 | 同一微环境反复读数当独立样本     |
| 表达 | 四格与总结能用自己的话解释证据           | 只复制图名或引用ID               |

系统只检查结构是否齐备，不能自动确认文字的科学真实性、证据是否解释充分或英语质量。重复数接受2–30，教学建议至少3；足够样本量仍取决于实际问题。
