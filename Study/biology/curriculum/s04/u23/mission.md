# U23 · 跨代选择的证据档案 / An evidence file for selection across generations

### 中文

保留L090两种环境及初始A一半/零的三代频率，写清复制与贡献假设。用L089区别新等位基因与重组，用L091独立证据检验主张，再画并旋转L092虚构树。提交主张、至少两组数据、因果链及模型遗漏；不得用“努力进化”替代机制。

提交物：分开的图、原始条件与数据、计算、主张—证据—机制段落、一个反例及下一步检验。自评每项0–2：数据可追溯、因果准确、守恒/跨代核对、限制明确；分数不计入四道课内题。

### English

Keep three-generation frequencies for both L090 environments and initial A at one half/zero; state copying and contribution assumptions. Distinguish allele origins from reshuffling using L089, evaluate independent evidence using L091, then draw and rotate the fictional L092 tree. Submit a claim, at least two data comparisons, a causal chain and model omissions.

Submit separate diagrams, original conditions and data, calculations, a claim–evidence–mechanism paragraph, one counterexample and a next test. Self-assess0–2 for traceable data, causal accuracy, conservation/generation checks and explicit limitations. This rubric is separate from the four scored lesson questions.
