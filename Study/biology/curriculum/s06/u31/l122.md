## Explain / 真正的科学解释

### 中文

**转录产生新分子，不把DNA搬走。** 基因表达从使用特定DNA区域的信息开始；启动子与相关蛋白帮助转录机器定位，RNA聚合酶读取一条模板链，利用游离核糖核苷酸合成RNA。DNA仍是DNA，局部解开后可重新配对。同一段信息可多次转录，因此少量DNA模板可以支持许多RNA分子的生成。

**模板与编码链不能混称。** 聚合酶沿模板3′→5′读取，RNA从5′端向3′端延长。模板T配RNA的A，模板A配U，G配C。与模板相对的编码链若按5′→3′写出，其字母顺序与RNA对应，只是DNA的T换成RNA的U。哪个是模板取决于该基因的转录方向，不能规定一整条染色体永远只用同一条链作模板。

**逐字检验一个例子。** 原创片段编码链为5′-ATG GCT TTT GGA TAA-3′，模板为3′-TAC CGA AAA CCT ATT-5′。RNA是5′-AUG GCU UUU GGA UAA-3′，共15个核苷酸。把第二编码三联体GCT改成GCC，对应模板CGA改成CGG，RNA第二三联体GCU改成GCC。RNA不是与模板字母相同；核苷酸数相同也不表示DNA原料变成RNA。这一片段为下一课的阅读框提供明确起点，不代表实际基因只有15个碱基。

**位置与产物要带条件。** 本课采用真核细胞核内蛋白编码基因的简化情景。初始RNA通常需要加工，例如切除内含子及形成合适的端部，成熟mRNA才能按相应条件输出并参与翻译；图只给出加工这一层，不模拟完整细节。另有基因的产物就是功能RNA，并不走向蛋白质。细菌没有核膜，因此不能把核内到核外的分区规则硬套到所有生物。判断陌生序列题时先写链名和端点，再做配对，最后检查U/T，是比只背“DNA→RNA”更可检验的方法。

**用对照识别方向错误。** 若同伴写出与模板字母相同的RNA，可以指出模板首位T应对应RNA的A，而不是只说答案不对。若同伴把正确字母标成反向端点，可用聚合酶向新链末端添加的规则检查。两种错误分别来自互补与方向，订正时应说清哪条规则被违反。把字母、端点和链角色同时列在证据卡上，能减少看似会配对却在陌生图上反转方向的失误。若把两端反过来展示同一片段，应同时反向排列字母，而不是只交换端点标签；否则写出的已不是同一条有方向的核酸序列。

### English

Transcription makes a new molecule without moving DNA away. Gene expression uses information from a particular DNA region. A promoter and associated proteins help position transcription machinery. RNA polymerase reads one template strand and joins free ribonucleotides into RNA. DNA remains DNA and can pair again after local unwinding. The same region can be transcribed repeatedly, so a small number of DNA templates can support many RNA molecules.

Template and coding strands have distinct roles. Polymerase reads the template 3′→5′ while extending RNA 5′→3′. Template T pairs with RNA A, template A with U, and G with C. The opposite coding strand, when written 5′→3′, corresponds to the RNA sequence except that DNA T is replaced by RNA U. Which strand serves as template depends on a gene's transcription direction; a chromosome does not universally use only one of its strands for all genes.

Check an explicit sequence. Our fictional coding fragment is 5′-ATG GCT TTT GGA TAA-3′ and its template is 3′-TAC CGA AAA CCT ATT-5′. The RNA is 5′-AUG GCU UUU GGA UAA-3′, containing fifteen nucleotides. Changing the second coding triplet from GCT to GCC changes the template segment CGA to CGG and RNA GCU to GCC. RNA is complementary to the template, not a same-letter copy of it. Equal nucleotide counts do not imply that DNA building blocks physically turned into RNA. This unusually short fragment provides a clear reading frame for the next lesson rather than representing a complete natural gene.

Attach conditions to locations and products. This lesson simplifies a nuclear protein-coding gene in a eukaryotic cell. Initial RNA usually undergoes processing, including appropriate end modifications and intron removal, before mature mRNA can be exported and translated. The figure names this layer without simulating every step. Other genes produce functional RNAs that are not translated. Bacteria lack a nuclear membrane, so nuclear-to-cytoplasmic compartment rules cannot be applied to every organism. For an unfamiliar sequence, label strands and ends first, apply complementary pairing next, then check U versus T. This provides a testable procedure beyond memorizing the arrow DNA→RNA.

Use explicit checks to identify directional errors. If a classmate copies the template letters unchanged into RNA, point out that the first template T requires RNA A rather than simply marking the answer wrong. If complementary letters are correct but end labels are reversed, check the rule that polymerase extends the new strand at its growing end. These are different errors: complementarity and orientation. Listing letters, ends and strand roles together helps prevent reversal when an unfamiliar figure changes layout. Displaying the same strand from the opposite direction requires reversing its letter order as well as its end labels; swapping labels alone describes a different directed sequence.

## Misconception / 容易搞错的地方

### 中文

RNA不是DNA换个名字；编码链与RNA同序列的说法必须带方向和T/U条件。

### English

RNA is not renamed DNA; sequence correspondence with coding DNA requires matching direction and the T/U distinction.

## Depth / 高中桥梁

加工可使同一初始转录物产生不同成熟RNA，但本例连续短片段未模拟可变剪接。转录强弱与最终蛋白量仍隔着翻译和降解。

### English

Processing can produce different mature RNAs, but this continuous fragment omits alternative splicing. Transcription level alone does not determine final protein amount.

## Vocabulary / 生物学英语

### 中文

- **转录** — 以DNA模板合成RNA的过程。
- **编码链** — 与RNA同向序列对应、但T代U的DNA链。
- **模板链** — 被RNA聚合酶沿3′→5′读取的DNA链。
- **RNA聚合酶** — 按模板合成5′→3′RNA的酶。
- **尿嘧啶** — RNA中与A配对、用U表示的碱基。
- **启动子** — 帮助定位与启动转录的DNA区域。
- **RNA加工** — 使初始转录物形成适当功能产物的修改。
- **核输出** — RNA等通过核孔离开细胞核的过程。

### English

- **transcription** — RNA synthesis using a DNA template.
- **coding strand** — DNA strand matching RNA in the same direction except T replaces U.
- **template strand** — DNA strand read 3′→5′ by RNA polymerase.
- **RNA polymerase** — An enzyme synthesizing RNA 5′→3′ from a template.
- **uracil** — The RNA base U that pairs with A.
- **promoter** — A DNA region helping position and initiate transcription.
- **RNA processing** — Modifications producing an appropriate functional RNA product.
- **nuclear export** — Movement of RNA and other cargo out through nuclear pores.
