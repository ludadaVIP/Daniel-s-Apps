# 生命探索 · Biology Explorer

面向 10–15 岁的本地双语试学版，沿用 Study 的 React、Vite、路由、`@study/shared` 类型和 `@study/ui` 语言组件。无需账户或新的服务器。

## 试用

照常启动 Study，打开 `http://localhost:3456/biology`。独立开发：`corepack pnpm --filter @study/biology-web dev`，端口 3460。

目前开放完整 U01、U02 共8课。U01：L001 它是活的吗、L002 生物都会做什么、L003 休眠种子、L004 病毒的生命边界。U02：L005 从鲸鱼到细胞、L006 放大镜与显微镜、L007 第一次认识细胞、L008 单细胞与多细胞生命。每课 15–20 分钟，按「先猜 → 发现 → 挑战 → 带走」完成；含双语图解、可暂停/逐步/重播模型、静态替代说明、4道反馈题、3–5个术语、误区解释及生活观察任务。高阶说明在“再想深一点”内按需展开。三种语言模式共享学习进度。

探索地图保留六阶段、36单元、144课的标题和编号。其余136课标为规划中，没有空课件入口。按完整单元增加，当前仍处于家庭试学阶段；完整课程目标尚未完成。

## 保存与复习

- `localStorage` 的 `study-biology-v1` 保存预测、步骤、已探索状态、回答、第一次回答、完成时间、发现笔记与单元 CER（主张、证据、推理）任务。U01沿用原任务字段，后续单元任务独立保存，旧版记录无需重置。共享语言偏好使用 `study-language`。
- 数据只在当前浏览器和当前站点地址保存；3456 与 3460 的记录相互独立。没有云同步。
- 每轮最多4题，错题优先。错题即刻进入复习；已完成课程的题目在约1、7、30天后进入回忆队列。再次答错仍保留，下次进入复习再次出现。
- 生物理解、推理与证据、英语词汇分别记录。概念题达到80%且推理题正确时显示理解已掌握；“已探索”表示完成流程，英语不会锁住下一课。
- 无法保存时显示警告并允许继续；无法解析旧记录时尽可能备份到 `study-biology-v1-backup`，不将坏记录当作学习成绩。

## 内容维护

`curriculum/index.json` 保存完整课程路线；`curriculum/s01/u01/l001.md` 至 `l004.md` 以及 s01/u02/l005.md 至 l008.md 是双语讲解、误区与进阶说明的真源，UI 使用固定区块读取。`apps/web/src/content.ts` 保存教学元数据、统一词卡、预测和题目反馈；U02 元数据独立放在 src/content/micro.ts。`Explore.tsx` 和 MicroWorld.tsx 保存原创SVG与交互组件，`models.ts` 保存可测试的简化规则。稳定资源ID为 `Lxxx-D01` 和 `Lxxx-I01`；来源记录在同单元的 `media.json`。

新增课程须编写完整 Markdown、题目、双语图示和交互，先核对内容再加入可学习列表；不要仅将路线表的状态改为可用。所有现有内容标为 `pilot`，用于家庭试学；儿童实际试用和外部科学审阅尚未完成。

## 验收

```bash
corepack pnpm --filter @study/biology-web test
corepack pnpm --filter @study/biology-web typecheck
corepack pnpm --filter @study/biology-web build
corepack pnpm --filter @study/hub build
```

浏览器试用：选一课 → 提交不评分预测 → 点图上数字查看结构 → 操作证据卡/模型 → 阅读解释 → 做4题 → 记录发现 → 完成本课。刷新确认恢复，切换三种语言确认内容和进度一致。故意答错后打开复习，检查解释与回看提示。在发现笔记填写主张/证据/推理，确认刷新后保留。

给孩子试用时只观察：能否独立走完一课、是否愿意继续、能否用自己的话解释。后续按完整单元推进课程，并根据实际反馈调整难度和篇幅，保持操作简单。
