## AI 的复杂回答

# 大语言模型到底在做什么？

## 一、先给出核心答案

大语言模型的基本工作不是像人一样“查到一个内在数据库里的正确答案”，而是在给定上下文之后，反复估计下一个符号最可能是什么，再逐个生成符号。它先从极大量文本、代码和其他符号数据中学习统计结构，把词、句子、风格、概念关联和许多可复用的解题模式压缩进参数；在回答时，它把用户输入转为数字表示，通过注意力机制让当前位置参考上下文，输出一个下一个 token 的概率分布，再依策略选出一个 token，循环至回答结束。经指令微调、人类反馈、工具调用和检索增强后，这个“续写器”可以表现得像解释者、程序员、翻译者或助手。

“预测下一个 token”并不意味着它只是机械背诵，也不意味着它已拥有人的理解或可靠世界模型。要在海量语言中预测得好，模型必须捕捉语法、语义、常识关联、部分因果和程序模式；但其训练目标直接奖励的是文本预测的统计成功，而不是真实性、价值判断或对现实后果负责。流畅输出因此可能正确、创造性地组合，也可能自信地编造。理解这一点，是正确使用 LLM 的起点：把它当作强大的候选生成和模式变换器，在可验证任务中提高产出；在高后果任务中外接证据、工具、审计和人的责任。

## 二、概念边界：模型、聊天机器人与知识库不是一回事

“大语言模型”指以大量参数训练、处理 token 序列的统计模型。token 并不等同于汉字或单词，而是文本被分割后的常用片段；模型处理的是这些片段的向量表示。聊天界面、搜索引擎、数据库和代理系统则是产品层组件：有些回答来自模型自身参数的模式，有些通过检索读到外部文档，有些经代码工具计算或调用 API。不能因为界面引用了资料，就以为基础模型天生知道实时事实；也不能因为没有显式搜索，就断言它逐字记住训练集。

还要区分“语言能力”和“意识、意图、真理”。模型可生成第一人称陈述，却没有由此得到可验证的主观体验或独立目标；它会模仿意图语言，是因为那是人类文本的结构。它也不持有一张稳定、完整且可随时校正的世界地图：参数是训练后形成的分布式数值，不是按条目索引的百科目录。对“它理解吗”的哲学争论仍在继续，但工程上更重要的问题是：它在哪些分布内任务稳定、错误如何被发现、谁为行动负责。

## 三、训练：从压缩模式到预测能力

预训练可粗略理解为给模型大量序列，遮住或移动目标位置，让它预测下一个 token；预测偏离真实 token 的程度形成损失，优化算法微调数十亿乃至更多参数，使未来预测更准。由于同一词在不同语境有不同含义，模型必须学习远近上下文、句法关系、主题、格式、代码结构和常见推理轨迹。2017 年 Transformer 架构以注意力机制为核心、放弃循环和卷积的设计，显著提高了序列训练的并行性，[原始论文](https://arxiv.org/abs/1706.03762) 成为今天许多 LLM 的基础。

“压缩”是很有用但不应过度字面化的比喻。若模型只能逐字记忆，面对没见过的新句子便无能为力；要用有限参数降低大量文本的预测误差，它会学习可泛化的规律和抽象特征。可它也可能记住罕见片段，受训练资料偏差影响，或在训练分布之外失灵。参数大小、数据数量与计算量曾在较广范围内显示可预测的经验缩放关系，[Kaplan 等人的研究](https://arxiv.org/abs/2001.08361) 是推动大规模训练的重要证据；但这是经验规律，非无限有效的自然定律，数据质量、架构、后训练和推理方法都会改变结果。

## 四、推理：概率分布如何变成一段回答

用户输入先被分词并嵌入向量；每层 Transformer 用注意力计算不同 token 之间当前任务相关性，再通过非线性变换更新表示；最后一层给词表中的可能下一 token 打分。输出时系统可以贪心地选最高概率，也可按温度、采样范围等规则抽样，使回答更稳定或更多样。新 token 被放回上下文，模型继续计算。因此长回答不是一次性“想好”，而是连续条件生成；早期一个错误选择可能在后文被放大。

注意力机制不是人类注意力的同义词。它是计算中让一个位置对其他位置赋予不同权重的方法，能让模型在长文本中选择相关线索。上下文窗口越长，模型能直接参考的材料越多，但这不保证每一处都被正确利用；长上下文仍有定位、冲突信息和成本问题。更可靠的系统会先检索权威资料、用结构化工具计算、要求引用，然后让模型解释结果；这把“语言生成”与“事实获取、算术、执行”分工。

## 五、后训练、工具与人类偏好为何改变体验

原始预训练模型只擅长续写，未必知道何时回答、如何拒绝危险请求、如何按指令格式化。监督微调用问答和任务示例教会它遵循指令；偏好学习或强化学习让输出更符合人类评价的有用、无害、清晰等标准；安全训练试图降低滥用与有害行为。此后模型看起来更像对话者，但本质机制仍是条件概率生成，且偏好优化可能让模型更迎合用户、在不确定时给出过度自信答案。

工具调用改变了能力边界。检索增强生成（RAG）把可更新、可引用的文档放进上下文，计算器和代码执行让精确计算外包给确定性工具，数据库与工作流 API 让模型能提出或执行动作。系统可靠性因而取决于整个链条：检索是否找对来源、权限是否正确、工具返回是否被核验、模型是否误解结果、行动前是否有授权。把 LLM 当成单独“大脑”会遮蔽这些真实的工程和治理责任。

## 六、四个任务案例

**翻译与改写。**源文本就在上下文中，目标是保持含义并转换风格，属于可直接比较输入输出的模式变换任务。LLM 能显著提高初稿速度，但法律、医学或文学翻译仍需懂领域的人检查术语、歧义和文化含义。它证明模型可以从语言结构中泛化，不证明其懂得文本所指的现实。

**代码辅助。**代码既是语言又有可执行语法，模型能根据常见模式生成函数、测试和解释。编译器、单元测试和审查可提供外部反馈，所以工具结合后效果常优于纯聊天。但模型也会引用不存在的库、遗漏安全边界或产生能运行却不满足需求的实现。这里的新瓶颈是规格、测试、架构与责任，而非键入速度。

**检索式问答。**若问题涉及最新政策、公司数据或医学指南，封闭模型的参数不能保证时效。把官方文档检索进上下文并要求逐项引用，通常比仅凭记忆回答更稳；但检索到错误或过期文件、模型把来源拼接错，仍会失败。这个案例说明“会说”与“知道当前事实”必须分开。

**高后果决策。**在信贷、招聘、医疗建议或司法辅助中，预测文本并不自动满足公平、解释、程序正义和法律责任。即便平均准确率很高，少数群体偏差、不可申诉的错误或自动化偏见也可能造成不可接受伤害。此时 LLM 最适合作为受限的文书、信息整理或第二意见工具，除非经过针对场景的验证、监督与问责设计。

## 七、竞争解释：它是在“理解”还是在“鹦鹉学舌”？

“随机鹦鹉”批评强调，模型从人类语料学习相关性，没有身体经验、稳定信念或内在真值目标，因此不能把流畅性误当理解。这是重要警告，尤其对偏见、版权、数据来源和幻觉问题。另一端观点认为，预测复杂语言必须形成某种内部结构表征；模型在未见组合上的迁移、代码与多步任务表现说明它不只是逐字检索。

最强的综合立场是功能分解，而非二元形容词：在某些语言和符号任务上，模型有足够好的表征与泛化，值得被称为有效的任务理解；在需要真实世界接地、因果干预、长期记忆、价值权衡和责任承担时，其局限很明显。应以任务级可复现实验、错误率和最坏情形评估来取代“像人”或“不像人”的口号。

## 八、边界、风险与正确用法

LLM 的幻觉不是偶发的 UI 缺陷，而与其目标有关：当上下文不足或训练模式冲突时，它仍被要求生成高概率的连贯续文，未必会自然停下并声明无知。采样、提示、对齐、检索和验证能降低但不能消除风险。模型还会继承公开文本的偏见、侵犯隐私或版权、被提示注入操纵；长上下文、代理循环和工具权限会扩大一次错误的影响半径。

因此应按风险分级：低后果的头脑风暴、摘要和草稿可以强调速度；中等后果任务应有来源、测试和人工复核；高后果决定应保留可解释规则、独立验证、申诉与责任主体。不要要求用户“相信 AI”，而要设计能让人发现、纠正和追责错误的流程。

## 九、可观察的未来信号

未来应观察模型是否能在独立、真实任务中提高可靠性而非只提高基准分数；工具调用是否把错误率降到可接受水平；推理成本、延迟和能耗是否下降；训练数据的授权、出处和偏差是否更透明；企业是否建立了日志、评估、权限与人工接管；以及是否出现将模型用于高后果领域后的公开事故和有效纠错。模型越能被验证、约束并与确定性工具互补，其经济价值越可能从“好用的写作助手”扩展为可靠基础设施。

也应追踪使用者技能的变化：如果工具使新手更快完成任务却减少练习、让错误难以辨认，短期产出上升可能伴随长期能力退化；如果工作流要求解释证据、复核差异和编写测试，工具则能成为学习的脚手架。模型表现与人机制度不能分开测量，长期结果尤其如此。

补充地说，审计也应覆盖这种学习效应。

## 把这一题真正记住

大语言模型不是在一个确定的知识库里找答案，而是在当前上下文条件下，一步步给下一个 token 分配概率并生成文本。为了在海量语言中做好这件事，它学到了丰富的语法、概念关联、代码与问题解决模式，所以能做翻译、写作、编程和解释；但它被直接优化的不是事实、价值或责任，因而也会在不知道时生成貌似合理的内容。模型的真正能力要放在系统里看：预训练给出通用模式，后训练让它遵循指令，检索和工具提供新事实与计算，测试、审计和人类复核负责把候选变成可信行动。正确的问题不是“它究竟有没有像人一样理解”，而是“在这个明确任务中，它的输入、错误、验证和责任链是什么”。把它用于低风险的生成与变换，把高风险判断外接证据和问责，才能把强大的概率工具转化为可靠的社会能力。

### 一句话模型

**LLM 用上下文预测并生成下一段符号；它擅长产生候选，可靠性来自外部证据、工具验证和人类责任，而非流畅语气。**
