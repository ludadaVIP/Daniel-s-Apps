# InsightMatrix · 认知矩阵

一个面向大屏幕的个人认知训练工作台。把「阅读概念 → 拆解案例 → 写下判断 → 回看证据」连成日常使用流程。

## 开始使用

需要 **Node.js 24.15.0 或更高版本**（使用内置 `node:sqlite`，无需另装数据库）。建议使用项目 `.nvmrc` 指定的版本。

```sh
npm install
npm run dev
```

也可以直接双击项目根目录的 `start.bat`（Windows）或 `start.command`（macOS）一键启动；脚本会在首次运行时安装依赖，并打开 `http://127.0.0.1:5757`。

开发地址固定为 **http://127.0.0.1:5757**。前端通过 Vite 代理连接本地 API，Node API 仅在 `127.0.0.1:5758` 提供服务。开发时若改动 Markdown 内容，请重启开发服务。

本地运行生产构建：

```sh
npm run build
npm start
```

打开 **http://127.0.0.1:5757**。生产模式由同一个 Node 服务提供页面与 API。`npm run preview` 也固定使用 5757；日常完整使用推荐 `npm start`。

验证：

```sh
npm test
npm run build
```

测试覆盖 Markdown 元数据与关联完整性、状态持久化与重启恢复、输入校验、跨站请求拒绝、API 404 和页面路由回退。

## 可以做什么

- 从今日工作台进入阅读、案例和思考练习。
- 浏览人性、心理、社会、经济、产业、投资六个领域的 Markdown 知识，按关键词查找内容。
- 阅读概念机制、应用边界、历史案例和思考题，并沿关联概念继续探索。
- 收藏文章、标记完成、保存自己的挑战回答。
- 写下投资判断的依据、反方证据、概率与证伪条件，并记录复盘。

知识库包含 **36 个概念、60 个历史案例**，人性、心理、社会、经济、产业、投资各有 10 个案例。案例包括当时的信息、决策机制、证据、反事实、适用边界和可执行练习，并附可追溯来源。

## 架构与数据

```text
src/                 React 界面、Markdown 阅读器、训练与判断工作区
content/             六大分类的 Markdown 原文，知识内容的唯一来源
server/content.js    frontmatter 解析、字段校验和关联检查
server/state.js      SQLite 状态持久化与输入校验
server/app.js        Express API 与生产静态文件服务
data/                本机用户记录（自动生成，已排除 Git）
dist/                构建产物（自动生成，已排除 Git）
```

知识库在服务启动时加载。收藏、阅读记录、回答、判断与活动保存在 **`data/insightmatrix.sqlite`**，刷新页面或重启服务后继续保留。没有账户体系；这是单用户、本机工作台。建议只在一个标签页中编辑个人记录：同一字段在多个窗口同时保存时，以后一次保存为准。

后端只绑定本机 `127.0.0.1`，默认不对局域网或公网开放。若需要多人使用，应先加入身份认证、用户隔离与并发版本控制。

可用环境变量：

| 变量 | 默认值 | 用途 |
| --- | --- | --- |
| `PORT` | `5757`（生产）/ `5758`（开发） | Node 服务端口；开发脚本已固定传入 5758，生产启动固定传入 5757 |
| `DATABASE_PATH` | `data/insightmatrix.sqlite`（项目绝对路径） | 指定 SQLite 文件位置 |

数据库采用事务写入；输入校验失败不会覆盖现有记录。若文件损坏，服务会明确报错，不会自动重置或删除个人数据。

## 备份与恢复

1. 用 `Ctrl+C` 停止服务。
2. 复制完整 **`data/` 文件夹** 到自己的备份位置；知识库修改可另行备份 `content/` 或纳入版本管理。
3. 恢复时同样先停止服务，再将备份的 `data/` 放回项目目录，最后启动服务。

SQLite 使用 WAL 日志。请停止服务后备份整个文件夹，避免只复制运行中的主数据库而漏掉尚未合并的写入。个人判断和回答都属于本机数据，清空 `data/` 会失去这些记录。

## 扩充内容

按 [content/README.md](content/README.md) 的模板新增 Markdown，填写唯一 ID、事件标识、学习目标和来源。运行 `npm run check:content` 检查重复候选、章节与证据结构，以及当前版本的逐篇编辑审读记录；报告位于 `artifacts/content-audit.json`。`npm run build` 会执行同一检查。修改后运行 `npm test` 并重启服务。Markdown 使用 React Markdown 渲染，不启用原始 HTML 执行。

阅读长页时，右下角会出现浅色悬浮箭头，点击回到顶部；开启减少动态效果时使用直接回顶。

## 当前边界

本版本不连接 AI、券商、实时行情或新闻源，也不把预设思考提示伪装成 AI 结论。每日练习来自内置题库；知识内容需要维护者按来源更新。未来可以接入带来源核验的研究助手和辩论教练，先保证当前的认知记录与复盘流程可长期使用。

产品设想保留于 `plan.md`；当前范围与后续方向见 [IMPLEMENTATION.md](IMPLEMENTATION.md)。
