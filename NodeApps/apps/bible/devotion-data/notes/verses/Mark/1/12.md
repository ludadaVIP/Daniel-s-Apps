# 圣灵就把耶稣催到旷野里去

对，这里的 **“催”** 是《马可福音》一个很值得注意的用词。它比我们现代中文里一般理解的“催促一下”要强烈得多。

> **“圣灵就把耶稣催到旷野里去。”**
> ——马可福音 1:12

原文是：

> **Καὶ εὐθὺς τὸ πνεῦμα αὐτὸν ἐκβάλλει εἰς τὴν ἔρημον.**
> *Kai euthys to pneuma auton ekballei eis tēn erēmon.*

其中最关键的词就是 **ἐκβάλλει（ekballei）**。

### 1. “催”原文其实非常强烈

**ἐκβάλλω（ekballō）** 的基本意思是：

**赶出去、驱逐、推出去、使出去。**

这个词绝不是普通的“建议”“引导”。有意思的是，马可福音大量使用这个词来描述**赶鬼**。

例如：

> “耶稣治好了许多害各样病的人，又**赶出**许多鬼。”
> ——可 1:34

这里“赶出”与可1:12“催”来自**同一个希腊动词 ἐκβάλλω**。

所以如果非常直译，可1:12甚至可以译成：

> **“圣灵立刻把他驱入旷野。”**

当然，这不是说耶稣不愿意、圣灵强迫祂做违背意愿的事情。重点在于马可刻意使用了一个**具有强烈推动力的动词**。

马太写得温和一些：

> “当时，耶稣被圣灵**引到**旷野……”（太4:1）

路加也是：

> “圣灵将他**引到**旷野……”（路4:1）

而马可却用了 **ἐκβάλλω——“催出去、驱出去”**。

这非常符合马可福音整体的叙事风格。

### 2. 为什么圣灵刚刚降临，就立刻把耶稣“催”进旷野？

把上下文连起来看，会非常有力量：

**受洗 → 圣灵降临 → 父宣告“你是我的爱子” → 圣灵立刻催祂进入旷野 → 撒但试探 → 开始公开传道。**

也就是说：

**圣灵降临之后，耶稣首先经历的，不是荣耀的公开事奉，而是旷野。**

可1:10：

> “他从水里一上来，就看见天裂开了，圣灵仿佛鸽子，降在他身上。”

可1:11：

> “又有声音从天上来，说：你是我的爱子，我喜悦你。”

紧接着：

> **“圣灵就把耶稣催到旷野里去。”**

这里有一个很重要的圣经神学观念：

**旷野不是耶稣偏离神旨意的地方；恰恰是圣灵把祂带进去的地方。**

因此，“处在神旨意中”与“环境顺利”在圣经里根本不能画等号。

耶稣完全顺服父，父也明确宣告“我喜悦你”，可是下一站竟然是——**旷野、禁食、野兽、撒但和试探。**

### 3. 更深一层：这是“新以色列”的旷野

这里实际上还连着整本旧约。

以色列：

**过红海 → 进入旷野 → 四十年 → 受试探 → 多次失败**

耶稣：

**经过约旦河受洗 → 进入旷野 → 四十天 → 受撒但试探 → 得胜**

所以耶稣在某种意义上正在重新走以色列走过的道路。

以色列是神的“儿子”：

> “以色列是我的儿子，我的长子。”（出4:22）

耶稣受洗时父说：

> “你是我的爱子。”（可1:11）

然后这个“儿子”进入旷野。

**第一个儿子以色列在旷野中失败；真正的爱子基督在旷野中得胜。**

而且还有更深的一层。

亚当：

**园子 → 撒但试探 → 失败**

耶稣：

**旷野 → 撒但试探 → 得胜**

所以基督不仅重新走以色列的道路，也以**末后的亚当**的身份，站在人类失败之处得胜。

### 4. “圣灵催耶稣”并不意味着圣灵在“试探”耶稣

这里要做一个重要区分。

马可说：

> 圣灵把耶稣催到旷野。

但接下来：

> “在旷野四十天，受撒但的试探。”（可1:13）

所以：

**圣灵引导耶稣进入试炼的处境；撒但是试探者。**

这两件事情不能混在一起。

神可以在祂的主权中带领人经过试炼，但神不是罪恶诱惑的来源。雅各书后来把这个原则说得非常清楚：

> “神不能被恶试探，他也不试探人。”（雅1:13）

同一个旷野，从神的旨意来看是**试炼与使命的预备**；从撒但的行动来看却是**试探与攻击**。

### 5. 我尤其觉得“催”这个字放在这里很有意思

因为它打破了一种很常见的属灵想象：

> **圣灵带领我 → 所以道路应该越来越舒服。**

马可福音第一章恰恰告诉我们：

> **圣灵降临 → 父神喜悦 → 圣灵催逼 → 进入旷野 → 撒但试探。**

所以有时候真正的圣灵带领，不一定是把一个人**带离旷野**，反而可能是把他**带进旷野**。

关键的问题因此不是：

**“为什么我到了旷野？是不是神不喜悦我？”**

因为耶稣进入旷野之前，父刚刚说：

> **“你是我的爱子，我喜悦你。”**

真正的问题是：

**“如果这是神所许可、甚至带领我进入的旷野，祂要在这里成就什么？”**

而在耶稣身上，答案非常清楚：

**旷野不是使命的终点，而是使命开始以前的战场。**

马可的叙事极其紧凑：受洗、圣灵降临、父神宣告、旷野试探，然后可1:14开始：

> **“耶稣来到加利利，宣传神的福音。”**

因此这个 **ἐκβάλλει——“催”**，其实把一个非常深的属灵次序呈现出来：

**蒙爱 → 受膏 → 旷野 → 争战 → 得胜 → 使命。**

尤其值得注意的是：**旷野并没有否定前一句“你是我的爱子，我喜悦你”；恰恰是在这个身份已经被父宣告之后，耶稣才进入旷野。**

这也是理解马可福音1:12时最容易被忽略、却非常重要的一点。
