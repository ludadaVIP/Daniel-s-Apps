# 以色列人在神所赐的地上，是寄居者和受托者

《利未记》25:23–34 如果只单独读，很容易觉得是在讲古代以色列的“房地产法规”。但放在整章来看，它实际上围绕一个非常重要的神学观念展开：

> **以色列人虽然拥有土地，却不是土地最终的主人；耶和华才是主人。以色列人在神所赐的地上，是寄居者和受托者。**

这也是为什么会出现我们现代人看起来很特别的制度：**土地可以卖，但不能永久卖断；贫穷的人失去祖业以后，还存在“赎回”的权利。**

---

## 一、先看最关键的23节

> **“地不可永卖，因为地是我的；你们在我面前是客旅，是寄居的。”**（利25:23）

这一节实际上就是23–34节的总纲。

现代人的产权观念通常是：

**我花钱买了 → 就是我的 → 我可以永久拥有 → 可以留给子孙。**

但是神给以色列的土地制度不是这样。

因为迦南地首先属于耶和华。

神把迦南赐给以色列，然后按照支派、宗族、家族分配土地。因此一个以色列家庭所得的土地，不单纯是一项可以买卖的“房地产资产”，而是**神赐给这个家族的产业（נַחֲלָה，nachalah）**。

所以：

**神 → 把地赐给以色列 → 分给十二支派 → 再分给各宗族家庭。**

因此一个人即使因为贫穷把土地“卖掉”，原则上也不能永久改变神最初所设立的产业归属。

这就产生了后面的**赎地制度**。

---

# 二、24–28节：为什么亲属可以把土地赎回来？

> “在你们所得为业的全地，也要准人将地赎回。”（25:24）

假设有一个以色列人叫甲。

他的祖先从约书亚时代开始，就分到了一块土地。

后来甲家里遭遇灾荒，越来越穷，没有钱生活，只好：

**把祖传土地卖给乙。**

按照现代房地产制度，可能就是：

> 乙付钱 → 完成交易 → 土地永远属于乙。

但摩西律法不是这样。

### 第一种情况：近亲替他赎回来

25节：

> “你的弟兄若渐渐穷乏，卖了几分地业，他至近的亲属就要来，把弟兄所卖的赎回。”

这里出现了一个非常重要的希伯来概念：

**גֹּאֵל（go'el）——至近的亲属、救赎者、赎业者。**

也就是说：

甲没有钱把土地买回来。

但是甲的哥哥、叔叔或者其他近亲有能力。

那么这个近亲可以出钱：

**从乙手里把土地赎回来，使产业重新回到原来的家族体系。**

这正是你刚才读《路得记》时遇到的背景。

波阿斯就是一个 **go'el（至近的亲属/赎业者）**。

所以《路得记》第4章不是突然出现一个奇怪的婚姻和房地产制度，而是在《利未记25章》等律法背景下发生的。

---

# 三、如果后来自己有钱了呢？

26–27节说：

> “若没有能给他赎回的，他自己渐渐富足，能够赎回，就要算出卖地的年数，把余剩年数的价值还那买主，自己便归回自己的地业。”

例如：

甲因为贫穷，把土地“卖”给乙。

后来过了10年，甲重新富裕起来。

那么甲可以要求赎回土地。

但是不能说：

> “这是神给我祖宗的，所以你现在免费还给我。”

不是。

因为乙当初确实支付了钱，而且已经合法取得这块土地一定年限的使用权。

所以必须计算：

**距离禧年还有多少年。**

然后按照剩余年数计算价值，把相应的钱还给乙。

这里就出现了一个理解《利未记25章》非常重要的概念：

## 严格来说，他们卖的不是土地永久所有权，而是“直到禧年的土地使用收益”。

比如：

距离禧年还有40年。

那么土地价格比较高。

因为买主还能使用40年。

如果距离禧年只有5年：

土地价格自然低很多。

所以前面15–16节已经规定：

> 禧年越远 → 价格越高
> 禧年越近 → 价格越低

因为经文本身说：

> “他照年数卖给你的是地的出产。”

换句话说，交易的经济实质很接近：

**购买从现在到禧年之间这块土地所产生的农业收益权。**

而不是永久取得土地本身。

---

# 四、如果原主人一直穷，永远没有钱赎呢？

这就是28节：

> “倘若不能为自己得回所卖的，仍要存在买主的手里直到禧年；到了禧年，地业要出买主的手，自己便归回自己的地业。”

这是整个制度最特别的地方。

即使：

**没有亲戚帮你赎 + 你自己后来也没有发财 + 完全没有能力买回来**

仍然不会永远失去祖业。

因为到了**禧年**：

**土地自动归回。**

所以可以把整个制度画成：

**神赐产业**

↓

家庭拥有祖业

↓

因贫穷出售

↓

① 近亲可以赎回
② 自己富裕后可以赎回
③ 两者都不行 → 等到禧年

↓

**禧年无条件归回原来的产业体系**

这就是为什么23节必须放在最前面：

> **“地不可永卖，因为地是我的。”**

最终原因不是经济学，而是**神的主权**。

---

# 五、29–30节突然讲“城里的房子”，为什么规则变了？

这里很有意思。

> “人若卖城内的住宅，卖了以后，一年之内可以赎回；在一整年，必有赎回的权柄。”（25:29）

但是：

> 如果一年之内没有赎回，城内的房屋就永归买主，**禧年也不归还。**

你可能马上会问：

**咦？刚刚不是说到了禧年全部归还吗？**

区别在于：

### 土地 ≠ 城里的普通住宅。

农业土地是神分配给各支派、宗族和家庭的**祖业体系的一部分**。

而城里的普通住宅具有更强的交易属性。

所以：

| 财产          | 是否可以永久卖掉     |
| ----------- | ------------ |
| 家族祖传土地      | ❌ 不可以        |
| 无城墙村庄的房屋    | ❌ 原则上随土地处理   |
| 有城墙城市里的普通房屋 | ✅ 一年以后可以永久转让 |
| 利未人的城中房屋    | ❌ 特殊保护       |

这说明律法不是简单规定“所有房地产都不能永久交易”。

它真正保护的是：

**神所分配的产业结构。**

---

# 六、为什么“没有城墙的村庄房屋”又算田地？

31节：

> “但房屋在无城墙的村庄里，要看如乡下的田地一样，可以赎回；到了禧年，都要出买主的手。”

这个很好理解。

古代农业社会里面：

**村庄住宅 + 周围田地**

往往是一个农业生产单位。

农民住在那里，就是为了耕种周围的祖业。

所以农村住宅和土地紧密绑定。

因此：

**乡村房屋 → 按土地规则处理 → 禧年归还。**

而有城墙城市中的住宅，则可以与农业祖业分开，因此适用另一套规则。

---

# 七、32–34节：为什么利未人的房子又例外？

这里又出现一个特殊规定：

> “然而利未人所得为业的城邑，其中的房屋，利未人可以随时赎回。”（25:32）

原因在34节：

> “只是他们各城郊野之地不可卖，因为是他们永远的产业。”

为什么利未人特殊？

因为利未支派与其他支派不一样。

其他支派有大片土地：

犹大有犹大的地，便雅悯有便雅悯的地，以法莲有以法莲的地……

但利未人没有得到一个完整的“利未省”。

因为神说：

> **“我就是你的分，是你的产业。”**（民18:20）

所以利未人散居在以色列各支派中的城市里，他们所得的城邑、房屋以及周围牧场，就是他们维持生活的重要产业。

如果允许这些房产像普通城市住宅一样永久卖断，长期下去：

**利未人的产业就可能逐渐消失。**

因此神特别保护他们。

---

# 八、现在你就能看懂《路得记》为什么会出现波阿斯了

这两段经文其实可以直接连起来读。

《利未记》25章规定：

> 一个以色列人因为贫穷卖掉祖业，至近亲属 **go'el** 有责任把产业赎回来。

然后到了《路得记》：

以利米勒一家离开伯利恒 →
以利米勒死 →
两个儿子死 →
拿俄米回来 →
家族产业面临继承问题 →
需要一个 **go'el** →
先找到那个更近的亲属 →
他不愿承担责任 →
波阿斯承担 →
产业得赎 →
家族名字得以延续。

所以你刚才问《路得记4:5》：

> 为什么波阿斯说买拿俄米的地，也涉及路得？

现在背景就越来越清楚了。

《路得记》的作者默认读者知道**摩西律法中的产业、近亲、赎业、家族名字与继承制度**。

不过这里还要精确一点：《路得记》的制度并不是单纯照搬《利未记25章》。它还结合了《申命记25:5–10》关于兄弟婚/为死者立后的原则，以及古代以色列更广泛的亲族义务。因此，**波阿斯事件可以说综合了“赎业者”和“保存死者家名”两个法律—社会传统**，不能简单说《利未记25章直接规定“赎地就必须娶寡妇”》。

# 九、这段律法背后其实有非常深的神学

如果只把它理解成“古代房地产法”，就低估了这段经文。

它至少表达了四层思想。

### 1. **土地属于神，人只是管家**

最重要的就是：

> “因为地是我的。”

这其实颠覆了绝对所有权的观念。

以色列人可以说：

> “这是我的产业。”

但更深一层却必须承认：

> **“它首先是耶和华的，我只是从神那里领受。”**

所以“拥有”并不等于“拥有最终主权”。

### 2. **贫穷不应该永久毁掉一个家庭**

如果没有这种制度，会发生非常典型的古代社会现象：

贫穷 →
卖地 →
失去生产资料 →
更加贫穷 →
借债 →
成为雇工甚至奴仆 →
下一代继续贫穷。

最终就形成：

**少数地主越来越富，大量家庭永久失去土地。**

《利未记25章》在制度层面设置了一个“重置机制”：

> **禧年。**

它不是保证所有人永远经济平等，而是防止一次经济失败永久剥夺一个家族在应许之地中的产业。

### 3. **救赎不是抽象概念，而是“付代价把失去的东西买回来”**

这对理解整本圣经非常重要。

希伯来文 **go'el** 所包含的画面非常具体：

> 我的亲人落入困境；
> 他自己没有能力恢复；
> 一个与他有亲属关系、同时又有能力的人站出来；
> 支付代价；
> 把失去的产业赎回来。

所以你以后再读：

**“救赎”**

这个词就不要只把它理解成抽象的宗教术语。

它原本带着非常强烈的：

**奴隶市场、债务、土地、亲属、产业恢复**

这样的现实背景。

# 十、最终又会把我们带到基督

从基督教的整本圣经神学来看，这里当然不能机械地说：

> “波阿斯就是耶稣，所以每个细节都预表耶稣。”

那样容易过度寓意化。

但是“**救赎—恢复产业—禧年—释放**”这条神学线索，确实继续向新约发展。

尤其《利未记25章》的禧年背景，会让《路加福音4章》变得非常有意思。

耶稣引用以赛亚：

> “叫我传福音给贫穷的人……叫那受压制的得自由，报告神悦纳人的禧年。”（参路4:18–19）

于是整条圣经神学线索逐渐形成：

**土地属于耶和华**
→ **以色列从神领受产业**
→ **人因贫穷可能失去产业**
→ **近亲救赎者赎回产业**
→ **禧年带来释放与恢复**
→ **先知宣告更大的释放**
→ **基督宣告神国的禧年临到**
→ **基督完成真正的救赎**
→ **神的百姓最终承受永恒的产业。**

所以《利未记25:23–34》真正的核心，不是“古代以色列人怎么买房”，而是：

> **神是产业真正的主人；神不愿祂所赐的产业因人的贫穷而永久丧失，因此祂设立赎业者与禧年，使失去的得以恢复。**

而你最近正在读《路得记》，**现在读《利未记25章其实正是时候**。把《利25:23–34》《申25:5–10》《路得记3–4章》三段放在一起，你就能把**“至近亲属—赎业—婚姻—为死人存留名字”**这一整套制度彻底串起来。
