# 大卫被膏后漫长的磨炼

这是一个非常好的观察。

很多人读《撒母耳记》，会有一种错觉：好像扫罗被膏、大卫被膏、大卫做王，几章经文就过去了。

但实际上，如果把时间轴拉开，你会发现：

**《撒母耳记》最大的主题之一，不是“大卫如何成功”，而是“大卫如何等待”。**

神膏立大卫的时候，他还是个放羊的少年；真正坐上全以色列王位的时候，他已经接近四十岁了。

中间大约经历了 **20多年漫长等待。**

------

# 第一阶段：扫罗被膏立（约公元前1050年左右）

## 撒上9-10章

撒母耳膏扫罗。

扫罗当时大约30岁。

圣经记载：

> 扫罗作王四十年（徒13:21）

这四十年很重要。

因为后面很多事件都发生在这段时间里。

------

# 第二阶段：少年大卫被膏（约公元前1025年左右）

## 撒上16章

撒母耳到伯利恒。

耶西七个儿子都看完。

最后叫来放羊的大卫。

神说：

> 这就是他，你起来膏他。

（撒上16:12）

------

这里有一个震撼的事实：

### 大卫被膏的时候并没有立刻做王

甚至：

- 没有王位
- 没有军队
- 没有权力

只是一个牧羊娃。

------

学者普遍估计：

### 此时大卫约15岁左右

（14-17岁区间）

------

# 第三阶段：大卫进入王宫

持续约1-2年

## 撒上16章后半段

扫罗被恶魔搅扰。

大卫被召入宫弹琴。

成为宫廷成员。

------

这时的大卫可能觉得：

> 神是不是开始成就应许了？

结果并没有。

因为后面还有十几年苦难。

------

# 第四阶段：击杀歌利亚

约16-18岁

## 撒上17章

歌利亚事件。

这是大卫人生重大转折点。

全国认识他。

名声暴涨。

------

妇女唱歌：

> 扫罗杀死千千，
>
> 大卫杀死万万。

（撒上18:7）

------

从这一刻开始：

## 扫罗开始嫉妒

然后持续追杀大卫很多年。

------

# 第五阶段：扫罗追杀时期

持续约8-12年

这是大卫人生最痛苦的一段。

也是《撒母耳记上》后半部分的主要内容。

------

## 第一阶段逃亡

撒上19-22章

时间约1-2年

地点：

- 拉玛
- 挪伯
- 迦特
- 亚杜兰洞

------

这里发生：

### 祭司被屠杀

多益告密。

扫罗杀死85个祭司。

（撒上22章）

------

大卫第一次感受到：

> 因为我，别人受害。

这是非常沉重的经历。

------

## 第二阶段旷野流亡

撒上23-26章

时间约3-5年

------

地点：

- 西弗旷野
- 隐基底
- 玛云旷野

等等。

------

这期间最著名的两件事：

### 第一次放过扫罗

撒上24章

洞穴事件。

------

### 第二次放过扫罗

撒上26章

取枪和水瓶事件。

------

很多人觉得：

> 为什么不杀？

事实上：

因为大卫相信：

> 神的应许不用靠犯罪完成。

------

这是大卫信心最成熟的阶段之一。

------

# 第六阶段：非利士地寄居

约1年4个月

这是圣经唯一明确记载时间的逃亡阶段。

## 撒上27:7

经文直接说：

> 大卫在非利士地住了一年零四个月。

------

这时大卫约28岁左右。

------

非常值得注意：

此时距离受膏已经十多年。

神似乎仍然沉默。

------

如果是今天很多人：

可能已经怀疑：

> 当年撒母耳是不是膏错人了？

------

但大卫还在坚持。

------

# 第七阶段：扫罗战死

公元前1010年左右

## 撒上31章

基利波山大战。

扫罗战死。

约拿单战死。

三个儿子战死。

------

注意：

此时大卫并没有立刻成为全国的王。

很多人第一次读都会以为：

扫罗死了，大卫终于上位。

并不是。

------

# 第八阶段：大卫作犹大王

持续7年6个月

## 撒下2章

大卫求问神：

> 我上犹大的一个城去可以吗？

神说：

> 可以。

------

于是：

在希伯仑受膏。

成为犹大王。

------

此时年龄：

### 30岁

圣经明确记载：

> 大卫登基的时候年三十岁。

（撒下5:4）

------

但问题来了：

### 北方十一支派不服

押尼珥立伊施波设为王。

于是开始内战。

------

持续：

### 7年6个月

（撒下5:5）

------

这期间发生：

- 押尼珥投降
- 约押杀押尼珥
- 伊施波设被刺杀

等等。

------

# 第九阶段：全以色列王

约37岁半

## 撒下5章

众支派来到希伯仑。

说：

> 我们原是你的骨肉。

------

然后：

第三次受膏。

成为全以色列王。

------

至此：

神在撒上16章给的应许终于完全实现。

------

# 整体时间轴总结

| 事件         | 大卫年龄 | 等待时间     |
| ------------ | -------- | ------------ |
| 被膏         | 约15岁   | 起点         |
| 进入王宫     | 16岁左右 | 约1年        |
| 击杀歌利亚   | 17岁左右 | 约2年        |
| 被追杀开始   | 18岁左右 | 约3年        |
| 旷野逃亡     | 20-28岁  | 约10年       |
| 非利士地寄居 | 28-29岁  | 约13年       |
| 扫罗死亡     | 29-30岁  | 约15年       |
| 犹大王       | 30岁     | 应许部分实现 |
| 全以色列王   | 37岁半   | 应许完全实现 |

------

# 更深一层：神为什么让大卫等这么久？

如果神愿意：

大卫被膏第二天就能登基。

神完全有能力这样做。

但神没有。

因为神工作的原则常常是：

> 神呼召一个人，往往很快；
>
> 神预备一个人，往往很慢。

如果16岁的牧童直接做全以色列王：

他很可能成为另一个扫罗。

------

所以神允许：

- 被误解
- 被追杀
- 被背叛
- 被遗忘
- 被羞辱

这些经历塑造了大卫。

当大卫后来写下诗篇时，你会发现很多诗篇不是坐在王宫里写的，而是在山洞、旷野、逃亡路上写的。

某种意义上说：

**神用十几年的等待，塑造了一个合神心意的人；然后才用几十年的时间，让这个人治理国家。**

从圣经整体来看，等待并不是神忘记了应许，而常常是神正在预备承受应许的人。

你若把视野再放大，会发现一个很有意思的规律：

- 亚伯拉罕等儿子，约25年；
- 约瑟从做梦到作宰相，约13年；
- 摩西从蒙召到带领以色列，约40年；
- 大卫从受膏到登基，约15-22年；
- 保罗归主后也经过多年隐藏才开始广泛事奉。

神给应许往往很快，但应许成熟却常常需要漫长时间。这几乎是贯穿整本圣经的属灵规律。
