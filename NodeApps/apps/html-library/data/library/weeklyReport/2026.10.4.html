周内时间线：五个交易日，五次市场叙事切换

MON · 9/28

油价 + 美债收益率 = 双重估值压力

Trump拒绝伊朗和平方案后，原油上冲，10月加息概率升至约70%。S&P 500跌0.77%，为8月20日以来最大单日跌幅。Boeing因737 MAX 10认证延误跌6.9%，Tesla因交付担忧与目标价下调跌3.9%；Nvidia凭借创纪录的1500亿美元回购授权逆势上涨1.6%。[R1][R17]

TUE · 9/29

长端利率继续冲高，但Fed官员开始给市场“踩刹车”

10年期美债一度至5.293%，30年期至5.6206%。John Williams称“不急于”继续加息，10月加息概率从约70%降至51.5%。JOLTS职位空缺降至707.9万，消费者信心跌至近12年半低位。FICO因住房金融定价规则变化暴跌26.5%，CarMax则因盈利改善涨4.7%。[R2]

WED · 9/30

通胀比预期温和，但经济并未塌

8月PCE同比3.4%，低于3.7%预期；二季度GDP终值上修至年化2.2%。这形成“通胀没那么糟、增长仍可”的组合。10月加息概率进一步降至约37%。科技板块相对强，HPE涨3.9%，Moderna因评级下调跌5.3%。[R3]

THU · 10/1

长端收益率摸到24年高位，然后突然回落

ISM制造业PMI 54.5，投入价格跳升，先把10年期收益率推到5.34%；随后债券买盘与Fed副主席Jefferson偏耐心的表态令收益率回落。能源板块因中国暂停成品油出口而上涨1.9%；Micron凭AI需求与客户承诺涨3%。[R4]

FRI · 10/2

非农远逊预期，“10月加息”几乎被市场移出主线

9月非农仅+2.9万，远低于+9万预期；失业率升至4.2%，工资同比增速降至3.0%。10月加息概率降到约22.7%。Nasdaq涨1.19%，Russell 2000涨0.9%，Tesla涨4.7%。但Nike因中国需求疲弱与裁员计划跌3.6%，Western Digital和Seagate因供给扩张担忧各跌约10%。[R5][R6]

利率与宏观：本周最关键的不是“Fed会不会加息”，而是“为什么长端不肯下来”

图2｜CME FedWatch中10月加息概率的周内变化：约70% → 51.5% → 37% → 28.2% → 22.7%。[R1][R2][R3][R4][R5]

这是一种“曲线分裂”

如果只看Fed，市场应该在周后半段明显降低利率压力；但10年期收益率周五仍在约5.28%，且本周约上行10bp，录得连续第五周上升。[R8]

这说明长端收益率的驱动已不只是短期政策利率，而是能源通胀、财政供给、期限溢价、以及AI基础设施融资对资本的巨大需求。这类力量不会因为一次偏弱非农就自动消失。

市场含义：
如果10年期长期钉在5%以上，那么“高估值成长股还能涨多少”与“便宜但负债重的公司能不能修复”都要重新计算。未来选股将更看资产负债表、现金流和融资依赖度。

AI链条的三层分化

Tier 1

平台与算力核心

Nvidia、Micron仍能用订单、现金流和回购证明资本回报；这是AI主线最坚硬的一层。

Tier 2

基础设施服务

HPE、Accenture等受益于网络、服务器与企业部署，但市场更看重订单和指引，而不再只看叙事。

Tier 3

供给扩张受害者

WDC/STX的下跌提醒市场：一旦供给跟上，AI需求增长也可能被价格竞争吞噬。

Risk

融资成本

超大规模AI资本开支越来越依赖债券市场；当10年期在5%以上时，资本成本本身会变成估值变量。[R7][R18]

与此前“七姐妹撑指数”的观察相呼应： 本周S&P 500跌0.27%，Nasdaq却涨0.45%；同时周内多次出现“指数跌幅不大，但新低家数显著多于新高”的现象。比如10月1日，S&P仅小涨0.2%，但指数成分中只有4个52周新高、41个新低；Nasdaq则41个新高、287个新低。[R4] 这说明指数韧性并不等于市场内部健康度完全恢复。

黄金与原油：两个“避险资产”给出了完全不同的答案

图4｜跨资产周度表现。STOXX 600约−1.9%为公开报道所述“接近2%”；Brent按9/25与10/2收盘粗算约−2.0%，WTI采用Reuters周度口径约−1.6%。[R9][R10][R11][R20]

黄金：为什么有战争、有不确定性，黄金却跌？

因为这一周主导黄金的不是“避险”，而是机会成本。周一油价上涨强化通胀与加息预期，黄金单日一度下跌约4%；到周五，金价约4140美元/盎司，全周约跌3.4%。[R9]

当美元走强、10年期国债收益率在5%以上时，无息资产黄金的持有成本上升。这个组合足以压过地缘政治避险需求。

观察点： 如果未来黄金重新走强，而10年期收益率仍高，那将意味着“财政/信用避险”开始压过“高利率机会成本”；这会是非常重要的市场状态变化。

原油：问题已从“有没有原油”转向“有没有成品油”

Brent在9月累计上涨约14%，9月30日收于103.50美元；10月2日则回落至约102.25美元。WTI周五约91.11美元，周度跌约1.6%。[R10][R19]

最值得注意的是：市场压力正从原油本身转向柴油等成品油。中国暂停成品油出口一度刺激能源股，随后欧洲与IEA成员同意释放柴油与原油储备，才让价格在周五回落。[R4][R10]

能源 → 通胀 → 利率 → 股票估值

这是本周最清晰的宏观传导链：

中东冲突 / 成品油短缺
→ 原油与柴油价格上升
→ 通胀预期上升
→ 长端收益率上升
→ 高估值股票折现率上升
→ 指数尤其传统权重与长久期资产承压

这条链条在周一的市场表现最典型。[R1]

欧洲与中国：欧洲在交易“财政风险”，中国在交易“制造修复 vs 消费谨慎”

欧洲：真正的风险点在法国债券，而不是单纯股市跌2%

STOXX 600周内接近下跌2%，为4月以来最差一周附近；但更值得关注的是法国与德国10年期国债利差一度扩至150bp以上，接近欧债危机时代的水平。[R8][R11][R15]

这意味着欧洲市场正在重新给财政可信度定价。法国2027预算与政治不确定性让主权债风险溢价上升，银行股在10月1日单日下跌3.7%。[R11]

为什么重要： 如果欧洲财政风险继续扩散，美元会因此受益，欧洲融资条件会进一步收紧，也会反过来影响全球风险资产估值。

中国：工业端出现改善，但家庭端仍然谨慎

9月官方制造业PMI回到50.1，私人调查PMI升至52.1，显示制造业与AI相关需求改善。[R13]

政策层面，国务院强调逆周期支持，万科9月29日上涨10%，市场押注地产支持加码；但假期消费呈现“人很多、钱花得谨慎”的特征，长途出行增加而人均旅游支出偏低。[R12][R14]

结构判断： 中国目前更像是“供给与制造先修复、居民资产负债表与消费信心后修复”。因此工业、科技、出口链与消费链之间的估值逻辑可能继续分化。

中国市场的技术细节

9月29日CSI 300上涨0.1%，上证综指上涨0.2%，恒生指数下跌0.5%；A股从10月1日起进入国庆假期，并于10月8日复市。[R12] 因此本周后半段没有完整的A股价格发现，节日期间的海外资产、能源与美元波动将在复市时集中反映。

深度观察：这周市场真正告诉我们的六件事

01｜“Fed暂停”不等于“金融条件宽松”

10月加息概率大跌，但10年期收益率仍在5.3%左右。市场的约束已经从政策利率转向长期资本成本。[R5][R8]

02｜AI正在进入资本效率阶段

AI行情仍强，但市场开始惩罚供给扩张、奖励订单兑现与现金回报。WDC/STX与Micron/Nvidia的反差尤其典型。[R4][R5][R17]

03｜就业不是崩塌，而是“低招低裁”

非农弱、工资降温，但初请仍低、没有广泛裁员。对Fed来说，这给了暂停空间，却还不足以支持快速降息。[R4][R6]

04｜黄金告诉你：高利率目前仍压过避险

战争和财政不确定性都在，但黄金全周仍跌3.4%。这是“真实收益率与美元仍占上风”的信号。[R9][R15]

05｜欧洲的“弱”是财政问题，不只是增长问题

法国-德国利差扩大、银行股承压，比单看STOXX 600更重要。欧洲风险正在从盈利端扩散到主权融资端。[R8][R11]

06｜指数接近高位，但“便宜钱时代”已经不在

S&P 500年内仍涨约13%，距离8月纪录高点约1%；与此同时10年期收益率处于24年高位附近。[R7] 这是一种很少见的组合：高估值资产需要靠盈利而不是单纯靠估值扩张继续前进。

本周最大的“照妖镜”： 过去几年投资者习惯问“Fed什么时候降息”；而现在更应该问：“谁能在5%以上的长期资金成本下继续创造高回报？” 这会把资本从纯叙事公司推向现金流强、负债可控、资本回报率高、拥有真实定价权的公司。

我会重点盯的三个“红灯”

Red flag 110年期收益率突破5.34%并站稳。

Red flag 2油价重新加速上行，同时黄金仍不涨——说明市场交易的是“滞胀+高利率”，而不是单纯避险。

Red flag 3Nasdaq还能创新高，但新低家数继续显著多于新高——说明指数越来越依赖少数巨头。

三个“绿灯”

Green 110年期回落且小盘/地产同步走强。

Green 2AI订单继续增长，同时企业债利差不再扩大。

Green 3就业放缓但消费与盈利保持稳定。

结论

9月28日—10月4日这一周，看起来只是S&P −0.27%、Nasdaq +0.45%的小波动；但它其实完成了一个重要的叙事切换：

从“Fed还要不要加息” → “长期资本成本为什么这么高”；
从“AI一起涨” → “谁真的有现金流与定价权”；
从“地缘冲突=黄金涨” → “高收益率可以压过避险”；
从“欧洲增长弱” → “欧洲财政风险开始被重新定价”。

这比单看指数涨跌重要得多。
