01 / THESIS

先把 Tesla 看对：它从来不只是一家“卖电动车”的公司

理解 Tesla 最困难的地方，是它同时处于汽车、能源、软件、AI、机器人、基础设施六个产业交界处。不同阶段，决定公司价值的“主引擎”也发生过改变。
① 汽车公司

今天现金流与营收的主体仍来自汽车。Model 3 / Y 是规模核心，S/X/Cybertruck 等承担品牌、技术或细分市场角色。

② 制造公司

Gigafactory、压铸、车身结构、电池包、供应链本地化与“设计即制造”思维，是 Tesla 早期最被低估的真正能力之一。

③ 能源公司

Powerwall、Megapack 与储能系统正在从“附属故事”变成利润率更高、增长更快的第二业务支柱。

④ 软件公司

OTA、车机、App、FSD 订阅、联网服务，让汽车变成持续更新的软件终端；这改变了汽车行业的产品生命周期。

⑤ AI 公司

2025 年 10-K 对公司的描述已明显转向“把 AI 带进现实世界”：FSD、Robotaxi、AI 训练与推理硬件成为战略核心。

⑥ 机器人公司

Optimus 是最远期、也最不确定的增长选项。若成功，它把 Tesla 从交通与能源扩展到“劳动供给”这个更大的经济变量。

核心判断：Tesla 的历史不是一条直线，而是连续完成了三次身份跃迁：“证明电动车可行” → “证明电动车可规模制造” → “尝试证明现实世界 AI 可以规模商业化”。前两次已经发生，第三次仍在进行中。
Tesla 的战略重心迁移
这是战略解释图，不是财务占比图。汽车在 2026 年仍然是公司收入主体。
02 / 2003—2006

创立：Tesla 不是“马斯克一个人创办的公司”

Tesla 的起源比公众印象复杂。创立、早期融资、技术方向与后来对“创始人”身份的争议，是理解公司治理文化的第一章。

特斯拉汽车公司（Tesla Motors）于 2003 年 7 月 1 日在美国特拉华州注册成立。最初发起公司的是工程师 Martin Eberhard 与 Marc Tarpenning。2004 年，Elon Musk 领投公司 A 轮融资并成为董事长；J.B. Straubel 与 Ian Wright 等关键早期成员随后加入。2009 年围绕“谁可以被称为创始人”的法律争议最终和解，此后 Eberhard、Tarpenning、Musk、Straubel 与 Wright 五人都可被称为共同创始人。

这段历史值得保留精度：Musk 并不是在公司法律注册时的两名最初创办者之一，但他很早就以主要资本提供者、董事长和产品推动者的身份进入，而且后来接管公司并塑造了绝大部分外界熟悉的 Tesla。如果把任何一端说成“完全是他创办”或“他只是后来买来的”，都过于简单。

为什么 2003 年会有人认真做电动车？

当时美国汽车产业对纯电动车普遍悲观。铅酸或早期电池能量密度不足、续航短、充电基础设施几乎不存在。Tesla 的反直觉判断是：消费电子行业已经大规模使用 18650 圆柱锂离子电芯，单体虽为消费级，但如果通过电池管理系统、安全设计和热管理，把数千个电芯组成一个可靠电池包，汽车性能可能发生质变。

早期技术假设

  • 不用等待“完美汽车电池”出现，先利用已经大规模商业化的锂电芯。
  • 先从昂贵高性能跑车切入，而不是一开始挑战廉价大众车。
  • 电动车不应该靠“环保牺牲感”销售，而应该在加速、响应、驾驶体验上更好。
  • 把电池、功率电子、电机、软件作为一个系统优化，而不是简单把发动机换成电机。

商业逻辑

  • 高端跑车允许较高售价，能吸收极高的早期单位成本。
  • 跑车市场对加速性能敏感，而电机的瞬时扭矩天然具有优势。
  • 小规模产品可以先验证技术，不必立即承担百万辆级制造复杂度。
  • 成功后再向更低价、更大规模车型下沉——这就是后来著名的 Master Plan。
Tesla 最初真正卖的不是“省油”，而是一种新命题：电动车可以比燃油车更令人向往。

2006 年的“秘密宏图”

2006 年 Musk 发表第一版 Master Plan：先造昂贵跑车，用所得资金发展更便宜的车，再继续向大众市场下沉，同时提供零排放能源方案。后来 Tesla 的车型路径——Roadster → Model S/X → Model 3/Y——在大方向上确实遵循了这一逻辑。

Master Plan 的“资金与规模阶梯”
03 / ROADSTER

Roadster：技术验证成功，但几乎把公司拖死

Roadster 是 Tesla 的“阿波罗计划”：它证明了电动车性能，却也暴露了创业公司做汽车最可怕的问题——成本、供应链、认证、质量与量产。

第一代 Roadster 使用 Lotus Elise 相关底盘基础，但 Tesla 必须自行解决电池包、热管理、控制系统、动力电子、电机、软件、碰撞安全、供应链和大量重新工程。对媒体而言，这是一辆“电动 Lotus”；对工程和财务而言，它远不是简单换动力总成。

Roadster 的历史意义有三层：

  1. 性能层：电机瞬时扭矩让电动车第一次以“快”而不是“省”进入高端消费语境。
  2. 续航层：200 英里以上级别续航打破当时大众对 EV 只能短途通勤的刻板印象。
  3. 资本层：一辆能让富裕早期用户愿意排队购买的产品，为后续融资提供了故事与实物证明。

但 Roadster 也暴露了 Tesla 的第一性问题：汽车不是软件

汽车产品的复杂性来自上万个零件、供应商、认证、良率、返修、物流、工装、售后和质量责任。创业公司可以在实验室里做出一辆很快的原型车，但从原型到可重复制造，是完全不同的能力。Roadster 项目出现严重成本超支与进度延迟，也加剧了公司内部管理冲突。

重要规律：Tesla 后来几乎所有重大危机都不是“产品有没有需求”，而是能不能以目标成本、目标节拍、目标良率把产品大量制造出来。Roadster 是第一次，Model 3 是第二次，4680/Cybertruck/Optimus 则在不同程度上重复了同一类挑战。
04 / 2007—2011

第一次生死关：管理层更替、金融危机、Musk 接任 CEO

Tesla 并不是一路高歌猛进。2008 年前后，它接近资金断裂；如果这一阶段没有挺过去，后来的 Model S、Model 3、上海工厂都不会存在。

2007 年起，公司管理层发生剧烈变化。Martin Eberhard 离开 CEO 职位，随后公司经历过多次临时领导安排。2008 年，Elon Musk 正式出任 CEO。与此同时，全球金融危机使资本市场冻结，Roadster 成本问题仍未彻底解决。

这一阶段 Tesla 的生存依赖多种资本来源：私人融资、战略投资、政府贷款以及后来公开市场融资。美国能源部先进技术车辆制造贷款计划在 2010 年向 Tesla 发放约 4.65 亿美元贷款，用于 Model S 和 Fremont 相关制造能力；Tesla 于 2013 年提前约九年偿还完毕。

2010 年 IPO：从“私人实验”进入公开市场

Tesla 于 2010 年 6 月在 NASDAQ 上市，IPO 价格为每股 17 美元（未按后续拆股调整），发行规模约 2.261 亿美元。这使 Tesla 成为极少数能够在美国公开市场融资的年轻汽车公司，也为后续 Fremont 工厂改造和 Model S 量产提供了资本通道。

05 / 2012—2015

Model S：Tesla 第一次证明“电动车本身可以是更好的汽车”

如果 Roadster 证明“电动车能很快”，Model S 则证明电动车可以在空间、交互、性能、软件与整车体验上建立自己的产品范式。

2012 年 Model S 交付，是 Tesla 公司史最关键的产品节点之一。它采用“滑板式”电池包布局，把重电池放在车底，形成低重心与平坦底盘；没有传统发动机与变速箱占据前舱；大型中央触摸屏、OTA 更新、联网能力让汽车开始具备消费电子产品的使用逻辑。

2013 年，Model S 获得 MotorTrend 年度车型等行业认可。其意义不仅是奖项，而是传统汽车媒体开始把 Tesla 当成汽车工程竞争者，而不是环保小众品牌。

Supercharger：Tesla 很早就知道“车只是系统的一部分”

电动车早期的核心障碍之一是补能焦虑。Tesla 从 2012 年开始建设 Supercharger 网络，实际上是在自己承担公共基础设施的一部分。传统车企习惯把加油站视为外部系统，而 Tesla 把充电体验纳入产品设计：导航、路线规划、电池预热、支付与车辆软件协同。

Model S 带来的行业改变

  • 大电池 + 长续航成为高端 EV 标准答案。
  • 中央大屏和软件驱动 UI 逐步成为行业模仿对象。
  • OTA 更新让“交付后仍升级”成为汽车能力。
  • 性能版电动车把 0–100 km/h 加速竞争推到新高度。
  • 直接销售模式削弱传统经销商在客户关系中的中介角色。

Tesla 开始形成的系统闭环

  • 车：Model S / X
  • 补能：Supercharger
  • 软件：OTA、导航、App
  • 能源：Powerwall / Powerpack
  • 数据：联网车队
  • 销售：直营与在线配置

2015：Model X 与能源产品

Model X 把 Tesla 拓展到 SUV，但鹰翼门、复杂座椅与结构设计也带来明显制造难度。更重要的是，同年 Tesla 发布 Powerwall 与 Powerpack，正式把电池能力从汽车延展到住宅和电网储能。这为十年后的 Megapack 高增长埋下了伏笔。

06 / 2016

2016：Model 3、SolarCity 与“大一统能源公司”

2016 年是 Tesla 叙事扩张最快的一年：一边准备进入大众汽车市场，一边吞并 SolarCity，把汽车、电池与太阳能合并成“可持续能源系统”。

Model 3 预订潮：需求不是问题，制造才是

Model 3 以更低价位进入主流市场，发布后获得巨量预订。市场第一次清晰看到：消费者对纯电动车的需求可能远大于行业原先估计。但 Tesla 随之面对一个远比 Roadster/Model S 更难的问题——几十万辆级别生产。

收购 SolarCity：战略上合理，治理上争议巨大

2016 年 11 月，Tesla 完成对 SolarCity 的收购，交易对价公允价值约 21 亿美元。公司给出的产业逻辑是：太阳能发电 + 电池储能 + 电动车消费可以形成一体化清洁能源产品。

争议则来自关联关系与财务状况：Elon Musk 当时既是 Tesla CEO，又担任 SolarCity 董事长；SolarCity 与 Musk 家族关系密切。此交易后来长期成为公司治理争论的一部分。

事后看：SolarCity 的“住宅太阳能整合”并未成为 Tesla 最大成功，但收购强化了 Tesla 的能源公司身份。真正跑出来的并非 Solar Roof，而是储能——尤其是后来面向电网的 Megapack。

Autopilot：软件叙事开始进入估值核心

Tesla 在 2010 年代中期逐步推出 Autopilot 驾驶辅助功能，并持续升级硬件与软件。其真正重要之处不是某一版功能，而是建立了一个模式：车辆拥有统一传感器与计算平台，软件可以通过 OTA 迭代；车队运行数据又可以反过来训练系统。

07 / 2017—2018

“Production Hell”：Model 3 把 Tesla 推到第二次生死关

Tesla 最重要的工业能力不是在 Model S 时代形成，而是在 Model 3 量产危机中被逼出来的。

Model 3 于 2017 年开始交付。Musk 曾对自动化程度抱有极高预期，但实际量产初期出现瓶颈：电池模组、总装节拍、机器人流程、供应商与质量等多环节都可能限制产量。

后来 Musk 自己承认过度自动化是错误之一。Tesla 不得不快速修改产线、增加人工、建立临时总装线，甚至使用大型帐篷式结构扩产。这种在传统汽车工业看来极不“优雅”的做法，却体现出 Tesla 的一种独特组织特征：宁愿边生产边重构系统，也不等待所有流程在纸面上完美。

为什么 Model 3 是公司史最关键车型？

因为它不只是销量更大。它迫使 Tesla 学会四件事：成本工程、制造节拍、供应链规模化、现金流纪律。没有这次“地狱式训练”，后来上海工厂快速爬坡和 Model Y 的成功几乎不可能发生。

从“产品工程”到“制造系统工程”
08 / 2019—2020

上海工厂与 Model Y：Tesla 从“会造车”进入“会复制工厂”

Tesla 的全球规模化真正开始于上海。这里不仅是产能问题，更是成本、供应链、本地市场与工厂复制速度的突破。

Gigafactory Shanghai

上海工厂是 Tesla 第一座海外整车超级工厂，生产 Model 3 与 Model Y。它的战略意义非常大：第一，贴近全球最大电动车市场之一；第二，大规模使用本地供应链降低成本；第三，成为出口基地；第四，证明 Tesla 可以比传统汽车工业更快建设并爬坡新工厂。

Model Y：从“成功车型”变成“公司主力平台”

Model Y 与 Model 3 共享大量架构和零部件，降低研发与制造复杂度。SUV/跨界车市场空间又显著大于轿车，因此 Model Y 很快成为 Tesla 最重要的销量支柱。到 2023 年，公司在官方材料中称 Model Y 成为全球最畅销车型。

2020：第一次全年盈利 + 加入 S&P 500

2020 年 Tesla 生产约 509,737 辆、交付 499,647 辆；全年营收约 315.4 亿美元，归属于普通股股东的 GAAP 净利润约 7.21 亿美元。这是公司首次实现全年 GAAP 盈利。2020 年 12 月，Tesla 被纳入 S&P 500，意味着它从“高风险成长股”正式成为美国大型指数核心成分之一。

Battery Day：4680 与“车身就是电池结构”

2020 年 Battery Day 提出 4680 大圆柱电芯、无极耳设计、干电极方向、结构化电池包等路线。它们背后的目标不是简单提高续航，而是降低每 kWh 成本、减少零部件与制造步骤、提高结构效率。但后续也证明：电池制造创新从实验室到大规模高良率生产非常困难，4680 的工业化速度远慢于最初最乐观预期。

09 / 2021—2023

扩张期：Berlin、Texas、Plaid、Semi、Cybertruck、NACS

这三年 Tesla 同时扩大工厂、产品线、充电标准和 AI 研发。公司从“电动车先锋”进一步变成行业标准制定者。
2021
Model S Plaid / AI Day / 总部迁往 Texas

Plaid 强化高性能电动车品牌；AI Day 让“自动驾驶 + 人形机器人”成为新的长期叙事。公司总部迁至奥斯汀，Texas 工厂成为新核心。

2022
Berlin 与 Texas 开始 Model Y 交付

全球制造从 Fremont + Shanghai 扩展为美国、欧洲、中国多极结构。Tesla Semi 开始向 PepsiCo 等客户交付。

2023
Model Y、NACS、Cybertruck、Optimus Gen 2

Model Y 成为公司规模核心；Ford、GM 等车企推动北美充电接口向 Tesla NACS 靠拢；年底 Cybertruck 开始交付。

NACS：Tesla 最成功的“平台外溢”之一

Tesla 原本是为自家车设计充电接口和 Supercharger 网络。2023 年后，越来越多北美车企宣布采用 Tesla 的 North American Charging Standard（NACS）接口并接入 Supercharger。到 2026 年 Tesla 官方 NACS 页面列出的支持品牌已覆盖 Ford、GM、Rivian、Mercedes-Benz、Hyundai/Kia、Honda、Toyota、Volkswagen、BMW、Stellantis 等众多厂商。

为什么重要：当竞争对手也采用你的接口、依赖你的充电基础设施时，Tesla 的角色从“卖车公司”向基础设施平台移动。这种平台价值通常比单纯汽车销量更难复制。

Cybertruck：工程激进主义的优点与代价

Cybertruck 的不锈钢外壳、独特几何造型、48V 低压架构、线控转向等体现 Tesla 的工程冒险精神。但它也再次展示“复杂新工艺 = 制造风险”：不锈钢外板公差、供应链、结构和产线爬坡都增加难度。它更像品牌与技术旗舰，而不是像 Model Y 那样承担公司大多数销量。

10 / 2024—2026

公司叙事发生根本变化：从“EV 增长股”转向“AI + 能源 + 自动驾驶”

2024 之后，Tesla 的汽车增长不再像 2020–2023 那样顺畅，但能源储存与 AI 业务的重要性快速上升。

2024：汽车交付首次出现年度回落

Tesla 2024 年共生产约 177.34 万辆、交付约 178.92 万辆。相比 2023 年约 180.86 万辆交付，出现小幅下滑。这是一个象征性变化：市场不能再简单用“每年 40%–50% 交付增长”解释 Tesla。

“We, Robot” 与 Cybercab

2024 年 Tesla 在 “We, Robot” 活动中展示 Cybercab、Robovan 与 Optimus，明确把未来价值中心放在“自主运输 + 通用机器人”。Cybercab 是无方向盘与踏板的专用自动驾驶车辆，商业逻辑并非卖给普通消费者，而是降低每英里出行成本、提升车辆利用率。

2025：Robotaxi 开始从演示变成商业服务

2025 年 6 月 Tesla 在 Austin 启动 Robotaxi 服务。公司 2025 年年报称，到年底已扩大服务并开始在 Austin 测试/移除安全监控员；Robotaxi 业务目前以 Model Y 为主，未来将加入 Cybercab。到 2026 年 10 月，Tesla 官方 Robotaxi 页面称其自动驾驶叫车服务已在美国多个城市提供。

2025：汽车承压，储能变强

2025 年 Tesla 生产约 165.47 万辆消费车辆，交付约 163.61 万辆，较 2024 年继续下降。与此同时，全年储能部署达到 46.7 GWh，显著高于 2024 年的 31.4 GWh。财务上，2025 年总营收约 948.27 亿美元，低于 2024 年的 976.90 亿美元；能源业务收入则从 2024 年的 100.86 亿美元增至 127.71 亿美元。

Model 3/Y 为什么是“真正的 Tesla”？

在投资叙事中大家容易被 Roadster、Plaid、Cybertruck、Cybercab 吸引，但公司财务史真正由 Model 3/Y 重写。它们共享架构、零部件和供应链，制造规模巨大，构成 Tesla 车队数据的主要来源，并为服务、充电、FSD 订阅创造安装基础。

12 / ENGINEERING

电池与制造：Tesla 最深的“硬科技护城河”其实是系统工程

Tesla 的优势从来不是拥有一种别人完全不会的电池化学，而是把电芯、结构、热管理、功率电子、软件与工厂同时优化。

电芯路线：18650 → 2170 → 4680，多化学体系并存

Tesla 早期通过大量消费级 18650 电芯建立 Roadster/Model S 能力；Model 3/Y 大规模使用 2170 等规格；后来开发 4680。与此同时，为控制成本与供应链风险，公司并不坚持单一化学路线——不同车型、地区和产品会使用不同供应商及化学体系，包括 LFP 等。

真正决定整车竞争力的是“每辆车的系统成本”

电池

电芯价格、成组效率、热管理、结构、电池管理软件决定续航和成本。

电驱

电机设计、逆变器、碳化硅功率器件、控制算法影响效率与性能。

车身

大型压铸、零件集成、结构电池包尝试减少焊点、零件和工位。

热系统

热泵、Octovalve 等集成方案将座舱、电池与电驱热管理协同。

软件

能耗预测、导航、充电预热、车辆控制共同决定用户实际续航体验。

工厂

产品设计若不能减少工位、缩短节拍、提高良率，就难形成成本优势。

Gigacasting：把几十个零件变成一个大件

Tesla 使用大型压铸设备制造大型前/后车体结构，思路是减少冲压件、焊点、夹具与装配步骤。好处是节拍和成本潜力，代价是模具、材料、维修、尺寸控制和工艺风险更集中。

“机器制造机器”

Musk 多年来反复强调工厂本身也是产品。这句话在 Tesla 历史中并非口号：Model 3 的失败经验让公司逐步理解，产品工程与制造工程必须在设计阶段同时发生。传统汽车也极重视制造，但 Tesla 更倾向于大幅重构零件数量和工艺，而不是仅优化既有生产线。

13 / SOFTWARE & AI

软件与自动驾驶：Tesla 最有想象力、也最容易被误判的部分

要同时避免两个极端：把 FSD 当成“已经完成的无人驾驶”，以及把它当成“永远不可能实现的营销”。正确方法是分层看能力、监管和商业化。

第一层：软件定义汽车——已经兑现

OTA、手机钥匙、车机生态、远程诊断、车辆设置云同步、充电规划等已经成为 Tesla 的日常产品能力。传统车企也快速跟进，但 Tesla 很早就通过集中式软件团队和统一车端架构形成领先体验。

第二层：FSD (Supervised)——正在快速迭代，但驾驶责任仍在人

Tesla 官方资料明确把当前消费者车辆中的 FSD 定义为 FSD (Supervised)。驾驶员仍需对驾驶负责。技术路线越来越依赖端到端神经网络、视觉感知、海量车队数据与持续训练。

第三层：无人监督 Robotaxi——已经在限定区域商业化，但规模与泛化仍需验证

2025–2026 年 Robotaxi 从 Austin 起步并向多个美国城市扩张，这是历史性变化：Tesla 不再只要求投资者相信未来视频演示，而开始产生真实乘客服务。真正决定经济价值的将是：无人监督比例、事故率/安全表现、运营边界、监管许可、每车每天利用率、清洁维护成本、保险成本与车队折旧。

第四层：Optimus——把自动驾驶的“现实世界 AI”迁移到人形机器人

Optimus 与汽车共享的不是车身，而是很多底层能力：视觉感知、运动控制、低功耗计算、电机、电池、制造、数据与神经网络训练。如果机器人能在工厂完成高重复劳动，Tesla 可以先作为自己的第一客户，再向外部销售。但人形机器人对手部灵巧性、可靠性、实时控制、安全和成本的要求远高于演示。

数据

联网车队产生真实世界驾驶长尾场景。

算力

GPU/Cortex/自研推理硬件支撑训练与部署。

模型

视觉、规划、端到端网络持续迭代。

实体

车辆与机器人把模型输出转成现实世界动作。

最关键的估值分界线：“FSD 功能越来越好”与“FSD 可以无人监督地、低成本地、跨城市大规模运营”不是同一件事。后者一旦成立，商业模式会发生跃迁；若长期不能成立，Tesla 的 AI 溢价就会承压。
14 / ROBOTAXI

Robotaxi：为什么它可能重写汽车经济学

传统私家车的经济模型是“一次性卖车 + 后续服务”。汽车绝大多数时间停在停车场，资产利用率低。Robotaxi 的理想模型则是：同一辆车每天服务更多小时，以里程或乘车次数持续产生收入。

从卖车到运营资产：收入模型变化

但 Robotaxi 不是“毛利率自动变高”

其成本会从零售汽车的制造成本，变成车队运营成本：清洁、轮胎、事故、维修、保险、空驶、充电、远程支持、监管、人力、折旧。真正的经济学只能在大规模真实运营后验证。

牛市情形

无人监督广泛获批，安全显著优于人类，Cybercab 成本极低，车队快速扩张；Tesla 变成全球移动网络。

中性情形

在部分城市、部分道路、部分时段运行，形成有价值但受地理边界限制的服务。

熊市情形

监管、长尾场景、安全或成本长期限制规模，Robotaxi 只能作为辅助业务，无法支撑平台估值。

被低估的第二曲线：储能正在变成真正的利润引擎

与汽车相比，能源业务过去存在感低，但 2023–2026 的增长速度和毛利率变化使它越来越难被忽略。

Tesla 能源业务分为住宅储能 Powerwall、公共事业/商业大储 Megapack，以及太阳能发电相关业务。真正爆发的是储能，尤其是 Megapack。

为什么大储需求会增长？

  • 风电、光伏输出波动，需要储能平滑电网。
  • 数据中心和 AI 负载推高电力需求与电网建设压力。

16 / CHARGING

Supercharger：Tesla 最早建立、最难复制的线下网络资产之一

充电网络具有典型的双边网络特征：站点越多，车主越放心；车辆越多，站点利用率越高，经济性越好。Tesla 在早期销量不高时就承担重资产投入，因此形成先发优势。

NACS 的标准化价值

当其他车企采用 Tesla 接口并逐步接入 Supercharger，网络的潜在利用率与战略价值进一步提高。Tesla 官方称其北美 Supercharger 网络持续向其他品牌开放，并列出大量已支持或正在过渡到 NACS 的品牌。

护城河不是“一个插头”。真正的护城河是：站点选址、并网、设备制造、可靠性、支付、导航、车机联动、实时占用数据与多年运维经验的组合。

19 / CAPITAL MARKETS

资本市场史：Tesla 的股价从来不是普通汽车股逻辑

Tesla 2010 年 IPO 后，资本市场长期围绕一个问题争论：它应该按汽车制造商估值，还是按科技平台估值？这个问题到 2026 年仍未解决，只是估值支点从“电动车高速增长”转移到“FSD / Robotaxi / Optimus / Energy”。

几个结构性节点

  • 2010 IPO：打开公开市场融资渠道。
  • 2013：Model S 成功、DOE 贷款提前偿还，破产风险明显下降。
  • 2018：Model 3 量产危机后产能突破，市场开始相信大规模制造。
  • 2020：连续盈利、S&P 500 纳入、五拆一，机构被动资金大规模进入。
  • 2022：三拆一，全球产能继续扩张。
  • 2024–2026：汽车增长放缓，但 AI 与自动驾驶预期成为估值中心。
估值悖论：如果只看当前汽车利润，Tesla 往往显得昂贵；如果把 Robotaxi 和 Optimus 假设为未来大规模平台业务，它又可能显得“仍在早期”。所以投资 Tesla 的本质不是预测明年卖多少辆车，而是判断未来利润结构是否真的会从汽车制造转向高利用率的 AI 服务和机器人。
20 / GOVERNANCE

管理与治理：Elon Musk 是最大资产之一，也是最大单点风险之一

为什么 Musk 对 Tesla 不可替代

  • 极端清晰的产品目标与技术叙事，能吸引工程人才、资本和用户。
  • 愿意做传统车企难以批准的高风险架构变更。
  • 把品牌传播与产品发布结合，显著降低传统广告依赖。
  • 能在危机中直接介入工程和制造细节，组织执行速度快。

为什么同一特征也会制造风险

  • 关键人依赖极高，CEO 同时参与多家公司和公共事务。
  • 时间承诺、社交媒体言论与政治参与可能影响品牌与治理。
  • 激进目标容易造成时间表反复延后，投资者需要区分愿景与可交付承诺。
  • 关联交易、薪酬、董事会独立性等长期引发争议。

2024 年 Tesla 从特拉华州公司转换为 Texas corporation，这本身也反映了公司治理与法律环境变化。对长期投资者而言，治理风险不能因“创始人天才”而被忽略，也不能因争议而否定其组织能力。

创始人型 CEO 的优势

需要特别警惕的认知错误

  1. 把技术领先等同于商业成功。优秀技术也可能因成本、监管和服务网络无法赚钱。
  2. 把演示等同于量产。Tesla 历史反复证明，量产是独立难题。
  3. 把车队数据等同于自动驾驶必胜。数据很重要，但算法、安全验证、仿真、监管同样重要。
  4. 把高估值等同于泡沫。高估值可能有未来期权价值；关键是未来利润是否兑现。
  5. 把愿景时间表当承诺。Musk 的时间预测历史上经常偏乐观，应关注实际发布与监管状态。

CONCLUSION

最后怎样理解 Tesla？

Tesla 的真正历史价值，并不只是“造出了一家值很多钱的电动车公司”。它至少永久改变了汽车工业的五件事：

  1. 证明消费者愿意因为性能和体验而买电动车，而不仅因为环保。
  2. 迫使全球车企把电动化从边缘项目提升为核心战略。
  3. 把 OTA、软件、App 和持续迭代引入汽车主流体验。
  4. 证明充电网络可以由车企深度垂直整合，并进一步成为行业标准。
  5. 把汽车制造重新拉回科技投资者视野：工厂、材料、供应链和大规模制造本身就是技术。

但从 2026 年继续往前看，历史已经进入另一个阶段。Tesla 不再只需要证明电动车优于燃油车——这个命题基本已被整个产业接受。它现在要证明的是更难的命题：现实世界 AI 是否能可靠驾驶、可靠劳动，并且以可规模复制的成本持续赚钱。

如果答案是“能”，Tesla 的最终形态可能远远超出汽车公司；如果答案只是“部分能”，它仍然可能是一家优秀的汽车 + 能源企业；如果 AI 兑现明显低于市场预期，那么过去十余年最成功的工业故事之一，也将重新接受传统制造业回报率和估值框架的约束。

Tesla 前二十年最重要的能力，是把“不可能”变成可以量产的产品。
下一个二十年的问题，是它还能不能再做一次。
