由此想到的投资之道

这不是“高点没关系”的结论

  1. 时间比择时更重要，但非无条件。本报告假设一直持有；若在回撤期卖出，结论会完全不同。
  2. 年度最高点是事后信息。真实世界无法识别；它恰好说明把买入纪律外包给日历，比预测更可执行。
  3. VTI 已高度分散，但仍是股票。历史上的深回撤并不保证未来不会更深、更久。
  4. 分红和成本很重要。上方两种账户价值的差额，提醒长期回报不只是价格曲线。
风险规则

先写下，再遇到下跌

  • 投资账户与 6–12 个月应急金分开；短期用钱不进股票。
  • 每年再平衡一次，或任一资产类别偏离目标 5 个百分点才处理。
  • 股票从峰值下跌 25% 时：不查看新闻做决策，只按既定自动买入继续。
  • 下跌 40% 时：暂停新增风险资产以外的消费/杠杆决定，绝不为“回本”加杠杆。

数据口径、限制与可复算性

行情来自 Yahoo Finance chart API 的 VTI 日线，下载于本报告生成时；价格为美元。年度“最高点”为日线 High 的最大值，实际成交可能因盘中时点、价差和佣金略有不同。账户在“价格回报”列按 $10,000/年度最高价得到份额并按截至日收盘价估值，不含税费、交易费、外汇和分红；“含分红再投资”用 Yahoo 的 adjusted close 近似处理现金分配再投资，仍是估算。2026-08-13 为新西兰日期，而美国市场最近已完成的日线为 2026-08-12；故 2026 仅为年内截至该日。回溯地选择每年的最终高点带有完整的后见之明，不可实盘执行。报告附带逐笔 CSV，可独立审计。
