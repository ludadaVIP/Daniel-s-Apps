中性情景

极乐观情景

07 / RESEARCH SUMMARY

最终观察优先级与研究纪律

FIRST PASS

INOD · AMPX

观察理由：一个有数据服务利润与经营杠杆，一个正在把先进电池产品转为真实销售。小市值使3倍市值扩张的绝对规模较小；两者的失败方式却完全不同。

SECOND PASS

OUST · TEM

观察理由：物理AI感知与医疗数据壁垒。看得到商业场景，但需要更高的收入、现金流与估值支撑未来3倍。

HIGH BETA

APLD · IREN

观察理由：AI算力基础设施需求真实，但项目融资、债务、折旧和股份稀释能完全改变股东回报。永远先核对资金表。

OPTIONAL / WATCH

SOUN · AEHR · PL · RKLB

观察理由：有明确事件驱动，但需分别核验有机增长、半导体订单兑现、卫星收入质量及Neutron延迟；不将它们全部视为同等强度机会。

重要界限：这不是对任何人“应该买入”或“应该投入某个仓位”的指令。所有公司均可能出现50%乃至更大回撤；也可能即使收入高增长仍无法取得3倍股价回报。这里提供的是一组可被财报证实或推翻的公开市场研究假说。
