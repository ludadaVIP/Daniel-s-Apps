02
SEVEN INVESTOR LENSES / 七位大师的审查框架

不是引用七位大师对这三只股票的实际看法，而是应用他们的投资哲学。

Benjamin Graham / 格雷厄姆

安全边际。今天的价格相对于保守、可核实的盈利究竟打了多少折？AMD 的高倍数要求格外严苛；UNH 和 HD 也必须考虑盈利短暂性。

Warren Buffett / 巴菲特

经济护城河 + 可预测现金。HD 规模和物流、UNH 保险与服务网络有优势；AMD 需证明其软件和平台粘性不仅来自周期性 GPU 供不应求。

Charlie Munger / 查理·芒格

逆向思考 + 排除致命错误。分别问：GPU 客户资金和供货关系是否可持续？UNH 是否因监管永久损坏利润结构？HD 是否被住房周期拖累更久？

Peter Lynch / 彼得·林奇

增速必须配得上估值。AMD 不是因为“AI”就自动值得任意 PE；HD 稳定但较慢的 EPS 增长，必须用更低的买入倍数换取合格收益。

Ray Dalio / 瑞·达利欧

经济周期与跨资产相关性。AMD 更依赖科技资本开支和流动性；HD 对利率和住房敏感；UNH 受医疗通胀和政策影响。三者并非完全独立。

George Soros / 乔治·索罗斯

反身性。AI 热潮高估值可支持资本融资与投入，但估值逆转也会冲击投资预期；需要跟踪资金链，而非盲目接受产业叙事。

Howard Marks / 霍华德·马克斯

第二层思维 + 风险控制。对企业好转的认知如果已经成为市场共识，投资回报未必好；必须在不乐观甚至被动情景下估算本金风险。

综合审查的实际操作

经营事实 → 现金流质量 → 增长兑现 → 利率/政策/竞争 → 终局 PE → 安全买入价 → 仓位上限。每一步都允许拒绝投资。

为何我对高价保持克制

  • 真实需求：EPYC CPU 与 Instinct GPU 同时推动数据中心增长，AI 整机方案能扩大客户服务范围；AMD 不仅靠单一消费电子周期。
  • 竞争改善：大型云厂商乐于拥有第二供应商，降低对某一 GPU 供应体系的依赖。成本/推理性能若持续优化，份额仍有增长机会。
  • 财务弹性：上半年经营现金流约 $5.321B、自由现金流约 $4.124B，流动性相对充足。
  • 估值：以 Q2 基本股数约 16.32 亿粗算，$507.93 对应市值约 $829B；这是量级估算，不是交易所实时市值。
  • 权证：OpenAI 和 Meta 各有最多 1.6 亿股、$0.01 行权价的附条件认股权证；合计上限 3.2 亿股，相当于 Q2 基本股数约 19.6%。并不代表全部一定兑现，且截至 Q2 尚未归属，但模型不可忽视摊薄。
  • AI 系统风险：NVIDIA 软件/网络优势、HBM 和封装供给、客户 AI 资本开支、出口控制以及客户融资路径，均可能压低未来净利润率或估值。
必须区分：与超大客户签下多吉瓦部署框架 ≠ 立即确认营收；营收增长 ≠ 归属普通股东的 EPS 同幅增长。情景中的 2029 EPS 应视为“包括未来潜在股数变化后的每股结果”，而不是未经调整的净利润增长。

  • 住房利率：Freddie Mac 2026-10-22 的 30 年固定抵押贷款平均利率为 7.32%，仍明显抑制换房和大项目装修需求。

METHOD & LIMITS / 假设、计算与不确定性

让“预测”具有可审计性。

价格模型

2029 年股票价格 = 2029 年普通股每股收益（EPS） × 终局市盈率（PE）。终局 2029 EPS 是研究者设定的未来近三年情景数，不应理解为管理层的官方 2029 指引。当前价格与目标股价的变化是简单价格回报，未考虑分红、交易成本、税费、汇率变动。

“3 倍”的定义是终点股价至少为当前价格的三倍，而不是公司总营收三倍、行业市场规模三倍、或从历史低点上涨三倍。

2026 经调整 EPS 与 2029 情景 EPS 用于经营趋势的简化比较；不同公司的 GAAP、非 GAAP 以及每股权证影响不完全同质，不能把各公司的 PE 一概横向等同。

估值不确定性

成熟企业和周期公司未来终局 PE 由利率、增长、风险溢价、资本结构与市场情绪决定。AMD 的 40–50× 退出估值并非“理所当然”，UNH 的医保政策前提不能忽略，HD 的 22–26× 退出估值取决于住房活动和资金成本。

本报告没有给出虚构的情景概率，因为缺少可验证的概率校准数据。情景为敏感性测试，不是统计意义上的置信区间，也不是确定性目标。

入场区间由长期 EPS×PE 与风险补偿逆推，再参考短期市场状态；不是“支撑位必然生效”的技术价格预测。
