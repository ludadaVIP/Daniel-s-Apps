03
Economic engines

三种“复利机器”的机制并不相同

GPCR · 技术期权

临床疗效 → 三期证实 → 审批 → 支付端覆盖 → 销售/合作收入。研发期销售额并不能代表资产潜力，但试验失败可以严重摧毁价值。

最关键的单位：成功概率、资金消耗、最终稀释后 ADS 数、可实现利润。

SE · 用户平台

交易额与广告 → 物流效率 → 商家变现 → 信贷交叉销售。依靠网络效应与运营效率滚动，但补贴竞争与信用损失会吞噬利润。

最关键的单位：每订单盈利、信贷损失、每股自由现金流、回购效率。

OKLO · 基建开发

技术与许可 → 燃料 → 建造 → 首次商用 → 电价与资本回报。巨大的合同容量是机会的上限，不是今天可兑现的现金。

最关键的单位：获批功率、建造成本/MW、融资结构、售电价与项目 IRR。
04 / NASDAQ: GPCR / CLINICAL-STAGE BIOTECH
GPCR｜现金很多，但“价值”仍取决于临床事件

Structure Therapeutics 以口服小分子为核心，主力资产 aleniglipron（GSBR-1290）针对 GLP-1 受体，另有 amylin/calcitonin 受体激动剂管线。真正的投资命题不是减重市场很大，而是产品是否能在真实竞争下获得可持续的差异化与支付。

核心观点：股价 $21.19、近似市值 $15.1 亿，对比 6/30 约 $13.43 亿现金及短期投资，形成看似便宜的资产负债表。但二季研发已花 $1.00 亿，公司持续烧钱，未来三期和上市准备可能吞噬大部分现有现金，因此并非接近现金就没有下跌空间。

价值创造路径

  1. 临床可重复：三期是否重现有效性，长期安全性和停药/依从性是否支持普及。
  2. 竞争地位：对口服小分子产品，关注耐受性、剂量、空腹限制、生产成本与保险支付。
  3. 平台价值：ACCG-2671 多剂量结果和 GLP-1 + amylin 组合可构成附加期权，但现阶段应低权重。
  4. 融资：2026 年已披露 ATM 融资安排；实际募集前不能把未发行股票算成现金。

必须接受的失败路径

  1. 三期未证实疗效或安全性事件，产品注册价值大幅损失。
  2. 减重赛道竞品迭代，使产品即便获批也缺乏经济护城河。
  3. 公司称现金可支持关键临床至 2028 年底，但不包括商业化生产等部分费用。
  4. 即使经营成功，后续融资和员工股权激励也会稀释每 ADS 对应价值。

看多所需的经营证据

  1. Shopee GMV 增长之外，核心 Marketplace 变现与订单单位利润改善；Q2 GMV $383 亿、Shopee EBITDA $2.55 亿。
  2. Monee 的损失率与融资成本可控；信用减值拨备增速下降，非 Shopee 场景放贷有净回报。
  3. Garena 稳定产生现金；Free Fire 贡献不应被当作永不衰退的永续年金。
  4. Sea Cloud / Monee IPO 有明确投入产出与股东权益安排。

空头需要被认真听取的理由

  1. 电商补贴、配送速度竞赛、跨境竞争让收入增速和 EBITDA 增速持续脱钩。
  2. 信贷坏账在经济疲弱或借贷快速扩张后往往滞后暴露。
  3. 金融业务现金、贷款和投资不等于可以任意分给母公司股东的净现金。
  4. 新的 AI Cloud 可能扩大资本支出，而且未必拥有可复制的外部竞争壁垒。

06 / NYSE: OKLO / FIRST-OF-A-KIND NUCLEAR ENGINEERING
OKLO｜潜在市场巨大，但资本和时间是最大的竞争对手

Oklo 正布局 Aurora 快堆发电、核燃料与同位素业务。Groves 试验反应堆的成功是有效工程进展，不过大型商用电力项目仍必须满足监管、供应链、燃料、建设与售电经济性等多层条件。

核心观点：6/30 有约 $30.06 亿现金及有价证券，近似市值约 $49 亿，表面上的 EV 扣现金空间似乎不大；但现金很大程度来自发行股份，未来每一兆瓦产能还需要资本投入。核反应堆商业化资产不是凭“现金+订单”简单相加就能估值。

把已经发生的成功和等待中的承诺分开

① 已实现2026.08.05 Groves 低功率同位素试验堆首次临界
② 进行中DOE 路线下 Aurora-INL 设计、监管审查、土建和燃料安排
③ 公司目标2028 年首座 Aurora 商用设施部署目标，存在延期风险

容易被误读的新闻：Groves“达到临界”只是低功率测试堆达到可维持核链式反应的状态，不是 Aurora 商业反应堆向电网出售电力。二季度 $121 万美元收入主要来自并购后工程和配套服务，并非成熟电力销售。[S11][S14]

支持牛市的真实进展

  1. Groves 试验堆在 2026 年 8 月实现首次临界；公司 10 月 13 日宣布 Groves-2 同位素试验设施规划。
  2. 与 Kiewit 合作准备 Aurora 项目工程；2026 年 1 月与 Meta 达成预付款安排，用于俄亥俄州拟议 1.2GW 项目早期燃料采购。
  3. 与 Centrus 签订核燃料供应意向书，所涉条件仍须落实最终协议。
  4. 核燃料循环和同位素创造额外潜在利润池，但并非现金流已确定。

需要折价处理的风险

  1. “12GW Master Power Agreement”和多个 LOI，不等于近端确定收入，非约束性合同更不能按建成电站贴现。
  2. 监管路径复杂，试验/DOE 授权不自动替代长期商用所需许可。
  3. 首次工程造价、发电成本、工期、燃料供应与并网存在深度不确定性。
  4. 2026 上半年流通股数明显增长，未来继续融资对每股价值不利。

Six investment frameworks

六位投资大师会提出的不同问题

以下是按各投资方法的核心思想进行的情景化推演，不是声称这些投资者曾评价、持有或推荐三只股票。将六种方法结合，是为了避免只用一种漂亮故事给公司估值。

Benjamin Graham · 格雷厄姆

安全边际不是“跌幅”，而是可证明净资产或保守盈利显著高于支付价格。
GPCR：现金扣除未来试验耗费，再谈安全边际。
SE：真实利润可检验，但 29 倍 PE 不算典型烟蒂价。
OKLO：现金账面强，未来 CAPEX 与稀释必须先扣。

Warren Buffett · 巴菲特

护城河和可预测股东自由现金流是估值中心；优质企业也不能任何价格买。
GPCR：药品尚未获批，护城河无法充分验证。
SE：平台网络效应最接近这一框架，重点看持久 ROIC。
OKLO：项目回报率与监管兑现尚未证明。

Charlie Munger · 芒格

先反过来想：什么会使投资永久损失资本？排除难以判断的关键断点。
GPCR：三期失败 + 持续消耗现金。
SE：放贷损失与补贴竞争同时爆发。
OKLO：工期、燃料、审批、融资多个条件同时延迟。

Peter Lynch · 彼得·林奇

股价最终跟随盈利增长；增长率必须与买入倍数一起判断。
GPCR：无稳定 EPS，不可机械使用 PEG。
SE：观察 EPS 是否从约 $2.59 实质提高。
OKLO：收入尚处萌芽，适合里程碑而非 PE 估值。

Ray Dalio · 瑞·达利欧

识别不同经济环境及相关性，避免把多只看似分散的成长股误认为风险互补。
GPCR：自身临床风险主导，但高贴现率不利估值。
SE：消费者需求、信贷周期与区域汇率影响。
OKLO：实际利率、长期融资和政策预期影响更强。

George Soros · 索罗斯

反身性：叙事推高价格 → 易于融资 → 推动项目 → 又可能支持叙事；反向亦然。
GPCR：临床新闻会骤然重定价。
SE：IPO 期待与 AI 云投入会改变估值叙事。
OKLO：高价增发改善现金，低价增发则反过来强化熊市。
综合原则：格雷厄姆决定“付多少钱”，巴菲特和芒格决定“哪些生意有资格重仓”，林奇决定“未来利润是否跟得上”，达利欧决定“总风险预算”，索罗斯提醒“市场叙事和融资条件如何自我强化”。

真正该避免的风险叠加

如果现有组合里有 QQQM、VGT、SMH、SOXX 等科技/半导体基金，OKLO 的 AI 数据中心电力叙事和成长股估值压力可能与科技股存在间接同向暴露；GPCR 是临床特有风险，但仍受小盘成长股融资条件影响；SE 则有区域经济和金融信用周期的独立风险。

与其平均分配三只股票，不如把 SE 作为可跟踪利润的卫星仓，GPCR / OKLO 作为可损失本金的高风险期权仓。这些持仓不能代替全球分散化的核心资产。

分批逻辑：从“买价格”转向“买新证据”

第一批：只在研究区内开跟踪型仓位，不把历史下跌当作确认。

第二批：重要数据如 Q3 业绩、临床试验或许可结果明确后，重做估值并核实先前假设。

第三批：若股价上行但长期价值提升更多，才考虑接近各自上限；如果投资论据被破坏，宁可放弃加仓，也不要以摊低成本为目标。

极端亏损压力测试：按最大仓位 SE 4%、GPCR 1.5%、OKLO 1.25%，分别下跌 50%、75%、70%，全组合损失约 4.0% = $16,000（不计其他仓位连带下跌、税费和汇率）。这不是极端最坏情况；如再叠加科技 ETF 回撤，总损失可能更大。未使用期权、保证金和融资买入假设。
