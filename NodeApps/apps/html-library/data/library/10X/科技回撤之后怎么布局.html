01 · EXECUTIVE JUDGMENT

可以开始加仓，但不能把“下跌”误当成“便宜”

对10年持有而言，最重要的是 指数结构 × 买入估值 × 总组合风险 × 资金部署纪律。此次回撤提升了半导体的入场赔率，却未消除其高估值和盈利周期风险；宽基没有明显大跌，但更适合扮演组合基础。

01 · LONG-TERM CORE
核心：VTI + VT

它们不一定是短期反弹最猛的品种，却是更容易长期持有、不被单一产业押注绑架的底盘。仅买少量作“平衡”，实际效果有限。

02 · GROWTH ENGINE
主增长：QQQM + VGT

偏向以 QQQM 为主、VGT 为辅。两只加总在六ETF权益篮子里控制于35%左右，避免不知不觉把科技股加成同一种大赌注。

03 · HIGH-BETA SATELLITE
卫星：SMH + SOXX

建议二者合计不超过权益ETF篮子的10%作为初始中枢；两只都买可以，但风险基本同向，不构成两份行业分散。

最需要正视的分歧

你希望 VTI、VT 只买一点点；但如果组合主体是 VGT、SMH、SOXX、QQQM，所有标的在AI资本开支、成长估值和半导体景气下行时会高度相关。本报告把“长期十年仍能执行”放在“短期涨得最快”之前。如果坚持高科技集中配置，应主动接受更大的潜在跌幅，而不是把这套组合称为均衡配置。

执行原则：把价格区间当作“条件订单/观察线”，不是预言的底部；先算目标持仓、再减已有底仓，最后为剩余差额分四笔执行。既有 VOO、个股、其它美股基金等都必须计入总风险。

市场状态：先判断驱动，而不只看K线

第一层：AI资本开支究竟是盈利驱动、还是债务驱动？芯片订单是否已由真实企业付费需求支撑？

第二层：通胀、收益率及贴现率：高久期成长公司常对利率波动更敏感。

第三层：市场资金是否只从芯片转到其它行业，还是同时撤离风险资产？价格走势不等于经过验证的资金净流入/净流出。

当前判断：价值重估与景气担忧同时发生；下跌是建立分批计划的理由，不是满仓抄底的证据。

十年回报不是盈利增长本身：还要减去估值压缩

不同行业ETF的市盈率可能采用不同盈利口径、亏损公司处理与权重方式，不能只凭一个 P/E 数字排序便宜程度。但初始估值是投资回报中不可忽略的一环。以每股盈利年增长、期初期末市盈率的组合，纯数学地推演：年化股价回报 ≈ (1 + EPS年增长率) × (终点PE ÷ 起点PE)^(1/10) − 1，不包含股息、费率、税与汇率。

仅供思考的估值情景EPS十年年均增长起点P/E → 十年后P/E数学年化股价回报
中高增长，但估值回归8%30× → 20×约 3.7%
强盈利增长，估值回归10%30× → 20×约 5.6%
极强增长，估值温和回归12%30× → 25×约 10.0%
高估值行业，即使增长不错10%50× → 25×约 2.6%

这些P/E变化与盈利增长是虚构情景的数学演示，不代表上述任一ETF的真实盈利增速或当前预测估值。BlackRock 在2026年10月7日公布 SOXX 的P/E约51.34×，但这不是10月16日估值；半导体周期导致静态P/E可能失真。这也是为什么 SOXX 从高点跌约25%后仍不应被自动认定为便宜。若利润预测大幅下修，即使价格跌了，前瞻估值仍可能偏贵。

何时应该修改原来的十年假设？

  1. 盈利质量变化：企业自由现金流持续落后于会计利润，利润率和订单结构反复恶化。
  2. 资本开支周期：云厂商/AI供应链投入增速与可实现收入明显脱节；融资成本和债务续借压力上升。
  3. 半导体结构性风险：台海/贸易限制、出口管制、制造与先进封装瓶颈、重大技术替代。
  4. 投资者自身约束：10年内可能需要资金、出现家庭大额支出、美元与纽币资产负债错配、税务成本变化。
  5. 组合上限：已有持仓与新增配置导致单一科技/半导体因子过度集中。
08 · CROSS-BORDER / NEW ZEALAND

新西兰税务居民长期持有美国ETF：税后收益才是收益

NZ · FIF
NZ$50,000 是成本门槛，不是每只ETF额度

现行 IRD 指引：个人海外 FIF 归属权益取得成本合计低于 NZ$50,000 通常可适用 de minimis；超出门槛时，一般需对适用资产整体评估FIF规则，而非仅对超出部分计税。常见 FDR 方法以年初市值的5%为计算基础，并有买卖调整。另有 CV 方法等，不能简单理解为“每年对收益征5%税”。

NZ · TRANSITIONAL RESIDENCE
新移民或有约四年海外收入临时免税资格

具体以成为NZ税务居民的日期、既往税务居民历史、是否申请 Working for Families/Best Start、是否退出豁免等条件判断。移民抵达年份不等于法定起算日期，不应默认仍有效。

US · ESTATE EXPOSURE
美籍注册ETF可能涉及美国遗产税

美国 IRS 对特定非美国公民、非美国遗产税居民的美国境内资产有申报门槛：通常超过 US$60,000 需评估 Form 706-NA；是否最终应纳税还取决于具体资产、身份与适用条约。持有大量美国注册ETF时应请跨境税务顾问核查，不能把 $60k 当免税保证。

FX · NZD / USD
纽币购买力与美元ETF收益是两种结果

资产美元上涨不必然对应相同纽币收益。若未来支出在NZD，应定期检查外汇敞口，避免因汇率或税款需求被迫在低点卖出。美国ETF还有股息源泉预扣税、申报表等问题，按身份和券商资料确认。

上述仅概述税收规则的普遍机制；2026年税改方案或有调整，但在法律正式生效前不应将拟议 NZ$100,000 门槛视为现行规则。大型长期跨境持仓宜先与新西兰税务顾问确认税务身份及结构。

09 · DECISION RULES / TEN-YEAR DISCIPLINE

最终执行清单

可以买的条件

  1. 六ETF只是权益子组合，已计入其它持仓和生活备用金。
  2. 确认自己有能力承受至少一次权益子组合30–45%的账面回撤。
  3. 使用限价/分档，不把10月16日的快照当作今天实时成交价。
  4. 半年后即使底部没来，也会根据估值和目标仓位继续时间分批。
  5. 税务居民身份、FIF与美国注册资产结构已有处理方案。

应该减速或暂停的条件

  1. 主要资金可能在5年内用到，或已有科技/半导体重仓。
  2. AI盈利兑现不及资本开支，且企业预测持续下修。
  3. 为追求“回本”越跌越买，超出预先定义的风险预算。
  4. 美元买入牵涉紧迫NZD支出或严重汇率错配。
  5. 主要结论依赖近期一次大跌之后必然发生V形反弹。

一句话的组合建议

若以十年为尺度，新增长期权益资金的买入优先顺序偏向 VTI / VT → QQQM → VGT → SMH / SOXX；若追求科技增长，则提高 QQQM 相对 VGT 的权重，而不是让两只半导体ETF成为最大仓位。买入决定仍应来自现有资产盘点与风险承受能力，不是这六个票的排名。
