被低估的负面：客户权证与循环融资

AMD分别向OpenAI和Meta发行了最多1.6亿股、合计最多3.2亿股的潜在认股权证，行权条件与GPU采购及部分股价/业务里程碑挂钩。2026Q2财报称两项权证当时均未归属或可行权。若仅以约16.3亿现有股数粗算，潜在3.2亿新股相当于当时股数的约19.6%；完全发行后约占扩大后股本的16.4%。这不是已发生稀释、也并非一次性必然实现，但对多年度每股估值不可忽略。[S05][S07][S08][S17]

同时，AMD承诺对Anthropic进行最多50亿美元的战略股权投资，该合作涉及最高2GW的MI450部署；这是业务拓展和资金投入并存的结构，不能把潜在订单全部看作独立外部需求。供应商对客户的投资或信用支持，应通过应收账款增长、预收与融资条款、自由现金流转换率检验订单质量。[S09]

竞争风险同样真实：NVIDIA的CUDA生态和整机网络能力、定制ASIC、GPU租赁市场供需、出口管制及数据中心电力限制，都可能改变2027–2028年的销量与利润率。AMD市值已约8630亿美元；“拿到合同”与“为股东创造超额收益”之间，仍有很长距离。[S17]

商业模式为什么优秀

Visa将消费者、商家、发卡机构、收单机构和技术服务商连接成全球网络。网络覆盖越广、交易越多，技术和合规投入的固定成本越容易被摊薄；其收入来自支付处理、服务、国际交易和增值业务。Visa通常不承担如普通发卡银行一样的大规模消费者信用违约敞口，但并非完全免疫信用周期——消费活动走弱仍会减少交易量。

2026年新机会与难题

中国准入：10月13日，Visa获人民银行批准开始筹备在华设立银行卡清算机构。这是战略选择权，而非已经正式运营；后续还需完成筹备和最终审批。不可立即把中国内地庞大的交易规模折算为Visa收入。[S12]

增值服务与跨境：全球旅行、数字化支付、安全风控、身份验证、Visa Direct、企业交易等改善单笔交易货币化；季度国际交易收入增长6%仍提醒我们量的增长和收益率可能不同步。[S10]

监管与替代：美国交换费相关诉讼、反垄断与借记卡规则可能影响利润；实时支付、账户对账户支付和稳定币结算既可能成为Visa的新服务，也可能让某些支付路径绕开传统卡网络。Visa的目标应是保持网络角色，而非阻止所有新技术出现。2026Q3存在与交换费多地区诉讼有关的诉讼拨备。[S10]

价值来自五条现金流，而非某一个热门赛道

保险与再保险

GEICO、再保险和原保险业务形成浮存金。优质承保能让低成本负债提供投资资本，但巨灾损失、赔付通胀与再保险费率变化存在尾部风险。

铁路 + 能源

BNSF、能源与公共事业拥有难以复制的网络和牌照。资本密集意味着持续再投资很重要，不能简单用高利润率逻辑评价。

制造零售 + 上市证券

成熟业务贡献分散利润，股权组合提供投资回报与波动。投资市值计入会计净利润，使GAAP利润随股市大幅浮动。

两个需要正确理解的指标

账面价值：2026Q2股东权益约7479亿美元；使用等效B股数估算每股账面约$347.22，收盘价$532.02对应1.53倍PB。PB可帮助识别历史估值位置，但因全资收购资产的会计成本、商誉、股票投资公允价值变化等原因，账面价值不是完整内在价值。[S14][S15]

现金与回购：伯克希尔几千亿美元级短债持仓可在高利率环境贡献投资收入，也为收购、股灾逆周期投资提供弹药。但在利率下降时，再投资收益会下滑。管理层在2026年上半年回购股份显示愿意适度配置，但不代表任何股价都有回购底。[S13][S14]

治理过渡：2026年处于巴菲特退休后的治理交接阶段，Greg Abel的投资决策、风险纪律和交易透明度值得持续跟踪。巴菲特式历史超额收益不能在领导交替后自动外推。[S24]

新西兰FIF制度：可能改变税后收益

对新西兰税务居民，美国上市股票和美股ETF往往属于境外投资基金（FIF）相关持仓；IRD目前公开的个人低额豁免说明仍使用合计取得成本NZ$50,000门槛，超出后常见FDR方法以期初市场价值的5%估算应税FIF收入（具体取决于适用资格及年度交易）。这并不是“每年固定交5%的税”，而是5%的所得计算基数再乘适用所得税税率；其他适用方法、临时居民豁免与特殊情况可能改变结果。[S18]

法律变动提醒：2026年提交的税务法案提议将低额豁免门槛从NZ$50,000提高至NZ$100,000、并涉及若干其他FIF规则修订，拟回溯适用部分税年。报告不把“法案提案”当已经生效的法规；应以正式通过法律和IRD最新指南为准。[S19]

还应检查：美元资产汇率折算对NZD总回报与FIF计税的影响、个人税务居民资格、潜在过渡居民四年豁免、美国股息预提税的协定待遇、以及美国遗产税的跨境法律风险。对40万美元规模的美国证券资产，可在交易前找熟悉NZ/US跨境投资的执业税务人员核查。
