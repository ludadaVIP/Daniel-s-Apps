# Invest Master · 投资大师研习室

一个本地运行的投资思想学习应用。Node.js + React + Markdown；不需要账户、云服务或 API Key。

## 启动

在 NodeApps 根目录运行：

```bash
npm install
npm run dev
```

打开 `http://127.0.0.1:5888`，点击 **Invest Master**。也可以在本目录执行 `npm run dev`，打开 `http://127.0.0.1:5788`。生产构建分别使用根目录或本目录的 `npm run build`。

## 学习方式

1. 从「学习路径」开始。先学证券、复利、报表、股票与债券分析、组合、宏观、衍生品基础和研究伦理，再研究格雷厄姆、巴菲特、芒格、林奇、马克斯、索罗斯、博格尔、达摩达兰、费雪、达里奥、斯文森十一条路线，最后完成综合研究。
2. 教材章节包含推导、算例、错误示范、练习答案、原始来源和至少五道理解题。点选题目选项即立即显示解析并保存答案，无须再点提交。答对本节所有题并保存达到该章字数要求的应用笔记，可以记录为已完成**练习**；毕业研究需至少 1,500 字草稿。任何完成标记都不代表已具备独立投资能力。
3. 完成课程后，其概念进入「记忆复习」。先自己回想，再按记忆情况决定下次复习时间。
4. 在「思想对照」看同一问题的不同视角，在「我的投资体系」写下自己的目标、能力圈、估值、风险和行为原则。「毕业作品」汇总五项实作的本机草稿，导出的 Markdown 附独立审读表，方便他人复算、指出错误并记录修订。

## 内容与数据

- `content/` 是 Markdown 内容库：当前 11 位思想者、120 节教材课程、20 个概念、16 个案例。十一条人物路线各有四节课程，毕业研究有五项综合实作；股票、债券、财报、概率、组合和衍生品等基础领域有独立课程。案例中的事前决策卡可先保存判断；青岚工业、杉岭物流与远山家庭综合训练分别检验股票估值、债券信用和客户投资政策，参考推导默认收起。Frontmatter 保存关联、题目和来源，正文可直接编辑。课程篇数已达到阶段规划，能力仍须通过独立作品与人工审读检验。
- `content/CURRICULUM.md` 列出本科程度课程的能力目标、现有章节与继续扩展的边界。页面完成比例只针对已开放章节；目前**不能**把完成比例等同于投资学学位或实际投资能力。
- `server/` 提供内容与学习状态 API。答题正确性由服务端判定；课程完成条件也由服务端校验。
- `data/invest-master.sqlite` 保存个人进度、答案、复习安排、笔记、收藏和投资体系。`data/` 已加入忽略列表；更新内容不会覆盖学习记录。
- `scripts/seed-content.mjs` 是首批课程、概念与案例的**原始生成脚本**。已设置保护；只有显式传入 `--force` 才会覆盖部分 Markdown 文件。日常修订请直接改 `content/`。

历史案例与教学模拟案例有显式标记。文章优先链接 Berkshire 股东信、Oaktree 备忘录、Soros 原文及书籍出版方页面；不复制受版权保护的长篇原文。内容旨在训练研究方法，不输出买卖结论。
