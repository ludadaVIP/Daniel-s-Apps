# Invest Master · 投资大师研习室

一个本地运行的投资思想学习应用。Node.js + React + Markdown；不需要账户、云服务或 API Key。

## 启动

在 NodeApps 根目录运行：

```bash
npm install
npm run dev
```

打开 `http://127.0.0.1:5888`，点击 **Invest Master**。也可以在本目录执行 `npm run dev`，打开 `http://127.0.0.1:5788`。生产构建分别使用根目录或本目录的 `npm run build`。

## 学习方式

第一版已收束，建议从 [第一版学习指南](content/STUDY_GUIDE.md) 开始：基础课程 → 四个阶段实作关口 → 大师方法 → 五项毕业作品。以独立复算和迁移推进学习。

1. 从「学习路径」开始。先学证券、复利、报表、股票与债券分析、组合、宏观、衍生品基础和研究伦理，再研究格雷厄姆、巴菲特、芒格、林奇、马克斯、索罗斯、博格尔、达摩达兰、费雪、达里奥、斯文森十一条路线，最后完成综合研究。路径顶部有四个阶段实作关口，可进入关联盲题并查看首次答卷是否已封存。
2. 教材章节包含推导、算例、错误示范、练习答案、原始来源和至少五道理解题。点选题目选项即立即显示解析并保存答案，无须再点提交。答对本节所有题并保存达到该章字数要求的应用笔记，可以记录为已完成**练习**；毕业研究需至少 1,500 字草稿。任何完成标记都不代表已具备独立投资能力。
3. 完成课程后，其概念进入「记忆复习」。先自己回想，再按记忆情况决定下次复习时间。
4. 在「思想对照」看同一问题的不同视角，在「我的投资体系」写下自己的目标、能力圈、估值、风险和行为原则。「毕业作品」汇总五项实作的本机草稿，导出的 Markdown 附课题与保存时间、模型文件索引、0–4 分锚点、返工条件和独立审读表，方便他人复算、指出错误并记录修订。外部计算表、年报和合同须另附；未保存文字不在导出中。

## 内容与数据

- `content/` 是 Markdown 内容库：当前 11 位思想者、121 节教材课程、20 个概念、30 个案例。十一条人物路线各有四节课程，毕业研究有五项综合实作；股票、债券、财报、概率、组合和衍生品等基础领域有独立课程。案例中的事前决策卡可先保存判断；青岚工业、杉岭物流与远山家庭综合训练分别检验股票估值、债券信用和客户投资政策。Costco、Adobe、Nucor、Union Pacific 与 NextEra 的真实披露盲题训练零售、软件、钢铁、铁路及公用事业的现金和资本配置；Costco 与 Nucor 题另须从年报勾稽现金、权益与资产负债，核对受限现金与收购口径，保留未能解释的残差；Bed Bath & Beyond 与 SVB 分别训练无担保债信用和银行流动性。美国财政部 2022 年真实拍卖与续发盲题训练发行价、应计利息和客户付款期限匹配；FINRA 裁决中的真实二级成交训练加价、确认书与可执行报价的区别。澄岳制造综合盲题另将税亏、养老金、资本成本、到期付款和客户风险预算连在一起。BLS 就业公告题训练首次发布、后来修订与客户付款之间的信息和现金边界。CME SOFR 合约题从官方乘数计算套保张数，再重放模拟保证金与强平现金。青衡策略数量方法盲题另把收益检验、费用、共同违约、客户付款与模拟误差连成一份限时委员会审议。首次答卷封存后才可打开参考推导。Frontmatter 保存关联、题目和来源，正文可直接编辑。课程篇数已达到阶段规划，能力仍须通过独立作品与人工审读检验。
- `content/CURRICULUM.md` 列出本科程度课程的能力目标、现有章节与继续扩展的边界。页面完成比例只针对已开放章节；目前**不能**把完成比例等同于投资学学位或实际投资能力。
- `server/` 提供内容与学习状态 API。答题正确性由服务端判定；课程完成条件也由服务端校验。
- `data/invest-master.sqlite` 保存个人进度、答案、复习安排、笔记、收藏和投资体系。`data/` 已加入忽略列表；更新内容不会覆盖学习记录。
- `scripts/seed-content.mjs` 是首批课程、概念与案例的**原始生成脚本**。已设置保护；只有显式传入 `--force` 才会覆盖部分 Markdown 文件。日常修订请直接改 `content/`。

历史案例与教学模拟案例有显式标记。文章优先链接 Berkshire 股东信、Oaktree 备忘录、Soros 原文及书籍出版方页面；不复制受版权保护的长篇原文。内容旨在训练研究方法，不输出买卖结论。

## 验证

```bash
npm test
npm run build
npm run audit:sources
npm run verify:simulation
npm run verify:risk-frequency
```

`audit:sources` 读取已发布 Markdown 的引用，检查公开链接并生成 `qa/source-audit.json`。报告记录响应、重定向、标题、受影响章节和检查时间；403、超时等保留为待核验，不自动判成失效。HTTP 成功只证明当次收到响应，不能证明原文支持教材结论或历史上已公开。历史归档在来源标签中注明；报告财年、公开日、归档抓取日须分别核对。

`verify:simulation` 是模拟课程的可运行教学脚本：固定种子抽样并对照解析 NPV、蒙特卡洛标准误，另重放两期付款和现金底线。可用 `npm run verify:simulation -- 1000000 20260925` 指定次数与种子。它不读取真实行情、账户或学习记录，输出只属于题设模型，不是未来风险预测。

`verify:risk-frequency` 是风险模型验证专题的解析基准：递推完整二项分布，核查越界次数规则及功效，复算零事件单侧置信上限、稀有事件漏抽概率与相对蒙特卡洛标准误。它不读取行情或个人数据，也不实际生成随机路径；结果仅适用于明确列出的固定、独立观测模型，不认证模型或学习者能力。
