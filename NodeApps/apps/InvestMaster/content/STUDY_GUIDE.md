# Invest Master · 第一版学习指南

2026-09-27 收束版。现有 121 节课程、910 道即时自测、11 位大师、20 个概念、30 个案例。学习从 APP 的「学习路径」进入，按实际掌握情况推进；课时是安排学习的参考。

## 怎么开始

打开 NodeApps 中的 Invest Master，进入「学习路径」。先完成「基础地基」，准备一份计算表和研究笔记。每次集中学一章，至少亲手复算一个例子，再答题、写迁移笔记。第二天不看答案解释一次：钱从哪里来、何时到账、谁有权得到、为什么值得这个价格。

## 四段主线

| 阶段 | 学习内容 | 换一份材料检验自己 |
| --- | --- | --- |
| 1. 看懂企业与数字 | 基础地基、定量方法、财报与会计、企业财务、股票估值 | 先做青岚工业，再做 Costco、Nucor 或 Union Pacific 披露盲题。把三表、资本支出、股东现金与估值做平；解释每一处残差。 |
| 2. 看懂债权与付款 | 债券与利率、信用分析 | 财政部原发→同券续发→FINRA 成交→杉岭物流→真实信用盲题。独立列付息日、净价、应计息、全价、到期墙和回收顺位。 |
| 3. 把投资放进客户约束 | 宏观、组合、衍生品与另类、行为与伦理；回看数量方法 | 远山家庭、青衡策略，再做 BLS、基金会或 LDI 题。把收益证据、共同冲击、保证金、资本调用和客户付款放到同一现金时间线。 |
| 4. 形成自己的研究方法 | 十一条大师路线、思想对照、跨行业综合、毕业研究 | 对同一资产分别用大师方法提问，写出各方法适用条件与可能失败之处；完成五项毕业任务，导出供独立读者复算。 |

「学习路径」顶部提供四个阶段实作关口，可直接打开对应盲题。碰到算例不会，返回相关基础课复算后再继续。

在「思想对照」选两位大师，用同一份青岚工业虚构资料分别作答。对照页列出各自应找的证据、复算与反证，并连接深入课程。把两条推导并列后，解释差异来自事实、假设、期限还是客户约束；材料不足的地方留为待核实，不要为凑出两份“赞成”意见补造数据。

## 每章的学习动作

1. **先说明问题。** 写明研究对象、时点、币种、期限，以及需要回答的决策。
2. **亲手复算。** 从现金流、数据和合同开始，保留公式、单位、日期、舍入与假设。先自己算，再看正文推导。
3. **即时自测。** 点击选项即判题、显示解析并保存。答错后先写下错误原因，再改答案；答对后也要能解释其他选项错在哪里。
4. **迁移笔记。** 换公司、债券或客户约束，记录原始证据、反证、计算结果和待核查资料。笔记可先保存草稿，达到章节要求后才满足完成条件。
5. **间隔复习。** 在「记忆复习」先回忆再展开；在「我的笔记」检查旧判断，修订时说明哪条证据改变了结论。

封题案例须先保存达到要求的首次答卷，才能展开参考推导。第一次作答用于保留事前判断；看完解析后在复盘中记录修正，避免把参考答案当成自己的第一次研究。

基础课复算时特别写明日期与口径：今日折现价值不等于未来到手现金，达到要求回报不等于只收回本金；基金分配是否再投资须明确，已进入净值的费用与已进入经营现金流的营运资本变动不能重复扣减。

## 什么时候算学透

以能完成以下任务为推进标准：别人拿到你的来源和计算表，能重现主要数字；你能解释为什么选这个模型、哪些假设会改变结论；一项不利证据出现后，能重新计算价值、损失与付款缺口，并修改行动。

最终在「毕业作品」完成两份跨行业股票研究、一份债券信用研究、一份客户投资政策与压力测试，以及反方答辩。选择未在教材中完整解答过的材料，导出 Markdown 与审读表，请独立读者复算并记录返工。页面进度用于管理学习，能力由这些作品检验。

综合研究课提供六维评分：每维至少 3 分、重大返工条件全部消除，才符合本课程的基础通过要求；至少 22/24 分，并有跨行业模型迁移和一次新披露后的可追溯复盘，才符合本课程的优秀要求。这是学习标准，须由审读者逐项给证据。导出附原始资料、模型索引与审读表；外部计算表和原始文件须另附。
