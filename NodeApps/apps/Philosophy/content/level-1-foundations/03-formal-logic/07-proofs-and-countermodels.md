# 证明与反模型

## 两种任务，两种完成标准

给一个论证式，若你认为它有效，目标是给出能让别人逐步检查的证明；若认为无效，目标是构造一个**前提全真、结论为假**的解释。证明可以需要创造性地选择中间步骤；反模型可能很小，却必须明确论域以及各谓词、关系在哪些对象上为真。只说“我想不到证明”既不是证明，也不是反模型。

从 `∀x(S(x)→R(x))` 和 `S(a)` 出发，先用**全称消去**将 x 换成论域中的 a，得 `S(a)→R(a)`；再用条件消去得 `R(a)`。这背后的道理是：如果每个学生都阅读，而 a 是学生，a 应满足阅读。这里不能把全称前提实例化为论域外一个根本不存在的名字；翻译和论域必须保持一致。

**存在引入**方向相反：若已得到 `R(a)`，且 a 指某个论域对象，就能得 `∃x R(x)`。但从 `∃x R(x)` 直接写 `R(a)` 是错误的，因为存在前提没告诉我们见证者恰好是事先命名的 a。要使用存在前提，可以在受控的子证明里给它一个全新的临时名字 c，推得一个**不依赖 c 特别是谁**的结论，再解除这个临时选择。若最后结论仍含自由的 c，通常说明你把“有某人”偷换成了“这个特定人”。

## 一个有效推理

前提是 `∀x(S(x)→R(x))` 和 `∃x S(x)`，结论是 `∃x R(x)`。用存在前提暂取一位学生 c；对全称前提实例化，得 `S(c)→R(c)`；由 `S(c)` 得 `R(c)`；由存在引入得 `∃x R(x)`。最后结论没有依赖 c 的名字，因此可以解除临时见证。即使你不知道 c 是谁，推理仍成立。自然语言中这相当于说：“至少有一名学生；每名学生都阅读；所以至少有一名阅读者。”

对照一个无效推理：`∃x S(x)` 和 `∃x R(x)`，所以 `∃x(S(x)∧R(x))`。第一个存在式可能由甲满足，第二个由乙满足。构造论域 `{甲, 乙}`，令 S 只对甲真，R 只对乙真，且没有任何对象同时满足二者。前提全真，结论假，反模型完成。问题就在于把**两个可能不同的见证者**合并成了一个。在日常争论里，“有人赞成改革，也有人担心成本”不意味着有同一个人两者都如此。

## 如何造最小反模型

先让结论为假，再尝试使前提都真。若结论是全称式 `∀x(P(x)→Q(x))`，要使它假，就找一位 P 真 Q 假的对象；若结论是存在式 `∃x(P(x)∧Q(x))`，要使它假，就确保没有对象同时满足 P 与 Q。然后看前提能否在同一论域里成立。若涉及关系 `L(x,y)`，用一张对象两两配对的表列出哪些有 L 关系。无需把现实世界搬进模型；两三个匿名对象往往足以暴露形式缺陷。

请小心**背景定义**。若 S 定义为“正方形”，Q 定义为“四边形”，在现实的通常定义下 S 真 Q 假的对象不可能出现；但若形式论证只列了 `∃x S(x)`，没有把“所有正方形是四边形”写成前提，模型可以独立解释两个谓词。要让形式测试忠实于概念关系，你应显式加入适当公理或定义。否则，反模型反驳的是裸形式，而未必反驳包含隐含定义的原论证。

## 你应记住

- 有效论证可用合法规则证明；无效论证要给前提真、结论假的同一模型。
- 全称可对论域对象实例化；存在句提供某个见证者，不自动指定其身份。
- 构造反模型时，先固定结论为假，再检查全部前提能否同时为真。
