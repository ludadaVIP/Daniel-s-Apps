# 论证图与最终改写

## 这门课的出口作品

分析短句比较容易，因为它把关键步骤暴露在一两行内。真实的哲学与公共论说并非如此：前提散布在几段之中，一个数据既可能支持事实结论，也可能只是制造紧迫感；同一个结论还会从不同路线获得支持。这次工作坊要求你把一段 **300–600 字**的论说做成可检查的论证图，再写一份 **400–700 字**的改写稿。成功标准不是把作者判成“好”或“坏”，而是让第三位读者知道你在哪里同意、哪里质疑、怎样改进。

可以使用你前面研究的图书馆、课程政策、教育技术案例，也可以选另一篇来源清楚、长度合适的论说。保存原文或稳定链接、日期和作者。不要挑一段你轻易嘲笑的极弱说法；选择值得认真处理的论证。

## 第一步：写出论证骨架

先用一句话说出最终结论，限定量词、对象和行动强度。然后逐段标注：这是事实主张、概念界定、价值原则、中间结论，还是例子和修辞？把支持关系写成 `P1 + P2 → C1；C1 + P3 → C2`。若 P4 单独支持 C2，就画第二条路径。图中的每一个箭头都应能回答：“**为什么这些前提加起来会增加我们相信结论的理由？**”

例如：

```text
P1 轮班读者很难利用现有开放时间〔需数据〕
P2 公共服务应考虑实际可及性〔需规范辩护〕
    P1 + P2 → C1 现有安排存在值得处理的服务缺口
P3 周日短时试行比可行替代方案更有效〔需比较〕
    C1 + P3 → C2 应试行周日短时开放
```

P3 若只是作者暗示而未明说，必须标“我的可能重建”。不要为了让图好看，就把自己的判断放进作者嘴里。

## 第二步：按节点批评

审查每个关键前提：哪些有可核对数据？数据是否独立、有代表性？哪些属于规范原则，其代价是否承认？对每个支持箭头问：结论范围是否变宽；若前提都真，有没有相关替代解释或反例？从图中找出**承重节点**：如果它被推翻，其他路径能否继续支持结论？

“这是以偏概全”这样的标签只有在指出样本、目标群体和外推步骤时才有解释力。“这是假两难”只有在提出真实可行的第三方案并比较它时才有价值。本课评阅看具体诊断，不看谬误名词数量。

## 第三步：替对方写最强反方

好的反方不靠否认显然事实。假设你赞成周日开放，最强反对可能承认轮班读者的困难，却指出晚间开放服务更多人、成本更低，而且更公平对待馆员。你须回答**为何仍选周日**，或把结论修订为“先比较两个试点”。若你坚持原结论，请给事实和原则；若暂时缺证据，诚实写条件式结论。

你也可以让对方反击你的改写：“你加入的补救条件虽合理，却不符合我原本的主张。”这提醒我们把两份作品分开：**忠实的原论证图**和**你提出的较好论证**。后者允许更大创造，前者受文本约束。

## 第四步：写可被继续批评的稿子

改写稿包含问题、明确论题、两至四项核心理由、一个强反方、实质回应和保留问题。末尾附一份很短的修订记录：你缩小了什么范围？换掉了哪条证据？哪个反例仍有压力？将原文和改写稿隔一天后再读，看看自己是否在某处把“可能”悄悄写成了“必然”。

如果有条件，请找一位愿意反对你的读者，只问两个问题：“哪里看不出结论怎样从前提来？”“哪一条反对意见我处理得最弱？”外部评阅比自我勾选更接近哲学学习中的真正检验。

## 你应记住

- 论证图显示理由的依赖关系，但不能替代证据或概念判断。
- 对手的最强反方会帮助你找到最需要修订的节点。
- 忠实重建与提出自己的改进论证要分开署名。
