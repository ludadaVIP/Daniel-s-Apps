# 共相、属性与相似

## 多个对象怎样同属一种性质

桌上两个苹果都红，日常说法简单；形而上学却问「红」在两者中是同一个可重复的东西，还是两个对象彼此相似而已。**共相实在论**允许同一性质由多个不同对象实例化；**唯名论**拒绝这类可重复共相，尝试用个体、词语、类别、相似或数目各异的性质样态解释共同谓述。这里「拒绝共相」未必等于「拒绝一切抽象对象」；一个人可以反对共相而接受集合，或反过来。[唯名论条目](https://plato.stanford.edu/entries/nominalism-metaphysics/)特别提醒这两个争论不可混写。

设苹果 A 和苹果 B 处于不同位置。共相论者可说两者都实例化「红性」，所以「A 是红的」与「B 是红的」并非只因我们把同一词贴到两物上。这个方案解释同样性的方式清楚，却必须说明一个共相如何与不同对象关联；若它整体地在两处，它如何不违反「一个东西只在一处」的直觉？并非所有共相论者都认为共相在时空中以同一方式定位，批评者须锁定具体版本。另一方面，诉诸「红性」也可能只是把「两者为何相似」改写为「为何都有红性」，还需解释实例化关系。

## 相似方案的压力

相似唯名论者可以从个体出发：A 与 B 在颜色上相似，因此我们合理地都称其为红。它节省了可重复属性的存在论承诺，却会面对「相似本身是否是一种关系共相」的后退问题。如果说 A、B 在颜色上相似，C、D 也在颜色上相似，这两个相似事实是否又有共同之处？若再引入相似之相似，理论可能未真正省去可重复结构。唯名论者可将相似当基本事实，或使用更复杂的相似网络；这不是形式上直接矛盾，却需要比较其解释代价。

数目上独立的**殊相**（trope）是另一选择：A 有 A 的红色样态，B 有 B 的红色样态；二者极其相似，但不是同一个可重复共相。这样既承认性质在解释中的角色，又拒绝多处完整共享同一属性。代价是「哪些殊相形成同一类」仍需标准，且对象如何由性质样态组成可能带来新的构成问题。若红色样态能在不同光源下改变，殊相本身是否持续也需说明。不能把「殊相」当作免除所有关于分类问题的魔法词。

## 同一分类的两种解释

比较科学与日常语言的情况。两片树叶在某个观察距离下看起来同绿，光谱反射却不同；两个不同物理装置可能执行同一计算功能。哪些相似对一个概念重要，取决于研究目的；这一点不自动证明性质全由语言制造。共相论者可说世界提供客观的相似基础，而分类会因用途选择；唯名论者可说分类是个体结构上的实践，没有独立共相。双方都应解释为什么某些分类能支持预测，而任意把苹果和钟表归成一类通常不能。

作业写一个「红色」的论证图：从 A 和 B 都红出发，列出共相实在论的解释，再列相似唯名论与殊相论各一版。为每版找最强的反问，例如多处定位、相似后退或分类边界。最后把例子改成「具有同一电荷」或「履行同一社会角色」，检查原先理论能否跨领域使用。若只能解释颜色，要说明范围；若宣称解释所有属性，要承担更广的反例。

## 语义与存在论不要相互偷渡

句子「A 和 B 都是红的」有一个重复使用的谓词「红」，但语言重复不直接推出世界里有一个可重复的红性。唯名论者可以承认一般词语很好用，只拒绝把每个一般词配给一个独立共相。反过来，某种性质即使没有现成的中文单词，也可能在解释科学规律时不可或缺。共相论的有力论证应指出这些性质在解释或规律中扮演何种不可替代角色，而非从词汇表直接列实体。唯名论也不该仅说「没有共相」，还要给出同样性的正面说明。

考虑一个反模型：两枚球在同一光线下都呈红色，一枚的表面反射光谱不同，另一枚是屏幕发光。若相似性按视觉外观划分，二者同类；按物理反射机制划分，二者异类。共相论者须说究竟有哪一个共同属性，以及不同研究任务为什么选择不同属性；唯名论者须解释分类灵活性为何不沦为任意性。把两派放在同一组案例中比较，比问「红性究竟在哪里」更能显示各自解释工作的细节。

进一步区分「性质是因果上有效的」与「性质只是分类工具」。若药物的某种化学结构使其与受体结合，我们可能认为结构属性解释了作用；但同一药物也属于「所有在星期二被研究的东西」这一集合，后者通常没有同等解释力。你的理论为何能区分这两种属性或分类？此处的回答会决定它能否从苹果颜色扩展到科学规律。

## 你应记住

- 共相论与唯名论争的是可重复性质的存在及解释作用，不能等同于是否使用一般词语。
- 相似与殊相方案减少某些承诺，却要说明相似和分类本身如何成立。
- 好的存在论比较同时考察解释力、反例与新增承诺，而非仅数实体种类。
