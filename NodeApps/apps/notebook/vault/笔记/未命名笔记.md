# 总要留在牌桌上，才有发财的可能

- 2015年左右，我当时做黄金交易时，才 1500美金左右，如今涨到了 5000美金。
- 我还劝过很多人买特斯拉，买美股，我也有钱，为什么我不去研究一下自己买美股啊？
- 2013年时我就有30万左右了，为啥我不买房啊？错过了2016翻倍的机会。
- 比特币，从几分涨到几万美金。我一直都知道区块链，可惜没有亲自去研究。
- 苹果，谷歌，特斯拉，微软等美股巨头，近些年都有显著增长
- SP500，Nasdaq100，近10年一直猛涨
- AI发展起来，英伟达，内存厂家等等，出现 十倍，百倍增长
- Moderna mRNA 癌症疫苗三期临床成功，股价暴涨
- OpenRouter 被收购，70亿美元。

## 反思

1. 普通人最大的优势，从来不是预测能力。而是我们可以长期留在市场里。
2. 财富往往不是来自每一次都猜对，而是来自：绝大多数时候不犯致命错误，少数几次真正的大机会出现时，你在场。
3. 投资中非常重要的一件事情是：不要轻易出局。
4. 已有的事，后必再有；已行的事，后必再行；日光之下，并无新事！
