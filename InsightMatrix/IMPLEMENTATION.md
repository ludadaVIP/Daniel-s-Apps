# 实施范围

`plan.md` 描述长期愿景。本次先完成可在本机持续使用的认知训练工作台。

## 第一版

- React + Vite + Tailwind CSS，大屏工作台布局与窄屏适配。
- 六领域知识体系，36 篇概念文章与 60 篇历史案例（每类 10 篇），Markdown 维护。
- 历史案例质量检查：重复事件与相似正文候选、可追溯来源、六段论证结构、逐篇审读及内容版本哈希。
- 长页浅色悬浮回顶按钮，支持减少动态效果设置。
- 搜索、筛选、文章阅读、关联知识、收藏与阅读进度。
- 内置每日认知挑战与回答记录。
- 个人判断档案：论点、证据、反方、概率、证伪与复盘。
- Node.js 24.15.0、Express、内置 SQLite；数据只留在本地。
- 内容校验、持久化与失败行为测试、本地生产构建。

## 后续优先级

1. 在真实日常使用中完善题目、复盘质量与提醒机制，并继续扩充核心概念；历史案例已超过原计划的 30 篇目标。
2. 引入带明确来源与不确定性说明的 AI 反方教练；模型配置、调用费用与隐私选项需可控。
3. 增加判断版本历史、校准统计与时间跨度足够的结果复盘。
4. 有多人需求后再加入账户、用户隔离、乐观并发控制与部署方案。

没有接入实时市场数据或 AI，不模拟实时行情、不生成虚假的 AI 分析结果。
