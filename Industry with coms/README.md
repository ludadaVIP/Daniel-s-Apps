# Industry Atlas

面向大屏的产业与公司研究台。v0.5 内置美国与中国两个研究库：每个市场均覆盖 15 个产业、180 家公司；每个产业固定 3 家“行业锚点”和 9 家“潜力观察”对象。欧洲、亚洲等市场已在信息架构上预留。

## 启动

Windows：双击 `start.bat`。

macOS：首次在终端执行 `chmod +x start.command`，之后双击 `start.command`。

也可以手动启动：

```bash
npm install
npm run dev
```

开发服务固定在 `http://127.0.0.1:5188`；若端口已被占用，会明确失败而不会悄悄切换到其他端口。

## 研究数据原则

- 每家公司提供 10 段研究档案和 12 个深读入口。美国库包含官网、IR、SEC 全披露/10-K/10-Q/8-K 等；中国库改用公司公告、港交所、上交所、深交所、巨潮资讯及年报入口。
- “潜力观察”不是买入评级，而是把增量收益、再评级空间与可证伪风险放到更高优先级的研究对象；应用内可按“行业锚点 / 潜力观察”独立筛选。
- 公司档案是用于研究框架的编辑型底稿，不能替代财报、公告或投资建议。重要新闻和最新数字必须以链接中的公司 IR、交易所和法定披露复核。
- “价格轨迹”是规范化演示数据，用于检验交互与视觉；接入合规行情源后应替换为真实收盘价，并标明时区、复权规则和更新时间。
- 生产版建议将 `src/researchData.js` 拆为 CMS 内容与行情适配器：基本面来自 SEC/IR/业绩会，价格来自已授权数据源。
